DSH Codex Subscription 详细部署教程

DSH Codex Subscription 是一个为 DeepSeek Harness (DSH) 设计的插件，它能让你在 DSH 中直接使用自己的 ChatGPT/Codex 订阅，无需 OpenAI API Key，也无需安装和配置 Codex CLI 。本教程将引导你完成从零开始的部署与配置。

1. 准备工作

在开始前，请确保满足以下条件：

要求 说明
DeepSeek Harness (DSH) 已安装并可以运行。可以是官方 npm 包或 DSH-Portable 版本。
ChatGPT 账户 拥有有效 Codex 使用资格 的 ChatGPT 账户 (Plus/Pro/Team 等订阅) 。
网络环境 能够正常访问 ChatGPT/OpenAI 服务。

重要：dsh 命令本身可能不存在于系统 PATH 中（取决于安装方式）。请务必根据你的实际情况选择对应的安装命令 。

3. 配置与登录

安装完成后，需要重启 DSH 并进行登录配置。

  1. 重启 DSH：完全退出并重新启动 DeepSeek Harness 应用。
  2. 打开插件设置：在 DSH 的设置界面中，找到 “Codex 订阅” 或类似名称的插件配置页。
  3. 登录 ChatGPT：点击“浏览器登录”按钮，它会引导你在默认浏览器中完成 ChatGPT 的 OAuth 授权登录。请勿手动粘贴 Token 或使用 Codex CLI 。
  4. 选择搜索来源 (可选)：你可以在设置中选择 DSH 默认搜索或 Codex 订阅搜索作为全局搜索来源。
  5. 开始使用：完成登录后，在 DSH 的模型选择器中，你应该能看到 Codex 相关的模型选项。选择它，即可开始使用你的订阅额度。

4. 核心功能与使用

插件成功运行后，你可以在 DSH 中享受以下增强功能 ：

功能 说明
订阅模型直连 直接使用 Codex 模型，所有对话和任务消耗你的 ChatGPT 订阅额度，而非 API 额度。
额度可视化 输入框附近会显示剩余额度（可配置为百分比、进度条或关闭）。Codex Spark 等特殊额度和普通 Codex 额度会分开显示 。
高速模式切换 在输入框的模型菜单中，可以直接切换 Codex 模型的“标准”与“高速”模式。高速模式消耗更多额度，但响应更快 。
图片生成与编辑 (Beta) 支持通过 Codex 生成新图片，或对已有图片进行编辑。生成的图片会保存在本地，并支持缩放、备注和下载精确原图 。
订阅搜索 可以将 DSH 的搜索功能路由到 Codex 订阅，使用订阅自带的搜索能力。

6. 故障排除

问题 可能原因与解决方案
dsh 命令未找到 你很可能使用的是官方 npm 方式安装的 DSH，此时应使用 npx -y @deepseek-ai/dsh@<版本号> ... 格式的命令。
安装后 Codex 模型不出现 1. 确认已完全重启 DSH。2. 确认在插件设置页面完成了 ChatGPT 登录。3. 检查登录的 ChatGPT 账户是否确实拥有 Codex 访问权限。
登录失败或无法跳转 检查网络环境是否能正常访问 OpenAI/ChatGPT 网站。尝试在浏览器中直接登录 ChatGPT 后，再重新进行插件内的登录流程。
额度显示不准确或滞后 额度信息由 ChatGPT 服务端返回，显示可能会有延迟。可以尝试在设置页面手动刷新或重新登录。
生成图片时出错 确认你的订阅计划包含图片生成功能 (Beta)。图片生成耗时可能较长，请耐心等待或查看 DSH 日志获取详细错误信息 。
如何提交问题反馈？ 在插件设置页底部点击 “生成支持诊断” ，然后将生成的报告粘贴到 使用问题表单 中。该报告不含任何敏感凭证 。

7. 总结

通过这个插件，你可以在强大的 DeepSeek Harness 环境中，无缝地使用你的 ChatGPT Codex 订阅，享受本地化、无 API Key 管理负担的 AI 编码体验。整个部署过程的核心是正确执行 DSH 的插件安装命令，并完成一次性的 OAuth 登录。
