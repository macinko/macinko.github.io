Apify Agent Skills 部署教程：网页抓取与自动化

更新于2026-09-13|aitool
|总字数:1.5k|阅读时长:5分钟|浏览量:

Apify Agent Skills 是一套专为 AI 编程代理（如 Claude Code、Cursor、Windsurf 等）设计的技能包，它能让你的 AI 代理直接调用 Apify 平台上的 30,000+ 个现成 Actors（即服务器端应用），轻松实现网页抓取、数据提取和自动化任务。本教程将指导你完成技能安装和基本使用。

核心概念与优势

  • 开箱即用的专业技能：安装后，你的 AI 代理立即获得处理复杂网络任务的能力，例如抓取社交媒体数据、提取 Google Maps 商家信息、或进行竞争情报分析。
  • 自然语言驱动：你只需用自然语言描述想要的数据（例如“从 Google Maps 获取前 50 个 AI 工具结果”），AI 代理便会自动选择合适的 Actor、处理输入、运行任务并格式化输出结果。
  • 丰富的技能集合：该项目提供了多个核心技能，涵盖通用抓取 (apify-ultimate-scraper)、Actor 开发 (apify-actor-development)、代码迁移 (apify-actorization) 和集成开发 (apify-integration-development) 等场景。
  • 广泛的代理兼容性：除了 Claude Code，这些技能也以标准 Markdown 格式提供，可被 Cursor、Windsurf、Codex、Gemini CLI 以及其他任何能读取 Markdown 文件的 AI 代理使用。

前提条件

在安装技能之前，你需要准备好以下 Apify 平台环境：

  1. Apify 账户：在 apify.com 注册一个免费账户。

  2. Apify CLI (推荐)：这是本地开发和部署的核心工具。

    安装后，通过 apify login 命令在浏览器中完成 OAuth 认证。

  3. API 令牌 (备选)：如果你在无头环境 (Headless) 或 CI 中使用，无法打开浏览器进行 OAuth 登录，可以在 Apify 控制台的“Integrations”页面生成 API 令牌，并将其设置为环境变量 APIFY_TOKEN。

  4. Node.js：需要 Node.js 20.6 或更高版本。

第二步：使用技能

技能安装完成后，你可以在对话中直接用自然语言提出需求。AI 代理会自动调用相应的技能来完成工作。

示例提示词：

  • 通用抓取：“Scrape the top 50 results for “AI coding tools” from Google Maps and save them to a CSV.”
  • Actor 开发：“Create a new Apify Actor in Python that scrapes news headlines from a given URL and saves them to the default dataset.”
  • 代码迁移：“Take this existing Python script (粘贴代码) and turn it into an Apify Actor with proper input and output handling.”

故障排查与常见问题

  • apify 命令未找到：请确认已全局安装 Apify CLI (npm install -g apify-cli)，并且其安装目录已添加到系统的 PATH 环境变量中。
  • 认证失败 (Login failed)：
    • 如果使用 apify login，确保浏览器可以正常打开并完成 OAuth 流程。
    • 如果是无头环境，请确认 APIFY_TOKEN 环境变量已正确设置并导出。可以通过 echo $APIFY_TOKEN 检查。
  • 技能未加载或未被识别：
    • 对于 Claude Code，确认 /plugin install 命令执行成功。
    • 对于其他代理，检查是否将项目仓库或 agents/AGENTS.md 文件正确地添加到了代理的上下文或知识库中。
  • Actor 运行失败：
    • 检查 Apify 账户是否有足够积分（免费套餐包含初始配额）。
    • 查看具体的错误日志，通常由输入参数格式不正确或目标网站结构变化导致。可以检查 Actor 的文档或在 Apify 控制台查看运行详情。
  • 技能只读性：所有技能默认以“只读”方式工作，即它们会指导 AI 代理生成代码或调用 API，但不会自动修改你的文件系统或 Git 仓库，除非你明确要求。

总而言之，Apify Agent Skills 是一个强大的工具包，它通过 AI 代理极大地简化了网页数据提取和自动化任务的复杂度。你可以从安装最核心的 apify-ultimate-scraper 技能开始，用自然语言尝试第一个抓取任务，从而快速体验其价值。建议同时收藏 Apify Store 以浏览所有可用的 Actor，并留意社区维护的 apify/awesome-skills 仓库以获得更多领域专用的技能。
