Video Digest 本地优先视频学习工具详细部署教程

Video Digest 是一款本地优先的 Chrome 浏览器扩展，专为利用 AI 辅助学习 YouTube 和 Bilibili 视频而设计。它能将视频字幕转化为可搜索的转录文本、双语对照视图，并利用您本地的 Codex 或 Trae CLI 生成摘要、解释和带时间戳的笔记，所有数据均在本地处理。本教程将指导您完成从安装到使用的全过程。

Video Digest 是什么

Video Digest 是一个 Chrome 扩展，它通过读取视频页面自带的字幕轨道，结合本地运行的 AI 命令行工具（Codex 或 Trae CLI），为您提供沉浸式的视频学习体验。

核心功能：

  • 多语言字幕支持：读取 YouTube 或 Bilibili 的原始字幕，并提供原文、简体中文或双语对照视图。
  • AI 辅助学习：一键生成视频章节、关键引用、解释、翻译和精炼笔记。
  • 交互式问答：针对任意字幕段落、章节或笔记提问，AI 会基于视频内容回答。
  • 时间戳笔记：保存带时间戳的笔记，点击即可跳转到视频对应位置。
  • 学习包 (Learning Pack)：将视频信息、笔记和您的反思打包，发送到本地工作区，供后续创作使用。

核心原则：本地优先，数据私有。

  • 不调用云端转录 API，直接使用平台字幕。
  • 不存储您的 API 密钥，所有 AI 请求通过本地 127.0.0.1:43110 的桥接服务发送。
  • 需要您本地已安装并登录 Codex 或 Trae CLI。

工作原理

  1. 读取字幕：扩展从您正在观看的 YouTube 或 Bilibili 视频页面直接读取已加载的字幕数据。
  2. 本地桥接服务：一个运行在您电脑上的 Node.js 服务 (bridge/server.js) 在本地 127.0.0.1:43110 端口监听来自扩展的请求。
  3. 调用本地 CLI：当您点击“生成概述”或“提问”时，扩展将请求和上下文发送给桥接服务。桥接服务调用您配置的 Codex CLI 或 Trae CLI 2.0，并返回结果。
  4. 呈现与保存：AI 的回复会直接显示在扩展侧面板中，您可以将有用的回答保存为笔记。

安装前准备

软件依赖

  1. Google Chrome 浏览器：版本 116 或更新。
  2. Node.js：版本 18 或更新。您可以从 nodejs.org 下载安装。
  3. 一个本地 AI 命令行工具（二选一）：
    • Codex CLI：需要已安装并在终端中登录 (codex login)。
    • Trae CLI 2.0：需要已安装并在终端中登录 (traecli login 或 traex login)。
  4. Git (可选)：用于克隆仓库。

步骤 1：获取项目代码

打开终端，执行以下命令克隆仓库：

或者，您也可以从 GitHub 页面下载 ZIP 压缩包并解压。

步骤 2：安装并启动本地桥接服务

这是一个关键步骤，需要在后台持续运行。

重要：

  • 启动后，此终端窗口需要保持打开。您可以使用 Ctrl+C 停止服务。
  • 如需开机自启，请使用您信任的进程管理器（如 pm2）来运行 node bridge/server.js。
  • 安全警告：此服务仅监听本地回环接口 (127.0.0.1)，切勿将其暴露到公网。

步骤 3：在 Chrome 中安装扩展

  1. 打开 Chrome 浏览器，在地址栏输入 chrome://extensions 并回车。
  2. 在页面右上角，开启“开发者模式”。
  3. 点击左上角的 “加载已解压的扩展程序” 按钮。
  4. 在弹出的对话框中，选择 Video Digest 项目仓库的根目录（即包含 manifest.json 文件的文件夹）。
  5. 点击“选择文件夹”。扩展程序应该会出现在列表中并已启用。

首次使用与配置

  1. 打开一个带有字幕的视频：在 YouTube 或 Bilibili 上打开一个视频，确保其有可用的字幕轨道（YouTube 的自动生成字幕或 Bilibili 的 CC/AI 字幕）。Bilibili 可能需要您先登录账号。
  2. 点击扩展图标：在 Chrome 浏览器右上角，点击 Video Digest 的扩展图标。
  3. 选择 AI 提供商：扩展侧面板会打开。在 Settings (设置) 中，选择您希望使用的本地 CLI 工具：
    • Codex：需要您已安装并登录 Codex CLI。
    • TraeWork：需要您已安装并登录 Trae CLI 2.0。
  4. 开始使用：选择提供商后，扩展会自动加载当前视频的字幕。您现在就可以开始使用“Overview (概述)”、“Ask (提问)”和“Notes (笔记)”等功能了。

核心功能与使用场景

1. 学习视频课程

  • 打开一个教学视频，点击扩展图标。
  • 点击 Overview，让 AI 生成章节摘要和关键引用，快速了解视频结构。
  • 选中一段字幕，点击 Explain (解释)，让 AI 用更简单的方式解释复杂概念。

2. 外语视频学习

  • 利用 双语视图 (Bilingual) 对照原文和翻译。
  • 选中不理解的句子，直接向 AI 提问：“这句话里的‘foo’是什么意思？”

3. 保存和整理知识

  • 在视频的关键时刻，点击 Save Note (保存笔记) 来记录带时间戳的思考。
  • 当您整理好笔记和反思后，在 Create (创作) 页面，点击 Send Learning Pack (发送学习包)，将所有内容打包发送到您配置的本地工作区（默认在 ~/Documents/youtube-digest-creator-workspace/inbox/youtube-digest/），便于后续写作或知识管理。

自定义与高级配置

修改 Creator Workspace 目标目录

运行 node bridge/generate-config.js 后，会生成 bridge/workspace-config.json 文件。您可以编辑其中的 workspaceRoot 值来改变学习包的存放位置。

安全边界

  • 扩展和桥接服务严格限制了请求和响应的大小、持续时间。
  • 桥接服务会忽略 CLI 的用户配置和规则，在一个只读的临时沙箱中运行，以保护您的系统安全。
  • 所有本地生成的配置文件（如 bridge-config.js）都已加入 .gitignore，请勿提交到版本控制系统。

更新与卸载

更新 Video Digest

  1. 停止正在运行的桥接服务（在终端按 Ctrl+C）。
  2. 进入项目目录，拉取最新代码：git pull。
  3. 重新启动桥接服务：node bridge/server.js。
  4. 在 Chrome 扩展管理页面 (chrome://extensions)，点击 Video Digest 卡片上的 刷新 图标。

卸载 Video Digest

  1. 停止桥接服务。
  2. 在 Chrome 扩展管理页面，点击 Video Digest 卡片上的 移除。
  3. 删除整个项目目录。

常见问题排查

问题：扩展无法加载字幕或提示无字幕。

  • 解决：
    1. 确保视频页面已加载完成且字幕轨道已开启。
    2. Bilibili 视频需要先登录账号，否则其播放器不会暴露字幕数据。
    3. 刷新页面后，再次点击扩展图标。

问题：点击“Overview”或“Ask”后没有反应或报错。

  • 解决：
    1. 确认桥接服务正在运行（终端窗口开着且没报错）。
    2. 检查您选择的 AI 提供商（Codex/Trae）是否已在终端中登录并有效。
    3. 检查防火墙设置，允许 Node.js 访问本地回环地址 127.0.0.1:43110。

问题：桥接服务启动报错 Cannot find module ...。

  • 解决：进入项目目录，运行 npm install 安装所需依赖。

通过以上步骤，您应该能够成功安装并使用 Video Digest。这个工具将帮助您从被动观看转变为主动学习，让每一段视频内容都能被更有效地理解和吸收。如需更深入的信息，可以查阅项目中的 PRIVACY.md 和 SECURITY.md 文件。
