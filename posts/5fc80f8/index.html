英国手机号注册 LemFi：无需地址证明，顺利认证 IBKR

更新于2026-09-05|globalbank
|总字数:1.9k|阅读时长:5分钟|浏览量:

最近很多宝宝都在焦虑“海外地址证明”这个问题，我也写过很多方法。可能有些宝宝不喜欢太折腾，还有就是很多文章已经沉入“历史长河”中。还有的方式呢冲的人太多已经被冲毁了。

然后我突然发现可以折腾一下这个跨境金融平台——LemFi。

去年认识它的时候其实一开始我是冲着它的跨境汇款功能去看的。

但是今天我们注册LemFi可不是仅仅只为了它那一个跨境汇款功能哦，因为LemFi的风控一点也不输于Wise。但是呢重点是这个思维，我讲一下这个重点思维啊。

大家小本本记一下哦：我们使用 LemFi 获取一个英国地址证明，因为用下面的注册方式无需提供地址证明。我们获得这个“英国地址证明”之后拿着这个地址证明去认证 dtcpay 和 IBKR (盈透)，过了dtcpay之后那么你就又有一个“合规”的地址证明了。明白了吗？就算 LemFi 被风控没了也无所谓了。

上面思维方式仅提供给急需海外地址证明的小伙伴，“正人君子”请绕行。非常感谢！

LemFi 本身主要就是做国际汇款的，美元、英镑、加元这些都可以用来汇款，具体支持哪些国家和收款方式，要看你注册地区以及当时 App 里的实际情况。

但我后来发现，它还有一个让我比较感兴趣的功能：

开户以后可以拿到英国本地账户，有 Account Number 和 Sort Code，而且可以生成账户 Statement。

所以我这次我讲 LemFi，主要不是单纯为了让宝宝们去体验汇款。

我的目的其实很明确：

看看能不能通过英国手机号＋英国流量环境注册，然后用中国护照完成身份认证，最后拿到一个英国本地账户和带地址的账户 Statement。

我把自己这次的过程记录下来，给大家做个参考。

（声明：此次注册我全程使用同学的身份信息注册的，因为我自己去年就注册过了无法再进行注册。）

先说我自己的注册方式

我这次用的方法很简单：

下载 LemFi App + 英国手机号 + 英国流量

很多宝宝会问，那目前哪几个英国手机号运营商可以呢？

前几天我正好写过 英国的手机运营商 Asda Mobile ，没有英国号码的宝宝可以自行去查看一下哦。

也就是说，注册 LemFi 的时候，我使用的是英国手机号接收验证码，同时整个注册和认证过程我们都要使用英国的网络环境。

这里我先强调一下，这只是我自己这次成功注册的方式。（因为有些人不知道什么原因会失败，不是说只要准备一个英国手机号和英国流量，就一定可以通过 LemFi 的审核。）

毕竟金融平台的 KYC 都是动态审核，地区、账户资料、证件以及当时的政策都有可能影响结果。

第一步：准备英国手机号

首先需要一个可以正常接收短信验证码的英国手机号。

我这次就是直接使用 Asda Mobile 公司的英国手机号注册。

打开 LemFi App 后，

输入邮箱和密码，

填写邀请码：PEIQ2UY8

【使用邀请码满足条件以后，新用户和邀请人双方都可以获得 $20 奖励。】

点击【创建账户】，

然后按照页面提示输入 +44 手机号，接收验证码。

验证码通过以后继续填写个人资料。

这里没什么特别复杂的，正常按照页面一步一步填就可以。

第二步：注册的时候保持英国流量环境

这个是这次比较关键的一点。

我在注册 LemFi 的时候，使用的是英国流量环境。

包括注册、登录以及后面的认证，我都是按照这个环境来操作的。

为什么这么做？

因为 LemFi 本身就是一个受地区限制的金融服务，不同国家和地区看到的产品、开户资格以及功能可能都不完全一样。

所以我这次注册的时候，没有一会儿英国、一会儿其他地区来回切。

整个过程尽量保持一致。

第三步：填写个人资料

手机号验证完成以后，就开始填写自己的个人资料。

姓名、出生日期、居住信息这些，全部按照自己的真实情况填写。

注意：居住地址去 Google Map上找一个英国当地住宅地址就好啦！

第四步：用中国护照完成身份认证

国籍选择的是：中国

然后身份认证使用的是：护照

这里大家要注意，LemFi 不同地区、不同时间的认证页面可能会发生变化。

所以你实际操作的时候，还是要以自己 App 里面显示的证件类型为准。

我这次比较顺利的一点是：

认证过程中没有额外让我提交传统的地址证明文件。

第五步：成功以后拿到英国本地账户

身份认证通过以后，我就开始看账户里面到底有什么。

结果比较有意思。

账户里面可以看到英国本地账户信息：

Account Number
账户号码

Sort Code
排序代码

这两个东西大家应该比较熟悉了。

简单来说，就是一个英国本地账户的基本收款信息。

如果你平时需要接收英国本地转账，这个功能还是挺方便的。

第六步：可以生成账户 Statement

进入账户相关页面以后，可以找到 Statement / 对账单功能。

生成之后可以导出 PDF。

我这次看到的 Statement 里面包含账户相关信息，同时会显示地址。

所以对于一些需要提交英国金融账户 Statement的人来说，这个功能确实比较有价值。

但这里千万不要理解成：

“LemFi 的 Statement = 所有平台都认可的英国地址证明。”

这个是不一定的。

不同银行、券商、交易所对于地址证明的审核标准都不一样。

有的平台接受金融机构 Statement，有的平台可能还会要求其他材料。

所以如果你的目的就是拿它去做某个平台的地址认证，最好提前确认一下对方到底接受什么类型的文件。

关于入金，我也顺便给大家又测试了一下

LemFi 本身就是做跨境汇款的，所以开户之后还会涉及入金。

如果你有英国本地银行账户，可以按照 LemFi 当时提供的收款信息进行转账。

我自己使用的是 Wise 的英国账户进行入金英镑。

最后说几个小提醒

第一，注册的时候我使用的是英国手机号＋英国流量，这是我这次自己的实际操作方式，不代表所有人的审核结果都会一样。

第二，Statement 虽然可以显示地址，但不代表所有银行、券商、交易所都会把它当成地址证明接受。
