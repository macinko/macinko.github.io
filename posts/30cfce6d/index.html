大陆身份嘉信理财开户全流程图文攻略

更新于2026-09-13|globalbankinvest
|总字数:2.3k|阅读时长:7分钟|浏览量:

盈透 IBKR 收紧了开户政策，大陆身份开户如今已需要提供海外居住证明。算是大巴车关上了门。

不少朋友把眼光瞄向了「嘉信理财」，尽管开户其实比较简单，但终归有新手朋友不知道如何下手，或者不敢操作。今天出一个图文教程。

PS：从段永平在雪球上晒的截图来看，他也是在用嘉信理财

嘉信理财简介

嘉信理财集团（Charles Schwab Corporation，NYSE：SCHW）位于美国加州旧金山，为一间经营经纪业务与银行业务之理财公司，由查尔斯·施瓦布（Charles R. “Chuck” Schwab）于1971年创办。

公司业务很多，我们主要了解它券商业务。

嘉信理财本身就有自己的券商业务，2019 年，又收购了德美利证券 TD Ameritrade，目前算是美国最大的在线券商。

嘉信理财优缺点

每一个券商都有优缺点，嘉信一样。

优点

  1. 嘉信理财是 FINRA、SEC 和 SIPC 的成员，作为最大在线券商，安全性无话可说。
  2. 交易免佣：在线购买股票或者 ETF 免佣金。
  3. 最好用的交易软件 thinkorswim 免费用：thinkorswim 随着 TD Ameritrade 的合并现在已免费向所有嘉信理财用户提供。
  4. 拥有中文客服电话：400-120-6217
  5. 无开户门槛，嘉信已经取消了 25000 美金的开户门槛（补充：尽管取消门槛，请尽可能入至少 1000 美金，避免账户被关）。

缺点

  1. 开户相对繁琐。
  2. 入金相对又一些门槛。如果没有美国的银行卡，需要使用 Wise 或者电汇。
  3. 大陆无法申请 Debit 卡。我个人认为无所谓，不必执拗在「集卡」上，不如专心投资。（投机取巧拿卡可能会被封号，得不偿失）
  4. 融资利率相对较高。
  5. 只有美股，没有港股和其他市场。

开户准备

因为流程较长，建议一次性准备好所有东西在手边，方便操作。

  1. 身份证件：有效期内的护照。
  2. 地址证明：信用卡、银行、水电煤的账单都可以。注意是国内地址，中文即可。
  3. Email 邮箱：推荐使用 Gmail，iCloud 等国外厂商邮箱。
  4. 手机号：需要能接收境外短信，因为反诈的原因，运营商默认关闭了你的境外短信功能，推荐使用境外号码。

开户流程

开户地址：

https://international.schwab.com/open-account-intro

注意！一定要进入国际站开户，主站点只能美国身份开户，也不建议去香港站开户。

打开上述开户地址，确认在国际站点没错后，下拉页面，找到图示位置，选择地区。

选择 「China」之后，页面会自动跳转，等待新页面加载完成。

跳转后的页面是让你选择账户类型，美国券商都有多种账户类型，包括联名账户、信托账户等。

这里我们选择普通的个人账户，也就是 「Individual Account」，找到如图位置，点击 「Continue」继续。

这是开户前最后的说明事项，可以看到：

\1. 嘉信理财目前无月管理费、无最低金额门槛。

\2. 开户你需要准备：非美国地址、护照或者身份证、工作证明（如要求提供的话）

如果有邀请码，可以在底部这里点击输入（嘉信不会给邀请人奖励，我就不放码了，有需要可以网上搜索“schwab referral code 就有海量”）。

点击下面绿色的 「Get Started」 按钮。

需要你同意一个声明，原有页面是纯英文的，我做了下双语翻译，仅供参考。

点击「I agree」我同意 按钮继续。

按照要求填写个人信息。

所有个人信息都按照你的护照填写！

所有信息使用英文填写，不要使用中文。

填完后，点击「Continue」

这里填写证件信息，**推荐使用护照信息开户，**理论上，身份证也可以作为一种地址证明在后续流程提交。

如果用身份证开户，请选择 Other government ID。

点击 「Continue」

输入邮箱收到的验证码，点击 Continue。

设置登录账号，请牢记这些信息。

点击「Continue」

输入居住地址，同样需要英文填写。「Street address」即详细的街道门牌号地址，写不下就分段放到下面的 2 和 3 中，请保证这里填的地址和后面上传的地址证明的地址一致。

不会英文也没问题，找 AI 大模型给你翻译。你可以复制下面的问题：

请将下面地址翻译为英文，地名部分使用汉语拼音，拆分为 Country、Street Address，City，请直接返回译文，不要添加其他信息：「你的地址」

点击「Continue」

这一步相当于设置紧急联系人，按需设置，也可以直接点「Continue」跳过。后续可以再添加。

选择开账户的目的和资金来源。

目的我们一般选择「General purposes」

资金来源一般选第一项，就是工资。

填写工作信息，同样，都需要用英文填写，没有英文名就填拼音：

第一项为在职状态，可参考：

Employed：在职 Self Employed：自雇 Student：学生 Homemaker：家庭主妇 Retired：退休 Not Employed：无业

完成后，点击 「Continue」

这一步询问你是否为上市公司高管或者证券相关金融机构的职员，大部分人都是选 「No」

无纸化设置，全部打勾继续，不然你加信箱会塞满美国寄来的信封

账户功能选择，Margin 即融资账户，一般都会开，选 Yes，Option Trading 即期权交易，如有需要可以选 Yes，thinkorswim 即交易软件，白送的，一定选 Yes。

注意：即便你觉得现在不会用到融资或者期权交易，也建议一并申请，嘉信在开户后升级账户权限非常麻烦。

如果开启了期权功能，会继续让你选择要开启的期权级别。我建议选择第二个或者第三个。最后一个很难通过。

区别是可以使用的期权策略有限制。（如果你还不懂这些限制，至少选第一个。嘉信后续申请期权级别非常困难！）

继续，资产状况和交易经验，根据实际情况填写。

参考值：

Total net worth：200,000

Liquid net worth:：100,000

Annual income: 50,000

Years of experience：6

Average treads per year：70~100

Average trade amount：5,000~10,000

交易经验，建议选择 Extensive 或者 Good

下一步确认信息，无误后继续 「Continue」

确认协议，全部打勾即可。其中有一个是二选一，即黄色背景的。是选择你是否是专业的交易者，一般都是选择 Nonprofessional，非专业。这里的专业是指在在美股相关机构注册职员，不是「炒股很厉害」的意思

这一步需要上传相关的材料

  1. Passport，护照的照片，需要带有名字、照片的详情页，拍全面
  2. Proof of residence，地址证明，银行卡账单等带有你的居住地址（前面填写的），中文没有关系。

重要：上传的文件名不能包含中文，否则无法上传！

注意：有人提供信用卡账单作为地址证明失败的，尽可能使用水电煤账单尝试。

都上传好后，点击 「Continue」，会进入机审阶段

见到此界面，开户就结束了，静待审核结果。

建议趁着等待审核的时间，可以先机下面的 「Complete Form W-8BEN」按钮，填写 W-8BEN，以获得税务优惠。

这一步自带中文，流程非常长，耐心操作。

这里的流程和续签是一样的，可以参考我之前写的续签图文教程：

嘉信理财 W8 续签

入金

嘉信理财也有多种入金方式：

  1. 如果持有美国卡，建议直接使用 ACH 入金。

  2. 如果只有港卡，可以电汇入金。

  3. 备用可以选择 Wise 入金（可以使用邀请链接开户 Wise：

    http://go.inm.ad/wise）。

其中，香港银行卡可以直接汇港币到嘉信的花旗账户，汇款后会自动转换为美元，这里附上汇款信息，详情可查阅官网说明（该账户也支持直接 FPS 入金）：

https://www.schwab.com/public/file/P-10740369

项目 内容

收款银行 Citibank N.A., Hong Kong SWIFT ID CITIHKHX Bank Code 006 Branch Code 391 Account Number 62286838 Account Name Charles Schwab & Co., Inc. 收款行银行地址 3 Garden Road, Central, Hong Kong 备注 请在汇款指示的备注栏中填写：Schwab 账户号（8 位） + 账户登记姓名（与 Schwab 账户一致）

软件

我强烈建议，既然申请了嘉信理财账户，请务必下载使用白送的顶级交易软件：thinkorswim。

如使用 iOS，推荐使用外区苹果账号安装。
