短视频工厂 (Short Video Factory)：开源的 AI 视频创作工具

更新于2026-09-05|aivideo
|总字数:1.2k|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 短视频工厂 (Short Video Factory)——一个开源的桌面端AI视频创作工具。它能通过简单的提示词和素材，自动生成产品营销或泛内容的短视频。

短视频工厂的核心价值在于自动化和本地化。您只需提供文本创意和视频/图片素材，它就能利用AI自动完成文案生成、语音合成、视频剪辑和字幕添加，批量产出成品视频。所有处理均在本地进行，确保您的数据隐私和安全。

📥 安装与运行

短视频工厂是跨平台桌面应用，支持 Windows、macOS 和 Linux。安装和使用流程非常简单。

  1. 下载应用：
    • 访问项目的 GitHub Releases 页面，下载适用于您操作系统的最新安装包（例如 .exe、.dmg 或 .AppImage）。
  2. 安装并启动：
    • Windows：运行下载的 .exe 安装程序，按照指引完成安装，然后从桌面快捷方式或开始菜单启动。
    • macOS：打开下载的 .dmg 文件，将 Short Video Factory.app 拖入“应用程序”文件夹，然后从 Launchpad 或“应用程序”中启动。首次启动可能需要右键选择“打开”以绕过未验证开发者提示。
    • Linux：为下载的 .AppImage 文件添加可执行权限 (chmod +x *.AppImage)，然后直接运行它。
  3. 界面概览：启动后，您将看到一个简洁直观的主界面。核心操作流程通常为：创建项目 → 输入提示词/文案 → 添加素材（视频/图片） → 生成语音 → 合成导出。

🚀 核心功能使用流程

1. 文案生成

  • 功能：基于您输入的主题或提示词，调用AI接口（兼容OpenAI格式）自动生成短视频的解说文案。
  • 操作：在“文案生成”模块中，输入您的产品名称、卖点或内容主题（例如“一款适合都市白领的智能咖啡机”），选择语言，点击生成。您也可以手动输入或编辑文案。

2. 语音合成 (TTS)

  • 功能：将生成的文案转换为自然流畅的语音旁白。目前集成了 EdgeTTS 服务。
  • 操作：在“语音合成”模块中，选择您已生成的文案，选择发音人（支持多种中文/英文音色），点击合成。生成的音频文件会自动添加到项目素材库中。

3. 视频自动剪辑

  • 功能：这是工具的核心。它会将您提供的视频片段、图片、文案和语音，按照设定自动剪辑、对齐、添加字幕和转场效果，合成一个完整的短视频。
  • 操作：
    1. 准备素材：在“视频剪辑”或“素材库”模块中，上传您的视频片段或图片（建议与文案内容相关）。
    2. 配置参数：设置视频比例（如竖屏9:16）、分辨率、字幕样式、背景音乐等。
    3. 自动合成：点击“开始合成”或类似按钮。工具会自动匹配语音时间轴，将素材剪辑、拼接，并添加字幕。
    4. 预览与导出：合成完成后，您可以预览视频，满意后导出为MP4等格式。

4. 批量处理

  • 功能：支持设置一个批量任务，按照预设规则（如使用不同的文案、不同的素材组合）自动、持续地合成多个视频，非常适合规模化内容生产。

⚙️ 重要配置与提示

  • AI 接口配置：文案生成功能需要一个兼容 OpenAI 格式的 API 接口。您可以在设置中配置自定义的 API 地址和密钥（例如，使用 OpenAI、Azure OpenAI 或本地部署的模型）。语音合成（EdgeTTS）通常无需额外配置即可使用。
  • 完全本地运行：除调用您配置的AI文案生成API外，所有媒体处理（剪辑、渲染、字幕）均在您的本地电脑上完成，确保数据隐私。这也是其一个核心优点。
  • 多语言支持：界面和生成的视频支持中文、英文等多种语言，可在设置中切换。

📖 进一步学习

  • 官方文档：建议访问项目的 官方文档 查看更详细的使用手册和功能介绍。
  • 示例视频：项目 README 中提供了“产品营销短视频”和“暖心治愈系语录”的示例，您可以快速了解成品效果。
  • 问题反馈：如果遇到 Bug 或有功能请求，可以在 GitHub 仓库的 Issues 页面提交。

总结来说，您只需下载安装、配置好AI文案生成的API密钥，就可以开始创建您的第一个AI短视频了。
