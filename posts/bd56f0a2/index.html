UZI-Skill 安装与使用指南：AI 驱动的个股深度分析引擎

更新于2026-09-05|aitool
|总字数:1.9k|阅读时长:6分钟|浏览量:

UZI-Skill 是一个让 AI 助手（如 Claude Code、Codex、Cursor 等）能够对 A 股、港股、美股进行深度分析的技能包。它模拟了 66 位投资大佬（巴菲特、段永平、赵老哥、黄仁勋等）组成评审团，调用 22 维数据 和 22 种机构级分析方法（DCF、LBO、Comps 等），最终生成一份详尽的 Bloomberg 风格 HTML 分析报告。

1. 系统要求与前提

1.1 软件前提

  • AI 编程助手：您需要安装并配置好以下任一 AI 编程助手：
    • Claude Code（推荐，支持最完善）
    • Codex (OpenAI CLI)
    • Cursor
    • Gemini CLI
    • OpenClaw / 龙虾
    • Windsurf / Devin 等
  • 网络：需要互联网连接以获取实时行情、财报等公开数据。
  • Python：如果使用 CLI 直跑方式，需要 Python 3.10+ 环境。

1.2 数据源说明

  • 全部免费：无需任何付费 API Key。数据来自东方财富、雪球、akshare、Yahoo Finance、巨潮资讯等公开数据源。
  • 可选增强：可配置 MX_APIKEY（免费申领）以提升数据获取稳定性，尤其在海外网络环境下。

4. 报告内容与解读

一份完整的分析报告包含以下核心部分：

  • 综合评分与 verdict：66 位评委投票后的综合得分和结论（如“值得重仓”、“可以蹲一蹲”、“观望优先”、“回避”）。
  • 66 位评审团审判席：每位评委的投票（绿色看多/红色看空/灰色中性）及其引用具体规则的评语。
  • 多空大辩论（The Great Divide）：看多与看空评委的激烈辩论，引用具体数据。
  • 22 维深度数据卡：包括财务、估值、技术、供应链、舆情、政策等维度的可视化图表。
  • 机构级分析模型：DCF 估值（含 5×5 敏感性热力图）、Comps 对标、LBO 测试、IC 备忘录等。
  • 一键分享素材：自动生成朋友圈竖图（1080×1920）和微信群战报图（1920×1080）。

6. 常见问题排查

问题 可能原因 解决方案
命令未找到或无法识别 未加 /stock-deep-analyzer: 前缀 使用全名，如 /stock-deep-analyzer:analyze-stock 贵州茅台。
分析卡在“数据采集”阶段 网络问题或数据源反爬 1. 检查网络连接。 2. 如使用海外网络，强烈建议配置 MX_APIKEY（见上文）。 3. 等待一会，脚本有自动重试和 fallback 机制。
报告显示“数据缺口”或橙色 banner 部分数据因网络或源限制未获取到 查看 .cache/<ticker>/_data_gaps.json 了解具体缺口。Agent 会自动尝试补齐，或您可稍后重跑。
评分看起来偏低（如茅台<65分） 评分校准使分值分布更合理（v2.11 校准） 分数是相对的。真正的坑会 <35分（回避），白马股通常在 50-65 分（观望/可以蹲）。请结合 verdict 文字结论判断。
macOS 提示“无法验证开发者”（Hermes 用户） Hermes Skills Guard 误判 使用一键安装脚本绕过：`curl -fsSL https://raw.githubusercontent.com/wbh604/UZI-Skill/main/install-hermes.sh

7. 总结

UZI-Skill 将复杂的个股基本面、技术面、情绪面分析封装成 AI 助手可直接调用的“超能力”。

核心使用路径：

  1. 安装：在您的 AI 助手中执行对应的安装命令（如 Claude Code 的 /plugin 命令）。
  2. 分析：使用 /stock-deep-analyzer:analyze-stock 股票名 命令开始分析。
  3. 阅读报告：在生成的 HTML 报告中查看综合评分、评委意见、估值模型和风险提示。
  4. 专项深入：使用 dcf、comps、ic-memo 等专项命令进行针对性分析。

建议：

  • 首次使用，建议先用 quick-scan 命令快速体验。
  • 对于核心标的，运行 analyze-stock 获得完整报告。
  • 报告是分析工具，不构成投资建议，请结合自身判断。
  • 遇到问题，可查看项目 docs/ 目录下的详细文档或在 GitHub 提交 Issue。
