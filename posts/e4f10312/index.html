last30days 强大的AI代理技能，它能跨平台（Reddit、X

更新于2026-09-05|aitool
|总字数:1.4k|阅读时长:4分钟|浏览量:

这份详细的部署教程将指引您安装和使用 /last30days——一个强大的AI代理技能，它能跨平台（Reddit、X、YouTube、Hacker News等）研究任何主题，并合成一份基于真实公众参与度的总结报告。

/last30days 就像一个由AI驱动的搜索引擎，其排序依据是真实的用户互动（如投票、点赞）和真金白银的押注，而非编辑推荐。它支持多种AI编程助手和客户端。

✨ 核心价值

  • 跨平台聚合：同时搜索多个“信息孤岛”（如Reddit、X、YouTube），这些平台的数据通常无法通过单一搜索引擎获取。
  • 真实信号排序：结果排名基于Reddit的赞、X的喜欢、YouTube的观看量、Polymarket的赔率（背后是真金白银），反映的是“人们实际参与什么”，而非SEO优化结果。
  • AI合成简报：AI代理会阅读所有搜索结果，为你生成一份简洁、有引用来源的总结，包含关键观点和数据。

📥 安装指南

/last30days 支持多种AI编程助手和客户端。请根据你使用的工具选择最合适的安装方式。

Claude Code（推荐）

这是官方最推荐的安装方式，支持自动更新。

更新：插件会自动更新，或手动运行 claude plugin update last30days@last30days-skill。

Codex、Cursor、Copilot、Gemini CLI 等（通用安装）

对于支持Agent Skills的50多种工具，可以使用统一的 npx skills 命令。

更新：运行 npx skills update last30days -g。

Claude Desktop（桌面应用）

通过MCP（模型上下文协议）服务器包安装。

  1. 从 最新 Releases 页面 下载适用于你平台的 .mcpb 文件。
  2. 打开Claude Desktop，进入 Settings > Extensions，将下载的 .mcpb 文件拖入即可。
  3. 按提示粘贴各平台的API密钥（全部可选，不填则仅使用免费来源）。

claude.ai（网页版）

  1. 从 Releases 页面下载 last30days.skill 文件。
  2. 访问 claude.ai > Customize > Skills，点击 + > Create skill > Upload a skill，上传该文件。
  3. 确保在Capabilities中启用了 “Code execution and file creation”。

其他工具

  • Grok (xAI Build CLI)：grok plugin install mvanhorn/last30days-skill

  • OpenClaw：clawhub install last30days-official

  • 手动安装（开发者）：

🔑 配置API密钥（来源解锁）

安装后，大部分免费来源（Reddit、Hacker News、Polymarket、GitHub、arXiv、Techmeme）开箱即用，无需任何配置。要解锁更多来源，你需要提供相应的API密钥或浏览器会话。

数据来源 所需配置 费用/备注
X / Twitter 浏览器中登录 x.com，或设置 XQUIK_API_KEY / XAI_API_KEY 浏览器Cookie免费；API密钥按提供商计费
YouTube brew install yt-dlp (macOS) 或同等工具 免费
TikTok, Instagram, LinkedIn等 获取 ScrapeCreators API密钥 10,000次免费调用，之后按量付费
Perplexity 设置 PERPLEXITY_API_KEY 或 OPENROUTER_API_KEY 作为备用 按量付费
Web搜索 设置 BRAVE_SEARCH_API_KEY 每月2000次免费查询

配置方式：

  1. 环境变量：在终端或 shell 配置文件中设置，如 export XAI_API_KEY="your-key"。
  2. .env 文件：在项目根目录或 ~/.config/last30days/.env 中创建文件，按行写入 KEY=value。
  3. macOS钥匙串（可选）：运行 skills/last30days/scripts/setup-keychain.sh 交互式存储密钥。

首次运行 /last30days 时，一个设置向导会引导你完成这些配置。

🚀 使用方法与技巧

在支持的命令行或AI聊天中，直接使用命令 /last30days 加上你的研究主题。

基础用法：

例如：/last30days 特斯拉新车型 或 /last30days 最新的AI编程工具趋势。

高级用法与参数：
你可以通过在主题后添加参数来精细控制研究。

  • 研究特定人物：/last30days Peter Steinberger（会查找其GitHub、X、YouTube访谈等）。
  • 招聘信号：/last30days Listen Labs --hiring-signals（分析公司招聘岗位透露的战略方向）。
  • 发现趋势：/last30days what's exploding in AI agents?（进入发现模式，给出5-10个速度排名靠前的话题）。
  • 对比工具：/last30days OpenClaw vs Hermes（生成并排对比表）。
  • ELI5模式：运行后输入 eli5 on，用更通俗的语言解释结果。
  • 保存与导出：
    • 默认保存到 ~/Documents/Last30Days/。
    • 使用 --save-dir <路径> 指定保存目录。
    • 使用 --emit=json 输出机器可读的JSON格式，方便集成到其他工作流。

⚙️ 工作原理（简要）

  1. 输入主题：你输入一个人、公司、产品或概念。
  2. 智能解析：AI代理自动解析出相关的X账号、Reddit子版块、GitHub仓库、YouTube频道等。
  3. 并行搜索：同时查询所有已配置的来源，并对结果进行相关性、参与度和新鲜度评分。
  4. 合并聚类：将跨平台报道的同一事件（如一个音乐节在Reddit讨论、X上热议、TikTok有票价信息）聚合为一个条目。
  5. AI合成：根据真实用户参与度，将所有发现合成为一份简洁、有明确引用的简报。

❓ 故障排查

  • 来源返回结果少或空：运行 --diagnose 或 doctor 命令检查各来源连接状态和凭证是否有效。
  • 权限问题：确保已授予AI助手执行代码和读写文件的权限（claude.ai网页版需在Customize中开启）。
  • Python版本：需要 Python 3.12+。可通过 python3 --version 检查。
