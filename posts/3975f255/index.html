.net框架是微软战略性的一款框架，.net出生就对标Java，在生态上，一点也不亚于Java。目前很多软件都是基于.net开发的，Windows从win vista就开始自带.net运行库，并且运行高版本的.net，系统没有就会自动下载，但是考虑到我们国家的网络环境，很多机器下载非常慢，所以自带一个离线包安装是不错的选择。

Windows Vista 自带了.net framework 3.0

Windows 7 自带.net Framework 3.5

Windows 8，10 自带.net Framework 4.5

Windows 11 自带.net Framework 4.8

目前，只需要电脑上有3.x版本和4.x版本，基本上就能运行所有.net程序了。Windows10用户基本上无需再次安装.net，Windows7用户，装一个4.0版本以上的就行。

如果需要.net Framework最新的版本请在“dotNet离线独立包”文件夹内下载安装，但是我觉得没必要安装最新版，大型软件开发商或开发软件的个人都没有那么快更新，你着什么急！

安装使用方法：

关闭所有杀毒软件、安全软件等

1、在本文末尾，下载软件后，解压，即可得到如下文件和文件夹

2、进入运行库文件夹，以管理员身份运行exe文件，点击下一步

3、选择组件，点击下一步

4、安装ing，等待

5、安装完成，点击“完成”，重启电脑

安装就是这么简单，这些组件确实是安装系统必备的组件，装机必不可少的框架，想要一个一个安装略显繁琐，偶尔不正常关机（蓝屏、死机等）会导致组件缺失，用这个软件一键安装就解决了。觉得有用就下载吧！
