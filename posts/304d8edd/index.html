DBTool：全功能开源桌面数据库客户端

更新于2026-09-05|toolssoftware
|总字数:733|阅读时长:2分钟|浏览量:

官方仓库：https://github.com/achi777/db-tool
官网下载：https://codemake.co/software

DBTool 是一款免费、开源、跨平台的桌面数据库管理工具，支持 PostgreSQL、MySQL、MariaDB、SQLite、Oracle、SQL Server 六大主流数据库，使用 Electron + React + TypeScript 构建。

定位类似 Navicat、DataGrip、DBeaver 等商业工具，但完全本地运行、无遥测、无账号、无云同步。

核心特点

  • 统一界面管理六大数据库
  • 密码使用系统钥匙串加密存储（Windows DPAPI / macOS Keychain / Linux libsecret）
  • 真正的服务端分页（适合百万级甚至更大数据量）
  • 可视化表设计器 + 实时 DDL 预览
  • 可视化视图构建器（拖拽联表）
  • ER 图支持外键编辑
  • 多查询标签页 + 智能自动补全（CodeMirror 6）
  • 可编辑数据网格（完整 CRUD，事务提交）
  • 导入/导出：CSV、JSON、Excel、SQL
  • 深色 / 浅色主题
  • 完整快捷键支持（按 F1 查看）

主要功能一览

类别 功能说明
连接管理 保存连接、系统钥匙串加密密码、对象树浏览
SQL 编辑 多标签、Schema 感知自动补全、查询历史
数据浏览 服务端分页、排序、类型感知过滤、可视化 AND/OR 过滤器
数据编辑 单元格直接编辑、批量提交（事务）、自动处理自增字段
表设计 可视化设计器、列/主键/外键/索引管理、实时 DDL
视图 / 函数 创建、编辑、删除（按引擎差异处理）
数据迁移 跨引擎数据传输、多种格式导入导出
其他 ER 图、主题切换、快捷键、原生菜单栏

支持的数据库

数据库 最低版本 备注
PostgreSQL 13+ 支持物化视图、枚举、扩展、多种索引类型
MySQL 5.7+ -
MariaDB 10.3+ 支持独立序列
SQLite 3 文件型，无需服务器
Oracle 12.1+ Thin / Thick 模式
SQL Server 2012+ 支持 Windows 认证

下载与安装

前往 Releases 下载对应平台安装包：

  • Windows：NSIS 安装包 或 便携版 .exe（未签名，首次运行可能提示 SmartScreen）
  • macOS：.dmg（未签名，需右键打开或执行 xattr -dr com.apple.quarantine /Applications/DBTool.app）
  • Linux：AppImage

快速上手

  1. 启动 DBTool
  2. 点击 Add connection，选择数据库类型并填写连接信息
  3. 测试连接 → 保存 → 连接
  4. 在对象树中点击表，即可查看可编辑数据网格
  5. 在 SQL 编辑器中写查询，按 Ctrl+Enter（macOS 为 ⌘+Enter）执行

总结：DBTool 是目前开源数据库客户端中功能比较完整的选择之一，尤其适合需要同时管理多种数据库、又希望完全本地运行、无云依赖的用户。界面和操作习惯接近主流商业工具，值得一试。
