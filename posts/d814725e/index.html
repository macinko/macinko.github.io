agent-skill-manager (asm) 详细部署教程

项目概述

agent-skill-manager（简称 asm）是一个专为 AI 编程代理设计的通用技能管理器。它是一个可脚本化的 CLI 工具，支持跨 21 种 AI 编程工具（如 Claude Code、Codex、Cursor 等）安装、搜索、审计和组织技能 。

核心特性：

  • 跨 21 个提供商管理技能，统一视图
  • 支持 --json 和 --yes 标志，适合非交互式自动化使用
  • 安装前进行安全扫描
  • 提供可选的 TUI 界面用于本地浏览
  • MIT 许可证，无账户要求，无遥测

部署前准备

系统要求

项目 要求
操作系统 Windows / macOS / Linux
Node.js 22+（安装脚本要求 18.0.0+）
npm 9.0.0+
终端 支持 ANSI 颜色的终端

常用命令

技能管理

任务 命令
列出所有技能 asm list --json
搜索技能 asm search "code review" --json
安装技能 asm install code-review -p claude --yes --json
卸载技能 asm uninstall old-skill --yes
检查技能详情 asm inspect my-skill --json

审计与统计

任务 命令
移除重复技能 asm audit --yes
查找功能重叠 asm audit overlap
查看上下文成本 asm stats --tokens
安全审计 asm audit security github:user/repo
常驻审计 asm audit residency

技能开发

任务 命令
创建新技能 asm init my-skill -p claude
实时开发链接 asm link ./my-skill -p claude
发布到注册表 asm publish ./my-skill --yes
评估质量 asm eval ./my-skill

常见问题排查

问题 症状 解决方案
命令未找到 asm: command not found 确保 npm 全局 bin 目录在 PATH 中，运行 npm prefix -g 查看路径
多个二进制文件冲突 版本不匹配警告 运行 asm doctor 诊断，移除旧版本
权限错误 EACCES 错误 使用 sudo 或配置 npm 全局目录权限
技能未显示 asm list 为空 检查提供商是否启用，运行 asm config show
安装失败 网络超时 检查网络连接，确保 git 已安装并在 PATH 中
