Mac Performance Monitor：菜单栏 macOS 性能分析器

更新于2026-09-13|osmacos
|总字数:1.4k|阅读时长:4分钟|浏览量:

📌 项目简介

Mac Performance Monitor 是一个位于菜单栏的 macOS 性能分析器与日志记录工具。它能持续记录 CPU、内存压力、GPU、网络、磁盘、电池和每个进程的使用情况到本地 SQLite 数据库，并提供仪表盘、进程探索器、磁盘映射、硬件清单和泄漏检测等深度诊断功能。它免费、开源、无遥测，所有数据留在本地。

⚙️ 首次使用与配置

  1. 启动应用：从“启动台”或“应用程序”文件夹中打开 Mac Performance Monitor。
  2. 菜单栏图标：应用启动后，你会在屏幕右上角的菜单栏中看到一个新的图标（一个仪表盘样式）。点击它，可以快速查看实时的 CPU、内存、GPU 等数据概览。
  3. 打开主面板：点击菜单栏图标，然后选择“打开仪表盘” (Open Dashboard) 或类似选项，即可进入主应用窗口。主窗口包含以下主要标签页：
    • 仪表盘 (Dashboard)：显示系统“健康”摘要、压力时间线、内存细分和交换趋势。
    • 进程 (Process)：查看所有运行中的进程，并可按 CPU、内存等排序。双击进程可查看详细随时间变化的资源占用。
    • 磁盘 (Disk)：监控磁盘吞吐量、IOPS、延迟，并查看启动盘的可用空间趋势。磁盘映射 (Disk Map) 功能可以扫描文件夹并以矩形树图展示空间占用。
    • GPU：查看 GPU 设备利用率、功耗，以及哪些进程在使用 GPU (支持 Apple Silicon)。能识别 AI 运行时 (如 Ollama、MLX)。
    • 硬件 (Hardware)：以树形图查看 Mac 的完整硬件清单，包括芯片、显示器、电池健康、USB/Thunderbolt 设备等。
    • 分析 (Analytics)：自定义时间范围，为特定进程创建性能图表。

🔧 功能亮点与使用建议

  • 泄漏检测与提醒：应用会标记内存占用持续增长的进程，并在出现关键内存压力、持续使用交换空间时发送通知 (默认静音，可在设置中调整)。
  • 进程组 (Process Groups)：你可以将相关的应用及其辅助进程 (例如 Chrome 的所有子进程) 归为一个“堆栈”，查看它们的总内存占用。
  • 深度诊断 (Insights)：利用可更新的检查包，应用能解释某个进程是什么以及其行为是否正常。
  • 隐私保护：所有记录的数据均保存在本地 SQLite 数据库中，不会上传至任何服务器。你可以在应用设置中管理历史数据的记录和清除。
  • 自动更新：通过 Homebrew 或 PKG 安装后，应用内置了 Sparkle 更新框架，会自动检查并安装新版本，无需手动下载。

🛠️ 常见问题与故障排除

  • Q: 安装时提示“无法打开，因为无法验证开发者”？
    A: 此应用已通过 Apple 公证，正常情况下不会出现此提示。若出现，请尝试重新下载 PKG 文件，或在“系统设置” -> “隐私与安全性”中，允许来自“已识别的开发者”的应用。
  • Q: 应用需要哪些系统权限？
    A: 为了监控网络、磁盘和系统进程，应用可能会请求“完全磁盘访问权限”或“系统事件”权限。请在系统提示时授予，或在“系统设置” -> “隐私与安全性”中手动启用。这些权限仅用于本地监控。
  • Q: 菜单栏图标不显示？
    A: 这可能是因为菜单栏空间不足。尝试关闭一些其他菜单栏应用，或重启 Mac Performance Monitor 应用。
  • Q: 如何卸载应用？
    A: 如果你通过 Homebrew 安装，执行 brew uninstall --cask mac-performance-monitor。如果是通过 PKG 安装，直接将“应用程序”文件夹中的 Mac Performance Monitor.app 拖入废纸篓即可。所有日志和配置数据通常存储在 ~/Library/Application Support/Mac Performance Monitor/ 和 ~/Library/Preferences/ 下。

💎 总结

mac-performance-monitor 的“部署”过程非常直接，普通用户通过 Homebrew Cask 或 下载 PKG 即可完成安装。它是一款功能强大但数据完全本地化的性能诊断工具，适合希望深入了解 Mac 运行状态、排查性能问题的用户。对于开发者，它也提供了清晰的源码结构和构建方式。
