Project NOMAD 部署教程：离线优先的知识与教育服务器

更新于2026-09-05|aitool

📋 部署前准备

  1. 操作系统: 需要一个 基于Debian的系统（强烈推荐 Ubuntu 26.04 LTS，也支持 24.04 LTS 和 Debian 12）。
  2. 硬件要求:
    • 最低配置: 2GHz双核CPU, 4GB内存, 5GB存储空间。
    • 推荐配置（以运行AI功能）: 如AMD Ryzen 7或Intel i7 CPU, 32GB内存, 至少250GB SSD, 推荐NVIDIA RTX 3060或同等显卡（显存越大，能运行的AI模型越大）。
  3. 网络: 安装过程中需要稳定的互联网连接以下载依赖。
  4. 权限: 需要具有 sudo/root 权限来执行安装脚本。

⚙️ 首次启动与配置

  1. 访问界面: 浏览器打开 http://localhost:8080 进入“指挥中心”（Command Center）管理界面。
  2. 设置向导: 首次访问会引导你进行初始配置，例如选择要下载的内容集合（如维基百科、Khan Academy课程等）。
  3. 安装应用: 通过界面内的“供应仓库”（Supply Depot），你可以一键安装各种工具，例如：
    • Kiwix: 用于离线阅读维基百科、医学参考等。
    • Kolibri: 用于访问Khan Academy等教育课程。
    • Ollama + Qdrant: 用于运行本地AI聊天和文档语义搜索（RAG）。
    • ProtoMaps: 用于下载和浏览离线地图。
    • CyberChef: 用于数据加密、编码和分析。

🔧 重要管理命令

安装完成后，在宿主机的 /opt/project-nomad 目录下会生成一些辅助管理脚本：

  • 启动所有容器:
    sudo bash /opt/project-nomad/start_nomad.sh

  • 停止所有容器:
    sudo bash /opt/project-nomad/stop_nomad.sh

  • 更新指挥中心核心（注意：此命令仅更新管理核心，不更新通过应用商店安装的工具）:
    sudo bash /opt/project-nomad/update_nomad.sh

🔐 安全与网络说明

  • 无内置认证: 项目默认没有用户认证系统，设计为在受信任的本地网络中开放使用。
  • 网络访问: 建议通过本地网络防火墙或路由器设置来控制访问，强烈不建议将其直接暴露在公共互联网上。
  • 隐私: NOMAD 没有任何内置遥测。除安装和主动下载内容外，不要求网络连接。其互联网连接测试默认会访问 https://1.1.1.1，但该行为可在UI或环境变量中配置。

🧪 测试自动更新（开发者/高级用户）

NOMAD支持配置自动更新核心（仅小版本和补丁）。管理员可以在 admin/ 目录下运行 node ace auto-update:dry-run 命令配合不同参数，来模拟测试更新决策流程，而不会实际执行更新。

部署后，你就拥有一个强大的离线知识中心了。
