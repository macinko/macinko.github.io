📋 部署前的准备

  • Python 环境：需要 Python 3.10 到 3.13。官方明确说明 Python 3.14 还不支持，用 3.14 可能会遇到依赖安装失败的问题。
  • 包管理器：推荐使用 uv，它比传统的 pip 更快，也能更好地处理依赖隔离。
  • 目标客户端：Claude Desktop、Codex、Cursor 或任何支持 MCP 的客户端。

第三步：重启并验证

保存配置文件后，完全退出 Claude Desktop（不是简单关闭窗口），然后重新打开。首次启动时，uvx 会自动下载并安装这个服务器，可能需要等待 30-60 秒。

之后，你可以试着问 Claude：“列出可用的 TradingView 工具”。如果看到 top_gainers、backtest_strategy 等工具名称，就说明部署成功了。

🔧 常见问题与解决

  • Windows 上首次启动超时：如果日志里出现 MCP error -32001: Request timed out，大概率是 Python 3.14 的问题。按上面的配置，确保参数里有 --python 3.13。
  • macOS 上提示 command not found：macOS 的 GUI 应用（如 Claude Desktop）可能找不到 uvx 的路径。需要把 command 改成 uvx 的完整路径，比如 /Users/你的用户名/.local/bin/uvx。
  • 工具没有出现在 Claude 里：检查配置文件的 JSON 语法是否正确（可以用在线校验工具）；确保在配置里用了绝对路径；修改配置后要彻底重启 Claude Desktop。

📱 进阶玩法：通过 Telegram 使用

如果你还想在手机上通过 Telegram 调用这些工具，可以用 OpenClaw 这个自托管 AI 网关，把 MCP 服务器包装一下接进去。官方文档里提供了完整的命令，核心步骤是：安装 uv 和 tradingview-mcp-server → 配置 OpenClaw 的 Telegram 频道 → 把 trading.py 包装脚本下载到 ~/.openclaw/tools/ → 启动网关。这样你在 Telegram 里发消息，就能调用底层的分析工具了。
