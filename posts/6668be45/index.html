X Money 正式开放｜X Card 权益全解析与开通条件

更新于2026-09-05|globalbank
|总字数:1.1k|阅读时长:3分钟|浏览量:

今天，X Money 官宣已经向美区 Premium / Premium+ 全量开放（部分日区也收到了入口邀请）。这篇就带大家完整了解一下 X Money 的核心权益、申请条件以及开通 X Card 的流程。

一、X Money 有哪些权益？

先说大家最关心的。

X Money 是整合在 X App 内的资金账户和支付服务，底层银行服务由 Cross River Bank 提供。

目前核心权益包括：

Premium：4.00% APY

Premium+：6.00% APY

Premium 用户满足 34 天内累计 $1,000 Qualifying Deposit，利率可升至 6.00% APY

X Card 符合条件的消费享 3% Cashback，无境外交易手续费

支持全球 ATM 取现，符合条件的 ATM 费用可返还

支持 Direct Deposit、ACH

符合条件并参与 Cash Sweep Program 后，资金可分散至多家 FDIC-insured institutions，合计 FDIC 保险覆盖最高可达 $10M，具体资格和额度以账户条款为准

注意：纽约居民目前不享受 APY；利率也会随时调整，以 X Money 页面显示为准。

二、有 SSN / ITIN，怎么申请 X Money？

目前官方开户要求会核验个人身份信息，包括 姓名、出生日期、美国住宅地址、手机号以及税务身份信息。

如果你有 SSN，这是目前简单的申请路径：

X App → Money → Get Started → 输入法定姓名、出生日期、美国住宅地址、已验证的美国手机号、SSN → 必要时上传政府签发证件并完成人脸验证 → 同意账户协议 → 等待审核

完成后就可以直接申请到卡片，开户即送15或25刀

已有 ITIN → X Money 申请

1.ITIN

从目前看到的案例来看，已经有一定美国信用/身份记录的 ITIN 用户，通过验证的案例居多。(这可能是因为已有信用记录的用户，其姓名、地址等信息已经进入美国信用及身份验证数据库，系统更容易完成自动匹配。)

而刚签发的新 ITIN，不建议下号后马上申请。

ITIN 刚下来时，虽然 IRS 已经签发了这个号码，但并不代表用于身份验证的其他数据库已经同步建立了足够完整的记录。

因此，新 ITIN 直接申请时，可能出现自动身份匹配不到的情况，可能随后进入进一步的 SSN Identity Verification。

如果 ITIN 刚下号、美国信用记录又比较空白，建议不要急着申请。

2. 美国手机号& 网络环境

在 VPN 环境下 进入x money申请入口 会识别或提示网络环境异常，我实测使用美国手机卡自身的漫游数据进入时会直接显示Get start。(也有家宽ip非常干净能进入口的，但样本量太少，所以以美国电话卡漫游流量为优先选项)

另外，X Premium 本身要求验证手机号，X 官方也明确要求 Premium 用户在注册过程中确认手机号。

所以建议使用自己长期持有、能够稳定接收 OTP 验证码的美国手机号。目前比较常见的选择包括：

Tello、Red Pocket、Ultra Mobile、T-Mobile

3. 正式申请

按页面填写：

Legal Name → 出生日期 → ITIN 后四位 → 身份/地址匹配 → 提交申请

从现在的成功案例来看，已有可匹配记录的 ITIN，流程通常比较快，部分用户填写姓名、出生日期和 ITIN 后四位后即可完成验证。

如果提交后跳转到 SSN Identity Verification，说明自动身份匹配可能没有完成，不要反复修改姓名、地址或更换账号尝试。

真正容易卡的主要就两个：ITIN 记录太薄，或者网络环境触发风控。

最后

单看现在的权益，6% APY + 3% Cashback + 无境外交易手续费，X Money 已经很能打了。

但我觉得它最好玩的地方，是从社交、创作者收入，到转账、储蓄和消费，如果这些最终全部在一个 X 账号里完成，那 X Money 才刚刚开始。

Everything App 最重要的一块拼图，现在算是正式落下来了。
