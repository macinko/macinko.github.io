一台 MacBook 连接 Linux、Mac mini 和 Windows：Tailscale

更新于2026-09-13|webnat
|总字数:6.9k|阅读时长:22分钟|浏览量:

差生文具多，这句话放我身上很准。设备越买越多，可我一出门，还是习惯只抱着一台 MacBook 去咖啡馆办公。电脑可以多，包里不能太重。

家里的设备也不能吃灰。Linux AI PC 负责跑模型，Mac mini 适合长期在线，Windows 留着运行专属软件。既然钱都花了，我希望人在咖啡馆时，它们也能继续干活。

我的需求就变成了：MacBook 留在手边，家里的 Linux、Mac mini 和 Windows 随时都能连。 我最后选了 Tailscale，把几台设备接进同一张私人网络。

这篇先带你看懂 Tailscale 这个软件有什么功能，再分别完成三条连接：

最后，你会得到一张以 MacBook 为中心的私人设备网。三台目标电脑使用不同系统，也不必在同一个 Wi-Fi 下。

本文按 Tailscale macOS 界面和官方文档整理。客户端更新后，图标和菜单名称可能移动；只要找到文中写出的功能名即可，不必逐像素照着截图点。

一、先把名字说对：本文讲的是 Tailscale

Tailscale 和 Telnet 不是同一个东西。

  • Tailscale 是组网软件，用来让自己的设备安全地互相找到。
  • Telnet 是一种年代很久的远程连接协议，内容通常不加密，新手不建议拿它远程控制电脑。

本文从头到尾使用的是 Tailscale。你可以把它想成一个只有自己设备才能进入的私人网络：MacBook、Linux、Mac mini 和 Windows 安装软件并登录同一账号后，会像坐在同一张桌子旁边一样互相看见。

个人设备可以先从免费计划开始，不需要为了这篇教程购买服务器或公网 IP。免费范围和设备数量以后可能调整，准备加入更多成员或大量设备时再看官方价格页。

Tailscale 自己负责什么？

Tailscale 主要解决两个问题：

  1. 让四台电脑互相找到；
  2. 在电脑之间建立加密网络。

它不会凭空替你生成远程桌面。你还要根据任务选择 SSH、macOS 屏幕共享或 Windows 远程桌面。Tailscale 负责把路铺好，这些工具负责让你在路上干活。

二、Tailscale 软件里的功能，先全部看一遍

第一次打开 Tailscale，你会看到一堆英文。先别急着连设备，这一节把教程会用到的功能逐个说清楚。

1. Devices：查看自己的设备

Devices 是设备列表，也是你最常打开的页面。每一台登录同一账号的电脑都会出现在这里。

你需要重点看三项：

  • 设备名前面的绿色圆点：代表设备当前在线；
  • 100.x.x.x 形式的地址：Tailscale 给设备分配的私人 IP；
  • 设备名称：例如 punk-linux、punk-macmini、punk-windows。

设备名尽量起得直白。过一个月以后，desktop-a3f9 很难认，punk-linux 一眼就知道是哪台电脑。

2. Taildrop：在设备之间传文件

选中一台设备后，右侧的 Taildrop 可以向它发送文件。点击 Select a File，或者把文件拖进虚线框即可。

比如你在 MacBook 上下载了一个模型配置文件，可以直接 Taildrop 到 Linux；在 Windows 导出了一份表格，也能传回 MacBook。它适合临时传文件，不用再给自己发微信或搭一套网盘。

3. Ping：测试两台电脑能不能互相找到

Ping 的意思是“敲一下门，看看对方有没有回应”。点击 Ping device 后，如果能看到延迟时间，说明两台设备已经连通。

Ping 成功只证明网络通了。SSH 或远程桌面仍然连接不上时，继续检查目标电脑有没有开启对应功能。

4. Details：查看设备详情

Details 会显示选中设备的系统、地址、版本、密钥到期时间等信息。排错时先看这里，可以确认你选中的是 Linux、macOS 还是 Windows。

5. Exit Nodes：把另一台电脑当成网络出口

Exit Nodes 是进阶功能。开启以后，你可以让 MacBook 的上网流量先经过另一台 Tailscale 设备，再访问互联网。

比如你在外面出差，希望临时使用家里的网络出口，可以把家里长期在线的 Mac mini 配成 Exit Node。第一次连接设备时先跳过它，基础功能跑通后再研究。

6. Settings：软件设置

右上角的滑杆图标通常会进入设置。这里能管理开机启动、账号、DNS、更新和其他高级选项。小白阶段只需要确认两件事：Tailscale 已连接，并且软件会跟随系统启动。

7. Machines：在网页里管理整张网

桌面客户端适合看在线状态和传文件，改设备名、批准路由、删除旧设备这些操作，要去

Machines 管理页面

。登录后看到的每一行，就是一台已经加入 Tailnet 的设备。

这两个入口很容易混：Devices 是 Mac 上的客户端页面，Machines 是浏览器里的管理后台。 平时连接设备看 Devices，需要改整张网的配置再开 Machines。

8. Bug Report：出问题时生成诊断信息

不同版本的图标位置可能变化，甲虫图标通常用于问题报告或诊断。普通连接失败先按文末的排错顺序检查；准备向官方支持反馈时，再生成诊断信息。诊断内容不要直接贴到公开平台。

看到四台设备都有绿色圆点，才进入后面的远程连接。

1. Tailnet

Tailnet 是你的 Tailscale 私人设备网。同一账号下的 MacBook、Linux、Mac mini 和 Windows，会进入同一个 Tailnet。

4. Ping

Ping 用来确认网络通不通。它不会登录电脑，也不会修改文件。

5. SSH

SSH 是一种加密远程命令工具。你在 MacBook 的终端里输入命令，就能进入 Linux、Mac mini 或开启了 SSH 的 Windows。

SSH 连接成功后，你看到的是文字终端，不是对方的桌面画面。

6. 远程桌面

远程桌面会把另一台电脑的图形界面显示在 MacBook 上。Mac mini 可以用 macOS 自带的屏幕共享，Windows 可以用 Windows App。

7. Terminal、PowerShell

Terminal 是 macOS 和 Linux 常用的命令窗口。PowerShell 是 Windows 常用的命令窗口。

8. sudo

sudo 的意思是“用管理员权限执行接下来的命令”。Linux 安装软件或启动系统服务时经常需要它。

输入 sudo 命令后，系统可能要求你输入 Linux 登录密码。输入时屏幕没有星号，这是正常现象，输完按回车即可。

2. 用 Taildrop 传文件

在 Tailscale 的 Devices 里选中目标设备，把文件拖进 Taildrop。接收设备通常会把文件放进下载目录。部分版本需要先到管理后台的 General 设置中开启 Send Files；界面里已经出现 Taildrop 时，直接发送一个小文件测试即可。

3. 把 Mac mini 当作长期在线设备

Mac mini 适合长期运行下载、自动化、文件服务或轻量程序。出门后从 MacBook 通过屏幕共享或 SSH 继续操作。

4. 使用 Windows 专属软件

一些财务、工程或企业软件只支持 Windows。你可以把它们留在 Windows 电脑上，通过 MacBook 远程桌面使用。

5. 临时使用家里的网络出口

把长期在线的设备配置成 Exit Node 后，MacBook 可以选择它作为上网出口。第十三节会用 Mac mini 跑一遍完整步骤。

手机也能加入同一张网。在 iPhone 或 Android 安装 Tailscale，登录同一个账号，就能访问 Linux 上的 AI 网页、接收 Taildrop 文件或选择家里的出口节点。

十、传文件、打开文件和自动同步，别混成一件事

设备连通以后，最容易产生的误会是“能传文件，就等于文件会自动同步”。这三种需求用的工具不同，先选对结果，再选工具。

1. 只送一次：Taildrop

安装包、截图、临时文档只需要送到另一台电脑一次，就用 Taildrop。发送完成后，两边各有一份；你修改 MacBook 上的原文件，接收设备那份不会跟着变化。

2. 文件仍放在目标电脑：SMB 文件共享

3. 两边文件夹自动一致：使用同步软件

如果你想让 MacBook 新建的文件自动出现在 Windows，Windows 修改后又传回 MacBook，需要 Syncthing 一类同步软件。Tailscale 负责让设备互相找到，同步软件负责监视文件变化。

第一次只同步一个测试目录，不要直接选择桌面、照片库或整个文档目录。同步会传播删除和损坏，重要资料还要保留一份不参与同步的备份。

Taildrop 管一次发送，SMB 打开远端原文件，同步软件维持两个文件夹。

十二、打印机和摄像头装不了 Tailscale，怎么办？

这属于可选玩法。打印机、老摄像头和部分 NAS 无法安装 Tailscale，但它们所在的家庭网络里有一台长期在线的 Linux 或 Mac mini，就能让这台常开设备充当入口。Tailscale 把它叫作子网路由器。

能直接安装 Tailscale 的 NAS，优先直接安装。只有目标设备无法安装客户端，而且你确实需要从外面访问它，才配置子网路由。

十三、把 Mac mini 设成 Exit Node

子网路由器让 MacBook 进入家里的局域网，Exit Node 会让 MacBook 的普通上网流量经过另一台设备。你只想 SSH、传文件或远程桌面时，不需要开启 Exit Node。

Mac mini 长期在线，很适合做家庭出口。先在 Mac mini 的 Tailscale 设置中找到 Exit Node，开启 Run Exit Node 或同义选项。然后打开 Machines 管理页面，找到 Mac mini，在路由设置中批准它作为出口节点。

回到 MacBook，打开 Tailscale 的 Exit Nodes，选择 punk-macmini。再访问一个显示公网 IP 的网站；如果地址变成 Mac mini 所在网络的公网 IP，说明出口已经生效。

不再需要时，回到 Exit Nodes 选择 None。这个动作只让 MacBook 恢复使用眼前的网络，不会把 Mac mini 从 Tailnet 中删除。

十四、出门前做一次无人值守测试

同一个 Wi-Fi 下连接成功，只能证明家里的场景能用。真正准备远程工作前，把 MacBook 切到手机热点，让它与三台目标电脑离开同一个局域网，然后依次检查：

  1. tailscale ping 仍能找到三台设备；
  2. Mac mini 锁屏后还能重新进入屏幕共享；
  3. Windows 重启后会自动回到 Tailscale 在线状态；
  4. Linux 重启后 SSH 服务和 Tailscale 都会启动；
  5. 三台设备进入睡眠后，哪些还能唤醒，哪些会彻底离线。

Tailscale 没有隔空把关机电脑开起来的通用按钮。Wake-on-LAN 需要设备、网络和家中常开节点共同支持。要长期无人照看，最稳的办法仍然是提前测试重启、锁屏和睡眠，不要等人已经出门才发现电脑离线。

十六、最常见的 9 个问题

1. Devices 里少了一台电脑

先检查那台电脑是否安装并打开 Tailscale，再核对四台电脑是否登录了同一个账号。

2. 设备是灰色的

灰色通常代表设备离线。检查目标电脑是否关机、休眠、断网，或者 Tailscale 是否退出。

3. Ping 成功，SSH 失败

网络已经通了，问题通常在目标电脑：SSH 没安装、服务没启动、用户名错误或防火墙拦截。

4. Mac mini 经常连不上

检查 Mac mini 是否进入深度睡眠。长期作为远程设备使用时，需要合理调整电源和睡眠设置。

5. Windows App 无法连接 Windows Home

Windows Home 默认不能作为微软 RDP 的被控端。可以升级版本，或者改用其他远程桌面工具。

6. 为什么 Tailscale 在线，却看不到桌面？

Tailscale 只提供设备之间的网络。你仍要在 Mac mini 开启屏幕共享，或者在 Windows 开启远程桌面。

7. 应该使用设备名还是 IP？

先用设备名，更容易记。设备名解析失败时，再复制 Devices 里的 100.x.x.x 地址测试。

9. 开着其他 VPN 或代理时突然失效

公司 VPN、商业 VPN、代理工具和 Tailscale 都会改动网络路径。先记下当前状态，只暂停其中一款，再重新运行 tailscale ping。一次只改一个变量，恢复后才能知道冲突来自哪里。

十七、安全提醒

  • 只把自己的设备加入 Tailnet；
  • Tailscale 账号开启双重验证；
  • Mac、Linux 和 Windows 都使用强密码；
  • 不要把真实账号、密码或完整设备 IP 发到公开平台；
  • 远程桌面和 SSH 只给需要的账号开放；
  • 长期不用的旧设备从 Tailscale 管理后台移除。

完成这套配置后，你平时只需要带 MacBook。Linux 负责算力，Mac mini 保持在线，Windows 运行专属软件，三台电脑都从 Tailscale 的 Devices 页面进入。

今天先完成最小闭环：四台设备同账号登录 → 三台目标设备 Ping 成功 → 任选一台完成第一次远程连接。
