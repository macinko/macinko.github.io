tick-stock-panel (TSP) 是一个自托管、零运维的A股量化工作台

更新于2026-09-05|globalaitoolinvest
|总字数:1.3k|阅读时长:4分钟|浏览量:

tick-stock-panel (TSP) 是一个自托管、零运维的A股量化工作台，集成了选股、监控、回测等核心功能。它采用插件化数据源设计，并支持LLM辅助分析。

以下是一份详细的部署教程，主要包含两种方式：开发模式 (推荐二次开发) 和 Docker部署 (最省心)。

📋 部署前准备

无论选择哪种方式，请确保你的系统满足以下基本要求：

  • 操作系统: macOS, Linux, 或 Windows。
  • Python: 版本 3.11 或更高。
  • Node.js: 版本 20 或更高。
  • 包管理工具:
    • uv (Python包管理): 用于后端依赖管理。
    • pnpm (Node.js包管理): 用于前端依赖管理。可以通过 npm i -g pnpm 全局安装。

🚀 方式一：开发模式 (Dev Mode)

此方式适合希望进行二次开发或自定义配置的用户，前后端分离运行，便于调试。

🏁 跑起来后的第一次使用

首次启动成功后，建议按以下步骤完成初始化配置：

  1. 检测数据源能力：进入 设置 → 凭据与能力，点击 “重新检测” 按钮。等待检测完成，确认显示的数据源档位（如 None/Free/Starter等）和能力路由矩阵符合你的预期。
  2. 拉取基础数据：在 设置 页面，找到并点击 “立即跑盘后管道” 按钮。此操作会拉取日K线数据并计算生成 enriched 指标表（包含MA、MACD、RSI等68列指标）。数据下载速度取决于你的网络和数据源，请耐心等待。
  3. 开始探索：
    • 在 自选 页面添加你关注的股票。
    • 进入 选股 页面，点击内置策略卡片进行全市场扫描。
    • 进入 回测 页面，选择策略和时间区间，体验回测引擎。
    • 在 监控中心 配置个性化监控规则。

🔧 高级配置与扩展

  • 配置详情: 所有 .env 配置项（如服务端口、AI接口、数据目录等）的详细说明，请查阅项目文档 docs/configuration.md。
  • 自定义数据源: TSP支持插件化数据源。如果你想接入其他数据源，可以参考 docs/custom-data-source.md 中的能力路由契约和YAML配置示例。
  • 更新代码: 如果使用Docker部署，拉取最新代码后重新执行 docker compose up --build 即可。如果是开发模式，拉取代码后重新运行 ./dev.sh 或 .\dev.ps1。

❓ 常见问题

  • 数据不显示或报错: 首先检查网络连接，然后确认 .env 中的数据源API Key是否正确。进入 设置 → 凭据与能力 重新检测状态。
  • 端口被占用: 可以在 .env 文件中修改 PORT 变量（后端端口）和 VITE_BACKEND_URL（前端连接的后端地址），然后重启服务。
  • 回测速度慢: 回测是计算密集型任务，尤其是全市场回测。可以适当缩小回测的时间范围或股票池。
  • AI功能不可用: 请确保在 .env 中正确配置了 AI_API_KEY 和 AI_BASE_URL（如果使用非OpenAI官方接口，如DeepSeek、Ollama）。

至此，你已经完成了 tick-stock-panel 的全部部署。这是一个功能非常丰富的系统，建议从选股和回测这两个核心模块开始熟悉，逐步探索其更强大的监控和分析能力。如有更深入的问题，可以查阅项目 docs/ 目录下的详细文档或在GitHub仓库提交Issue。
