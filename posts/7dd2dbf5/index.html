TTT Editor 完整部署教程：终端里的现代化IDE

更新于2026-09-05|toolssoftware
|总字数:1.5k|阅读时长:5分钟|浏览量:

TTT Editor 是一款在终端中运行的、功能完整的代码编辑器，旨在成为 VS Code、Zed 和 Sublime Text 的替代品。它提供了图形化界面般的体验（如鼠标支持、侧边栏、标签页），但完全运行于终端环境。它采用 Go 语言编写，是一个单一二进制文件，零配置即可启动。

本教程将指导你通过多种方式完成 TTT 的安装、配置和运行。

📦 第一步：选择你的安装方式

TTT 支持多种安装方式，请根据你的操作系统和使用习惯选择最合适的一种。

1.2 Linux (安装脚本)

1.4 NixOS

1.5 使用 Go 安装 (Go 1.18+)

确保 $GOPATH/bin（默认 ~/go/bin）在你的 PATH 环境变量中。

1.6 直接下载预编译二进制文件

访问 Releases 页面，下载适用于你平台（Linux、macOS、Windows）的二进制文件，将其设置为可执行文件，并放入 PATH 目录。

🚀 第二步：启动与基本使用

2.1 快速启动

2.2 核心界面导航

  • 侧边栏：通过快捷键或鼠标点击切换不同面板。
    • Ctrl+K E - 文件浏览器
    • Ctrl+K F - 搜索面板 (依赖 ripgrep)
    • Ctrl+K C - Git 变更面板
    • 命令面板中输入 Outline - 符号大纲
  • 底部面板：Ctrl+K B 切换。
    • 终端：Ctrl+T 切换，Alt+T 全屏，Ctrl+K T 新建终端标签页。
    • 问题：显示 LSP 诊断信息。
  • 命令面板：Ctrl+P 打开，可执行所有命令。
  • 标签页管理：
    • Ctrl+W 关闭当前标签页。
    • Alt+. / Alt+, 切换到下一个/上一个标签页。
    • 点击已打开的标签页可固定它。

⚙️ 第三步：配置与定制

TTT 的配置文件位于 ~/.config/ttt/ 目录下。

3.1 核心配置文件

  • settings.json：编辑器设置（如 tabSize, wordWrap, theme 等）。
  • keybindings.json：自定义快捷键（使用 VS Code 风格的键位格式）。
  • themes/\*.json：自定义颜色主题。

3.2 图形化设置

大多数设置可以通过图形界面修改：View → Settings (Ctrl+K ,) 打开设置表单，修改后点击 Apply 应用。部分设置（标记为 restart）需要重启编辑器生效。

3.3 主题切换

TTT 内置了 10 种主题（如 One Dark, Solarized Dark）。通过 View → Switch Theme 或命令面板实时切换。要自定义主题，可将内置主题文件复制到 ~/.config/ttt/themes/ 目录下修改，并在 settings.json 中指定 "theme": "你的主题文件名"。

🔌 第四步：扩展功能（插件与 LSP）

TTT 通过 Lua 插件系统扩展功能，并内置了对语言服务器协议（LSP）的支持。

4.1 安装与使用插件

  1. 打开插件面板：在侧边栏或命令面板中找到 Plugins 面板。
  2. 浏览与安装：从社区注册表浏览插件，或使用 Plugins: Install from URL 从 Git 仓库安装。
  3. 管理插件：在已安装列表中可以启用/禁用、更新或卸载插件。
  4. 关键插件：
    • 编辑器模式：Vim Mode 或 Emacs Mode。
    • 语言支持：lsp-go (Go), lsp-python (Python), lsp-typescript (TypeScript/JavaScript) 等，安装插件时会引导你安装对应的语言服务器二进制文件。
    • 工具集成：formatter-prettier, docker-manager, todo-scanner 等。

4.2 配置 LSP

  • LSP 插件安装后，通常会自动启动对应的语言服务器。
  • 状态栏中的语言段会显示服务器状态：◉ 已连接，◌ 启动中，⚠ 失败。点击可打开 OUTPUT 面板查看日志。
  • 可手动在 ~/.config/ttt/settings.json 中自定义 LSP 服务器配置或完全禁用 ("lsp": { "enabled": false })。

🩺 第五步：自动化与测试（--exec 模式）

TTT 提供了强大的脚本化交互能力，非常适合自动化测试或 AI 代理驱动。

5.2 常用 --exec 命令

  • click X Y - 模拟鼠标点击屏幕坐标。
  • key COMBO - 模拟按键，例如 key ctrl+p。
  • type TEXT - 逐字输入文本。
  • exec "Command Name" - 执行命令面板中的命令。
  • wait-for TEXT [timeout=MS] - 等待屏幕上出现特定文本。
  • screenshot PATH / debug PATH - 保存屏幕截图或编辑器调试状态。

📋 常见问题与前提条件

  • 必要依赖：
    • git - 用于 Git 集成功能。
    • ripgrep (rg) - 用于工作区搜索功能。请确保它在你的 PATH 中。
  • 构建依赖：从源码构建需要 Go 1.18 或更高版本。
  • 鼠标支持：确保你的终端模拟器（如 iTerm2, Windows Terminal, GNOME Terminal）支持鼠标事件。
