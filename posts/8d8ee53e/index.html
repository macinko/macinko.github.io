中国专利.skill：专为专利工作设计的 AI 技能

更新于2026-09-05|aiagent
|总字数:1.4k|阅读时长:4分钟|浏览量:

这份详细的部署教程将指引您安装和使用 中国专利.skill——一个专为专利工作设计的AI技能，能够帮助您进行专利点挖掘、撰写交底书（发明/实用新型/外观设计）、通俗解读专利文件、嗅探政策动向，以及辅助审查答复。

该技能的核心价值在于，它将专利工作从零散的文档和流程中整合出来，通过AI辅助系统化地完成从创意到交付的各个环节，并将解读后的专利知识沉淀为个人知识库。它支持多种AI编程助手，通过自然语言即可触发。

整个部署流程非常简单，您只需根据您使用的AI工具选择对应的安装方式，无需复杂的环境配置。

📥 安装方式

该技能是标准的 Agent Skill，支持大多数主流AI编程助手。请根据您的工具选择以下任一方式安装。

通用安装方式 (推荐)

对于支持 Agent Skills 的50多种工具 (如 Claude Code, Codex, Cursor, Gemini CLI等)，可以使用统一的 npx skills 命令进行安装。

  1. 前提条件：确保已安装 Node.js (版本 18 或更高)。

  3. 更新技能：运行 npx skills update 并按提示操作。

各平台手动安装

如果您偏好手动操作，或 npx skills 无法使用，可以按以下方式手动安装。

  • Claude Code

  • Cursor / Windsurf

    • Cursor：将整个技能目录（或 SKILL.md 文件）复制到项目的 .cursor/rules/ 目录下。
    • Windsurf：复制到 .windsurf/rules/ 目录。

  • OpenClaw

  • 其他工具 (如 GitHub Copilot, Cline, 或通用规则)

    • 大多数工具支持将 SKILL.md 文件的内容，或指向该文件的说明，放入其项目或用户级别的规则/指令文件中（例如 .github/copilot-instructions.md 或 .clinerules/ 目录下）。

🚀 首次使用与核心功能

安装后，您可以通过自然语言或斜杠命令触发该技能。

如何触发

在您的AI助手中，可以直接用中文对话提出需求，例如：

  • “写一份交底书，项目路径在 ./my-project”
  • “帮我解读这篇公开专利 CN202410123456”
  • “审查答复：处理 ./office-action/ 下的通知书”
  • “技能进化：嗅探近期的专利审查政策动向”
  • 或使用命令：/交底书、/读专利、/审查答复、/技能进化

四大核心功能

该技能包含四个主要工作模式（详见 SKILL.md）：

  1. 专利交底书编写：这是核心功能。您只需提供项目路径或技术主题，技能会：
    • 自动扫描项目文档/代码，挖掘可申请的专利点。
    • 根据您指定的类型（发明/实用新型/外观设计）选择对应模板。
    • 进行查新：优先使用国知局官方接口，无结果时降级为网络搜索。
    • 生成包含框图/结构图的Markdown交底书，并可导出为 Word (.docx) 文件。
    • 支持多轮迭代修改，并保留修改记录。
  2. 专利通俗解读：将晦涩的公开专利文件（PDF）转化为通俗易懂的笔记。
    • 生成一句话总览、权要树、术语表和解读故事线。
    • 推荐配合 Obsidian 使用：技能可自动将解读内容、术语、图谱存入您的Obsidian知识库，利用双链和关系图构建个人专利知识网络。安装配置指南见 docs/obsidian-setup-guide.md。
  3. 政策感知与技能进化：联网嗅探国知局等官方渠道的近期政策和审查动向，生成参考清单，帮助您判断技能或撰写策略是否需要调整。
  4. 审查答复辅助：辅助处理审查意见通知书。
    • 可将历史通知书和答复案例脱敏存入Obsidian作为经验。
    • 对新通知书进行标签过滤，并可启用本地向量检索（一种RAG方式），然后由AI起草意见陈述书草稿。

  • 基础运行：技能本身是纯文本指令，在支持技能的AI助手中可直接运行，无需额外安装。但为了使用查新和文件解析等高级功能，建议配置Python环境：

  • 外部工具：

    • Obsidian (强烈推荐)：用于“专利通俗解读”功能，实现知识图谱和知识管理。需安装并设置环境变量 PATENT_READER_OBSIDIAN_VAULT 指向您的库目录。
    • Word文档生成：系统需安装 pandoc 以将Markdown转换为 .docx 文件。

📚 进一步学习

  • 详细示例：项目 examples/ 目录下包含了发明、实用新型、外观设计交底书以及专利解读的完整示例，推荐先运行查看效果。
  • 完整文档：请阅读项目根目录的 SKILL.md、INSTALL.md 以及 docs/ 文件夹下的各专题文档，了解所有工作流和配置细节。
  • 贡献：欢迎提交 Issue 和 Pull Request。
