MicYou 能将你的安卓手机变成一个高品质的电脑麦克风

MicYou 详细部署与使用教程

MicYou 是一款功能强大的开源工具，能将你的安卓手机变成一个高品质的电脑麦克风，支持Wi-Fi、USB和蓝牙连接，并内置了降噪、自动增益控制（AGC）等专业音频处理功能。本文将详细介绍从下载到配置完整的全过程。

一、准备工作

在开始之前，请确保你具备以下条件：

  1. 硬件：一台运行Windows、macOS或Linux的电脑，以及一部运行Android 5.0+的智能手机。
  2. 软件：良好的网络环境（用于下载）。
  3. （可选，但推荐）：一个用于创建虚拟音频设备的驱动，这是让手机麦克风被电脑上所有软件识别的关键。Windows系统需要 VB-Cable，macOS系统需要 BlackHole，Linux系统则使用 PipeWire。

二、下载安装文件

你需要分别在手机和电脑上下载对应的程序。

  1. 下载手机端 (Android APK)：
    • 前往项目的 GitHub Releases 页面：https://github.com/LanRhyme/MicYou/releases
    • 下载最新版本的 APK 文件（寻找带有 Latest 标识的版本）。
  2. 下载电脑端 (桌面服务端)：
    • 在同一个 GitHub Releases 页面，根据你的操作系统选择对应的安装包：
      • Windows：下载 ...-windows-x64-installer.exe 或 .zip 便携版。
      • macOS：下载 .dmg 文件（Apple Silicon 芯片选 -arm64.dmg，Intel 芯片选 -x64.dmg）。
      • Linux：下载 .deb、.rpm 或 .AppImage 文件。

注意：如果GitHub访问速度慢，可以尝试使用代理加速服务，或寻找国内镜像站。

三、电脑端与服务配置

首先在电脑上完成核心配置。

  1. 安装桌面端：双击下载的安装包，按照提示完成安装。

  2. 安装虚拟音频驱动：

    • Windows：这是最关键的一步。打开MicYou桌面端，进入 设置 -> 通用，找到 VB-Cable驱动 并点击安装，耐心等待完成。你也可以从 VB-Cable官网 手动下载安装。

四、手机端连接与配对

手机端的配置相对直观。

  1. 安装并打开App：在手机上安装下载好的APK文件，并打开。
  2. 授权权限：根据提示，授予App录音权限。
  3. 选择连接方式：根据你的需求，选择以下三种方式之一。

方式一：Wi-Fi 连接（最便捷，适合日常使用）

  • 要求：手机和电脑连接到同一个Wi-Fi网络。
  • 操作：
    1. 在电脑端MicYou界面，找到显示的IP地址和端口号（通常是 6000）。
    2. 在手机App上选择 Wi-Fi 模式，输入电脑的IP地址和端口，或直接扫描电脑端显示的二维码进行连接。

方式二：USB 连接（延迟最低，适合游戏或专业场景）

  • 要求：一条数据线，并开启手机的USB调试模式。
  • 操作：
    1. 开启USB调试：进入手机 设置 -> 关于手机，连续点击 版本号 7次以进入 开发者选项，然后返回设置，在 开发者选项 中开启 USB调试。
    2. 连接与配对：在电脑和手机App上都选择 USB 模式，然后用数据线连接手机和电脑。电脑端可能需要安装ADB工具（可通过 winget install -e --id Google.PlatformTools 命令安装），并在手机上允许USB调试授权。连接成功后，App将自动配对。

方式三：蓝牙连接

  • 操作：在电脑和手机的系统蓝牙设置中完成配对，然后在App中选择蓝牙模式连接。

五、最终测试与使用

连接成功后，就可以开始使用了。

  1. 确认连接：电脑端和手机端界面都会显示“已连接”状态。
  2. 设置系统输入设备：
    • 打开你电脑的 声音设置。
    • 在 输入 设备列表中，选择你安装的虚拟音频设备（例如 CABLE Input）。
  3. 在应用中使用：现在，打开任何需要使用麦克风的软件（如微信、腾讯会议、OBS、游戏等），在其音频设置中，将输入设备同样选择为 CABLE Input 或 BlackHole 即可。此时，你的手机就变成了电脑的麦克风。

常见问题与技巧

  • 手机和电脑无法连接？
    • Wi-Fi模式：检查是否在同一局域网，并确认防火墙已正确放行端口。
    • USB模式：检查USB调试是否开启，数据线是否支持数据传输，以及ADB驱动是否安装成功。
  • 声音有延迟？
    • 优先使用USB连接，其延迟最低。
    • 在软件设置中尝试调低音频缓冲区大小。
  • 电脑软件无法识别麦克风？
    • 确认已成功安装VB-Cable或BlackHole等虚拟驱动，并在系统和软件中正确选择了该虚拟设备作为输入源。
  • 声音背景嘈杂？
    • 在手机App或电脑端的设置中，开启内置的降噪（Noise Suppression）和自动增益控制（AGC）功能，可以明显改善收音质量。

如果遇到其他问题，可以前往项目的 GitHub Issues 页面反馈，或加入用户交流群寻求帮助。
