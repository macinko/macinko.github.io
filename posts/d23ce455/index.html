avoid-ai-writing：检测并改写文本，去除 AI 写作痕迹

更新于2026-09-13|aiagent
|总字数:1.1k|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 avoid-ai-writing——一个能帮您检测并改写文本，以去除AI写作模式（如陈词滥调、模板化表达）的技能。它适用于Claude Code、OpenClaw、Codex等多种AI编程助手。

此技能的核心价值在于，它不止于简单提示，而是提供了一个结构化的检测与改写流程，并内置了一份包含上百种AI写作模式（”AI-isms”）的清单。它能精准地找出问题并给出更自然、更人性化的改写建议。

🚀 快速安装（通用推荐）

这是最快捷的安装方式，适用于大多数支持Agent Skills的AI工具（包括Claude Code, Codex, Cursor, OpenClaw, Hermes等）。它使用社区 skills 命令行工具。

前提条件：需要安装 Node.js 22.20.0 或更高版本。您可以通过 node --version 检查版本。

更新：运行 npx skills@1.5.23 update 并按提示操作即可。

  • Codex：将 SKILL.md 放入 .agents/skills/avoid-ai-writing/（项目根目录）或 ~/.agents/skills/avoid-ai-writing/（全局）。
  • 通用方法：大多数工具都支持将 SKILL.md 文件放入其指定的 skills/ 或 rules/ 目录。具体路径可参考项目README中的表格。

🎯 使用方式与模式

安装完成后，您可以通过自然语言触发该技能。例如：

  • “Remove AI-isms from this post”（去除这篇文章中的AI腔）
  • “Audit this draft for AI tells”（审计这份草稿的AI痕迹）
  • “Make this sound less like AI”（让这段文字读起来不那么像AI写的）

三种核心模式：

  1. 重写模式（Rewrite，默认）：技能会标记AI模式并提供改写建议，还会进行第二次审查，确保第一次改写中遗漏的问题也被修复。返回结果包含四个部分：发现的问题、改写版本、改动摘要、二次审查。
  2. 检测模式（Detect）：仅标记AI模式，不进行改写。当您只想快速扫描、判断问题而非修改内容时使用。触发词包括：”detect”（检测）、”flag only”（仅标记）、”audit only”（仅审计）等。
  3. 编辑模式（Edit）：原地编辑一个文本文件，进行最小化、有针对性的改动。它会保留已经是人类写作风格的部分，并拒绝修改源代码、配置文件等，以免破坏结构。

额外选项：

  • 语音风格（Voice Profile）：您可以通过可选参数指定希望达到的写作风格，例如 casual（随意）、professional（专业）、technical（技术）、warm（温暖）或 blunt（直率）。

🧠 工作原理简介

该技能内置了庞大的检测规则库，并持续更新。

  • 词汇替换表：包含112个词汇替换条目，分为三个严重等级。例如，将 “leverage” 替换为 “use”。
  • 模式分类：覆盖69种以上的AI写作模式，包括结构问题（如过度使用列表）、语言模式（如”首先、其次、最后”的模板）、内容模式（如夸大其词）和元模式（如节奏过于均匀）等。
  • 确定性检测引擎：项目还附带了一个独立的、零依赖的检测引擎（detector/目录），可以给文本一个0-100的AI倾向评分。

📚 更多信息

  • 独立MCP服务器：项目还提供了 avoid-ai-writing-mcp，一个本地MCP服务器，可以将其检测能力集成到其他支持MCP的工具中。
