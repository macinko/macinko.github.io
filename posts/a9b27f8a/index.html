DeskBox 是一个用 WinUI 3 写的 Windows 桌面整理工具

更新于2026-09-13|toolssoftware
|总字数:1.3k|阅读时长:4分钟|浏览量:

DeskBox 是一个用 WinUI 3 写的 Windows 桌面整理工具，和 Fences 是同类产品，但它坚持”文件还是普通文件”的理念——文件就在原文件夹里，DeskBox 只是在桌面上加了一层小部件来管理它们。部署起来很简单，因为它是个原生 Windows 桌面应用，不涉及服务器或 Docker。

📥 方式一：下载安装包（推荐，最省事）

这是绝大多数用户的首选。当前最新稳定版是 DeskBox 1.4.9，从 GitHub Releases 页面下载即可。

根据你的电脑选对安装包：

你的设备 下载文件 说明
大多数 Intel/AMD 电脑 DeskBox 1.4.9 for x64 绝大多数 Windows PC 选这个
Snapdragon、Surface Pro X 等 DeskBox 1.4.9 for ARM64 Windows on ARM 设备选这个

不确定自己电脑类型的话，在 设置 → 系统 → 关于 → 系统类型 里看一眼就行。

两个安装包都是 Full Native AOT 构建，自带匹配的 Windows App Runtime 2.4，不需要额外下载 .NET 10 运行时，离线也能装。

每个 Release 还会附带对应的 .sha256 校验文件。安装包目前没有代码签名，所以 Windows 可能会弹出 SmartScreen 警告。如果你在意安全性，可以先校验哈希值再运行。

🖥️ 安装与首次运行

DeskBox 用的是 Inno Setup 安装器，默认只为当前用户安装，不需要管理员权限。覆盖安装会保留你之前的所有设置、小部件配置和托管存储。

首次启动注意：DeskBox 是”托盘优先、静默启动”的，安装后它不会自动弹出主窗口，而是常驻系统托盘。你在托盘图标上右键就能看到所有功能入口。如果 DeskBox 已经在运行，再次启动会直接退出，不会重复打开设置窗口。

⚙️ 核心配置：文件存储位置

DeskBox 的数据分两部分存：

内容 默认位置
应用设置、小部件数据 %LocalAppData%\DeskBox\data
新建用户的托管文件 优先选一个非系统盘，如 D:\DeskBox\用户名；没有的话放在 %UserProfile%\DeskBox

这两个位置都可以在设置里备份和恢复，也支持配置自动快照（1.5.0 版本加入了定时备份功能，间隔可从 5 分钟到 5 天不等，保留 3–30 份快照）。

🔍 可选组件：Everything（用于文件搜索）

DeskBox 的桌面搜索功能依赖 Everything 的本地索引。Everything 本身没有打包在 DeskBox 里，需要你单独安装。装好之后，DeskBox 会自动检测到它，通过本地 IPC 读取索引，把文件搜索结果和笔记、待办、设置合并到同一个搜索窗口里。如果没装 Everything，文件搜索这部分就不能用，其他功能不受影响。

🔧 方式二：从源码构建（开发者）

如果你想自己编译或者参与开发，需要满足以下环境要求：

  • Windows 11（开发环境）
  • .NET 10 SDK
  • Visual Studio，并安装 Windows App SDK 工作负载
  • Rust 工具链（版本由仓库里的 rust-toolchain.toml 固定）。只有在使用 -p:DeskBoxRustNative=true 发布时才需要，正式发布版本就是用这个参数构建 Rust 原生层（负责快捷方式、系统音量、快速访问、回收站等 Shell 路径）。

还原、测试、构建 x64 Debug 版本：

发布正式安装包：官方脚本 scripts\publish-aot-retail.ps1 是权威路径，它会生成带私有 Windows App Runtime 的 Full Native AOT 载荷，构建匹配的 Rust DLL，生成用于安全升级的安装清单，并对产物做审计。

重要提醒：不要用裸的 dotnet publish 替代这个脚本，因为安装器需要脚本生成的 DeskBox.InstallManifest.txt 来安全地清理旧版本文件、避免误删用户自己创建的文件。

最后用 Inno Setup 6 或更高版本编译离线安装包：

⚠️ 系统要求

  • 操作系统：Windows 10 版本 21H2 (build 19044) 或更高；想要完整的视觉效果，建议 Windows 11 22H2 或更高。
  • 处理器：x64 或 ARM64，要和安装包匹配。
  • 运行时：Windows App Runtime 2.4。1.4.8 及之后的 Full 安装包已经自带，Native AOT 也不需要单独装 .NET 10。

Windows 10 上部分材质、圆角动画会自动降级为兼容视觉效果，但文件同步、拖拽和核心小部件功能都经过兼容性验证。

💡 使用要点

  • 卸载时：卸载程序会明确问你”保留应用数据”还是”彻底删除”。彻底删除会清掉 %LocalAppData%\DeskBox、DeskBox-Recovery、临时文件和注册信息，但托管存储路径里的用户文件始终会保留。
  • 隐私：DeskBox 不需要账号，也不强制云同步，数据默认存在本机。只有天气、更新检查、拖入远程 URL 导入这几项会主动联网。
