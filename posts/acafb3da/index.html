RedPocket 电话卡｜$30 年卡购买、激活到开启漫游全流程

更新于2026-09-05|globalsim
|总字数:1.3k|阅读时长:4分钟|浏览量:

RedPocket（红包卡）算是比较适合保号的一张美国电话卡，这篇写一下它的购买和激活流程。

先提一下RedPocket的缺点：

$30 eBay 年卡国际漫游权益恢复到了 100 分钟通话 + 100 条短信 + 100MB 流量，但有过改套餐的前科，所以这项权益可能会变。另外，Wi-Fi Calling 稳定性一般，偶尔会出现通话中断。

准备工作：

  • 一台支持原生 eSIM 的手机或一张可用的外置 eSIM 卡

  • Gmail邮箱

  • 可以正常海外付款的 Visa / Mastercard

  • 如果有 美区 PayPal，建议优先套 PayPal 付款，支付更稳

  • 一个稳定的美国网络环境（住宅 IP ＞ 机房 IP）

  • eBay 购买套餐链接（$30/年）：

    https://ebay.io/m/CXS3y9

后续操作建议全程保持美国节点全局模式，避免中途切换网络导致地区信息变化

一、购买Red Pocket eSIM

打开上方 eBay 的 RedPocket 套餐购买链接，选择 eSIM 套餐后点击购买。

⚠️ 下单时记得选择 eSIM，不要选成 SIM。选 SIM 会进入实体卡寄送流程。

选好后点击 Buy It Now → Check out as guest（以访客身份结账）

如果自己有使用多年的 eBay 老账号，可以直接登录购买。我自己的账号是 2023 年注册的，这次就是直接用老号下单。

如果没有 eBay 账号，建议直接选择游客结账。新注册账号马上下单更容易触发风控，可能出现砍单+封账号，没必要为了这张卡特地注册新号。

进入结账页后，将 Country/Region 选为 US，填写邮箱、姓名、美国地址、ZIP Code 和手机号；地址找 Google Maps 上的真实地址，手机号可找生成器。

（邮箱和姓名使用自己的：邮箱用于接收订单及激活邮件，同时也方便与后续注册 RedPocket 账号时的信息保持一致）

随后选择 PayPal 或 Visa / Mastercard 付款，点击 Confirm and pay。不同州税费不同，我当时额外支付了约 $1.8。

想省税可以填免税州，不过我个人更建议地址州和美国 IP 所在州保持信息一致性。

下单成功后，通常几分钟内会收到 Red Pocket 的激活邮件。内含Order ID + Confirmation Code，后续按照邮件提供的激活凭证继续操作即可，记得把邮件保存好

二、激活 eSIM

1. 填写信息

收到 Confirmation Code 后，点击邮件里的激活链接(第一个链接)，填写 Confirmation Code + IMEI 继续激活。

IMEI 查询：拨号界面输入 *#06#

原生 eSIM 手机直接填写本机 IMEI；如果使用外置 eSIM卡，可以先确认自己手机兼容性（如果本机 IMEI 无法通过，也可以尝试 IMEI 生成器，生成的 IMEI 不保证百分百能通过兼容性验证，以实际结果为准）

Red Pocket IMEI 兼容性检测：

https://www.redpocket.com/plans/add/M03GR

选择手机型号并输入 IMEI 检测。

两个信息输入完毕后会让你注册 Red Pocket 账号，建议填Gmail。注册时填写的姓名、地址等信息尽量与 eBay 下单时保持一致，减少信息不一致带来的风控。（开头提到过）

2. 选择号码

接下来选择 Get a new number（申请新号码） 或 Port-in（携号转入）。如果只是用来保号，直接选择新号码即可。填写 Service ZIP Code，系统会根据 ZIP Code 分配对应地区的号码和区号。

3. 完成激活并安装 eSIM

激活成功后，网页端会生成 eSIM QR Code。页面会提供 iOS 和 Android 两个选项，记得选择与自己设备对应的版本。同时二维码也会同步发送到邮箱，保存好后即可安装。

原生 eSIM 手机：连接 Wi-Fi 后，直接扫描 QR Code，按照系统提示添加 eSIM 即可。建议先保存好二维码，确认安装成功后再关闭页面。

**外置 eSIM 卡：**将 QR Code 导入对应的外置 eSIM 管理 App / 写卡工具，完成写入后再在手机中启用线路。二维码同样建议提前保存好。

三、开启国际漫游（这里用手机端演示，网页端操作也差不多）

登录 Red Pocket 后，依次进入 Profile → 右上角 → My Services → Roaming，选择漫游国家/地区（如 China）并开启。页面显示 It’s Enabled 就代表国际漫游已经成功启用。

四、开启 Wi-Fi Calling（手机端可以开飞行模式操作）

设置 → 蜂窝网络→ Red Pocket → Wi-Fi 通话 → 打开“在此 iPhone 上进行 Wi-Fi 通话”→输入E911 Emergency Address拉起wifi calling

安卓端步骤一样

最后手机端再打开一下漫游：

设置 → 蜂窝网络 / 移动网络 → Red Pocket → 打开“数据漫游”

到这里 Red Pocket（红包卡）的购买、激活和漫游设置基本就完成了。整体流程不算复杂，主要注意下单信息、IMEI 兼容性以及漫游设置即可。
