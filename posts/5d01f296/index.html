Navop：数据库、SSH、远程桌面与 AI 一体的桌面工作台

更新于2026-09-23|aitool
|总字数:1.1k|阅读时长:3分钟|浏览量:

Navop 是一个将数据库管理、SSH/SFTP、远程桌面和 AI 助手等功能整合于一体的原生桌面工作台。它采用 Rust 和 GPUI 构建，具备 GPU 加速渲染能力，旨在解决开发运维人员在多个工具间频繁切换的痛点。本篇教程将指引你完成从下载到基本使用的全流程。

📥 第一步：下载与安装

Navop 支持 Windows、macOS 和 Linux 平台，你可以根据系统选择对应的安装包。

操作系统 可用安装包格式 备注
Windows MSI 安装包、EXE 安装包、普通 ZIP（使用系统用户数据目录）、便携 ZIP（数据保存在程序旁） 推荐普通用户使用 EXE 或 MSI 安装包；便携版适合用于 U 盘等场景。
macOS DMG、tar.gz（Apple Silicon / Intel） 如果 macOS 提示无法验证开发者，请在终端运行 sudo xattr -rd com.apple.quarantine /Applications/Navop.app。
Linux tar.gz、deb、rpm、AppImage 选择合适的包格式，例如 Ubuntu/Debian 使用 .deb，Fedora/RHEL 使用 .rpm。

所有安装包均可从 GitHub Releases 页面 下载，下载后建议使用提供的 sha256sums.txt 校验文件完整性。

🚀 第二步：快速上手配置

安装并首次启动后，你可以开始配置核心功能。

1. 设置界面语言

Navop 内置英文、简体中文和繁体中文界面，你可以在设置中切换。

2. 配置数据库连接

Navop 支持 MySQL、PostgreSQL、SQLite、Oracle、达梦、金仓等多种数据库。

  • 连接管理：点击左侧边栏的“数据库”图标，通过“新建连接”向导输入地址、端口、凭证等信息。
  • 驱动说明：内置 Oracle 驱动需要额外安装 Oracle Instant Client；如果不想安装，可从扩展市场安装纯 Go 实现的 Oracle 驱动。

3. 建立 SSH 连接与终端

作为一站式工作台，SSH 管理是其核心。

  • 新建 SSH 会话：在连接侧边栏选择 SSH/SFTP，输入主机 IP、用户名和密码或密钥。
  • 终端体验：支持标签页、分屏、广播输入（向多个会话同时发送命令）等功能。
  • SFTP 文件管理：在 SSH 会话中可一键打开 SFTP 面板，进行文件上传、下载、远程编辑和跨服务器复制等操作。

4. 连接 AI 助手

Navop 为 AI 提供了深度集成的接口。

  • 配置 AI 提供商：在 AI 设置中，你可以接入智谱、Codex、Claude Code 等外部 Agent 的服务。
  • 功能场景：在 SQL 编辑器中通过 AI 生成或解释 SQL；在终端中通过 AI 辅助分析命令输出或执行任务。

🔧 第三步：进阶配置与扩展

1. 启用 Public MCP Server (重要)

Navop 可以将自身工具暴露给外部 AI 客户端（如 Codex, Claude），实现自动化操作。

  • 进入 设置 > 通用 > MCP，开启 MCP Server。
  • 选择合适的权限配置文件（Safe/Confirm/Auto）并勾选需要暴露的工具组。

通过内置的扩展市场，你可以安装来自 navop-extensions 仓库的额外数据库驱动、远程桌面提供程序、文档渲染器等。

💎 总结

Navop 通过将多种高频工具整合到一个原生桌面应用中，有效提升了开发运维工作的连贯性和效率。无论你是 DBA、运维工程师还是全栈开发者，它都可能是一个值得尝试的“瑞士军刀”。如果想深入了解其全部特性，可以查阅项目的 官方文档。
