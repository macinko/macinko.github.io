手把手带你通过 ZenMux 上手 Codex + GPT-6

更新于2026-09-13|aitool
|总字数:716|阅读时长:2分钟|浏览量:

最近GPT-6 Astra发布，时间线上有非常多有意思的案例，特别是和Blender结合做3D，看得非常震撼。有个做硬件的朋友跟我感慨，看到B站上都有GPT 6画PCB的教程了，感觉再发展下去明年就要失业了，模型确实牛逼。

虽然我前面也发过怎么订阅codex，但还是有卡在非iPhone，接不了验证码上面。

这篇文章我就重点介绍下我常用的正规的API平台ZenMux如何使用GPT模型。

第一步：ZenMux

先打开 ZenMux：

https://zenmux.ai/invite/8TBXQL

注册登录这一步很简单，用Google登陆点一两下按钮就行。

ZenMux目前支持216个模型，包括openai/gpt-image-2.5-sunburst、openai/gpt-image-2.5-flare、openai/gpt-6-astra、anthropic/claude-fable-5.1等，而且还经常搞新模型免费体验。

充值可以选择按量付费（Pay as you go）或者订阅，具体差异可以参考这里 👉

ZenMux的两种使用方式

我一般是配合n8n或者其他工作流使用，不要Rate Limit 限制，并且需要精确统计token成本，所以用PAYG API，下面就以PAYG做示例。

充值之后，进入后台创建 API Key。

创建完成后，把 API Key 复制下来，一般长这样：

text

这串 key 后面要填进 CC Switch。

⚠️ 特别提醒！，API Key 不要发给别人！

到这里，ZenMux 这一侧就完成了。

第二步：CC Switch

接下来安装 CC Switch。

下载地址：

https://github.com/farion1231/cc-switch/releases

CC Switch 它提供一个图形化的操作界面配置，让Codex/ChatGPT等可以走第三方的API。

基本就是填供应商、填地址、填 key，然后启用就行。Codex/ChatGPT、Hermers、Pi啥的都支持。

安装完成后，打开 CC Switch，在ChatGPT页面，新建一个供应商。

这里按下面的信息填写。

供应商名称：

text

请求地址：

text

API Key：

text

也就是你刚刚在 ZenMux 后台复制的 API Key。

接着点4️⃣ 获取模型列表，点5选择 gpt-6-astra，最后点击添加

供应商这里就ok了，点保存就行。启用 ZenMux。

最后打开 ChatGPT。

如果之前已经开着 ChatGPT，建议先退出再重新打开一次。

然后输入：

text

能正常回复，就说明 ChatGPT已经通过 CC Switch 走 ZenMux 了。

总结

cc switch 管理codex供应商还是非常方便的，无论是在RagFlow、n8n、nocobase等，都有非常好的支持。而且经常有免费的模型试用。

如果是应用在企业场景中，一个稳定可靠的供应商是真的很重要，这也是我一直推Zenmux并且长期使用的原因。

有需要的朋友趁现在活动赶紧冲 👉

https://zenmux.ai/invite/8TBXQL
