dsh-im 为 DeepSeek Harness 设计的 IM 机器人插件

更新于2026-09-05|aideepseek.webp
|总字数:1.6k|阅读时长:5分钟|浏览量:

dsh-im 为 DeepSeek Harness 设计的 IM 机器人插件，能让你通过扫码或凭据，将飞书、微信、钉钉、企业微信、QQ、Slack、Telegram、Discord 和 WhatsApp 这 9 个平台的机器人连接到 DeepSeek Harness。

🧭 核心功能与适用场景

dsh-im 作为一个插件，其核心价值在于打通了 IM 平台与 DeepSeek Harness 智能体之间的通道。它让你能在日常使用的聊天软件中，直接与 Harness 进行交互。

  • 多平台支持：覆盖国内外主流 IM 工具，每个渠道都支持接入多个机器人。
  • 双向交互：不仅支持向 Harness 发送文字和图片，还能接收 Harness 的流式回复、思考过程、工具执行进度，并支持结果文件（如图片、文档）的回传。
  • 命令控制：支持丰富的斜杠命令（如 /new 开启新会话、/model 切换模型、/workspace 切换工作区），方便在聊天中管理 Harness 会话。
  • 安全设计：所有机器人的凭据（Token、Secret）只保存在本机 Harness 的受保护存储中，不会通过浏览器或插件回传。

📦 部署与安装

dsh-im 是 DeepSeek Harness 的一个插件，安装过程在 Harness 环境中进行。

1. 前提要求

  • 你已安装并配置好 DeepSeek Harness 环境。
  • 你拥有至少一个目标 IM 平台的机器人账号或开发者权限。

2. 安装插件

推荐通过 npm 安装稳定版本：

安装后，重启 dsh web 服务。然后在 Harness 的 Web 界面中，进入 设置 → 插件 → IM机器人，即可看到所有支持的 IM 渠道和 AI Office Connector。

试用最新代码：如需安装未发布到 npm 的开发版，可使用 GitHub 源安装器：npx -y github:xmanrui/dsh-im install。

🚀 快速接入：以飞书和微信为例

安装插件后，接入步骤在各个平台类似，但细节略有不同。

1. 接入飞书机器人

  1. 在 dsh-im 设置页中，点击“飞书”图标。
  2. 按照页面引导，使用飞书 App 扫码，即可自动创建一个与 Harness 绑定的飞书机器人。或使用已有的 App ID + App Secret 手动绑定。
  3. 绑定成功后，在你的飞书群或私聊中，即可与机器人对话。

2. 接入微信机器人

  1. 在设置页中，点击“微信”图标。
  2. 使用微信 App 扫码，插件会通过腾讯 iLink 协议与你的个人微信建立连接，并将其转化为一个机器人。
  3. 绑定后，你的微信账号即可作为机器人，在微信群或个人聊天中响应消息。

其他渠道概览

渠道 接入方式简述
钉钉 扫码创建，或使用 Client ID + Client Secret 绑定。支持 AI Card 流式回复。
企业微信 扫码创建智能机器人，或使用 Bot ID + Secret 绑定。支持“正在思考”状态显示。
QQ 扫码创建，或使用 AppID + AppSecret 绑定。群聊时被 @ 才响应。
Slack 使用预置的 App Manifest 创建应用，填写 Bot Token 和 App Token。支持 Socket Mode。
Telegram 使用 @BotFather 生成的 Bot Token 绑定。支持私聊/群聊模式切换和富消息流式预览。
Discord 使用 Developer Portal 生成的 Bot Token。支持在频道中创建线程进行会话。
WhatsApp 使用手机 WhatsApp 扫码关联设备。可设置仅自己、指定联系人或开放响应模式。

⚙️ 核心功能与配置

1. 机器人命令

在聊天中向机器人发送以 / 开头的命令，可以控制会话。常用命令包括：

  • /new：强制开启一个新的 Harness 会话。
  • /model [序号或模型ID]：切换当前会话使用的模型。
  • /workspace [绝对路径]：切换当前机器人的 Harness 工作目录。
  • /stop：立即停止当前正在运行的任务。
  • /steer [补充指令]：向正在运行的任务追加指令。

2. 安全与权限

  • Telegram 安全模式：可为每个机器人设置私聊白名单，只响应白名单中用户的私聊消息，忽略群聊消息。
  • WhatsApp 访问模式：支持“仅自己”、“指定联系人”和“开放响应”三种模式，精细控制机器人响应范围。
  • 凭据安全：所有用于连接的 Token 和 Secret 均仅存储在本机 Harness，并受 Harness 的凭据存储保护。

3. 多机器人管理

同一个 IM 渠道下，你可以接入多个机器人。每个机器人独立保存其凭据、连接状态、工作区路径、Agent Preset 和聊天会话映射，互不干扰。

❓ 常见问题与注意事项

  • Telegram 命令不工作？ Slack 和某些平台可能会拦截以 / 开头的消息。请在命令前加一个前导空格发送，例如 /presetlist。
  • 文件发送失败？ 不同平台对文件大小、类型和权限要求不同。
    • 请检查机器人是否具有相应权限（如飞书的 im:resource 权限）。
    • 注意平台限制（如微信基于协议能力，飞书文件需 <30 MB）。
    • 插件会优先以原生图片/文件消息发送，并在平台不支持时尝试回退。
  • 如何切换机器人使用的 Harness 工作区？
    • 在 dsh-im 设置页的机器人卡片上，可以直接修改或选择工作区路径。这会清除该机器人的旧聊天映射，后续消息将使用新工作区。
    • 在聊天中也可使用 /workspace 命令切换。

总结

dsh-im 为 DeepSeek Harness 提供了一套完整、安全的 IM 接入方案。部署的核心是在 Harness 中安装插件，然后按各平台指引进行扫码或凭据绑定。通过它，你可以将 Harness 的强大能力无缝集成到日常沟通工具中，无论是个人使用还是团队协作，都能实现随时随地与 AI 智能体交互。使用时，请留意各平台的接入方式差异和权限设置，并根据需要配置工作区和安全模式。
