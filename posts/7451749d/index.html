激活说明

1.运行绿色补丁ZW3D2025-2024-Patch执行修补.
2.检查以下路径该补丁有没成功释放该浮动许可文件.
如果补丁没有成功释放，请手动复制该文件到该目录即可激活.

.Net Framework 4.7.2+, Windows 7 SP1 或更高版
