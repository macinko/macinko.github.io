EtchDroid：在 Android 上把系统镜像写入 USB 的开源应用

更新于2026-09-05|osandroid
|总字数:1k|阅读时长:3分钟|浏览量:

🧭 核心功能与定位

EtchDroid 是一款 Android 应用，其主要用途是在你没有可用的电脑时，通过 Android 手机或平板制作一个可启动的 Linux 系统 U 盘。它的核心价值在于：

  • 无需电脑：完全在 Android 设备上运行。
  • 无需 root：不需要破解或获取系统超级权限，使用安全。
  • 支持多种镜像：可以写入现代 GNU/Linux 发行版（如 Ubuntu、Arch Linux、Fedora）和树莓派 SD 卡镜像等。

重要限制：

  • 不支持：官方 Windows ISO 镜像、Apple DMG 镜像、USB 硬盘/SSD、内置 SD 卡槽。
  • 支持但不推荐：社区修改版 Windows 镜像（可能存在安全风险）。

📱 安装与准备

1. 获取应用

EtchDroid 是一个 Android 应用，你可以通过以下方式安装：

  • Google Play 商店：搜索“EtchDroid”并安装（包含可选遥测）。
  • F-Droid（开源应用商店）：搜索并安装（无遥测）。
  • GitHub Releases：下载最新 .apk 文件手动安装（包含可选遥测）。

2. 准备硬件

  • 一个 USB 闪存盘（或 USB SD 卡读卡器）。
  • 一个 OTG (On-The-Go) 转接头：用于将 USB 设备连接到你的 Android 手机。确保你的手机支持 USB OTG 功能。

🚀 使用步骤

  1. 连接 U 盘：通过 OTG 转接头将 U 盘连接到 Android 设备。
  2. 下载或准备镜像文件：将你想要写入的 OS 镜像文件（通常是 .iso 或 .img 格式）保存到你的 Android 设备存储中。重要：如果是树莓派 .img 文件，请先解压（如 .zip 或 .xz 压缩包）。
  3. 启动 EtchDroid：打开应用。
  4. 选择镜像：点击“写入镜像”或类似按钮，浏览并选择你准备好的镜像文件。
  5. 选择目标设备：应用会列出检测到的 USB 驱动器。请务必仔细确认，选择正确的 U 盘，以免误写其他存储设备。
  6. 开始写入：点击“写入”按钮。应用会显示写入进度，并可能要求你确认操作。
  7. 完成：写入成功后，会有提示。安全弹出 USB 驱动器，然后就可以用它来启动电脑了。

⚙️ 高级设置与注意事项

  • 遥测（Telemetry）：
    • 从 Google Play 或 GitHub 下载的版本会收集匿名的使用数据（如镜像文件名、USB 设备 ID），以帮助开发者改进应用。不收集个人身份信息。
    • 如果你不希望共享这些数据，可以在应用菜单中禁用遥测，或选择 F-Droid 版本。
  • 支持的镜像格式：应用底层使用 dd 命令的等效实现，因此理论上支持任何原始磁盘镜像格式。但它主要是为 Linux 和树莓派镜像设计的。
  • 写入速度：取决于你的 Android 设备性能、USB 驱动器和 OTG 接口速度。
  • 安全警告：请勿使用 EtchDroid 写入从非官方渠道下载的 Windows 镜像，这些文件可能包含病毒或恶意软件。

❓ 常见问题与排查

  • 应用无法识别我的 U 盘：
    1. 确保 U 盘正确连接到 OTG 线缆，且手机支持 OTG。
    2. 尝试重新插拔 U 盘。
    3. 检查 U 盘是否被其他应用占用（如系统文件管理器）。
  • 写入过程中失败：
    1. 检查 U 盘是否有足够的剩余空间。
    2. 尝试格式化 U 盘为 FAT32 或 exFAT 格式（应用通常会处理）。
    3. 确保镜像文件完整，没有损坏。
  • 提示需要 root 权限：EtchDroid 不需要 root 权限。如果出现此提示，说明你的设备环境可能有问题，或应用版本不正确。

总结

EtchDroid 是一个在应急情况下制作 Linux 启动盘的高效工具。你只需在 Android 手机上安装该应用，连接 U 盘，选择镜像文件即可开始写入。它的核心优势在于便携性和无需电脑，非常适合系统管理员、开发者或经常需要安装 Linux 的用户。使用时，请务必仔细核对目标 USB 设备，以免数据丢失，并注意从官方或可信来源下载镜像文件。
