🚀 三种部署与使用路径对比

模式 适用人群 核心步骤 费用
免费试用 想先体验功能，不想配置的用户 1. 下载官方 DMG 安装包 2. 安装并打开应用，直接开始使用 7 天免费，由作者承担
自带 Key 追求永久免费、不限字数，愿意花几分钟配置的用户 1. 获取火山引擎和阿里云百炼的 API Key 2. 在 Typefree 设置中填入 Key 永久免费，但模型调用费走你自己的账户
会员 不想申请 Key，希望省心全包的用户 1. 下载官方签名版 DMG 2. 安装后开通会员 ¥188 / 年，包含识别、整理、问 AI 全包

🛠️ 路径一：快速免费试用 (最简单)

这是最快上手的方式，无需任何配置。

  1. 下载安装包：访问 Typefree 官网或 GitHub Releases 页面，下载最新版的 .dmg 文件。
  2. 安装应用：打开下载的 DMG 文件，将 Typefree 图标拖拽到 Applications 文件夹中。
  3. 启动使用：从启动台或应用程序文件夹打开 Typefree。首次打开时，系统可能会提示安全警告，请在“系统设置 -> 隐私与安全性”中允许来自该开发者的应用。
  4. 开始体验：根据应用内的一分钟动画指引，在任意输入框中按住鼠标左键说话，松开后文字就会自动整理并输入。

🔑 路径二：自带 Key 永久免费 (推荐)

这是性价比最高的方案，需要你分别申请火山引擎（用于语音识别）和阿里云百炼（用于 AI 整理）的 API Key。

第一步：获取火山引擎 API Key (语音识别)

Typefree 使用火山引擎的“豆包语音”大模型进行高精度语音识别。

  1. 注册并认证：访问火山引擎官网，注册账号并完成实名认证。

  2. 开通服务：登录后，进入新版“豆包语音”控制台。在“开通管理”页面中，找到并开通 “录音文件识别大模型-极速版” 服务。

  3. 获取 API Key：在控制台的 “API Key 管理” 页面，创建一个新的 API Key，并复制保存好。

    注意：请务必使用“豆包语音”控制台签发的 Key。火山引擎旗下其他平台（如火山方舟）的 Key 不能用于此服务。

第二步：获取阿里云百炼 API Key (AI 整理)

Typefree 使用通义千问模型来整理识别后的口语，使其变得通顺、有标点。

  1. 注册并开通：访问阿里云官网注册账号。然后进入阿里云百炼大模型服务平台，阅读并同意协议以开通服务。如果提示需要实名认证，请先完成认证。
  2. 获取 API Key：开通后，在百炼控制台左侧导航栏找到 “API-KEY” 管理页面，点击“创建我的 API-KEY”，复制生成的 Key 并保存。

第三步：在 Typefree 中配置

  1. 打开 Typefree，进入 “设置” -> “模型”。
  2. 在对应的输入框中，分别粘贴你刚获取的火山引擎 API Key 和阿里云百炼 API Key。
  3. 保存设置。现在你就可以享受永久免费、不限字数的语音输入服务了。

✨ 核心使用技巧

  • 鼠标长按说话：在输入框内，按住鼠标左键即可开始录音。如果想在说话中途松手锁定，可以把鼠标向下拖拽一点；如果不想要这次输入，把鼠标拖远，看到红光后松开即可取消。
  • 随时问 AI：在网页或文档的空白处按住鼠标说话，AI 的回答会出现在屏幕右上角，支持追问和固定。
  • 语音翻译：说完中文后，结尾加一句 “用英文”，最终输入的就是英文。日文、韩文同理，这是程序规则识别的，无需担心误触发。

💡 注意事项

  • 隐私安全：API Key 仅保存在你 Mac 的本地钥匙串中。在“自带 Key”模式下，音频会直接从你的设备发送给火山引擎和阿里云，不经过作者的服务器。
  • 费用提醒：虽然 Typefree 软件本身免费，但火山引擎和阿里云百炼会对 API 调用按量计费。不过根据作者实测，高强度使用一年的费用也仅需几十元。
