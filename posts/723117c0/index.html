Quickemu 部署教程：快速创建优化的虚拟机

本教程将指导你部署和使用 Quickemu——一个 QEMU 的封装工具，能自动下载操作系统镜像并生成最优配置，让你用两条命令就能运行 Windows、macOS 或 Linux 虚拟机。

📋 准备工作

1. 硬件与系统要求

  • 操作系统：Linux 或 macOS 主机。
  • 处理器：支持硬件虚拟化（Intel VT-x / AMD-V）。
  • 内存与磁盘：至少 2GB 内存（推荐 8GB 以上）和 10GB 可用磁盘空间。
  • 网络：稳定的互联网连接，用于下载操作系统镜像。

2. 检查虚拟化支持

🛠️ 安装 Quickemu

方式一：通过包管理器安装（推荐）

操作系统 安装命令
Ubuntu/Debian (使用 PPA) sudo add-apt-repository ppa:flexiondotorg/quickemu sudo apt update sudo apt install quickemu
Ubuntu/Debian (使用 DEB 包) 从 Release 页面 下载 .deb 包，然后执行 sudo apt-get install ./quickemu-*.deb
Arch Linux (AUR) 使用 AUR 助手（如 yay）安装：yay -S quickemu

🚀 使用 Quickemu：两步创建虚拟机

安装完成后，你只需要两个命令就能创建并运行一台虚拟机。

第一步：下载操作系统镜像并生成配置

使用 quickget 命令自动下载所选操作系统的镜像并创建 .conf 配置文件。

quickget 会列出所有支持的系统。命令执行后，会生成如 windows-11.conf 的配置文件。

第二步：启动虚拟机

使用 quickemu 命令，加载上一步生成的配置文件来启动虚拟机。

首次启动会进入系统安装界面，按屏幕提示完成安装即可。安装完成后，再次运行相同命令即可直接进入系统。

⚙️ 进阶配置：调整虚拟机参数

quickemu 会根据主机硬件自动分配 CPU 和内存。如有特殊需求，可以编辑 .conf 配置文件。

💡 常见问题与技巧

  • 无法找到命令：如果从源码安装，需在 quickemu 目录下执行 ./quickemu，或确保已将脚本复制到 /usr/local/bin。
  • Windows 11 安装失败：请检查 .conf 文件中是否包含 tpm="on" 和 secureboot="on"，这是 Windows 11 的硬性要求。
  • macOS 安装：在安装过程中，需要先在“磁盘工具”中抹掉 QEMU HARDDISK Media，然后才能选择“安装 macOS”。
  • 剪贴板共享：在 Linux/Windows 虚拟机中安装 spice-vdagent 即可启用与主机的剪贴板共享。

通过以上步骤，你已经成功部署了 Quickemu，并能够快速创建和运行经过优化的虚拟机。这个工具特别适合需要频繁测试不同操作系统或搭建跨平台开发环境的场景。
