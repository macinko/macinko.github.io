记了几年笔记，需要用的时候还是重新搜？教你如何用Obsidian 从

更新于2026-09-05|toolssoftware
|总字数:1.9k|阅读时长:5分钟|浏览量:

很多人不是没做笔记，而是做了几年笔记，最后什么都没留下

文章收藏了几百篇，Notion 塞满页面，Google Drive 全是资料，手机备忘录也越来越长

看起来记了很多，真到写东西、做项目、找资料的时候，还是重新搜一遍

因为大多数笔记从记下来的那一刻起，就已经“死”了

没人整理，没人连接，也很少再被翻出来

真正有用的笔记，不是存得多，而是以后还能找得到、接得上、用得起来

这也是我推荐 Obsidian 的原因

它不是再给你一个新的收藏夹，而是把过去那些零散的笔记重新连起来：

一篇笔记能指向另一篇，旧内容也会因为新的记录重新被翻出来

而且所有内容都直接存在自己电脑里，还是普通的 Markdown 文件

以后换软件、备份、接 Codex 或其他 AI 工具，都很方便

这篇就给大家分享一下 Obsidian 最基础、也最实用的几个功能

1. Obsidian 最重要的一点：笔记就是你自己的文件

Obsidian 里的每篇笔记，本质上都是一个 Markdown 文件：

SEO.md AI.md 读书笔记.md 项目记录.md

文件直接存在电脑里，不是只能待在某个平台的数据库里

以后不用 Obsidian 了，VS Code、Typora，甚至普通文本编辑器都能打开

这也是它很适合接 AI 的原因

Markdown 本身就是纯文本，Codex、Claude Code 这类工具可以直接读取整个文件夹，不需要先导出一遍

软件可以换，笔记不用跟着搬

2. 第一次打开，先建一个仓库

安装 Obsidian 后，选择：创建新仓库

“仓库” 其实就是一个普通文件夹

例如： Documents/Obsidian/第二大脑

以后所有笔记、图片、PDF 都会放在这里

位置最好一开始就选好，放在自己平时会备份的目录里

因为这整个文件夹，就是你的知识库

3. 先把附件收好，不然后面真的会乱

建完仓库，我建议马上改一个设置：

设置 → 文件与链接 → 新附件的默认位置

然后单独建一个：

Attachments
附件

以后图片、截图、PDF 全部丢进去

不改的话，用一阵子以后根目录很容易变成：

image.png image 1.png Screenshot 2026…
image.png 图像 1.png 截图 2026…

几十个附件还好，几百个以后再整理会很麻烦

这个设置两分钟就能搞定，最好一开始就做

4. Markdown 不用系统学，先会这几个

标题

# 一级标题

## 二级标题

### 三级标题

加粗

重点内容

快捷键：Ctrl/Cmd + B

列表

- 第一项

- 第二项

待办

- [ ] 待完成

- [x] 已完成

日常记笔记，这些基本已经够用

Markdown 的优势也不是语法多厉害，而是简单、通用

几年以后换软件，文件依然能直接打开

5. 真正要学会的是 [[双向链接]]

这是 Obsidian 最核心的用法

比如你在写 AI，里面提到了 SEO，直接输入：[[SEO]]

已经有这篇笔记，就直接连过去

还没有，也可以先写：[[AI SEO]]

以后再点进去补

我觉得这个功能最好用的一点，是不需要为了分类打断自己

写到一个相关概念，先把链接留下，继续往下写

至于那篇笔记放哪、什么时候补，可以之后再处理

6. 反向链接，能把以前的内容重新翻出来

假设你有一篇：内容创作.md

后来又在：

SEO.md AI写作.md X运营.md 个人品牌.md

里面链接过它

再打开“内容创作”，Obsidian 会直接列出哪些笔记提到过它

这就是反向链接

文件夹只能告诉你：

这篇笔记放在哪

反向链接还能告诉你：

这篇笔记后来在哪些地方被用过

笔记少的时候感觉不明显

等你记了几个月，再打开一篇旧笔记，经常会顺着这些链接翻出以前完全忘掉的内容

这才是双向链接真正有用的地方

7. 想把另一篇笔记直接放进来，用嵌入

普通链接只能点过去

如果想直接显示另一篇笔记的内容，在前面加一个 !：

![[笔记名]]

比如你有：

本周任务.md

正在阅读.md

项目进度.md

可以单独做一个首页：

  • ## 本周任务 ![[本周任务]]
  • ## 正在阅读 ![[正在阅读]]
  • ## 项目进度 ![[项目进度]]

以后只打开这一页，就能看到几个地方的内容

原笔记一改，这边也会跟着更新

做项目首页、学习总览、工作台都很方便

8. 文件夹别一开始建十几层

刚用 Obsidian，很容易把大量时间花在“这篇到底该放哪”

其实先简单一点更好

我比较推荐新手从这几个开始：

  • Inbox：暂时没整理的资料、想法
  • Notes：长期留下来的笔记
  • Projects：正在做的项目
  • Daily：每日记录
  • Attachments：图片、PDF、截图
  • Templates：模板
    模板：模板结构

先用起来，再根据自己的习惯改

有一句很好记：

文件夹负责位置，链接负责关系

比如一篇“AI SEO”，它可能同时和 AI、SEO、内容创作有关

如果全靠文件夹，你必须硬选一个地方

用链接就不用纠结

9. 关系图谱看看就好，别为了它乱加链接

关系图谱会把笔记显示成一个个点，笔记之间的链接变成线

内容多了以后，同类主题会慢慢聚在一起，看起来确实很直观

但别为了让图谱好看，见什么都连

两个概念真的有关，就加链接

没关系就别加

图谱是结果，不是任务

平时的笔记关系做得清楚，它自然就会长出来

10. 最容易犯的错：换了 Obsidian，习惯还是收藏

文章整篇复制、视频让 AI 总结一下丢进去、推文随手截图

半年以后仓库里两三千个文件，看起来东西很多，真要用的时候还是不知道从哪开始

那其实只是做了一个更高级的收藏夹

我现在觉得，一条东西要不要留下，至少可以多做两步：

  • 第一，用自己的话写一两句，它到底讲了什么
  • 第二，看看它和自己以前记过的什么有关，加一个 [[链接]]

不用每条笔记都写成文章，也不用整理得特别漂亮

但最好别只复制完就走

真正值得留下来的，不是“我以前看过”，而是以后还能找回来继续用

最后

刚开始用 Obsidian，我的建议是先把这些用熟：

Markdown、双向链接、反向链接、附件管理、嵌入、简单目录

然后开始正常记，写到相关内容就连一下，没整理的先扔 Inbox

用上几个月以后，再回头调整结构，通常比第一天就设计一套完美系统靠谱得多

如果今天第一次用，先做四件事：

下载安装 → 建仓库 → 写第一篇笔记 → 加一个 [[双向链接]]

先让这套东西真正跑起来
