新手买域名保姆级教程（付费/免费域名锐评一次讲清）

更新于2026-09-05|proxynet
|总字数:3.6k|阅读时长:11分钟|浏览量:

一、介绍

最便宜的域名，往往只便宜第一年。

真正让人后悔的，通常不是注册费，而是第二年、第三年的续费价格。

我自己也走过一遍弯路：一开始想用免费的

EU.org

，但审核没通过，后来直接换到了 Cloudflare。

所以这次我把常见的域名购买渠道重新梳理了一遍，重点只看几个问题：

  • 首年到底多少钱？
  • 续费会不会突然涨很多？
  • 隐私保护是否免费？
  • 能不能转出？
  • 适不适合中国大陆用户？
  • 免费域名到底能不能长期用？

本文价格以 2026 年 8 月官网公开页面为准，默认比较普通非 Premium 域名。促销、税费、地区和账号状态可能影响最终价格，结账页才是最终标准。

先说一个公式：

长期成本 = 首年注册费 + 后续续费费 × 年数 + ICANN 费/VAT + 可选服务费

不要只看“首年 0.01 美元”。

二、付费域名测评

1. Cloudflare Registrar 1. Cloudflare 注册器

官网：

Cloudflare Registrar
Cloudflare 注册器

主要后缀价格：

  • .com：约 US$10.46/年，注册和续费原则上相同 计算方式是注册局成本 US$10.26 + ICANN US$0.20。
  • .net：约 US$11.11/年，按照当前注册局成本估算。
  • .org：约 US$11.20/年，按照当前注册局成本估算。
  • .ai、.app、.dev：后台实时显示，Cloudflare 不公开固定价目表。

**Cloudflare 的核心优势是“注册局成本价”，不额外赚域名差价，也没有夸张的续费加价。**支持免费 WHOIS 隐私、DNSSEC、DNS、CDN 和 SSL。

官方说明

不过需要注意，Cloudflare Registrar 通常要求使用 Cloudflare 的 Nameserver。如果你想长期使用其他 DNS 服务，体验可能没有那么自由。

我自己本人的域名 coucouya.com 也是用Cloud flare 注册的，用Codex搭建非常丝滑！！！

优点：

  • 长期续费成本低
  • 没有隐藏加价
  • 隐私保护、DNSSEC、DNS、CDN、SSL 都比较完整
  • 适合技术用户和长期持有域名的人

缺点：

  • 对 Cloudflare 生态依赖比较强
  • 部分注册、转移费用不支持退款
  • 价格会随着注册局成本变化

适合人群：

想长期持有 .com，并且不介意使用 Cloudflare DNS 的人。

2. Spaceship

官网：

Spaceship Domains

主要后缀价格：

  • .com：首年 US$8.88，续费 US$9.98
  • .net：首年 US$11.20，续费 US$11.20
  • .org：首年 US$6.65，续费 US$11.39
  • .ai：首年 US$79.98，续费 US$79.98
  • .online：首年 US$0.98，续费 US$21.38
  • .io：首年 US$31.98，续费 US$51.75
  • .xyz：首年 US$1.86，续费 US$13.77

部分通用后缀页面会另外列出 US$0.20/年的 ICANN 费用。

Spaceship 最大的特点是价格比较激进，尤其是 .com、.net 和 .ai。但很多新后缀首年很便宜，续费会明显变高。

例如 .online 首年不到 1 美元，但第二年续费已经超过 20 美元。

优点：

  • .com、.net 长期价格比较有竞争力
  • 免费域名隐私
  • 价格表比较清晰
  • 支持自动续费

缺点：

  • 不同后缀的价格差距很大
  • 促销后续费可能翻倍
  • 部分后缀需要额外计算 ICANN 费

适合人群：

想买低价 .com、.net，又不想绑定 Cloudflare DNS 的人。

Porkbun Domain Pricing

  • .com：首年 US$11.08，续费 US$11.08

  • .org：首年 US$7.98，续费 US$11.84
  • .ai：首年 US$82.70，续费 US$82.70

Porkbun 的价格通常接近注册局成本，而且官方页面显示的价格已经包含 ICANN 等费用。

官方价格说明

它还免费提供 WHOIS 隐私、SSL、URL 转发、邮箱转发和 DNS 管理。

优点：

  • 价格透明
  • 续费没有明显套路
  • 附带功能比较丰富
  • 适合长期持有

缺点：

  • 中文支持不如国内平台
  • 部分支付方式对中国用户不一定友好
  • 新后缀促销价格仍然可能和续费价差距很大

适合人群：

想找 Cloudflare 之外的长期低价注册商，并且重视隐私和转发功能的人。

官网：

NameSilo 提供免费 WHOIS 隐私、邮箱转发、Domain Defender 和 DNS 管理。

官方价格页

它还有 Discount Program，批量注册时价格会下降。不过折扣价、促销价和续费价需要分开看，不能把注册页上的最低价当成长期价格。

优点：

  • 隐私保护和 DNS 功能免费
  • 价格结构比较透明
  • 支持大量域名后缀
  • 适合批量管理域名

缺点：

  • 默认标准零售价不算最低
  • 后台界面相对传统
  • 促销和 Discount Program 容易让新手看不懂
  • 支付方式需要以当前结账页为准

适合人群：

想批量管理域名，或者希望所有域名附加功能都免费的用户。

官方价格表

但它的续费价格明显高于 Cloudflare、Spaceship 和 Porkbun。

优点：

  • 后台界面友好
  • 新手容易上手
  • 免费长期隐私保护
  • 客服和帮助文档比较完善

  • .com 续费 US$18.48，长期成本偏高
  • 首年促销容易让人忽略续费
  • 部分后缀可能另加 US$0.20 ICANN 费用

适合人群：

第一次买域名、重视界面和客服体验的新手。

三、免费域名测评

先说结论：

免费域名大多数情况下，其实是免费“子域名”，不是你真正拥有的顶级域名。

1. EU.org

官网：

EU.org

EU.org

的定位是给个人和非营利组织提供免费子域名，例如：

yourname.eu.org

它不是欧洲联盟官方服务，申请需要人工审核，官方也明确说明不提供正式客服支持。

优点：

  • 不需要购买普通注册费
  • 可以用于个人项目和测试网站
  • 比随机平台子域名更像一个独立地址

缺点：

  • 申请需要审核
  • 审核结果不稳定
  • 不是真正拥有 .org 顶级域名
  • 平台政策变化时可能影响使用
  • 不建议绑定长期邮箱、支付回调和商业品牌

我自己申请过，但审核没有通过。

适合人群：

想低成本测试项目，不急着做品牌的人。

2. GitHub Pages

官网：

GitHub Pages

默认地址一般是：

username.github.io

适合放个人主页、项目文档、开源项目和静态博客。

优点：

  • 免费
  • 适合开发者
  • 可以直接关联 GitHub 仓库
  • 支持绑定自己的域名

缺点：

  • 不适合复杂后端服务
  • 地址带有 GitHub 品牌
  • 需要一定技术基础
  • 平台规则变化会影响使用

3. Vercel

官网：

Vercel Domains

部署项目后会自动分配：

project-name.vercel.app

Vercel 很适合 Next.js、React 和 AI 项目，部署速度快，体验也比较好。

但它本质上仍然是平台子域名，不能完全替代自己的 .com。

适合：

  • AI 工具 Demo
  • 个人作品集
  • 前端项目
  • 快速验证想法

4. Netlify

官网：

Netlify Domains

默认地址一般是：

your-site.netlify.app

Netlify 提供免费部署和免费子域名，适合静态网站、Landing Page 和小型项目。

缺点是免费额度、构建次数和流量都有上限，项目流量变大后需要升级。

5. DuckDNS

官网：

DuckDNS

DuckDNS 提供类似：

yourname.duckdns.org

它主要是动态 DNS 服务，用来把不断变化的家庭宽带 IP 映射到一个固定地址。

适合：

  • 家庭服务器
  • NAS
  • Home Assistant
  • 个人实验项目

不适合：

  • 品牌官网
  • 商业邮箱
  • SaaS 产品
  • 支付和登录回调

免费域名的正确用法是：

  • 测试项目：可以用免费子域名
  • 内部 Demo：可以用免费子域名
  • 个人主页：前期可以用免费子域名
  • 商业网站、品牌邮箱、支付回调：建议直接买自己的域名

如果一个项目真的做起来了，尽早买一个自己的 .com，然后把免费地址 301 重定向过去。
