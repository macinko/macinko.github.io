一个 Skill 让 Agent 自动操作浏览器：ego lite 保姆级教程（告别重复枯燥任务）

更新于2026-08-22|aiagent
|总字数:1.6k|阅读时长:5分钟|浏览量:

ego lite 是专为 人机协同 设计的 Chromium 浏览器：Agent 在独立 Space 中并行工作，继承你的 Chrome 登录状态、Cookie、扩展，但不会干扰你正在使用的标签页。任务完成更快、Token 消耗更低（内部基准最高提速约 3.45 倍）。目前仅支持 macOS（评论中也多次确认 MAC ONLY），免费、零配置、数据本地存储。

1. 引言：为什么需要这个工具？

传统浏览器自动化（Playwright、Puppeteer、browser-use 等）痛点明显：

  • 需要单独启动浏览器，登录状态难以干净继承。
  • 你和 Agent 争抢同一套标签页，互相干扰。
  • 一轮工具调用 → 观察 → 再调用，往返多、Token 贵、速度慢。
  • 复杂页面（嵌套 iframe 等）快照质量差。

ego lite 的解决思路：

  • 同一浏览器，独立 Space：Agent 在隔离工作区操作，你的日常标签页完全不受影响。
  • 直接继承 Chrome 数据：一键导入登录态、Cookie、扩展、历史，Agent 可操作需要登录的网站（如 X、小红书、后台系统）。
  • 语义快照 + 一次性脚本：高质量压缩 Snapshot（整页通常只要 200–400 Token），Agent 写一段 Node.js 代码一次性完成导航、观察、点击、填表。
  • 任意 Agent 可用：通过 ego-browser Skill 接入，不锁定特定厂商。

适用场景：自动关注账号、抓取社媒内容、批量填表、监控网页更新、登录后数据查询、重复性网页操作等，告别手动重复劳动。

2. 基础使用

安装 ego lite

  1. 访问 https://lite.ego.app/ 下载 Mac 版 DMG。
  2. 打开 DMG，将 ego (lite) 拖入「应用程序」文件夹。
  3. 启动应用，完成 onboarding（引导）。
    • 首次启动会自动扫描本机已安装的 Agent，并把 ego-browser Skill 写入它们的技能目录（如 /.agents/skills、/.claude/skills/ 等）。
    • 可选一键导入 Chrome 数据（登录状态、扩展等），强烈推荐。

3. 技术原理

核心架构：

  • ego lite 浏览器：基于定制 Chromium，嵌入 Node.js 运行时（体积仅增加约 10MB）。

  • Space：同一浏览器内的隔离工作区（不是新窗口、不是新 Profile、不是 headless）。多个 Agent 可并行运行多个 Space，互不干扰。

  • ego-browser 运行时

    ：通过 Chrome DevTools Protocol (CDP) 控制真实会话。Agent 以 Node.js heredoc 形式一次性提交完整脚本：

  • Snapshot：高质量语义快照（无障碍树 + 简短 ref），远比原始 HTML 节省 Token，对嵌套 iframe 处理更好。

  • 辅助函数：snapshotText()、click()、fillInput()、js()（页面内 JS 注入）、cdp()（原始 CDP）、browserFetch() 等，全部预注入脚本作用域。

4. 进阶实战

常用命令模式

  • 创建/复用任务 Space：useOrCreateTaskSpace(‘任务名’)
  • 打开/复用标签：openOrReuseTab(url, { wait: true, timeout: 20 })
  • 获取快照：snapshotText() 或更详细版本
  • 交互：click(‘@ref’)、填表、滚动、等待
  • 输出：cliLog(…)

真实场景示例

  1. 自动关注 / 互动：让 Agent 在 X 上关注指定账号、点赞、评论（继承登录态，无需重新登录）。
  2. 内容抓取与总结：打开多个博客/社媒页面，提取最新文章核心并总结（适合每日信息流）。
  3. 批量操作：多 Space 并行处理多个网站（如同时监控竞品、填多个后台表单）。
  4. 复杂流程：登录后台 → 查询数据 → 导出/截图验证 → 回报结果。
  5. 与其他 Skill 结合：配合知识库、文件读写等，形成完整工作流。

进阶技巧

  • Experience / Learnings：Skill 支持按站点积累经验包（manifest + notes + tools），让 Agent 对特定网站越来越聪明。
  • 观察与接管：在 ego lite 中可随时查看 Agent 的 Space，手动干预。
  • 多 Agent 并行：不同 Agent（Claude + Codex）同时驱动不同 Space，互不冲突。
  • 安全注意：复用真实登录态意味着 Agent 能访问你的登录数据。仅在可信环境使用，避免过度自动化触发平台风控。反爬检测仍需注意（官方建议“别太过分”）。

故障排查

  • Skill 未识别：重启 Agent，确认路径 ~/.agents/skills 或对应目录。
  • 启动失败：检查 macOS 权限，确保 Full access。
  • 快照异常：复杂页面可尝试 js() 注入或原始 CDP。
  • Windows/Linux：目前不支持，可关注官方更新或用 Playwright 自行复刻（需解决登录态拷贝问题）。

总结与资源

ego lite + ego-browser Skill 把浏览器自动化从“笨重框架”变成“Agent 原生能力”，真正实现人机并行、登录态无缝、Token 高效。适合日常重复网页任务、信息收集、轻量爬虫、自动化办公。
