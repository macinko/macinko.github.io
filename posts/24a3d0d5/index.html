Intelligent Terminal 由微软开发、原生集成 AI 代理的实验性

更新于2026-09-05|aitool
|总字数:1.7k|阅读时长:5分钟|浏览量:

这份详细的部署教程将指引您安装和使用 Intelligent Terminal——一个由微软开发、原生集成 AI 代理的实验性 Windows Terminal 分支版本。

Intelligent Terminal 的核心价值在于，它将 AI 助手直接嵌入到您的命令行工作流中。您可以在终端内与 AI 代理（如 GitHub Copilot、Claude、Codex 等）对话，它能自动感知您的 Shell 输出和错误，并提供上下文相关的建议、命令修复，甚至直接生成并执行任务。

📥 安装 Intelligent Terminal

Intelligent Terminal 需要 Windows 10 2004 (内部版本 19041) 或更高版本。推荐通过以下方式安装，以便自动更新。

方式一：Microsoft Store（最推荐）
这是最简单的安装方式，能确保您始终使用最新版本。直接在 Microsoft Store 中搜索 “Intelligent Terminal” 并安装。

方式二：使用 WinGet 安装
如果您习惯使用包管理器，可以在终端中运行以下命令：

方式三：手动下载安装包
您也可以从 GitHub Releases 页面 下载适用于 x64、arm64 或 x86 架构的安装包（App Installer 或 .msixbundle）进行手动安装。

🚀 首次启动与初始配置

安装完成后，首次启动 Intelligent Terminal 会引导您完成基本设置。

  1. 选择您的 AI 代理：启动时，终端会自动检测您电脑上已安装的 ACP 兼容代理 CLI（如 GitHub Copilot、Claude Code、Codex 等）。如果没有找到，它会默认安装 GitHub Copilot CLI。
    • 如果您还没有代理：只需按提示操作，Intelligent Terminal 会通过 WinGet 自动为您安装 GitHub Copilot CLI。
  2. 身份验证：根据您选择的代理，代理面板会引导您完成登录。例如，GitHub Copilot 需要您登录 GitHub 账户并授权。对于 GitHub Copilot Enterprise 用户，在登录提示时按 E 键并输入您的企业主机地址（如 your-org.ghe.com）。
  3. 开始使用：完成登录后，您就可以在代理面板中提问了。代理会自动获取当前 Shell 的上下文（如命令输出），无需您手动复制粘贴。

首次启动常见问题：

  • 如果在 PowerShell 中看到 “running scripts is disabled on this system” 或 UnauthorizedAccess 错误，说明执行策略阻止了脚本运行。请以管理员身份运行 PowerShell 并执行：Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned，然后重新启动 Intelligent Terminal。

⌨️ 核心功能与快捷键

安装并登录后，您可以通过以下快捷键和功能，将 AI 无缝集成到命令行工作中。

快捷键 功能描述
Ctrl+Shift+. 切换代理面板的显示/隐藏。这是最常用的快捷键。
Ctrl+Shift+I 在终端内容和代理面板间切换焦点。
Ctrl+Alt+. 打开代理面板并自动加载错误上下文，用于诊断最近的命令失败。
Ctrl+Shift+/ 打开代理管理面板，查看所有活跃代理和会话。
Alt+Shift+/ 打开命令面板并直接进入提示输入模式，用于快速发起任务。
Alt+Shift+B 在新标签页中打开一个交互式代理标签页，不包含启动提示。
Alt+V 将剪贴板中的图片粘贴到代理面板中（支持截图或图表，具体使用取决于您的代理是否支持图像输入）。

代理面板内的命令

在代理面板的输入框中，输入 / 可以查看所有可用的斜杠命令。常用的包括：

  • /agent [id]：为当前标签页切换不同的代理。
  • /model [id]：为当前面板切换不同的模型（如您配置了自定义提供商）。
  • /fix [hint]：诊断当前终端并建议修复方案，可添加可选提示，如 /fix the path looks wrong。
  • /clear：清除当前对话历史（保持会话）。
  • /new：开始一个全新的代理会话（丢弃历史）。
  • /restart：重启代理会话。
  • /config：配置当前会话的参数，如模式（agent/plan/autopilot）、推理努力等。

⚙️ 高级配置与自定义

您可以通过 设置 → Agent 页面进行详细配置。

  • 默认代理与模型：设置您首选的代理（如 GitHub Copilot）和模型。您也可以在此配置自定义提供商 (BYOK)，使用自己的 OpenAI 兼容 API 端点（如本地 Ollama 模型）。API 密钥会安全存储在 Windows 凭据管理器中。
  • 代理面板位置：可以将代理面板固定在窗口的 顶部、底部（默认）、左侧或右侧。
  • 错误检测与建议：配置终端是否自动检测命令失败，以及是否自动将错误发送给代理以获取修复建议。您也可以随时使用 /fix 命令手动触发。
  • 按配置文件指定代理：您可以在每个 Shell 配置文件（如 PowerShell、WSL Ubuntu）的设置中，指定该配置文件专属的代理，覆盖全局设置。对于 WSL 配置文件，代理选择器还会列出该发行版内安装的代理。

🔒 数据与隐私须知

Intelligent Terminal 本身只是一个本地传输层，它不会直接调用云端 API。您的数据（提示词、Shell 上下文）会发送给您选择的代理 CLI，其数据路由和处理方式由该代理的供应商决定。

  • 默认代理：使用 GitHub Copilot 时，数据会发送到 GitHub 后端，适用其 隐私政策。
  • 第三方代理：使用 Claude、Codex 等第三方代理时，数据将由该供应商处理，请务必查看其隐私条款。
  • 遥测数据：Intelligent Terminal 会收集使用数据以改进产品，但您可以在设置中禁用遥测。更多详情请参阅项目中的 PRIVACY.md 文件。

🆘 获取帮助与反馈

  • 问题反馈：Intelligent Terminal 处于实验阶段，如果您发现 Bug 或有功能建议，请在 GitHub Issues 提交。
  • 收集日志：当您提交问题时，可以使用 Ctrl+Shift+P 打开命令面板，搜索并运行 “Report a bug (collect logs)”，生成的 ZIP 日志文件将自动在文件资源管理器中打开，请将其附加到 Issue 中以便排查。

Intelligent Terminal 会作为一个独立应用安装，与您现有的 Windows Terminal 并存。您可以根据需要随时切换使用，不会影响现有的终端工作流。
