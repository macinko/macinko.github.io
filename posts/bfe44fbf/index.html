Open Notebook 的官方仓库，这是一个开源的、注重隐私的

更新于2026-09-13|toolssoftware
|总字数:1.2k|阅读时长:3分钟|浏览量:

🧭 核心特性与优势

Open Notebook 让你能完全掌控自己的研究数据，并自由选择 AI 后端。它的核心优势包括：

  • 隐私至上：数据完全由你控制，支持 100% 本地运行（通过 Ollama/LM Studio），无需上传至云端。
  • 模型自由：支持 18+ AI 提供商，包括 OpenAI、Anthropic、Google、Groq、Ollama 等，并允许在同一界面中切换使用。
  • 强大的播客生成：支持 1-4 位演讲者的自定义播客脚本，比 Google Notebook LM 的 2 人模式更灵活。
  • 丰富的内容支持：可处理 PDF、视频、音频、网页等多种格式，并提供智能搜索（全文+向量）和上下文聊天功能。
  • 开源与可扩展：拥有完整的 REST API，便于集成和二次开发。

📦 部署方式

项目提供了多种部署方式，以适应不同用户的需求。Docker Compose 是最推荐、最快捷的方式。

方式一：Docker Compose 部署（推荐）

这是最简单、最标准的生产部署方式，适合所有用户。

步骤：

  1. 准备 docker-compose.yml 文件：
    在目标目录中，直接下载官方文件或手动创建：

  2. 设置加密密钥（关键安全步骤）：
    编辑 docker-compose.yml，找到 open_notebook 服务的环境变量，将 OPEN_NOTEBOOK_ENCRYPTION_KEY=change-me-to-a-secret-string 中的值替换为一个只有你知道的强随机字符串。此密钥用于加密数据库中的 API 密钥等敏感信息。

  3. 启动服务：

    等待约 15-20 秒，服务启动完成后，访问 http://localhost:8502 即可打开 Web 界面。

  4. 配置 AI 模型：首次进入界面后，需导航至“Models”页面，添加并配置你需要的 AI 提供商（如 OpenAI）的 API 密钥，然后“Sync Models”并“Auto-Assign Defaults”。

使用免费本地 AI：如果你想完全离线运行，可以参考项目提供的 examples/docker-compose-ollama.yml 文件，配合 Ollama 使用。

方式二：从源码运行（开发者模式）

适合希望进行二次开发或贡献代码的用户。

环境要求：Python、Node.js、Poetry 等。

  1. 克隆仓库。
  2. 分别设置后端（Python/FastAPI）和前端（Next.js/React）开发环境。
  3. 配置数据库（默认使用 SurrealDB）。
  4. 详细步骤请参考项目中的开发文档。

🚀 快速开始：创建你的第一个笔记本

部署成功后，即可开始使用：

  1. 创建笔记本 (Notebook)：在主界面点击“新建”，为你的研究项目（如“量子计算调研”）命名。
  2. 添加内容源 (Sources)：在笔记本中，你可以：
    • 上传 PDF、Word 文档。
    • 粘贴网页 URL。
    • 上传音频或视频文件。
    • 系统会自动处理并索引这些内容。
  3. 与 AI 聊天 (Chat)：在笔记本的聊天界面中提问，AI 会基于你添加的内容源进行回答，并引用来源。
  4. 生成播客 (Podcast)：这是 Open Notebook 的亮点功能。你可以：
    • 选择笔记本中的内容作为播客素材。
    • 配置 1-4 位演讲者的角色、声音和对话脚本。
    • 生成专业的多人对话式播客音频。

⚙️ 高级配置与管理

  • 多模型管理：你可以在一个笔记本中为不同任务（如聊天、嵌入、播客旁白）分配不同的 AI 模型。
  • 内容转换 (Transformations)：内置了摘要、提取要点等操作，你也可以创建自定义处理流程。
  • MCP 集成：支持与 Claude Desktop、VS Code 等 MCP 客户端连接。
  • API 访问：提供了完整的 REST API，可实现自动化操作。
  • 安全：可为公开部署设置密码保护，防止未授权访问。

❓ 常见问题与排查

  • API 密钥无效：确保密钥正确，并在“Models”界面中点击“Test”验证连接。
  • 本地 Ollama 连接失败：检查 docker-compose-ollama.yml 中的网络配置，确保 Open Notebook 服务能访问到 Ollama 容器。
  • 数据库连接错误：确保 SurrealDB 容器已正常启动，且 docker-compose.yml 中的连接字符串（SURREAL_URL）正确。
  • 端口冲突：检查 8502（Web UI）和 5055（API）端口是否被占用，可在 docker-compose.yml 中修改映射端口。

总结

Open Notebook 是一个功能强大且灵活的“第二大脑”式研究工具。对于个人用户和小型团队，强烈推荐使用 Docker Compose 方式部署，它能在数分钟内让你拥有一个完全自控的、类似 Notebook LM 的环境。部署的核心是正确配置 OPEN_NOTEBOOK_ENCRYPTION_KEY 以保障数据安全。日常使用中，可以充分发挥其多模型支持和高级播客生成能力，构建个性化的知识工作流。如果遇到问题，可以加入其 Discord 社区或查阅详细文档获得帮助。
