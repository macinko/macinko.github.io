LinkSwift 安装与使用指南：网盘文件直链获取助手

更新于2026-09-05|toolssoftware
|总字数:1.6k|阅读时长:4分钟|浏览量:

LinkSwift 是一款用户脚本，可以在您访问百度网盘、阿里云盘、123云盘等主流网盘的网页版时，自动添加“下载助手”按钮，帮助您获取文件的直接下载链接，并支持推送到多种下载器（如IDM、Aria2）。

1. 前提条件

在安装 LinkSwift 之前，请确保您的浏览器满足以下要求：

  • 浏览器：Chrome、Edge、Firefox、Safari 等主流浏览器。
  • 用户脚本管理器：您需要先安装一个浏览器扩展来运行用户脚本。推荐：
    • Tampermonkey（油猴）：最流行的脚本管理器，支持所有主流浏览器。
    • ScriptCat（脚本猫）：国内开发者维护，对国内网盘兼容性更好。
    • Violentmonkey：开源的替代方案。
  • 网盘账号：您需要登录相应的网盘账号（部分分享链接无需登录）。

2. 安装 LinkSwift 脚本

2.1 选择安装源

LinkSwift 提供了多个安装源，您可以根据网络情况选择。推荐从 GitHub 或 脚本猫 安装，以获取最新版本。

  1. GitHub（国际，推荐）：访问 GitHub 仓库，点击 （改）网盘直链下载助手.user.js 文件，然后点击 Raw 按钮，脚本管理器会自动识别并提示安装。
    • 直接链接：https://raw.githubusercontent.com/hmjz100/LinkSwift/main/（改）网盘直链下载助手.user.js
  2. 脚本猫（国内）：访问 脚本猫脚本站，点击“安装此脚本”。
  3. OpenUserJS（国际）：访问 OpenUserJS 页面，点击“Install”。

2.2 安装步骤（以 Tampermonkey 为例）

  1. 点击上述任一安装链接。
  2. Tampermonkey 会自动打开一个新标签页，显示脚本源代码。
  3. 点击页面上的 “安装” 按钮。
  4. 安装完成后，脚本图标会出现在浏览器扩展栏中。

3. 使用方法

安装脚本并登录网盘网页版后，您会在页面右上角或文件列表附近看到新增的 “下载助手” 或 “API下载” 按钮。

3.1 基本流程

  1. 打开网盘页面：登录您要下载文件的网盘（如百度网盘），进入文件列表。
  2. 勾选文件：勾选您想要获取直链的一个或多个文件。
  3. 点击“下载助手”：点击页面上的“下载助手”按钮（或类似命名的按钮）。
  4. 获取链接：在弹出的窗口中，会显示文件的直接下载链接。
  5. 选择操作：您可以直接复制链接，或选择“推送到 IDM”、“推送到 Aria2”等。

3.2 支持的网盘与功能

  • 支持的网盘：百度网盘、阿里云盘、123云盘、中国移动云盘、天翼云盘、迅雷云盘、夸克网盘、UC网盘。
  • 主要功能：
    • 获取文件直链（API 下载）。
    • 批量获取多个文件的链接。
    • 推送到 IDM、Aria2（需配置 RPC 服务）、比特彗星 等下载器。
    • 复制 cURL 命令。
    • 自定义下载界面主题色。

4. 配置与个性化

点击脚本管理器（如 Tampermonkey）中的脚本图标，选择“助手设置”可以打开设置面板。

4.1 常用设置选项

  • RPC 下载器配置：如果您使用 Aria2，需要在此填写 Aria2 RPC 的地址、端口和密钥（默认：127.0.0.1:6800，密钥 123456）。可以点击“测试连接”验证。
  • 网盘主题美化：支持修改百度网盘、阿里云盘等页面的主题色。
  • 深色模式：支持跟随系统或强制开启/关闭深色模式。
  • 下载链接缓存：开启后可避免重复获取相同文件链接。
  • IDM 设置：可配置推送到 IDM 时的客户端参数。

5. 注意事项与免责声明

  • 合规性：LinkSwift 仅通过网盘官方公开的 API 获取下载链接，不破解限速。下载速度取决于网盘服务商的策略和您的网络环境。请勿相信任何“加速破解”的夸大宣传。
  • 安全性：脚本完全在浏览器本地运行，您的网盘账号信息（如 AccessToken）仅用于获取直链，不会被上传到第三方服务器。
  • 更新：网盘页面更新可能导致脚本失效。请定期检查脚本版本，或关注 GitHub 仓库的更新。
  • 金丝雀版：仓库中可能提供“金丝雀版”（预览版），包含最新功能但可能不稳定，建议普通用户使用正式版。

6. 常见问题排查

问题 可能原因 解决方案
安装后网盘页面没有出现“下载助手”按钮 脚本未生效或与网盘新版页面不兼容 1. 确认脚本管理器中脚本状态为“已启用”。 2. 刷新页面。 3. 尝试更新脚本到最新版本。
点击按钮后弹出“401”或“9019”错误 网盘 AccessToken 过期或授权失效 1. 退出并重新登录您的网盘账号。 2. 确保浏览器允许第三方 Cookie。
“推送 Aria2”失败或提示 RPC 连接错误 Aria2 RPC 服务未运行或配置信息不正确 1. 确认 Aria2 已启动且 RPC 功能已开启。 2. 在脚本设置中检查 RPC 地址、端口和密钥是否与 Aria2 配置一致。 3. 点击“测试连接”验证。
获取到的链接无法下载或速度慢 链接可能已过期，或网盘对直链有限速 部分网盘直链有有效期，请尽快下载。下载速度受网盘服务商限制，此为正常现象。
脚本更新后部分功能失效 网盘页面改版，脚本适配需要时间 请关注 GitHub 仓库，提交 Issue 反馈问题，并耐心等待开发者更新适配。

7. 总结

LinkSwift 是一个实用、轻量的浏览器脚本，旨在简化从各大网盘获取文件直链的流程。

核心使用路径：

  1. 安装脚本管理器（如 Tampermonkey）。
  2. 安装 LinkSwift 脚本（从 GitHub 或脚本猫安装）。
  3. 登录网盘网页版，勾选文件。
  4. 点击“下载助手”，获取直链或推送到下载器。

该脚本方便了无法或不便使用官方客户端的用户实现合法文件下载，建议定期关注项目更新以保持兼容性。如遇问题，可在 GitHub 仓库提交 Issue 反馈。
