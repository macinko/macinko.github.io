Crisp 是专为 macOS 设计的免费开源外接显示器控制工具

更新于2026-09-05|osmacos
|总字数:1.5k|阅读时长:4分钟|浏览量:

Crisp 是一款专为 macOS 设计的免费开源外接显示器控制工具，以轻量级菜单栏应用的形式呈现。它弥补了 macOS 对外接显示器支持的不足，提供锐利的 HiDPI（Retina 级）缩放、真实 DDC 亮度控制、预设配置、虚拟显示器等功能，是 BetterDisplay 和 Lunar 的免费开源替代品。所有功能完全免费，无 Pro 版本、无授权限制。

  • 官方仓库：https://github.com/didriksg/Crisp
  • 官方网站：https://crispmac.app/
  • 中文页面：https://crispmac.app/zh.html
  • 对比页面：https://crispmac.app/crisp-vs-betterdisplay.html
  • 解决模糊外接显示器指南：https://crispmac.app/fix-blurry-external-monitor-macos.html

开源协议：MIT（完全免费）

1. 核心特性

  • 锐利 HiDPI 缩放：让外接显示器（尤其是 1440p 及以上）显示清晰的 Retina 级界面，不再模糊或文字过小。自动为支持的显示器配置，并保持面板最高刷新率（避免 144Hz 显示器被锁到 50Hz）。
  • 平滑缩放（Smooth Scaling）：比 macOS 自带选项更精细的缩放调节，类似 BetterDisplay 的核心卖点。
  • 亮度控制：通过 DDC 直接控制外接显示器真实背光；不支持 DDC 的显示器则使用软件调光，并可低于硬件最低亮度。支持平滑过渡，亮度键可跟随鼠标、控制全部显示器或指定显示器。
  • Extra Brightness（超高亮度）：解锁 XDR MacBook 屏幕和 HDR 显示器的 HDR 亮度储备，突破 100%（类似 BetterDisplay 的 brightness upscaling）。
  • 音量控制：通过 DDC 控制外接显示器内置扬声器音量，支持键盘音量键映射。
  • 预设（Presets）：一键保存/应用分辨率、亮度、排列等配置，支持自定义图标和颜色。
  • 显示器排列：拖拽式画布调整位置，切换主显示器。
  • 断开显示器：从菜单一键关闭/开启物理显示器（Apple Silicon 支持睡眠唤醒后记忆状态）。
  • 系统开关：一键切换深色模式、Night Shift、True Tone。
  • 颜色管理：ICC 配置文件切换、XDR 参考预设、HDR 开关、伽马/对比度/色温/反色等图像调整。
  • 虚拟显示器：创建 HiDPI 虚拟屏幕。
  • 其他实用功能：合并亮度滑块、跟随内置显示器自动亮度、保持唤醒、隐藏 Notch、开机启动等。

完整本地化支持英文和简体中文。

2. 系统要求与权限

系统要求：

  • macOS 14（Sonoma）或更高版本
  • 在 macOS 26 上会使用原生 Liquid Glass 背景

所需权限：

  • 管理员密码（一次性，针对每个显示器）：仅在开启「平滑缩放」时需要，用于安装受保护的显示覆盖文件。普通 HiDPI 缩放和其他功能无需密码。
  • 辅助功能（Accessibility）：仅在开启「亮度键控制外接显示器」时需要。不开启也不影响其他功能。

3. 安装方法

方法一：Homebrew（推荐）

方法二：直接下载 DMG

  1. 前往 Releases 页面 下载最新的 Crisp.dmg。
  2. 打开 DMG，将 Crisp 拖入「应用程序」文件夹。
  3. 双击启动即可（已签名并经 Apple 公证，正常打开无警告）。

从 v1.5.0 开始支持应用内自动更新（后台静默检查，一键安装）。

4. 基本使用

  1. 安装后，Crisp 会以菜单栏图标形式运行。
  2. 点击菜单栏图标，弹出控制面板。
  3. 面板会显示所有已连接显示器，提供：
    • 分辨率 / 缩放选择
    • 亮度滑块（支持 DDC）
    • 音量滑块（支持时）
    • 预设按钮
    • 排列与其他开关

常用操作建议：

  • 首次连接 1440p 或更高分辨率显示器时，优先尝试开启 HiDPI 缩放，体验清晰度提升。
  • 需要精细调节界面大小时，开启「平滑缩放」。
  • 创建多个预设（如「办公」「游戏」「影音」），一键切换。
  • 将亮度键设置为「跟随鼠标」或「控制全部显示器」，提升多屏体验。

5. 与 BetterDisplay / Lunar 的对比

Crisp 专注于日常最常用功能，并全部免费开放：

  • 灵活的 HiDPI 与平滑缩放
  • 硬件 DDC 亮度 + Extra Brightness
  • 预设、断开显示器、颜色调整、自动亮度同步

BetterDisplay 和 Lunar 功能更深、更全面（尤其是高级虚拟显示器、EDID 编辑等），但核心常用功能常需付费。Crisp 的定位是「把 macOS 隐藏的显示器控制能力集中到一个轻量免费工具里」。详细对比见官网：https://crispmac.app/crisp-vs-betterdisplay.html

6. 从源码构建（开发者）

更详细的构建与开发循环说明见仓库 docs/BUILDING.md。

7. 支持与贡献

Crisp 完全免费，主要成本是每年 $99 的 Apple 开发者计划（用于签名与公证）。如果你觉得好用，可考虑赞助：

  • GitHub Sponsors：https://github.com/sponsors/didriksg
  • Ko-fi：https://ko-fi.com/didriksg
  • 爱发电：https://ifdian.net/a/didriksg

欢迎提交 Issue、Feature Request 或 Pull Request。遇到兼容问题的显示器，也欢迎反馈。

起源：基于 FreeDisplay 的 fork 进行了大幅重写（自定义面板架构、原生控件、亮度管线重构、完整重新设计）。

8. 总结与使用建议

如果你正在使用外接显示器，并经常遇到以下问题：

  • 文字模糊或过小
  • 无法方便调节外接屏亮度
  • 想要快速切换不同显示配置
  • 不想为常用功能付费

那么 Crisp 是目前最推荐的免费解决方案之一。

快速上手步骤：

  1. 用 Homebrew 或 DMG 安装。
  2. 打开菜单栏面板，为外接显示器开启 HiDPI。
  3. 根据需要开启平滑缩放和 Extra Brightness。
  4. 创建几个常用预设。
  5. 按需开启亮度键控制和开机启动。
