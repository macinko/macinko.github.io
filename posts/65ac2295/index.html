📦 Linux-on-Android (Termux) 详细部署教程

本教程将指导您把一部旧安卓手机无需 root、无需电脑、无需云服务，通过 Termux 改造为一台带 GPU 加速的 Linux 桌面（XFCE4/KDE 等）或一个 Home Assistant 智能家居服务器。

⚙️ 部署前准备

硬件要求

  • 处理器：arm64 (64位) 架构。Snapdragon (骁龙) 芯片最佳，能提供最好的 GPU 加速支持 (Turnip/Adreno 驱动)。Mali 等 GPU 也可工作，但性能会弱一些。
  • 内存：建议 3GB 以上 (4GB+ 才推荐运行 KDE Plasma)。
  • 存储：至少 5-10GB 可用空间 (安装 Wine 需要更多)。
  • 电量：建议连接充电器，避免安装过程中断电。

❓ 常见问题与排查 (FAQ)

  • 脚本中途退出：检查日志 ~/termux-setup.log 的最后几行，定位失败的包。常见原因是网络中断或特定包冲突。
  • 启动桌面后 Termux-X11 黑屏：先运行 bash ~/stop-linux.sh 停止，再重新 bash ~/start-linux.sh 启动。KDE 首次启动可能需要更长时间。
  • 桌面没有声音：PulseAudio 需要几秒钟初始化，在桌面出现后等待片刻。
  • “D-Bus” 相关错误：这是会话总线问题。脚本已包含修复，如果出现在旧安装上，请重新运行 termux-linux-setup.sh 以更新启动脚本。
  • 安装包时出现 “Conflicts” (冲突) 错误：脚本已内置冲突处理逻辑。如果仍出现，请记录设备型号和 Android 版本，在 GitHub 提交 Issue。
  • Home Assistant 设备无法自动发现：这是 Android 10+ 限制 /proc/net/dev 导致 mDNS 失效导致的。请务必手动通过 IP 地址添加设备。

📚 进阶技巧

  • 自定义 GPU 驱动：GPU 环境配置保存在 ~/.config/linux-gui.sh，可手动编辑 Mesa 参数。
  • 更新 Home Assistant：运行 bash ~/upgrade-homeassistant.sh。
  • SSH 免密登录：将电脑的公钥 (~/.ssh/id_rsa.pub) 追加到手机 Termux 的 ~/.ssh/authorized_keys 文件中。

更详细的配置、视频教程和故障排查，请务必查阅项目的 GitHub 仓库 和 README 文档。
