OPC Skills 为独立开发者、一人公司准备的 AI 助手技能库

更新于2026-09-05|aiagent
|总字数:1.2k|阅读时长:4分钟|浏览量:

OPC Skills 是一个为独立开发者、一人公司准备的 AI 助手技能库，可以帮助你快速为常用的 AI 编程工具（如 Claude Code, Cursor, Codex）扩展自动化功能。它本身是一个即插即用的工具集，不需要复杂的后端部署，重点在于将技能安装到你的 AI 工作流中。

📦 核心技能概览

这个技能库主要聚焦于产品探索、营销和开发效率。根据官方文档，目前包含以下核心技能：

技能名称 功能描述 依赖技能
seo-geo 针对 ChatGPT、Perplexity 等 AI 搜索引擎的 SEO 与 GEO 优化 twitter, reddit
requesthunt 从 Reddit、Twitter/X 和 GitHub 研究用户需求 无
domain-hunter 查找域名、比较注册商价格、发现优惠码 twitter, reddit
logo-creator 利用 AI 创建 Logo，支持裁剪、去背景、导出为 SVG nanobanana
banner-creator 为 GitHub、Twitter、LinkedIn 等平台创建横幅 nanobanana
nanobanana 使用 Gemini 3 Pro Image 模型生成图片 无
reddit 通过公共 JSON API 搜索和检索 Reddit 内容 无
twitter 通过 twitterapi.io 搜索和检索 Twitter/X 内容 无
producthunt 搜索 Product Hunt 上的帖子、话题、用户和合集 无
archive 将会话中学到的知识和调试方案存档为带索引的 Markdown 文件 无

注意：安装具有依赖关系的技能时（如 domain-hunter），需要将依赖技能一同安装。

🚀 核心工作流：使用 archive 技能

archive 技能是一个很有用的功能，它能解决 AI 会话间上下文丢失的问题。

  1. 触发存档：在解决完一个棘手的问题或完成一个阶段性的部署后，你可以对 AI 助手说：“Archive this” 或 “Save these learnings”。
  2. 自动记录：AI 助手会将本次会话的关键信息、解决方案等，生成一个带 YAML 元数据（如标签、分类）的 Markdown 文件，存放在项目根目录的 .archive/YYYY-MM-DD/ 文件夹下，并更新 .archive/MEMORY.md 索引。
  3. 跨会话复用：在未来的会话中，AI 助手可以读取 .archive/MEMORY.md，快速找到过往的相关解决方案，实现知识的累积和复用。

🗑️ 更新与卸载

  • 更新技能：重新运行安装命令即可获取最新版本，例如 npx skills add ReScienceLab/opc-skills --skill reddit。
  • 卸载技能：手动删除对应技能目录即可。例如，项目级安装的技能目录为 .factory/skills/<skill-name>/。

通过以上步骤，你应该已经顺利将 OPC Skills 集成到了你的 AI 工作流中。这些技能可以帮你快速完成许多重复性的研发和调研任务，节省下来的时间可以用来专注在更有创造性的工作上。如果在使用特定技能时遇到问题，可以随时参考项目官方文档或在对应的 GitHub 仓库中查看更详细的说明。
