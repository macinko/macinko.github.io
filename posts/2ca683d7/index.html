Xianyu AutoAgent 闲鱼机器人：实用工具推荐

更新于2026-08-22|toolssoftware
|总字数:456|阅读时长:1分钟|浏览量:

Xianyu AutoAgent：

一款专为闲鱼平台打造的AI值守解决方案，实现闲鱼平台7×24小时自动化值守，支持多专家协同决策、智能议价和上下文感知对话。

准备

需要准备下面文件，部署的时候需要用到

创建 .env 配置文件

获取通义千问 API：

https://bailian.console.aliyun.com/?tab=app#/api-key

获取闲鱼 Cookie：

https://www.goofish.com/

按 F12 打开开发者工具，切换到 Network（网络）标签，点击登录

登录以后刷新一下网页，复制请求头中的 Cookie

创建提示词文件

提示词内容从 GitHub 源代码中获取

https://github.com/shaxiu/XianyuAutoAgent

可以通过编辑 prompts 目录下的文件来自定义各个专家的提示词

●classify_prompt.txt：分类提示词

●price_prompt.txt：价格提示词

●tech_prompt.txt：技术提示词

●default_prompt.txt：默认提示词

按实际需要修改里面内容，文件名称需要重命名

安装

Docker Compose

参数说明（更多参数设置建议去看文档）

/app/data（路径）：数据存储目录，包含聊天历史和日志
/app/prompts（路径）：提示词模板目录
/app/.env（路径）：环境变量配置文件

创建文件夹，将上面文件放到隐射路径里面

使用

启动容器后，查看日志正常运行

如果有客户询问，会自动进行回复

总结

虽然目前闲鱼也有 AI 回复功能，但其实不太智能，用这个可以灌更多知识更详细回答问题。这里只作为分享，不保证是否会有封号的风险。
