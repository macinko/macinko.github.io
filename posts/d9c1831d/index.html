OpenMausBot：把 AI 当微信联系人聊天的开源应用

更新于2026-09-05|toolssoftware
|总字数:503|阅读时长:1分钟|浏览量:

一个开源的 AI 聊天应用，相当于自己搭一个 Grok Bot。核心思路是把 AI 当成通讯录里的联系人，每个机器人有独立性格、独立模型、独立电脑，聊起来跟微信差不多。

Github地址

https://github.com/milind-soni/OpenMausBot

功能特性

  • 多机器人并排聊：侧边栏像微信列表，每个机器人单独配置模型，Claude 和 Codex 放一起比都行
  • 每台机器人配电脑：云端 Linux 桌面或者本地 Mac，实时看屏幕，随时接管
  • 敏感操作要审批：执行命令、改文件、访问权限，弹卡片让你点允许还是拒绝
  • 语音对话：按喇叭念回复，或者打过去实时聊，用的是 ElevenLabs，自己带 API key
  • 连外部应用：Gmail、Slack、GitHub、Notion 这些，OAuth 一次，所有机器人都能用
  • 本地优先：聊天记录、密钥全存 ~/.openmausbot，不走别人服务器

怎么跑起来

有现成安装包就最省事：

系统 下载 装法
macOS Apple 芯片 OpenMausBot.dmg 拖进 Applications，已签名公证
Windows 64 位 OpenMausBot-setup.exe 双击装，不用管理员权限，SmartScreen 报未知发行商时点”更多信息 → 仍要运行”

Ubuntu 24.04 也有 beta 包，但本地屏幕控制和语音还没上。

从源码编译

要 Node 24+、pnpm，以及至少装了一个 CLI 工具：claude、codex、grok，登录过就行，模型选择器会自动识别。

打安装包：

几个要填的 key（可选，不填也能本地聊天）

  • Composio Connect key：连 Gmail、GitHub 等应用
  • Composio API key：看完整应用市场
  • Box API key：给机器人配云端电脑
  • ElevenLabs key：语音朗读和打电话
