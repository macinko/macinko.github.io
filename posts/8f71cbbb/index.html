Ydisks 闲鱼助手：Go + React 多账号自动发货与消息回复系统

更新于2026-09-05|toolssoftware
|总字数:1.7k|阅读时长:5分钟|浏览量:

Ydisks闲鱼助手”的官方仓库，这是一个基于 Go 和 React 构建的闲鱼多账号自动发货与消息回复系统。以下是完整的部署与使用教程。

⚠️ 重要法律与合规声明

在开始之前，请务必阅读并理解以下关键声明：

  • 非官方授权：本项目未获得闲鱼/阿里巴巴任何官方授权，调用的是闲鱼网页端非公开接口。
  • 违反用户协议：使用本软件将违反闲鱼用户协议，可能造成闲鱼账号封禁。
  • 风险自担：本项目仅用于个人技术学习研究，所有使用后果由使用者自行承担，项目作者不承担任何责任。
  • 随时可能归档：收到平台下架通知时，本项目会随时删除归档。

🧭 核心功能与适用场景

Ydisks闲鱼助手是一个自托管的 Web 管理系统，主要解决多账号管理、自动化和统一客服问题。

  • 多账号统一管理：集中管理多个闲鱼账号的在线状态、消息和订单。
  • 自动发货：针对数字商品（如兑换码、资料链接），付款后自动发送卡密或内容。
  • 智能客服：支持关键词自动回复、默认回复，并可接入 OpenAI 兼容的 AI 接口进行智能对话。
  • 自动化运营：支持自动评价、每日“擦亮”商品、订单同步等功能。
  • 数据看板：提供订单、营收、库存、商品销量等统计。

🚀 初次使用流程

部署成功后，按照以下流程配置和使用：

  1. 登录账号：
    • 进入“账号管理”。
    • 使用闲鱼 App 扫描二维码完成账号授权。
    • 关键提示：每次重启程序都会向闲鱼申请登录凭证，频繁操作会触发风控！有账号登录时，不要频繁重启本程序。
  2. 准备交付内容：
    • 进入“卡密库存”，创建文本、批量卡密或图片类型的交付内容。
  3. 配置自动化规则：
    • 在“自动化规则”中，将闲鱼商品与你创建的卡密库存关联，设置触发条件（如“付款后发货”）。
  4. 设置自动任务：
    • 在“账号管理 → 自动评价与每日擦亮”中，配置自动评价文案和每日擦亮时间。
  5. 监控与客服：
    • 通过“在线聊天”集中处理所有账号的会话。
    • 根据需要配置“关键词回复”、“AI 回复”和“通知告警”（支持钉钉、飞书等）。

📋 常用配置与重要目录

  • 核心配置文件：.env（环境变量）和命令行参数。
  • 数据库连接：支持 SQLite（默认）、MySQL、PostgreSQL。生产环境推荐 PostgreSQL。
  • 数据加密密钥（XIANYU_DATA_KEY）：用于加密 Cookie、密码、令牌等敏感信息。此密钥极其重要，丢失后无法解密已有加密数据，必须与数据库备份一起妥善保管！
  • 日志与上传目录：默认在 data/ 目录下。桌面端位置见上表。

❓ 常见问题排查

  • 首次打开页面如何初始化管理员？
    启动服务后访问页面，如果数据库为空，页面会自动显示“首次设置管理员密码”的界面，填写密码即可创建 admin 用户。
  • 账号频繁掉线或需要安全验证？
    1. 查看账号管理中的状态和日志。
    2. 根据页面提示在手机闲鱼 App 完成人脸或安全验证。
    3. 避免在多个实例同时运行同一账号。
    4. 若一直提示验证，请先登录闲鱼官方网页版，人工通过风控后等待一会儿再尝试登录。
  • 修改 XIANYU_DATA_KEY 后无法读取凭证？
    这是正常的安全行为。你必须恢复使用原先的密钥。如无法恢复，只能重新登录所有账号并重新配置所有加密字段。

总结

Ydisks闲鱼助手是一个功能强大的自托管工具，但其合规性风险极高。强烈建议仅将此项目用于个人技术学习研究。如果你决定在生产或半生产环境使用，必须优先使用 Docker Compose 方式部署，并务必备份好 .env 中的 XIANYU_DATA_KEY 和 PostgreSQL 数据库。同时，务必做好账号被平台风控甚至封禁的心理准备和应对预案。
