  3. 一个可用的模型订阅或 API Key

几个高频操作

这些命令基本够你完成日常使用

  1. /model：选择或切换模型；
  2. /settings：调整推理强度、主题等设置；
  3. /session：查看当前会话、token 和成本；
  4. /resume：打开以前的会话；
  5. /tree：回到历史节点，从那里尝试另一条路线；
  6. /compact：压缩较早内容，为长任务释放上下文；
  7. /new：开始一个新会话；
  8. /hotkeys：查看全部快捷键；
  9. /quit：退出 Pi。
