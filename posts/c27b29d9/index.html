VeighNa (vnpy) 详细部署教程

VeighNa（原名 vnpy）是一套基于 Python 的开源量化交易系统开发框架，自发布以来已积累众多来自私募基金、证券公司等机构的用户。本教程将指导你完成从环境准备到最终启动量化交易终端的全流程。

准备工作

系统与硬件要求

  • 操作系统：Windows 11/Windows Server 2022、Ubuntu 22.04 LTS、macOS 10.13+。
  • Python 版本：Python 3.10 以上（64 位），推荐 Python 3.13。
  • 硬件：内存至少 4GB（虚拟机需调至 4GB 以上，否则编译会报错）。

前置知识

  • 基础命令行操作。
  • 了解 Python 虚拟环境概念（推荐使用 conda 或 venv）。

Windows 部署（推荐新手）

VeighNa 为 Windows 用户提供了一站式 Python 发行版 VeighNa Studio，这是最快捷的安装方式，集成了 Python 解释器、VeighNa 框架及所有依赖库。

方式一：VeighNa Studio 一键安装（最简单）

第一步：下载安装包

  • 访问 VeighNa 官网，找到 VeighNa Studio 下载链接。注意官网提供的是 VeighNa Station（图形化管理工具）的下载入口，Studio 是包含完整环境的安装包。

第二步：运行安装

  1. 双击下载的安装包，推荐右键选择“使用管理员身份运行”。
  2. 按照安装向导，点击 “快速安装” 使用默认路径（C:\veighna_studio）。
  3. 等待安装完成，桌面会出现 VeighNa Station 图标。

第三步：启动
双击桌面 VeighNa Station 图标，登录社区账号后，点击 “VeighNa Trader” 按钮即可启动量化交易终端。

源码手动安装（进阶）

如果你需要对 VeighNa 进行二次开发，可以选择源码安装模式。

通用步骤：

  1. 克隆项目：git clone https://github.com/vnpy/vnpy.git
  2. 安装依赖：pip install -r requirements.txt
  3. 安装框架：pip install -e .（可编辑模式，便于开发调试）

各平台对应脚本：

  • Windows：install.bat
  • Ubuntu：install.sh
  • macOS：install_osx.sh

注意事项：在 Linux 上编译 C++ 接口时，若使用 --no-build-isolation，需提前安装 meson-python、meson、pybind11、ninja-build 等依赖。

常见问题与解决

  • Q: 安装时提示 command 'gcc' failed？
    • A: 缺少 Python 开发头文件。运行 sudo apt-get install python3-dev（Ubuntu）或确保 Windows 上已安装 Visual C++ Build Tools。
  • Q: Ubuntu 启动时提示 qt.qpa.plugin: Could not load the Qt platform plugin "xcb"？
    • A: 图形驱动依赖缺失。运行 sudo apt-get install libxcb-xinerama0。
  • Q: 连接 CTP 接口时出现 locale::facet::_S_create_c_locale name not valid？
    • A: 系统缺少中文编码。运行 sudo locale-gen zh_CN.GB18030 并安装中文字体。
  • Q: Docker 容器内无法显示图形界面？
    • A: 需要配置 X Server（如 Windows 上的 XLaunch）并正确传递 DISPLAY 变量和挂载 X11 socket。参考 Docker 部署 章节。
  • Q: 提示内存不足？
    • A: 编译过程需要较大内存，虚拟机请将内存调至 4GB 以上。
  • Q: VeighNa Station 和 VeighNa Studio 是什么关系？
    • A: VeighNa Studio 是一整套量化 Python 发行版，而 VeighNa Station 是这个发行版中的图形化管理工具，用于启动 VeighNa Trader 等应用。

通过以上步骤，你应该已经成功部署了 VeighNa 量化交易框架。无论你是想进行策略回测还是实盘交易，这套框架都提供了完整的工具链。建议从 CTA 策略回测模块入手，逐步探索其强大的功能。
