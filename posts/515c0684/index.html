ScriptCat（脚本猫）是功能强大的开源用户脚本管理器浏览器扩展

更新于2026-09-05|toolssoftware
|总字数:1.9k|阅读时长:6分钟|浏览量:

ScriptCat（脚本猫）是一款功能强大的开源用户脚本管理器浏览器扩展，完全兼容油猴（Tampermonkey）脚本，并在此基础上创新实现了后台脚本运行框架、定时任务、更丰富的 API，以及内置智能代码编辑器。它能让你轻松定制网页、去广告、自动化操作、增强视频体验等，真正给浏览器装上“超能力”。

  • 官方仓库：https://github.com/scriptscat/scriptcat
  • 官方文档：https://docs.scriptcat.org/
  • 脚本站：https://scriptcat.org/
  • 社区：油猴中文网（https://bbs.tampermonkey.net.cn/）、Telegram、Discord

开源协议：GPLv3（完全免费、开源、无广告）

1. 核心特性

云端同步

  • 脚本与配置跨设备同步，换浏览器/重装系统后一键恢复
  • 脚本订阅：创建脚本合集，支持团队协作

强大功能

  • 完全兼容油猴：现有 Tampermonkey 脚本几乎零改动直接使用
  • 后台脚本：无需打开网页标签页，脚本也能持续后台运行
  • 定时脚本：支持 Cron 表达式，实现每日自动签到、定时提醒等
  • 丰富 API：比传统油猴更多强大接口（文件存储、跨域请求、通知等）

安全可靠

  • 沙盒隔离运行，防止恶意代码互相影响
  • 权限明确申请，敏感操作需用户二次确认

开发体验

  • 内置 Monaco 智能编辑器（语法高亮、智能补全、ESLint）
  • 完善调试工具与日志
  • 现代化 UI

最新版本还支持 AI Agent（预览）、@unwrap、window.onurlchange、右键菜单运行等新特性。

2. 安装方法

2.1 推荐：从扩展商店安装（自动更新）

浏览器 正式版链接 Beta 版链接 状态
Chrome 正式版 Beta ✅ 可用
Edge 正式版 Beta ✅ 可用
Firefox 正式版 Beta ✅ MV2

2.2 手动安装（无法访问商店时）

  1. 前往 GitHub Releases 下载最新 .zip 或 .crx 文件。
  2. 若是 .crx，先改后缀为 .zip 并解压到固定文件夹（此文件夹不可删除或移动）。
  3. 打开浏览器扩展管理页面（chrome://extensions 或 edge://extensions），开启开发者模式。
  4. 点击「加载已解压的扩展程序」，选择刚才的文件夹。
  5. 安装完成后，点击扩展图标 → 右上角 ┆ → 「获取脚本」即可进入脚本站。

注意：手动安装不会自动更新，更新时需重复上述步骤替换文件并重新加载。

2.3 安装后首次操作

  • 点击浏览器工具栏中的脚本猫图标，进入管理面板。
  • 系统会自动启动新手引导（也可从「帮助中心」重新打开）。
  • 引导内容包括：安装脚本、管理操作、备份、从其他管理器迁移、同步与订阅。

3. 获取与安装脚本

3.1 推荐脚本来源

  1. ScriptCat 官方脚本站：

    https://scriptcat.org/

    • 支持后台脚本 / 定时脚本专区
    • 界面友好，可直接发布自己的脚本

  2. GreasyFork：https://greasyfork.org/（海量经典脚本）

  3. Userscript.Zone：通过 URL/域名搜索脚本

  4. GitHub / Gist：搜索 ==UserScript==

  5. 油猴中文网：获取资讯与教程

3.2 安装脚本步骤

  1. 在脚本站找到想要的脚本，点击「安装」。
  2. 脚本猫会弹出安装确认页，显示权限与元数据。
  3. 确认后即可使用。 大多数油猴脚本可直接安装；若遇不兼容，请到 GitHub Issues 反馈。

后台脚本专区：https://scriptcat.org/zh-CN/search?script_type=3（体验独有能力）

4. 日常使用与管理

4.1 管理面板功能

  • 启用 / 禁用脚本：一键开关
  • 编辑脚本：内置智能编辑器，支持语法检查与补全
  • 运行 / 停止：对后台脚本尤为有用
  • UserConfig：脚本自定义配置界面
  • 运行日志与调试：查看错误与输出
  • 备份与恢复
  • 云同步设置
  • 订阅管理

4.2 从其他管理器迁移（Tampermonkey 等）

官方提供专门迁移文档： https://docs.scriptcat.org/docs/use/from-other/migrate-from-tampermonkey/

通常只需导出原管理器的脚本备份，再在脚本猫中导入即可。

4.3 云同步与订阅

  • 在设置中开启云同步（支持多端）
  • 创建脚本订阅：把多个脚本打包成合集，方便分享与团队使用

5.2 常用元数据说明

元数据 说明
@name 脚本名称
@namespace 命名空间（与 name 一起唯一标识脚本）
@version 版本号（建议语义化版本）
@match / @include 匹配的网址
@exclude 排除的网址
@grant 申请权限（如 GM_setValue、GM_xmlhttpRequest 等）
@run-at 运行时机：document-start / end / idle / body 等
@crontab 定时任务（Cron 表达式，后台脚本常用）
@connect 允许跨域请求的域名

完整元数据说明见：https://docs.scriptcat.org/docs/dev/meta/

6. 高级功能亮点

  • AI Agent（v1.4+ 预览）：支持对话、工具调用、Skill 系统、MCP 协议等（目前主要在 Beta 版可用）
  • Cloudflare 等防护绕过相关能力（配合其他工具）
  • 文件存储、OPFS、Cookie、下载、通知、剪贴板 等增强 API
  • 右键菜单运行（@run-at context-menu）
  • window.onurlchange 支持

7. 常见问题与注意事项

  1. 脚本不运行：检查 @match 是否匹配、权限是否正确授予、是否被禁用。
  2. 后台脚本不执行：确认已开启相关权限，并查看运行日志。
  3. 与其他脚本管理器冲突：建议同一时间只启用一个主要管理器。
  4. 手动安装无法更新：需手动替换文件并重新加载。
  5. 权限提示过多：这是安全设计，敏感操作需要确认。
  6. 开发者模式：加载解压版时必须开启。

更多问题可查阅官方文档或到 GitHub Issues / 油猴中文网提问。

9. 总结与快速上手建议

  1. 从扩展商店安装正式版。
  2. 打开管理面板，完成新手引导。
  3. 去 https://scriptcat.org/ 安装几个热门脚本（视频增强、去广告、自动签到等）。
  4. 需要时再学习编写自己的脚本或使用后台/定时功能。

ScriptCat 把「普通用户一键安装脚本」和「开发者强大后台能力」很好地结合在一起，是目前中文社区最活跃、功能最全面的用户脚本管理器之一。
