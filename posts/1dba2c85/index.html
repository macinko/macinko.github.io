最新 X 原创内容奖励绑定 Stripe 与 Wise/香港银行卡简易教程，建议收藏

更新于2026-09-16|aitool
|总字数:1.3k|阅读时长:3分钟|浏览量:

X 原创内容奖励审核通过后，非美国用户需要连接 Stripe 收款账户。可以使用 Wise 港元账户，也可以使用普通香港银行卡，两者的操作流程相同，只有填写的银行账户资料不同。

一、申请原创内容奖励

进入 Creator Studio → 原创内容奖励，点击 下一步。

阅读并同意创作者协议。内容应为本人原创，不要搬运作品、操纵互动数据或使用自动化工具制造互动。

页面要求提交作品，从近期20~30个帖子中选择非搬运的原创内容。提交后等待审核即可。每个人情况不一样，原创的价值帖子大多15分钟通过。

二、提前准备收款账户

有香港银行卡的用户可以直接使用银行卡；没有香港银行卡，可以提前申请 Wise 港元账户。

从 8 月开始，部分用户反馈开通 Wise 港元账户资料时需要先存入约 170 元人民币。这通常是验证入金，不是开户费，具体以 Wise 页面显示为准。

Wise 的港元账户审核时间因人而异，有的约一周，有的需要一至两个月；额外审核最长可能达到 60 个工作日，建议尽早准备。

三、连接 Stripe

X 审核通过后，进入 支付详情，点击 连接 Stripe 账户。

按页面提示完成以下操作：

\1. 输入常用邮箱；

\2. 输入可以长期使用的手机号码（有条件就用香港的，没条件用86也可以，我这里使用的是香港Club SIM）；

\3. 填写短信验证码。

Stripe 邮箱可以与 X 邮箱不同。

四、填写商家和个人信息

商家类型：

• 国家/地区：中国香港特别行政区；

• 商家类型：Individual（个人）。

个人信息

按身份证明文件填写英文姓名、出生日期和居住地址。姓名按以下顺序填写：

\1. 名（Legal first name）；

\2. 姓（Legal last name）。

居住地址通常我们没有，直接查看Wise账户里面的地址，对应怎么填写可以直接截图询问AI（银行卡同理）。

五、添加提现账户

Wise 港元账户和普通香港银行卡的填写方式相同，只是资料来源不同。

提交前确认姓名、银行代码、分行代码和账号完全正确。账号栏不要重复加入银行代码或分行代码，点击继续完成提交。

六、填写 W-8/W-9 税务证书

进入信息确认页面后，如果看到“缺少 W-8/W-9 证书”，点击 更新。

主要填写内容包括：

• 是否属于美国税务居民：否；

• 邮寄地址是否相同：是；

• 美国税号：留空；

• 非美国税号：有护照填写护照号码，没有就填写身份证号码；

• 税收协定待遇：否。

阅读声明并完成电子签名。签名使用法定英文姓名，并与个人详情中的姓名和顺序保持一致。

七、提交并等待收款

返回确认页面，检查个人信息、提现账户和税务证书。确认无误后点击 同意并提交。

出现“Stripe 设置已完成”，说明收款账户已经连接成功。

Stripe 的审核速度因账号而异，有的十几分钟完成，也可能需要更长时间或补充资料。

审核通过之后，原创内容奖励变成了已启动，里面已经不是50W曝光量页面，而是收益发放情况，每两周发放一次。

八、提现及 Wise 注意事项

• 首次提现免手续费，后续提现可能收取“固定费用＋百分比费用”；

• 如果免费提现仅限一次，可以确认可提现余额后再操作，避免拆成多笔；

• Wise 对部分加密货币比较敏感，不要用于不受支持的买卖或 P2P 收付款；

• 支持转账至支付宝或微信；

• 遇到大额收款时，Wise 可能要求提供资金来源证明，请保留 X 和 Stripe 的付款记录。

常见问题

找不到对应银行

根据银行代码搜索，不要只看银行名称。同一家银行可能存在多个实体或分行。

银行账号无法通过

检查是否把银行代码、分行代码和账号填写在同一个输入框中。账号栏通常只填写独立账号。

姓名不匹配

检查 Stripe、身份证明和收款账户上的英文姓名拼写及顺序。

税务证书一直未完成

检查是否遗漏税务身份、地址、税号、协定待遇、声明确认或电子签名。
