CloddsBot 详细部署教程

项目概述

CloddsBot 是一个开源的、自托管的 AI 交易代理，由 Claude 驱动，能够在 1000+ 个市场中自主运行。它集成了预测市场、加密货币现货、永续合约（带杠杆）、代币发行和 Bittensor 子网挖矿等功能，并可通过 21 种消息平台进行交互。

核心特性：

功能模块 说明
消息平台 21 个平台（Telegram、Discord、Slack、WhatsApp、WebChat 等）
预测市场 10 个平台（Polymarket、Kalshi、Betfair 等）
永续合约 7 个交易所（Binance、Bybit、Hyperliquid 等），最高 200x 杠杆
交易策略 118+ 种策略（动量、均值回归、DCA、鲸鱼追踪等）
风险管理 统一风险引擎，含熔断、VaR/CVaR、凯利公式等
WebChat 内置浏览器界面，支持无限历史记录和上下文压缩
技能系统 119 个内置技能，可按需懒加载
AI 系统 8 个 LLM 提供商，4 个专业代理，语义记忆
数据持久化 SQLite（本地）、LanceDB（语义记忆）、PostgreSQL（分析）

技术栈：Node.js + TypeScript + Claude API

WebChat 使用

CloddsBot 内置浏览器界面，无需设置，无第三方依赖：

  • 访问地址：http://localhost:18789/webchat
  • Claude 风格侧边栏：Chats、Projects、Artifacts、Code 四个标签页
  • 无限历史：每条消息存储在专用数据库表中，无消息上限
  • 上下文压缩：旧消息自动摘要，AI 不会完全忘记讨论内容
  • 会话管理：通过 REST API 创建、重命名、删除对话

安全注意事项

根据官方安全策略：

凭据安全

  • 永不提交凭据——使用环境变量
  • 使用 .env 文件——保持在 .gitignore 中
  • 定期轮换 API 密钥
  • 限制权限——尽可能使用只读密钥

交易安全

  • 从模拟模式开始——实盘交易前先测试
  • 设置损失限制——配置熔断机制
  • 使用独立钱包——不要使用主钱包
  • 监控仓位——设置大额交易警报

常见问题排查

问题 解决方案
缺少 ANTHROPIC_API_KEY 这是必需项，在 .env 中配置
配置更改不生效 编辑 .env 或 clodds.json 后重启机器人
WebChat 无法访问 检查端口 18789 是否被占用，确认容器运行状态
模型列表过时 已知问题，等待更新或手动配置模型
Docker 容器无法启动 检查环境变量是否正确传递
数据丢失 确保 clodds_data 卷正确挂载

诊断命令

clodds doctor 会检查 AI 提供商、消息通道、交易平台、外部服务和 Bittensor 依赖。

数据持久化

数据默认存储在 ~/.clodds/ 目录：

文件 说明
clodds.db SQLite 数据库（WebChat、交易历史）
backups/ 自动备份

备份建议：定期备份 ~/.clodds/ 目录，尤其是包含 SOLANA_PRIVATE_KEY 的配置文件。
