Defender Remover：彻底删除 Windows 8-11 的 Defender

更新于2026-09-05|toolsossoftwarewindows
|总字数:654|阅读时长:2分钟|浏览量:

删除/禁用 Windows Defender，包括 Windows 安全应用程序、基于 Windows 虚拟化的安全性 (VBS)、Windows SmartScreen、Windows 安全服务、Windows Web 威胁服务、Windows 文件虚拟化 (UAC)、Microsoft Defender App Guard、Microsoft 驱动程序阻止列表、系统缓解措施以及 Windows 10 或更高版本上的设置应用程序中的 Windows Defender 页面。

注意事项：如果你还想恢复windows defender，建议在运行脚本之前先进行系统还原点创建，这个脚本程序会彻底删除Windows Defender

软件截图

软件操作

  1. 从Releases下载打包的脚本
  2. 以管理员身份运行“.exe”
  3. 按照显示的说明进行操作
    • Y删除Windows Defender防病毒+禁用所有安全缓解
    • A只删除Windows防御，但保持UAC启用
    • S禁用所有安全缓解

常见问题

⭕ 为什么下载的可执行文件被标记为病毒？

这是一个误报。

一些安全应用程序会将此应用程序标记为病毒，因为它的“.exe”文件的创建方式。使用git或源代码 .zip 下载将表明此应用程序无病毒。从 Defender 12.6.x 开始，某些版本会被视为病毒，而某些版本则不会（这是我的 bug，所以不要为此提交文件）。

⭕ 为什么 Windows 更新后补丁不起作用？

Windows 更新包含一个Intelligence Update脚本，它可以阻止某些操作并修改 Windows Defender/安全策略。如果该脚本无法正常工作，请检查您是否安装了 Windows 安全智能更新。如果已安装，请禁用防篡改保护，然后重新运行该脚本。

⭕ 如何在不从发行版下载可执行文件的情况下使用软件包卸载程序？

使用 PowerRun 从 cmd 运行所需的“.bat”文件（通过拖拽到可执行文件）。必须重启才能使更改生效。

⭕ 如果删除脚本不起作用，如何禁用 VBS

使用此命令禁用并重新启动。

此后您将无法使用虚拟机。

⭕ 为什么 VBS 在 Windows 11 上保持启用？

默认情况下，该脚本会禁用 VBS 以提高系统性能。保持 VBS 启用的因素是 Windows 虚拟化。

Windows 虚拟化使用的应用程序和功能：

  • 适用于Android / Linux 的Windows 子系统
  • HyperV 虚拟机
  • Microsoft 模拟器 （Windows 10X 模拟器，可在 Microsoft Store 中找到）
  • Android Studio 与 VisuaL Studio 或其他模拟器的集成（适用于 Windows 10 22H2（2025 年 3 月更新或更新版本））
