n8n 工作流自动化平台部署教程

更新于2026-08-22|toolssoftware
|总字数:1.4k|阅读时长:5分钟|浏览量:

n8n 是一个”fair-code”（源码可见）的工作流自动化平台，允许您通过视觉化画布构建复杂的自动化流程，连接超过 1500+ 应用和服务。它原生支持AI能力，可与多种模型（OpenAI、Anthropic、Google等）集成，并支持自托管或云端部署。

1. 部署方式选择

n8n 提供了多种部署方式，您可以根据自己的需求和技术栈选择：

部署方式 适用场景 难度
快速安装脚本（推荐） 新手快速体验，使用Docker ⭐ 简单
Docker（手动） 熟悉Docker的用户，生产环境 ⭐⭐ 中等
npm安装 开发者本地测试或集成 ⭐⭐ 中等
源码构建 开发贡献或深度定制 ⭐⭐⭐ 较复杂

2. 前提条件

根据您选择的部署方式，需要准备以下环境：

  • Docker方式：安装 Docker 和 Docker Compose（可选）。
  • npm方式：
    • Node.js：版本 18.x 或 20.x（推荐 LTS）。
    • npm：随 Node.js 安装。
  • 源码构建：
    • 需要 Node.js、pnpm、Rust（部分原生依赖）等，具体请参考项目文档。

4. 高级配置（生产环境）

对于生产部署，建议通过环境变量进行配置，以增强安全性、稳定性和性能。

4.1 基础安全设置

  • N8N_BASIC_AUTH_ACTIVE=true：启用基本身份验证。
  • N8N_BASIC_AUTH_USER 和 N8N_BASIC_AUTH_PASSWORD：设置登录用户名和密码。
  • N8N_ENCRYPTION_KEY：设置加密密钥（用于加密凭证），需是一个32字符的随机字符串。

4.2 数据库配置（使用外部数据库）

默认使用 SQLite。生产环境建议使用 PostgreSQL。

  • DB_TYPE=postgresdb
  • DB_POSTGRESDB_HOST=your-db-host
  • DB_POSTGRESDB_DATABASE=n8n
  • DB_POSTGRESDB_USER=your-user
  • DB_POSTGRESDB_PASSWORD=your-password

4.3 端口与访问

  • N8N_PORT=5678：指定监听端口。
  • N8N_HOST=your-domain.com：指定主机名（用于生成链接）。
  • N8N_PROTOCOL=https：如果使用HTTPS，设置此变量。

5. 常见问题排查

问题 可能原因 解决方案
无法访问 localhost:5678 服务未启动或端口被占用 检查容器/进程是否运行，确认端口是否被其他程序占用。
Docker 容器立即退出 数据卷权限问题或端口冲突 检查日志：docker logs n8n。确保 v n8n_data 卷挂载正确。
npm 安装失败 Node.js 版本不兼容或网络问题 检查 Node.js 版本（>=18），使用国内镜像源（如淘宝镜像）。
工作流执行失败 凭证配置错误或外部服务不可达 检查各节点的凭证（如API密钥）是否正确，并确保网络连通性。
数据丢失 未挂载持久化数据卷 确保 Docker 运行时使用了 -v 参数挂载卷，或 npm 方式指定了 --data-directory。

6. 总结

n8n 是一个功能强大、部署灵活的自动化平台。

核心部署路径：

  1. 快速体验：使用官方安装脚本 curl -fsSL https://get.n8n.io | sh，立即通过 Docker 运行。
  2. 手动控制：使用 Docker 命令或 npm install n8n -g 安装，获得更多配置灵活性。
  3. 生产部署：务必配置加密密钥、外部数据库（如PostgreSQL）和基本认证，并使用 Docker 的 --restart 策略或系统服务（如 systemd）确保高可用性。
  4. 开发贡献：从 GitHub 克隆源码，使用 pnpm 构建和运行。

成功启动后，您将进入 n8n 的 Web 编辑器，可以通过拖拽节点来创建从简单到复杂的自动化工作流。

项目地址：https://github.com/n8n-io/n8n
