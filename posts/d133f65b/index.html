Flow 轻量级提词器详细部署教程

Flow 是一款专为 Windows 平台设计的轻量级提词器，基于 Tauri 和 Rust 构建。它提供了一个极简、始终置顶的阅读界面，并集成了脚本管理、AI 生成、语音控制和实时协作等功能，非常适合内容创作者、教育工作者和需要阅读提词的用户。本教程将指导您完成部署、安装和基础配置。

Flow 是什么

Flow 是一个专为 Windows 设计的桌面提词器应用。它的核心目标是让您在录制视频、直播或进行演示时，能够自然地阅读脚本，同时目光保持看向摄像头。

核心设计理念：

  • 轻量级：基于 Tauri 框架，资源占用低，启动迅速。
  • 始终置顶：提供多种风格的透明或半透明阅读窗口，悬浮于其他应用之上。
  • 本地优先：脚本和设置默认存储在本地，支持离线使用。
  • 现代化功能：集成了 AI 辅助脚本生成、实时多人协作编辑和语音控制。

核心功能

  • 多种提词显示风格：支持高亮、滚动、逐行、箭头指示和语音追踪五种模式。
  • 内置脚本编辑器：支持文本编辑、字数统计、预估阅读时间和章节导航。
  • AI 辅助生成：可选的 Groq 集成，用于根据提示生成或重写脚本。
  • 实时协作编辑：通过私有浏览器房间，允许多人同时编辑同一脚本。
  • 语音控制：本地运行的 Vosk 语音识别模型，支持通过语音命令控制提词器（如滚动、暂停）。
  • 消息注入：允许远程向提词器发送消息或提示，并在界面中显示。
  • 多语言支持：界面和语音模型支持多种语言。

系统要求与准备

最终用户

  • 操作系统：Windows 10 或 Windows 11（64位）。
  • 网络：仅用于下载应用、使用 AI 功能（Groq）或进行实时协作。

开发者（如需从源码构建）

  • Node.js：推荐 LTS 版本。
  • Rust：需要安装 Rust 工具链。
  • Windows Tauri 开发依赖：需安装 Visual Studio 生成工具（包含 C++ 开发组件）和 WebView2 运行时（通常 Windows 已内置）。
  • Git：用于克隆仓库。

最终用户安装

方法一：从 Microsoft Store 安装（推荐）

  1. 在 Windows 搜索栏输入 Microsoft Store 并打开。
  2. 搜索 Flow Teleprompter。
  3. 点击“获取”或“安装”按钮。安装完成后，即可从开始菜单启动。

方法二：从 GitHub Releases 手动安装

  1. 访问项目的 GitHub Releases 页面。
  2. 下载最新版本的安装文件，通常是 .exe（安装程序）或 .msi（Windows 安装包）。
  3. 双击下载的文件，按照安装向导提示完成安装。
  4. 安装完成后，可从开始菜单或桌面快捷方式启动 Flow。

配置与使用

基础使用流程

  1. 启动 Flow：从开始菜单或桌面快捷方式打开应用。
  2. 创建或导入脚本：
    • 在主界面点击“新建脚本”或使用内置编辑器粘贴文本。
    • 支持从 .txt 文件导入。
  3. 启动提词器：点击“开始”或“播放”按钮，文本会以您选择的风格在置顶窗口中滚动。
  4. 调整设置：在设置菜单中，您可以调整滚动速度、字体大小、窗口透明度、主题颜色等。

高级功能配置

  • AI 助手：如需使用 Groq 生成脚本，请在设置中配置您的 Groq API Key。
  • 语音控制：首次使用语音功能时，应用会下载所需的 Vosk 语音模型。在设置中可以选择不同的语言模型包。
  • 实时协作：在编辑器界面生成一个房间链接，分享给协作者，即可多人同时编辑脚本。

更新与卸载

更新

  • Microsoft Store 版本：通过 Store 的“获取更新”功能自动更新。
  • GitHub 手动安装版本：
    1. 检查 GitHub Releases 是否有新版本。
    2. 下载最新版本的安装包（.msi 或 .exe）。
    3. 运行安装包，它会自动覆盖旧版本（用户数据和设置通常会被保留）。

卸载

  • 通过 Windows 设置：
    1. 打开 设置 > 应用 > 已安装的应用。
    2. 找到 Flow Teleprompter，点击“卸载”。
  • 通过开始菜单：在开始菜单中找到 Flow，右键点击并选择“卸载”。

常见问题排查

问题：应用无法启动，提示缺少 WebView2 组件。

  • 解决：Windows 10/11 通常已内置 WebView2。如未安装，请从微软官网下载并安装 WebView2 运行时。

问题：语音控制不工作或提示“模型未找到”。

  • 解决：首次使用语音功能时，Flow 会下载语音模型。请确保网络连接正常，并在设置中确认已选择了正确的语言模型。如果下载失败，可以尝试手动从 Vosk 官网下载模型，并放置在应用指定的目录中。

问题：提词器窗口在屏幕录制或共享时无法显示。

  • 解决：Flow 提供了“防捕获”选项，启用后窗口内容在截屏或录屏中不可见。如果需要录制提词器内容，请在设置中关闭此选项。

问题：无法连接到协作房间。

  • 解决：检查网络连接，并确保防火墙没有阻止 Flow 的通信。协作者需要使用您生成的相同房间链接。

通过以上步骤，您应该能够顺利安装和使用 Flow。这款轻量级提词器是提升视频创作和演示效率的有力工具，其丰富的功能也值得深入探索。如需获取最新信息或参与开发，欢迎访问其 GitHub 仓库。
