Codex 额度又用完了？网页版 ChatGPT 接手本地项目，无限用

更新于2026-09-19|aiagent
|总字数:1.6k|阅读时长:4分钟|浏览量:

最近用 Codex，额度实在是不顶用。

一个任务还没做完，就达到 5 小时限额，恢复得再等好几个小时，完全干不了活，简直太痛苦了！！！

之前看到有人分享过用网页版 GPT 干活的方案，我就去收集了一下资料，然后实测了下。

现在，我能在网页版 ChatGPT 里，直接让它读取和修改本地项目的代码文件了。

先看看效果截图

本地有哪些项目、项目里有哪些文件，它都能列出来。

通过 Web 版 GPT 实现读取本地文件、改代码。简直不要太爽！

用到的工具叫 WebCodex。下面把配置过程整理出来，推荐额度不够用的朋友试试！

为什么我选了 WebCodex

网上收集了一些信息，主要有两个备选方案：codex-with-chatgpt、WebCodex

codex-with-chatgpt 的思路是让网页版 GPT 做规划，再交给客户端 Codex 执行。配置相对简单，适合还想保留客户端执行流程的情况。

WebCodex 则让网页版 GPT 通过工具连接到电脑，直接操作配置好的本地项目。设置稍微多一点，但更符合我的需求。

毕竟，我最头疼的是客户端额度已经用完了，还需要有个地方能继续处理本地文件。所以这次选了 WebCodex。

整个过程分成四部分，先装桌面端，再拿到隧道配置，回到电脑填好，最后在 ChatGPT 网页版连接。

第一步，「电脑」安装 WebCodex Desktop

打开

WebCodex 下载页面

，选择与你电脑系统对应的安装包。

安装完成后，打开 WebCodex Desktop。先放在一边，我们去 OpenAI 开放平台拿接下来要填的两项信息。

第二步，「OpenAI 开放平台」创建隧道和 API Key

这一步会用到两个页面，分别用来获取 Tunnel ID 和 Tunnel API Key。两项信息获取后复制备用

1. 创建 Tunnel

打开

OpenAI Platform 的 Tunnels 页面

，创建一个 Tunnel。

Tunnel 可以理解为网页版 ChatGPT 连接你电脑的通道。名称自己取，创建好后，把 Tunnel ID 复制下来备用。

这里留意一下WorkSpace设置。按我这次的配置，需要给 Tunnel 选择默认的 workspace，否则后面在 ChatGPT 里可能找不到它。

2. 创建 API Key

接着打开

API Keys 页面

，创建密钥。

建议选 Restricted key，也就是受限密钥，按这次配置只授予 Tunnels 所需的 Read + Use 权限。

Key 只显示一次，创建后记得立即复制保存。 这串密钥后面填在 WebCodex Desktop 里

两项都拿到了，就可以回到电脑继续。

第三步，「WebCodex Desktop」配置连接

1. 选择在这台电脑上使用

进入 WebCodex Desktop 首页，点击第一个卡片。

2. 选择项目，填入隧道信息

选择一个本地文件夹作为项目，再展开安全隧道配置。

把刚才记录的 Tunnel ID 填入 ID 输入框，把 API Key 填入 Tunnel API Key 输入框。

确认项目文件夹和两项配置都填好后，点击「配置 WebCodex」，等待它启动。

这里只选你希望 AI 处理的项目文件夹就行，不需要把整块硬盘都加进去。

3. 检查运行状态

回到首页，点击「查看运行诊断」。

重点看本地服务、Runner 和项目是否就绪，再看 ChatGPT 隧道的状态。

如果显示隧道就绪、等待 ChatGPT 连接，就可以继续下一步了。这时只是电脑这边准备好了，最后还要在网页版实际读取一次文件，才能确认整套连接可用。

如果你安装的版本没有自动启动隧道，可以到「连接」页面选择 OpenAI Secure Tunnel，再点击启动。新版桌面端的入口也可以对照

项目安装说明

。

第四步，「 ChatGPT 网页版」添加插件

1. 开启开发者模式

打开 ChatGPT 网页版，进入设置。

我这次的入口是 设置 → 账户安全与登录，在里面开启开发人员模式。

也可以从

这次使用的设置入口

进入。先打开这个开关，后面才能添加自定义插件。

2. 添加自定义插件

进入

ChatGPT 插件页面

，点击右上角的添加插件。

接下来按图配置。

  • 连接方式选 隧道。
  • 选择前面创建的 Tunnel
  • 身份验证选 无身份验证。

这里的「无身份验证」是这条官方隧道连接方式对应的设置，跟着选就行，不用把 Tunnel API Key 再填到 ChatGPT 里。

如果隧道列表是空的，先回到 OpenAI Platform，检查前面创建的 Tunnel 和默认 workspace 设置，再确认桌面端隧道已经启动。

3. 授权连接

创建好后，按页面提示授权这个自定义插件。

我给它起的名字是 localGPT，你可以自己取一个好认的名字。

到这里，配置部分就结束了。接下来试一下它能不能真的读到本地项目。

最后，发一句话测试

打开网页版 ChatGPT 的聊天窗口，在输入框输入 @，选择刚才添加的插件。

我的就是 localGPT。

选中后，可以先发这段话。

请列出 WebCodex 中可用的项目，再列出我刚添加的项目下的顶层文件。先不要修改任何内容。

下面是我这次连接测试的结果。

能列出项目和文件目录后，再从返回结果中选一个实际存在的文件，让它读一下内容。

能读到这个文件，才算真正连通了。 光看到桌面端的状态正常，还不够。

使用期间记得让电脑和 WebCodex 保持运行。项目在你的电脑上，电脑这边断开了，网页也就没法继续操作文件。

END

GPT 额度是真的不够用，特别 Plus 账号的 5 小时限制，太影响工作了

有了这个方式，即使 5 小时额度蹬满了，也不怕了

目前网页版只能使用 GPT 5.6 Sol，不过把强度开到 High也绝对够用了

额度不够用的朋友赶紧试试，配置过程中遇到问题，也欢迎评论区交流～
