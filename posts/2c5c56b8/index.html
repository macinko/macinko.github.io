LosslessCut 安装与使用指南：无损视频/音频编辑的瑞士军刀

更新于2026-09-05|toolssoftware
|总字数:1.7k|阅读时长:5分钟|浏览量:

LosslessCut 是一款跨平台的无损视频和音频编辑工具，其核心功能是无需重新编码即可对视频、音频文件进行快速剪辑、合并和提取操作。它利用强大的 FFmpeg 在幕后工作，实现了极快的处理速度和零质量损失，非常适合处理来自运动相机、无人机等设备的大体积原始素材。

1. 系统要求

  • 操作系统：支持 Windows、macOS 和 Linux。
  • 硬件：无特殊要求，但处理大文件时建议配备足够的内存（RAM）。
  • 格式支持：基于 Chromium 的 HTML5 播放器，原生支持 MP4、MOV、WebM、Matroska (MKV)、OGG、WAV 等格式，以及 H264、AV1、VP8/9、H265（需硬件解码）等视频编码。不支持的格式可以通过 FFmpeg 辅助播放。

2. 下载与安装

LosslessCut 提供了多种获取方式，您可以选择最适合自己的途径。

2.1 从官方应用商店下载（推荐，自动更新）

  • macOS：从 Mac App Store 获取。
  • Windows：从 Microsoft Store 获取。
  • Linux：从 Snap Store 获取。

通过应用商店安装的好处是安装过程简便，并能获得自动更新。

2.2 从 GitHub 手动下载（免费、开源）

您也可以从项目的 GitHub Releases 页面 下载适用于您操作系统的独立可执行文件。

  • macOS：下载 .dmg 文件（注意：.pkg 文件无法正常工作）。
  • Windows：下载 .7z 压缩包（注意：Windows 7、8 和 8.1 在 v3.50.0 后不再支持）。
  • Linux：下载 .tar.bz2 或 .AppImage 文件（支持 x64、ARM64 和 Raspberry Pi armv7l 架构）。

下载后解压或安装即可使用。

2.3 其他来源

  • Flathub：Linux 用户也可在 Flathub 找到非官方维护的版本。
  • 最新开发版 (Nightly)：如果您想尝试最新功能，可以下载 Nightly 构建版，但请注意其稳定性可能不如正式版。

3. 快速开始：核心使用流程

  1. 打开文件：启动 LosslessCut，通过 文件 菜单或拖放方式打开您的视频或音频文件。
  2. 浏览与标记：在时间轴上播放预览，找到您想要保留或删除的片段起始点和结束点。
    • 设置入点 (I)：标记片段的开始。
    • 设置出点 (O)：标记片段的结束。
  3. 操作片段：
    • 保留 ( “+” 操作)：标记出您想要保留的片段，软件将丢弃未标记部分。
    • 删除 ( “-“ 操作)：标记出您想要删除的片段，软件将保留未标记部分。
  4. 导出：点击 “导出” 按钮。软件会极快地生成一个新的文件，该文件仅包含您选择的部分，且质量与原始文件完全相同。

4. 核心功能概览

功能分类 具体功能 说明
无损剪辑 剪切、删除片段 通过标记入/出点，快速提取或移除视频/音频部分，无质量损失。
无损合并/连接 合并多个文件 将多个具有相同编码参数的文件（如同一个相机拍摄的）合并为一个，不重新编码。
多轨道编辑 组合/移除/提取音轨、字幕轨 可以从不同文件组合音轨和字幕，或从文件中单独提取视频、音频、字幕等轨道。
格式转换 (Remux) 更改容器格式 将视频从 MKV 无损转换为 MP4 等格式，仅改变封装，不改变编码。
截图与帧导出 导出 JPEG/PNG 快照、导出帧序列 可以从视频中截取单张高质量图片，或将一段视频导出为连续的图片序列（可按帧、时间或场景变化导出）。
元数据编辑 修改旋转、标题、作者、GPS 信息等 更改视频的旋转方向、添加标题、艺术家信息，甚至查看 DJI 无人机视频中的 GPS 轨迹。
高级功能 黑场/静音/场景检测、按大小/时长分割、速度调整、HTTP下载 支持自动检测场景变化、按文件大小分割视频、改变视频播放速度（会改变FPS），以及从网络（如 HLS .m3u8）下载视频。
工作流优化 键盘快捷键、项目文件、导入/导出剪辑列表 支持高度自定义的键盘快捷键，可以将剪辑方案保存为项目文件，或导入/导出为 CSV、EDL、YouTube 章节等格式，便于在不同工具间协作。

5. 常见问题与技巧

  • Q：软件打不开或闪退？
    • Windows：请确保您的系统为 Windows 10 或更高版本（v3.50.0 后不支持旧版）。如遇问题，可尝试以管理员身份运行。
    • macOS：请从官方渠道下载 .dmg 文件，不要使用 .pkg 安装包。如果提示“无法验证开发者”，请右键点击应用选择“打开”。
    • Linux：确保已安装必要的系统库（如 libfuse2 用于 AppImage）。如果使用 Snap 包，请确保 Snap 服务正常运行。
  • Q：播放画面是黑屏或花屏？
    • 某些编解码器（如 H265）可能需要硬件解码支持，或者您的显卡驱动需要更新。您可以尝试在“文件”菜单中启用 “最快：FFmpeg 辅助播放” 选项，这会将文件临时转换为一个低质量的代理文件用于预览，而实际导出仍基于原始文件，保证无损。
  • Q：导出的文件时间长度不对？
    • 请确保您的剪辑点（入点/出点）设置准确。注意，LosslessCut 是基于关键帧 (Keyframe) 进行切割的，因此实际切割点可能与您标记的精确时间有微小偏差。如需精确到帧，可以参考文档中的高级技巧。
  • Q：导出的文件没有声音或音画不同步？
    • 检查您在导出时是否选中了正确的音频轨道。如果文件包含多音轨，请确认导出设置中包含了您期望的轨道。

6. 总结

LosslessCut 是一款强大且易用的视频处理工具，其核心流程是：下载安装 → 打开媒体文件 → 标记入/出点 → 选择保留或删除操作 → 导出。

它最大的优势在于极快的速度和零质量损失，非常适合对原始素材进行粗剪、去广告、提取音乐或片段等快速处理任务。建议您先通过官方文档或内置教程熟悉键盘快捷键（如 I 和 O 键标记入出点），这将大幅提升您的操作效率。
