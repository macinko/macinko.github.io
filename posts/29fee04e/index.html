Kition 安装与使用指南：AI驱动的一体化知识工作空间

更新于2026-08-22|aitool
|总字数:1.5k|阅读时长:4分钟|浏览量:

1. 系统要求

  • 操作系统：目前提供 macOS 和 Windows 版本。
  • 网络：需要网络连接以使用AI代理和浏览器研究功能（某些功能可离线使用）。
  • 注意：项目目前处于 Beta 阶段，建议在使用生产工作流前备份重要工作区并审查代理更改。

2. 安装步骤

Kition 提供了两种主要的安装/运行方式：下载官方桌面应用（推荐）和从源码运行。

2.1 下载官方桌面应用（推荐）

这是最便捷的方式，适合大多数用户。

  1. 获取安装包：前往项目的 GitHub Releases 页面。
  2. 选择您的平台：
    • macOS：下载最新的 .dmg 文件。
    • Windows：下载最新的 .exe 安装程序。
  3. 安装：
    • macOS：打开 .dmg，将 Kition.app 拖入 Applications 文件夹。
    • Windows：运行下载的 .exe 安装程序，按照提示完成安装。
  4. 首次运行：启动 Kition，您会看到一个“Getting Started”工作区，其中包含实用的文档、表格和工作流示例，帮助您快速上手。

3. 核心功能与工作流

安装成功后，您可以开始探索 Kition 的核心功能：

3.1 文档 (Documents)

  • 编写：使用 Markdown 编写，支持实时预览、内部链接、反向链接、标签、大纲、嵌入、代码块、数学公式、图表 (Mermaid)、每日笔记、全文搜索。
  • 导出：将完成的工作导出为 PDF 或 DOCX 文件。

3.2 数据表 (Data Tables)

  • 创建：创建结构化表格文件 (.kitable)，支持类型字段、附件、公式、筛选、排序、分组、多视图和快速记录编辑。
  • 用途：可用于研究、内容管道、轻量级CRM、库存管理或项目跟踪。
  • AI字段：支持AI辅助字段，可从记录上下文中生成文本、结构化值甚至媒体内容。

3.3 AI 代理 (Agent)

  • 操作：代理可以读取和更新您当前的Markdown文档，检查表格模式，创建或修改记录，在浏览器标签页中进行研究，并使用各种工具。
  • 可审查的编辑：当代理修改文档时，Kition会打开一个文档审查界面，高亮显示添加、删除和重写的内容。您可以逐项接受或拒绝每个更改，完全控制最终文档。
  • 交互方式：不再是空白的聊天框，而是让代理直接工作在您的项目文件上。

3.4 工作流 (Workflows)

  • 可视化构建：在可视化画布上组装触发器-动作工作流。
  • 测试与调试：可以测试单个步骤，检查运行历史，并在启用前解决缺失的输入。

3.5 内置场景示例

  • 批量生成营销资产：从关键信息和照片开始，使用表格的AI字段批量生成多个尺寸的缩略图变体。
  • 从收据图片提取记录：将收据照片拖入附件字段，AI视觉字段自动提取商家、地址、类别和结构化JSON数据。
  • 从产品简报扩展为完整资产管道：一个产品概念可驱动多个设计候选、视图、风格板等，所有结果都关联到源记录。

4. 高级配置

  • 设置：通过应用设置，您可以配置：
    • 模型、代理、MCP (Model Context Protocol) 连接。
    • 邮箱连接（支持收件箱到表格的工作流）。
    • 代理、更新、桌面集成等。
  • 数据存储：工作区数据默认存储在本地（使用 IndexedDB）。请确保定期备份重要的工作区。

5. 常见问题排查

问题 可能原因 解决方案
应用无法启动或闪退 系统版本不兼容或安装文件损坏 检查是否满足系统要求，重新下载安装包并重试。
AI代理无法连接或响应 网络问题或模型配置错误 检查网络连接，在设置中验证AI模型和API密钥配置。
文档更改无法保存 文件权限问题或内部状态错误 确保应用有权限写入工作区目录，尝试重启应用。
表格AI字段无反应 字段配置不正确或缺少输入 检查字段公式和依赖的字段值是否正确。

6. 总结

Kition 是一个创新的桌面工作区，将知识管理（文档）、数据处理（表格）和AI自动化（代理与工作流）紧密集成。

核心使用路径是：

  1. 下载并安装适合您操作系统的桌面应用。
  2. 浏览“Getting Started”工作区，了解文档、表格、代理和工作流的基本用法。
  3. 创建或导入您的项目内容（Markdown文档、表格数据）。
  4. 使用AI代理处理复杂任务，并通过审查界面控制其对文档的修改。
  5. 将重复性任务构建为可视化工作流，实现自动化。

建议您先通过官方示例场景熟悉其核心循环：用文档提供上下文，用表格管理结构化状态，用代理处理不确定的工作，用工作流固化重复步骤。
