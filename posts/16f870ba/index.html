📦 Kimi Code CLI 详细部署与使用教程

Kimi Code CLI 是由月之暗面 (Moonshot AI) 开发的一款终端 AI 编程代理。它能直接在你的终端中运行，具备读写代码、执行 Shell 命令、搜索文件、抓取网页等能力，并能根据反馈自主决策下一步操作。它原生支持月之暗面的 Kimi 模型，也可配置为使用其他兼容的模型提供商。

⚙️ 部署前准备

  1. 基础环境：
    • 操作系统：macOS、Linux 或 Windows。
    • 终端：一个可用的命令行终端（PowerShell、bash、zsh 等）。
    • （Windows 必须）Git for Windows：Kimi Code CLI 依赖其捆绑的 Git Bash 作为 Shell 环境。请从 Git 官网 安装。如果安装路径非默认，需设置环境变量 KIMI_SHELL_PATH 指向 bash.exe 的绝对路径。
  2. 网络与账号：
    • 能够访问互联网。
    • 一个 Moonshot AI 开放平台 的账号或 Kimi Code 的 OAuth 授权。用于获取后续运行所需的凭证（API Key 或登录授权）。

Kimi Code CLI 是一个单二进制文件，安装过程无需 Node.js 环境。根据你的操作系统，选择对应的安装命令。

❓ 常见问题 (FAQ)

  • kimi 命令找不到：安装脚本可能未将二进制文件目录添加到 PATH。找到安装目录（如 ~/.local/bin 或 ~/.kimi/bin），手动将其添加到你的 Shell 配置文件（如 .bashrc、.zshrc）中，或重启终端。
  • Windows 下启动报错：最常见原因是缺少 Git Bash 环境。请确保已安装 Git for Windows，并在设置中启用 “Git from the command line and also from 3rd-party software” 选项。
  • 网络连接问题：Kimi Code CLI 需要与 Moonshot AI 的 API 通信。请确保你的网络环境能正常访问相关服务。如使用代理，可能需要设置 HTTP_PROXY 和 HTTPS_PROXY 环境变量。
  • 升级 Kimi Code CLI：目前官方推荐的升级方式是重新运行安装脚本，它会覆盖旧版本。kimi 命令本身暂不包含内置的 upgrade 子命令。

更多详细信息、配置选项和故障排除，请查阅 Kimi Code CLI 官方文档。
