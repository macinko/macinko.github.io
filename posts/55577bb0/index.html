最新Claude 防封号与申请虚拟卡订阅全指南

更新于2026-09-05|aiclaude
|总字数:4.8k|阅读时长:14分钟|浏览量:

我的账号状态：注册到现在 1 年 2 个月，没被封过一次，没收到过任何警告。现在是 200 刀的 Max 账号，还另外开了一个 6 个多月的 Team 版账号，目前都安全。

我几乎每天都在用，Claude Code、桌面客户端、多台设备同时开着，中间还换过一次节点方案。

同一段时间里，我身边不少人的号活不过三个月。有人一下午烧完白送的 200 刀，当晚号就没了；有人开着 TUN 模式，以为自己一直走的是代理；有人为了省几块钱，在两个区之间横跳。

读完这篇，你会拿到一份完整的防封号做法、一张国内就能申请的新加坡卡的办卡流程，以及订阅 Claude 时那几步不能弄错的顺序。

导读

  • Claude防封号指南：第一部分
  • 海外银行卡申请指南：看第二部分
  • Claude订阅步骤：直接跳到第三部分视频

1 防封号

1.1 订阅的国家和使用的国家，永远是同一个

这是我唯一一条从不妥协的规则。订阅区是新加坡，节点是新加坡，账单地址是新加坡，卡也是新加坡的，从注册第一天到今天没变过。

新加坡区比某些区贵几块钱，我也订新加坡。省下的那几块，跟一个 200 刀的账号加一个 Team 摆在一起比，不值得赌。

很多人的操作是反过来的：哪个区便宜订哪个区，然后挂着另一个区的节点用。钱是省了，号活不过三个月。风控看的不是你在哪个国家，是你说的和做的一不一致。

1.2 节点：只要都在新加坡，脏一点没关系

新加坡节点我前后用过两种方式，都没出事。一种是买机场的新加坡节点，同一个机场里有好几个新加坡出口，我在这几个之间乱飞；另一种是自己开一台新加坡的机器，专门给 Claude 用，防止用 AI 的时候老断线。IP 纯不纯净、是不是数据中心 IP，我完全没管过。

两种都跑了很长时间，账号都没有异常。所以我的判断是：同一个国家里换出口，影响很小；跨国家换出口，才是真的危险。很多人花大价钱去追所谓的纯净住宅 IP，方向错了。

大陆和香港节点不要用。

1.3 代理分两层：Claude Code 和客户端，走法完全不一样

这是最多人栽的地方。大家默认代理开了就是全都走代理，不是的，这两个吃代理的方式根本不一样。

Claude Code：TUN 不够，还得让它自己走代理

TUN 有时候不稳，网络切换、休眠唤醒、代理软件重连都可能让它临时失效。而 Claude Code 会兜底去读 ~/.claude/settings.json 里的代理配置，这个文件大多数人从来没打开过。结果就是代理绿灯亮着，它发出去的每一条请求走的都是国内 IP。

在 ~/.claude/settings.json 里加上这段，或者让 AI 帮你加：

端口换成你本地代理的监听端口，Clash 默认是 7897。加完重启 Claude Code，去代理软件的连接列表里搜 claude 和 anthropic，确认这些连接走的是新加坡节点。不验证等于白配。

重点 - Claude app：可以用 settings.json，也可以用 TUN，但是不能用 .zshrc 里的环境变量。

这一层才是最关键的。桌面客户端是个 Electron 应用，环境设置里翻遍也找不到代理选项，它只认settings.json或者 TUN。 这里也是很多人翻车的地方。他们用系统代理，没有用 settings.json，有时候用TUN，很容易使用大陆节点直连 claude。

客户端的危险在于它一直在后台跑，自己同步会话、发心跳、拉更新。Claude Code 是你敲命令才发请求，代理断了你能察觉；客户端不一样，TUN 掉两分钟，它就在这两分钟里静默用国内 IP 发一批请求出去，你收不到任何提示，如果你现在用了代理，那这些请求都不会打出去。

我的做法：

  • TUN 和系统代理两个都开着，互为兜底
  • Clash软件要重启，先把Claude APP/Cli完全退出
  • 验证的时候两层都要看，不能只验证 Claude Code 那一边
  • 我所有设备走的都是新加坡节点，绝不会出现这台走新加坡、那台走日本
  • 手机 App 我主力账号从来不登。手机切网络太频繁，代理 App 还会被后台杀掉，任何一次都可能漏一个国内 IP，而且是在你不知情的时候。要测手机端就用小号。

1.4 注意事项

明确不做的事：

  • 不要把账号授权给任何第三方客户端或者插件
  • 少用 claude -p，脚本化的批量调用最像中转站
  • 不要做任何形式的反代中转，专号专用

建议不做的事：

  • 不要在手机上用 Claude。减少多余的动作，少一个出口就多一份安全

2 这次要测的卡

这一章会从卡是什么、怎么注册、怎么入金、怎么出金来讲。

上面那套方案里，有一环我一直没有好的答案给别人：卡。

我现在用的是一张新加坡的实体银行卡，Claude是它开的。这张卡很稳，但办卡门槛不低。绝大多数人拿不到新加坡本地的实体卡，只能退而求其次，用大陆卡、香港卡，或者来路不明的虚拟卡去订阅。这就直接破坏了第一条规则：发卡地和你的节点对不上。

这次我要试的是 Starryblu。选它的原因很简单：它是新加坡的，而且国内就能申请。

Starryblu 是什么

形态上它接近 Wise：一个多币种账户，配一张能全球刷的卡。但真正让它和市面上那些虚拟卡拉开差距的，是它给你一个新加坡的同名收款账户。

拆成三层看：

  • 账户层：钱以 SGD、USD、EUR、GBP、HKD 等十来种货币存着，可以互相兑换
  • 支付层：卡走 Mastercard 网络，同时接了 Alipay+ 和微信支付，扫码也能花
  • 收款层：一个你本人名下的新加坡收款账号，本地转账和电汇都走它，你从自己其他账户转钱进来也是走这条

第三层是重点，也是最容易被写错的地方。

网上很多教程写成：护照免费开新加坡 OCBC 银行账户。这个说法不准确。你拿到的不是一个能登录 OCBC 网银的个人银行账户，而是 Starryblu 给你开的收款信息，客户资金托管在 OCBC 的监管账户里。你能收钱，能用这个账号做同名转账，但你不是 OCBC 的储户。

这个区别看着像抠字眼，实际影响有两面。

好的那面：资金托管在 OCBC，新加坡三大本地银行之一，比钱放在小机构手里踏实得多。而且账户是你本人同名的，很多券商和平台只认同名出入金，这一点直接决定了它能不能用。

要注意的那面：托管不等于存款保险。 新加坡的存款保险只保银行储户，你不是储户，你走的是支付服务法要求的资金隔离存管，是另一套机制。所以这张卡当支付通道用就好，别把钱囤在里面。

运营主体是新加坡的 WoTransfer Pte. Ltd.（UEN 201941244H），持有新加坡金融管理局（MAS）的大型支付机构牌照（Major Payment Institution，牌照号 PS20200501），许可范围包括账户发行、境内汇款、跨境汇款、商户收单和电子货币发行。这些不用听我说，MAS 的持牌机构名录里能直接查到。

做过跨境汇款的人大概率听过同一家公司的另一个产品：熊猫速汇。这也不是营销话术，MAS 名录上给 WoTransfer 登记的官网，就是熊猫速汇的域名。

两个产品同门，分工不同。熊猫速汇解决的是把钱从 A 打到 B，像快递，是一个过程；Starryblu 做的是账户本身，钱放进来，能管、能换、能花、能转出去。相当于快递公司开始给你提供仓库和收银台。

WoTransfer 在跨境支付做了很多年，拿过红杉、Lightspeed 这些机构的投资，2020 年进过 Mastercard 的 Start Path 项目。这个背景决定了它手里有牌照、有银行合作关系、有清算网络。支付这行拼的就是这些看不见的基建。

开户支持的国家和地区很多，中国大陆用户拿护照就能办，这是我这次选它的直接原因。

对我这套方案来说，它补上的正是这一环：新加坡发行的卡，新加坡的账单地址，新加坡的节点，新加坡的订阅区。一条链上四个环节，全在同一个国家。

下面是我自己走了一遍的完整流程。

2.1 注册

App Store 搜 Starryblu 下载。

打开后国家地区选中国。也可以直接用网页注册：

专属注册链接：

https://sg.starryblu.com/x/6RvUV38H

想一个ID登录名（最好用邮箱不容易忘）、密码、手机号（可以直接填国内号码）。

授权码那一栏，一定要填我的：MPFK01O

使用这个专属注册链接，填了能拿 60 新币的消费现金券。这一栏是可选的，很多人看一眼就跳过去了，跳过就等于把这 60 新币扔掉。

2.2 身份认证

证件类型选中国护照，按提示拍照上传。正常情况下几分钟就能过。

需要一份地址证明。身份证、信用卡账单、银行流水、水电账单这类都可以，上传之后等审核。

2.3 选卡

审核通过就能登录账户，进去选卡。

免费的星空卡可以直接申请，但要排队等审核，时间不太确定。

想快一点，可以开 9.9 美元的星空 Plus 会员或者 19.9 美元的星球会员。会员的审核会插队，当天或者次日就能过，而且能免费制作并邮寄一张实体卡。有需要的可以开，没需要的就等。

2.4 入金

卡本身不带钱，得先充值进去。Starryblu 支持几种入金方式，速度和成本差别很大。推荐用香港银行或 wise，0 手续费，国内银行入金有手续费，出金有额度免费。wise 不支持港币入金，支持新币。

渠道一：香港银行 FPS 转数快（我用的，最推荐）

这是最快也最省的一条路，秒到，免手续费。我用的是香港的中银香港，其他银行同理，支持转数快就行。

先拿到充值信息：

  1. 在 Starryblu 里点充值，地区选中国香港，方式选 FPS 转数快
  2. 输入你要充的金额，页面会给出一个收款 ID（FPS 识别码）和一段备注

接下来去银行 APP 转：

  1. 打开你的香港银行 App，转账时填这个 FPS 识别码，收款金额填一致
  2. 备注一定要一字不差地照抄 Starryblu 给你的那串。这串是用来认领你这笔钱的，漏了或者填错，钱会挂在那里或者原路退回，处理起来很麻烦

正常情况下1秒到账，Starryblu 里会直接看到余额。

渠道二：国内银行电汇

没有港卡也没有海外账户的话，国内银行也能转，但这是三种里最贵的：电汇手续费、中间行费用、汇损，一笔下来几百块很正常，到账还慢一些。

如果你打算长期订阅，建议还是先弄一张港卡，或者开个 Wise，长远算下来省得多。

充多少：有多少用多少，别囤

这一点我要专门说一下，因为我看到不少人一上来就往里面充一大笔。

没必要。按你实际要订的东西算就行，需要多少充多少。

给个参考。走新加坡区会加个税 GST，要按含税的数算：

  • 只订 Pro，一个月含税30新币， 约等于$23.5美元/$185港币
  • 订 Max 5x，一个月含税150新币， 约等于$118美元/$923港币
  • 订 Max 20x，一个月含税300新币， 约等于$235美元/$1,846港币
  • 再放一点汇率的余量

卡里只放 200 刀去扣 Max 20x 是会失败的，这笔税别忘了算进去。

我自己的做法是：第一次先充一笔很小的金额，确认这条通道走得通、卡能正常扣款，再按一到两个月的订阅额度补进去。后面每个月快扣款前看一眼余额够不够，不够再充。

到这一步，卡就能用了。

2.5 怎么出金

进得去也得出得来，这是我评估一张卡的时候一定会看的一项。Starryblu 有三个出口，其中两个是 Wise 那类产品给不了的。

跟前面 Claude 相关的，**万一哪天被封号，**订阅的费用也会原路返回到这张卡里，你就可以用下面这些渠道把它消费掉。

一、提现

支持提现到银行卡、支付宝、微信。能直接提到支付宝和微信，这个灵活度在同类产品里不多见。实测口径是有 500 元人民币的免费额度，超出之后每笔 20 元，具体以 App 里显示的为准。

二、直接扫码花掉

支持微信支付的商户，可以用 Starryblu 扫码或者出示付款码直接付，外币余额按实时汇率结算。境外部分地区还接了 Alipay+ 网络。

这里有个机制值得单独讲。个人每年有 5 万美元的结售汇便利化额度，很多人把钱提回国内的时候都会撞到它。

提现和扫码消费，走的是两条不同的管道。 提现到支付宝或者微信，本质是把外币换成人民币进你的境内账户，通常算结汇，占用那 5 万的额度；而扫码消费走的是跨境消费通道，性质上是你拿外币账户在境内付款，不占这个额度。众安卡绑微信刷卡不占额度，是同一个道理。

这段我按公开讨论的口径写，实际执行以银行和外汇管理部门的规定为准。但把管道的差别理解了，你就知道什么钱该提出来，什么钱直接花掉更划算。

三、汇款

Starryblu 自带全球汇款，走国际和本地电汇通道，可以直接汇到境外的银行账户。覆盖的国家和地区不少，具体某个目的地能不能到、手续费多少，在 App 里查一下就知道。

订阅 Claude 这件事本身用不到出金，钱进得去、卡能扣上就够了。但办一张卡是长期的事，进得去出不来的产品不值得办。三个出口都通，这张卡才算真的能用。

3：用这张卡订阅 Claude

拿到卡之后，订阅本身不难，但顺序不能错。

先把节点切成新加坡，再用无痕窗口打开

claude.ai

，不要反过来。

3.1 切节点，并且验证
