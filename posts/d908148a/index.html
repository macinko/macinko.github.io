last30days-skill 能让 AI 智能体跨平台（Reddit, X, YouTube

更新于2026-09-05|aiagent
|总字数:684|阅读时长:2分钟|浏览量:

本文将指导你通过多种方式部署 last30days-skill，这是一个能让 AI 智能体跨平台（Reddit, X, YouTube, Hacker News, Polymarket 等）搜索并生成摘要的工具。核心安装方式概览如下：

部署平台 / 方式 适用场景与说明 核心安装命令 / 步骤
Claude Code (推荐) Claude Code 用户，利用其市场功能可实现自动更新。 /plugin marketplace add mvanhorn/last30days-skill /plugin install last30days
通用 Agent Skills 宿主 Codex, Cursor, Copilot, Gemini CLI 等50多种AI编码助手。 npx skills add mvanhorn/last30days-skill -g
Claude.ai (网页版) 在 Claude 网页版中使用，需手动上传技能文件。 1. 从 Releases 下载 last30days.skill。 2. 在 claude.ai 中进入 Customize > Skills > + > Create skill > Upload a skill 上传。 3. 确保在 Capabilities 中启用 “Code execution and file creation”。
Claude Desktop 通过 MCP (Model Context Protocol) 服务器方式安装。 1. 从 Releases 下载对应平台的 .mcpb 文件 (如 macOS Apple Silicon)。 2. 打开 Claude Desktop，进入 Settings > Extensions，拖入下载的文件。 3. 按提示配置 API 密钥，重启应用。
OpenClaw OpenClaw 插件管理器用户。 clawhub install last30days-official
Hermes 在 Hermes AI Agent 中安装。 hermes skills install mvanhorn/last30days-skill/skills/last30days --force
手动安装 (开发者) 从源码安装，便于开发或贡献代码。 git clone https://github.com/mvanhorn/last30days-skill.git 创建符号链接至技能目录。

⚙️ 配置与密钥

  • 零配置启动：Reddit, Hacker News, Polymarket, GitHub 等数据源无需任何配置即可使用。
  • 首次运行向导：首次使用 /last30days 命令时，会自动启动一个设置向导，帮助你配置 X (Twitter)、YouTube (需 yt-dlp) 等更多数据源。
  • 自带密钥：为获得完整功能，尤其是访问 X、TikTok 等平台，你可能需要提供自己的 API 密钥或浏览器 Cookies。所有密钥信息均为可选配置，系统会在无密钥时自动降级。密钥可以存储在 .env 文件或 macOS 的钥匙串中。
  • 诊断工具：运行 python3 skills/last30days/scripts/last30days.py --preflight 可以检查配置状态，而不实际执行搜索。

📊 输出与使用

  • 基本用法：在支持的 AI 环境中，直接使用命令，如：/last30days "你的研究主题"。
  • 输出格式：默认生成 Markdown 格式的摘要。可以通过 --emit=json 获取机器可读的 JSON 数据，或用 --emit=html 生成可分享的 HTML 简报。
  • 高级功能：支持使用 --discover 进行趋势发现，使用 --store 将结果存入 SQLite 数据库进行跟踪等。

💡 安装前须知

  • Python 环境：本地需安装 Python 3.12 或更高版本。
  • 更新方式：不同安装方式的更新命令不同，请参考上表。使用 npx skills 全局安装的，可通过 npx skills update -g 更新所有技能。
