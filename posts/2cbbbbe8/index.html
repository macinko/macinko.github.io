零基础20分钟学会 Obsidian 95% 的功能：实测可用，开箱即用

更新于2026-09-05|toolssoftware
|总字数:3.4k|阅读时长:10分钟|浏览量:

很多人第一次打开 Obsidian，最容易犯的错误不是“不会用”，而是一上来就开始装插件、抄别人的知识库、研究复杂工作流。

结果折腾两个小时：插件装了一堆，笔记一篇没写。

其实对于刚接触 Obsidian 的人来说真正需要先掌握的东西并不多：

Markdown、内部链接、Backlinks、嵌入、Graph、Canvas、Templates，再加两个快捷键。

这些基本可以覆盖新手日常最常使用的一批核心操作。

如果你刚开始用 Obsidian，下面这 20 分钟入门路线照着操作一遍就行。

01｜先搞懂 Obsidian 到底是什么 🧠

很多人把 Obsidian 理解成：“又一个记笔记的软件。”

这么理解不能说错，但会低估它。

Obsidian 最重要的特点之一是：本地文件优先。

Obsidian 官方文档明确说明：一个 Vault，也就是我们常说的“仓库”，本质上就是你电脑本地文件系统中的一个文件夹。

你的普通笔记则主要以 Markdown 格式的 .md 纯文本文件存储。

例如：

My Second Brain/ ├─ AI.md ├─ Obsidian.md ├─ 知识管理.md └─ 第二大脑.md

这也是 Obsidian 一个很重要的优势：即使以后不用 Obsidian，这些 .md 笔记仍然可以被普通文本编辑器打开和管理。

如果你使用的是具备本地文件访问能力的 AI 编程或知识管理工具，也可以在你授权相应目录后处理这些 Markdown 文件。

注意：这并不意味着“任何 AI 都能自动读取你的 Obsidian”。

前提永远是：对应工具本身支持本地文件读取，并且你授予了它访问该目录的权限。

另外，还有一个常见误区：

“Obsidian 里面所有文件都是 Markdown。”

这句话现在并不准确。

目前官方支持的文件类型包括：

  • Markdown：.md
  • Bases：.base
  • JSON Canvas：.canvas
  • 图片
  • PDF
  • 音频
  • 视频等

其中普通笔记主要是 .md，Canvas 则保存为开放的 .canvas 格式。

所以更准确的说法是：Obsidian 的普通笔记以本地 Markdown 文件为核心，而不是“整个 Obsidian 只有 Markdown”。

02｜创建第一个 Vault 📁

第一次打开 Obsidian 后创建一个新的 Vault。

例如：My Second Brain

选择电脑上的保存位置。

完成。

这个文件夹就是你的知识库。

我建议新手先只创建几个最基础的文件夹：

00-收件箱 附件 模板 日记 归档

够用了。

先别学网上那些：

01-工作 02-学习 03-生活 04-读书 05-AI 06-编程 07-资料 08-项目 ……

然后继续套五六层目录的知识库。

因为 Obsidian 真正有意思的地方不只是：

“这篇笔记应该放在哪里？”

而是：

“这篇笔记和哪些知识存在关系？”

这也是接下来双向链接真正解决的问题。

03｜先把“附件乱飞”这个坑填了 🖼️

这一项建议刚建库就设置。

因为 Obsidian 官方目前的默认设置是：新附件默认放到 Vault 根目录。

如果长期截图、拖图片和 PDF，很容易出现：

My Second Brain/ ├─ image.png ├─ image 1.png ├─ screenshot.png ├─ 第二大脑.md ├─ AI.md ├─ image 5.png ……

越来越乱。

建议进入：Settings → Files & Links → Default location for new attachments

选择：In the folder specified below

然后指定：附件

官方目前提供的附件位置选项包括 Vault 根目录、指定文件夹、当前笔记所在文件夹，以及当前文件夹下的子目录。

对新手来说，统一放进一个：附件

文件夹已经足够简单。

知识之间可以复杂，文件系统最好简单。

04｜Markdown 不需要专门学两小时 ✍️

Obsidian 使用 Markdown 作为普通笔记的主要格式。

新手先记下面几个就够了：

# 一级标题 ## 二级标题 ### 三级标题 - 普通列表 - [ ] 未完成任务 - [x] 已完成任务 加粗 ==高亮==

这些写法目前都在 Obsidian 官方 Markdown 语法中得到支持。

例如：

# 今日学习 ## Obsidian - [x] 学会 Markdown - [ ] 学会内部链接 今天最重要的知识是： ==链接比分类更重要==

就已经可以满足绝大多数普通笔记需求。

不要把“学 Markdown”变成使用 Obsidian 的前置课程。

先写。

需要什么格式，再查什么语法。

05｜现在进入 Obsidian 最重要的功能——内部链接 🔗

创建一篇：第二大脑.md

写：第二大脑不是单纯收藏资料，而是把知识保存下来，并建立它们之间的关系。 我正在使用 [[Obsidian]] 建立自己的 [[第二大脑]]。

重点来了：

[[Obsidian]]

就是 Obsidian 默认常用的 Wikilink 内部链接写法。

输入：

[[

就可以搜索并关联 Vault 中的文件。

Obsidian 官方目前同时支持：

[[Obsidian]]

这种 Wikilink，

以及标准 Markdown 内部链接格式。

默认情况下，Obsidian 更倾向于生成 Wikilink；如果你特别在意其他 Markdown 软件之间的兼容性，也可以在 Files & Links 中关闭 Wikilinks，改用 Markdown 链接格式。

一个非常好用的习惯：先挂链接，后写笔记

假设你正在写：很多人记笔记最后都会变成 [[知识囤积]]。

但：知识囤积.md

现在根本不存在。

没关系。

这个内部链接依然可以先保留。

Obsidian 支持指向当前尚不存在笔记的内部链接；之后可以通过这个链接创建对应文件。

于是你写东西的时候，不需要：

想到一个新概念 → 停下来 → 创建文件 → 找目录 → 写两行 → 再回来

而是：

[[知识囤积]]

写完继续。

先连接，后补充。

这个习惯非常适合持续积累知识。

06｜理解 Backlinks，你才真正理解所谓“双向链接” 🔄

这里必须纠正一个特别常见的误解。

很多教程会说：

“Obsidian 会自动帮你创建双向链接。”

这句话很容易让新手以为：A 链接 B 后，Obsidian 会自动在 B 文件里面写一条：

[[A]]

实际上不是。

假设：

第二大脑.md 里面写了：

[[知识管理]]

那么：

A → B

这个内部链接真实存在于 A 文件中。

当你打开 B 时，Obsidian 的 Backlinks 功能可以识别：哪些笔记链接到了当前笔记。

这就是 Backlink。

官方对 Backlinks 的描述也是查看链接到当前笔记的 Linked mentions，以及相关的 Unlinked mentions。

也就是说：内部链接负责“我指向谁”，Backlinks 帮你看到“谁指向我”。

这才是 Obsidian 所谓“双向浏览知识关系”的核心。

Backlinks 是 Obsidian 的 Core plugin，如果已启用，可以在右侧边栏查看当前笔记的相关链接信息。

这一点非常重要。

因为随着你的笔记越来越多，你可能会突然发现：半年前的一篇笔记，竟然和今天研究的问题产生了关系。

知识真正开始产生复利，往往发生在不同笔记重新连接的时候。

07｜一个直接把另一篇笔记嵌进来 🧩

普通内部链接：

[[Obsidian]]

是链接到这篇笔记。

如果前面加：

!

变成：

![[Obsidian]]

就是 Embed，也就是嵌入。

Obsidian 官方支持在内部链接前加 !，把对应内容嵌入当前笔记；除了 Markdown 笔记之外，其他受支持的文件类型也可以被嵌入。

例如：

# 我的知识主页 ## AI 学习 ![[AI学习]] ## 当前项目 ![[当前项目]] ## 本周复盘 ![[本周复盘]]

你就可以把多个独立笔记组合到一个概览页面。

它特别适合制作：

  • Dashboard
  • 项目主页
  • 学习主页
  • 周复盘主页

这里的重点不是“复制一遍内容”。

而是：源笔记仍然独立存在，当前页面只是把它嵌入显示出来。

08｜Graph View 到底有什么用？ 🕸️

接下来打开：

Graph View

Graph View 是 Obsidian 官方 Core plugin，用于可视化 Vault 中文件之间的链接关系。

假设你有：

第二大脑 ↓ Obsidian ↓ 知识管理 ↓ AI知识库

并且这些笔记之间存在内部链接。

Graph View 就可以把这些关系可视化。

官方 Graph 设置中还专门有：Existing files only

因为一个内部链接即使指向尚未实际创建的笔记，也可以存在于知识库里。

不过这里提醒新手：不要为了让 Graph 好看而疯狂制造链接。

如果：AI 和：早餐吃什么没有真正关系，就别硬连。

Graph 的价值不是：

“我的知识库看起来像大脑神经网络。”

真正有价值的是：

帮助你观察哪些知识确实存在连接。

你还可以使用 Local Graph 查看当前笔记附近的关联网络，而不是每次都看整个 Vault。

09｜Canvas 专门解决“脑子里东西很多，但还没整理好” 🗺️

如果 Graph 是自动呈现已有链接，

Canvas 更像一张：无限大的数字白板。

Canvas 是 Obsidian 官方 Core plugin，可以在二维空间中摆放：

  • 笔记
  • 文本卡片
  • 图片
  • 附件
  • 网页

并通过连线和分组组织它们。

例如你准备研究：

AI 内容创业

可以先在 Canvas 放：

市场需求 ↓ 内容生产 ↓ 流量获取 ↓ 产品设计 ↓ 商业化

旁边继续拖：研究笔记、PDF、图片、网页。

先把想法铺开，然后再慢慢整理关系。

Canvas 文件目前保存为：.canvas

使用开放的 JSON Canvas 格式。

所以它和普通 Markdown 笔记并不是同一种文件格式。

10｜记住两个快捷键，效率直接提升 ⚡

笔记一多以后，

别每天：

打开文件夹 → 找子目录 → 找文件 → 点击打开

Windows / Linux：Ctrl + O

macOS：Cmd + O

打开：Quick Switcher

然后直接搜索笔记名。

Quick Switcher 是官方 Core plugin，可以通过键盘搜索、打开笔记；如果没有匹配的笔记，也支持直接创建新笔记。

再记一个：

Windows / Linux：Ctrl + P

macOS：Cmd + P

打开：Command Palette

Command Palette 可以搜索并执行 Obsidian 中可用的命令，同时查看相关快捷键。

所以以后你不知道：

“这个功能到底藏在哪里？”

第一反应可以变成：

Ctrl + P

然后搜功能名称。

11｜Templates 解决重复写笔记的问题 📋

假设你每天都写：

今天完成： 今天学习： 遇到问题： 明天计划：

没必要每天复制。

创建：

模板/每日复盘.md

内容：

# 1787840828000 每日复盘 ## 今天完成 ## 今天学习 ## 遇到的问题 ## 明天计划

然后启用 Templates Core plugin。

进入它的设置：Core plugins → Templates → Template folder location

指定：模板

之后通过：Templates: Insert template 插入。

Templates 是官方 Core plugin，目前支持的基础变量包括：

零基础20分钟学会 Obsidian 95% 的功能：实测可用，开箱即用 1787840828000

其中日期和时间还可以进一步自定义格式。

以后：每日复盘、会议记录、项目记录、内容选题……

都可以建立模板。

12｜最后才轮到社区插件 🔌

这一步顺序非常重要。

新手第一天：真的没必要安装几十个插件。

Obsidian 自带的 Core plugins 已经包括：

  • Backlinks
  • Bases
  • Canvas
  • Command Palette
  • Daily Notes
  • Graph View
  • Quick Switcher
  • Search
  • Templates
  • Properties View
  • Outgoing Links
  • Outline

等等。部分核心插件可能需要在 Settings → Core plugins 中启用。

先把原生功能用起来。

什么时候真的发现：

“原生功能解决不了这个需求。”

再考虑社区插件。

目前 Obsidian 默认运行在：

Restricted Mode（受限模式）

用于阻止第三方插件代码执行。

需要使用社区插件时，可以进入：

Settings → Community plugins

然后选择：Turn on community plugins

之后再进入 Browse 安装插件。

这里还有一个很重要的安全提醒。

Obsidian 官方明确说明：

社区插件属于第三方代码，而且插件并没有细粒度沙箱权限隔离，可以继承 Obsidian 本身的访问能力，例如：

  • 访问电脑上的文件
  • 连接互联网
  • 甚至安装其他程序

因此，官方也建议只有在信任插件作者的情况下再关闭 Restricted Mode。

所以：插件不是装得越多越专业。

尤其你的 Vault 中存在：工作资料、商业资料、私人资料时，

更不要看到推荐就随便安装。

最后：到底应该用“文件夹”还是“链接”？

这是 Obsidian 新手最容易纠结的问题之一。

其实可以用一个非常简单的比喻理解。

文件夹 = 地址 🏢

解决：

东西存在哪里？

例如：

附件 模板 日记 归档 项目

这些位置比较确定的内容。

内部链接 = 道路 🛣️

解决：

它和谁有关系？

例如：

第二大脑 ↓ 知识管理 ↓ Obsidian ↓ Markdown ↓ AI知识库

Backlinks 再帮助你从反方向看到：谁引用了当前笔记。

所以你可以记住一句话：文件夹负责“放在哪里”，链接负责“和谁有关”。

两者不是竞争关系。

也不是：

“用了双链以后就完全不能建文件夹。”

真正舒服的做法往往是：用少量文件夹管理确定性的物理结构，用链接表达知识之间不断变化的关系。

一个能持续使用的简单知识库，永远比一个搭建三天、使用三天的“完美系统”更有价值。
