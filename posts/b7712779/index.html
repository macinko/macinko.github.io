MicYou：把 Android 手机变成 PC 高品质麦克风的开源工具

更新于2026-09-13|osandroid
|总字数:1.2k|阅读时长:4分钟|浏览量:

MicYou 详细部署教程

项目概述

MicYou 是一款开源工具，能将你的 Android 手机变成 PC 的高品质麦克风。它通过 Wi-Fi、USB 或 Web 方式传输音频，并支持 Windows、Linux、macOS 桌面端。

核心特性：

功能模块 说明
连接模式 Wi-Fi、USB (ADB)、Web 扫码（无需安装 App）
桌面端 提供 GUI、CLI、TUI 三种运行模式，共享配置
音频处理 内置 AI 降噪、回声消除 (AEC)、去混响、均衡器、自动增益 (AGC)、语音活动检测 (VAD)
虚拟麦克风 配合 VB-CABLE (Windows)、PipeWire (Linux)、BlackHole (macOS) 作为系统麦克风输入
可定制 调整采样率、声道数、音频格式；支持深色/浅色主题、多语言

技术栈：Android (Kotlin + Jetpack Compose) · Desktop (Tauri 2 + Rust + Vue 3)

部署前准备

系统要求

平台 要求
Android 手机 Android 5.0+（项目通过 Gradle 兼容 API 21）
Windows 桌面端 Windows 10/11 (64位)
macOS 桌面端 macOS 10.15+
Linux 桌面端 现代发行版（需 PipeWire）

准备工作

  1. Android 手机：确保有可用的麦克风，且与电脑在同一网络（Wi-Fi 模式）或可连接 USB 数据线
  2. 电脑：安装对应操作系统的桌面端程序
  3. 虚拟声卡：根据你的操作系统安装（见下文”虚拟声卡配置”）

部署步骤

步骤 1：下载安装包

访问 MicYou 的 GitHub Releases 页面下载：

  • Android APK：用于手机端
  • 桌面端安装包：根据操作系统选择（.exe / .dmg / .AppImage 等）

国内用户：GitHub 下载可能较慢，可使用 GitHub Proxy 加速。MicYou 也提供了镜像下载服务。

步骤 2：安装虚拟声卡（关键步骤）

虚拟声卡负责将 MicYou 接收到的手机音频注册为系统可识别的麦克风设备。

Windows — VB-CABLE

  1. 访问 VB-Audio 官网下载 VBCABLE_Driver_Pack45.zip
  2. 解压到临时文件夹（不能在压缩包内直接运行）
  3. 右键点击 VBCABLE_Setup_x64.exe，选择”以管理员身份运行”
  4. 安装完成后必须重启电脑

macOS — BlackHole

Linux — PipeWire

Linux 通过 PipeWire 创建虚拟麦克风。MicYou 通常会引导你完成配置，或可参考 PipeWire 社区教程手动创建 virtual source。

步骤 3：安装并运行桌面端

  1. 运行 MicYou 桌面端程序
  2. 首次启动时，程序可能自动下载所需的 VB-Cable 驱动（Windows），耐心等待安装完成
  3. 启动后，桌面端会显示本机 IP 地址和监听端口（默认 TCP 6000，UDP 6001）

步骤 4：安装 Android 端并连接

  1. 在手机上安装 MicYou APK
  2. 打开 Android 应用，选择连接模式：

Wi-Fi 模式（推荐日常使用）

  • 确保手机和电脑在同一局域网
  • 在桌面端和手机端都选择 Wi-Fi 模式
  • 在手机端输入桌面端显示的 IP 地址和端口号
  • 点击连接

USB 模式（低延迟）

  • 在手机开发者选项中启用 USB 调试
  • 用数据线连接手机和电脑
  • 在桌面端和手机端都选择 USB 模式
  • 连接自动建立

Web 模式（无需安装 App）

  • 桌面端选择 Web 模式
  • 手机浏览器扫描桌面端显示的 QR 码

步骤 5：系统音频设置

连接成功后，在电脑的声音设置中：

  1. 将播放设备设置为 CABLE Input（Windows）或对应虚拟设备
  2. 将录音设备设置为 CABLE Output 或 MicYou 虚拟麦克风
  3. 在 Zoom、OBS、微信等应用中，将麦克风选择为 MicYou 对应的虚拟设备

常见问题排查

问题 解决方案
Wi-Fi 连接失败 检查 Windows 防火墙是否拦截端口 6000/6001。以管理员运行 PowerShell：New-NetFirewallRule -DisplayName "MicYou-6000-TCP" -Direction Inbound -LocalPort 6000 -Protocol TCP -Action Allow 和 New-NetFirewallRule -DisplayName "MicYou-6001-UDP" -Direction Inbound -LocalPort 6001 -Protocol UDP -Action Allow
USB 模式检测不到设备 确认已安装 ADB 工具。运行 adb devices 检查设备连接。如果有多台设备，指定序列号：adb -s <序列号> reverse tcp:6000 tcp:6000
连接成功但没有声音 确认虚拟声卡驱动已安装且设备已启用（播放设备中的 CABLE Input，录音设备中的 CABLE Output）
声音有延迟 尝试 USB 模式，或关闭占用网络的软件，或调低音频缓冲区设置
路由器 AP 隔离 确认路由器已关闭 AP 隔离或网络设备隔离功能

总结

MicYou 的部署分为三步：

  1. 下载安装：从 Releases 获取 Android APK 和对应平台的桌面端
  2. 配置虚拟声卡：Windows 用 VB-CABLE，macOS 用 BlackHole，Linux 用 PipeWire
  3. 连接使用：Wi-Fi（便捷）、USB（低延迟）或 Web 扫码

对于初次使用，建议从 Wi-Fi 模式 开始，配置最简单。如果遇到延迟问题，切换到 USB 模式。所有主流音视频应用（Zoom、OBS、微信、腾讯会议等）都能通过选择虚拟麦克风设备直接使用手机收音
