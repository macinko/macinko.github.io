前言

这两天全网都被 OpenAI 的最新模型 GPT-6 Astra 刷屏了，很多人看见别人做出来的炫酷效果，也想上手试用一下。但目前 GPT-6 Astra 只在 GPT 的高级订阅中可用，而很多人只是想尝鲜，并不打算长期使用，所以直接订阅 GPT 的话可能用不回本。

今天分享一个可以用 GPT-6 Astra 模型的中转站，大家可以根据自己的使用需求买少量额度试试水。

优点：

  • 支持按量付费，体验更灵活
  • 全程国内网络，无需魔法
  • 不消耗 WorkBuddy 的官方积分

我跟这个中转站的老板线下见过面了，他说这个中转站是不掺水的。

除了 GPT-6 Astra 外，还支持 Claude、Gemini、Grok、DeepSeek、Kimi 等热门模型，均价约为官网的六折。

下面以 GPT-6 Astra 为例，演示如何接入 WorkBuddy。

第一步：创建 API Key

中转站链接：[置顶评论的链接 1]

先在链接注册账号：[置顶评论的链接 2]

来到中转站的「API 密钥」面板，链接：[置顶评论的链接 3]

按下面的步骤创建 API key：

（1）点击「创建密钥」。

（2）填写 API key 的名称，选择分组，不同系列的模型有不同的消耗倍率，此处以 GPT 系列为例。

（3）其余配置保持默认即可。

（4）复制 API key，「sk-」开头。

第二步：获取额度

网站不支持直接充值，需从闲鱼下单。

闲鱼链接：（没贴错链接，直接问客服）

【闲鱼】 CZ321 [置顶评论的链接 4]「我在闲鱼发布了【ai技术服务】」 点击链接直接打开

也可以直接加中转站的老板， +ν：cjs010301（备注「桃推荐」）

价格：

￥30 块对应 $100 的额度。

在闲鱼上付款后，复制客服发给你的兑换码。

回到中转站的「兑换」面板，链接：[置顶评论的链接 5]

填入兑换码，兑换额度。

右上方显示的余额增加。

第三步：配置 WorkBuddy

在 WorkBuddy 的切换模型处，选择 「配置自定义模型」。

添加自定义来源。

配置：

（1）endpoint URL 直接复制：

https://www.yunnaotoken.cloud/v1/chat/completions

（2）API Key 填第一步获得的 sk 开头的。

（3）模型名称填「gpt-6-astra」。（也可替换为其他支持的模型，如「gpt-5.6-sol」）
