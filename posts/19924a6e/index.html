Skill Recorder：录制屏幕操作生成可复用 AI 代理 Skill

Skill Recorder 详细部署教程

Skill Recorder 是微软发布的一款桌面应用，它能录制你的屏幕操作过程，然后利用 GitHub Copilot CLI 将操作过程重构为清晰的意图（Intent）和有序步骤，最终生成可供 AI 代理（如 Microsoft Scout、Copilot Cowork 或 Copilot Studio）重用的 Skill 或 Automation。

本教程将引导你完成安装、配置和使用。

1. 重要前提

在安装 Skill Recorder 之前，请确保满足以下条件：

  • GitHub 账户：需要拥有 Copilot 访问权限 的 GitHub 账户。
  • 操作系统：macOS 是主要支持平台。Windows 11 (x64 和 ARM64) 也支持。
  • 网络：安装和“分析”功能需要网络连接。

2. 安装 Skill Recorder

Skill Recorder 以源码发布形式提供，通过一条命令即可在本地完成构建和安装。

2.1 查找发布版本与 Commit ID

  1. 访问项目的 GitHub Releases 页面。
  2. 选择你希望安装的版本（建议选择最新的稳定版）。
  3. 复制该版本对应的 40 字符的 Commit ID（例如 a1b2c3d4e5f6789012345678901234567890abcd）。每个发布版本都精确绑定了一个代码提交。

2.4 首次启动与权限授予

  1. 从应用程序列表或桌面快捷方式启动 Skill Recorder。
  2. macOS 屏幕录制权限：首次启动时，系统会提示请求屏幕录制权限。必须授予，否则无法录制。
  3. 登录 Copilot：当首次点击“分析”（Analyze）时，应用会引导你登录 GitHub Copilot。

3. 基本工作流程

Skill Recorder 的核心工作流程非常简单，围绕“录制 → 分析 → 生成”展开。

步骤 操作 说明
1. 录制 点击 “录制” 按钮或按全局快捷键 ⌘⇧R (macOS) / Ctrl+Shift+R (Windows) 开始录制你的屏幕操作。一个常驻顶部的控制条会显示录制状态和麦克风状态。
2. 执行任务 正常进行你的操作 录制过程中，可以随时静音/取消静音或切换麦克风。注意：请勿录制任何密码、令牌等机密信息。
3. 停止录制 点击控制条上的“停止”按钮 录制结束，录制内容保存在本地。
4. 分析 点击 “分析” 按钮 应用会将录制数据发送到 GitHub Copilot 云端，由 AI 重构出一个总体意图和有序步骤列表。首次分析会要求登录 Copilot。
5. 审查与编辑 在界面中查看生成的意图和步骤 你可以根据需要进行审查和编辑，确保步骤描述准确。
6. 生成 点击 “创建 Skill” 或 “创建 Automation” 从已批准的分析结果，生成一个可复用的 Skill（按需运行）或 Automation（定时/触发运行）。生成的成果会优先使用代理的原生工具（如 gh CLI 或 web_fetch）。

4. 重要注意事项

4.1 数据隐私与安全

  • 数据不离开本地：录制、存储、视频帧提取和可选的语音转录（使用 Whisper 模型，首次使用需下载约 252 MB 的模型文件）全部在本地计算机上完成。
  • 数据发送至云端：只有当你点击 “分析” 按钮时，事件时间线（窗口标题、URL、剪贴板预览）、提取的屏幕图像和语音文本才会发送至 GitHub 的云端，由 Copilot 进行处理。
  • ⚠️ 请勿捕获机密：绝对不要在录制过程中输入、粘贴、展示或口述任何密码、访问令牌、API 密钥等敏感信息。

4.2 系统兼容性

  • Windows：Windows 11 (x64 和 ARM64) 均受支持，但更详细的验证信息请参考项目中的 WINDOWS-VALIDATION.md 文档。
  • Linux (Ubuntu)：脚本方式安装，但需要确保系统满足 Electron 应用的基本依赖。

5. 故障排除

问题 可能原因与解决方法
macOS 无法录制屏幕 检查“系统设置” > “隐私与安全性” > “屏幕录制”中，是否已允许 Skill Recorder。
分析失败或提示登录 确认 GitHub 账户拥有 Copilot 权限，并按提示在应用内完成登录。
安装脚本执行失败 1. 检查提供的 Commit ID 是否正确。2. 确认网络能够访问 raw.githubusercontent.com。3. Windows 用户确保以管理员身份运行 PowerShell。
生成的 Skill 不准确 这是正常情况。录制时操作越清晰、步骤越规范，AI 重构的准确性越高。生成后可以手动编辑步骤。
如何更新 目前需关注 Releases 页面，获取新版本的 Commit ID，然后重新执行安装命令（会覆盖旧版）。
应用没有响应 早期版本可能存在 Bug。可以尝试重启应用。若问题持续，请在 GitHub Issues 中搜索或报告。

7. 总结

Skill Recorder 提供了一个直观的“演示一次，即可教会 AI”的工作流。通过录制并分析你的操作，它能将重复性任务转化为可复用、可自动化的技能，是构建个人或企业级 AI 自动化助手的有力工具。
