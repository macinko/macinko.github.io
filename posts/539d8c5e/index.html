DSH Mobile 部署教程：在手机上安全访问 DeepSeek Harness

本教程将指导你部署 DSH Mobile，这是一个 DeepSeek Harness (DSH) 的社区插件，让你可以通过 Android 应用或手机浏览器，在局域网或远程安全地继续使用电脑上的 DSH 会话、工作区和工具。

📋 准备工作

1. 环境与软件要求

  • 电脑端：
    • 已安装并运行 DeepSeek Harness (DSH)。
    • 安装了 Node.js 和 pnpm（用于通过源码或命令行安装插件）。
    • 网络环境：能够访问局域网，或根据需要配置远程访问（Tailscale、cpolar 或自建 FRP）。
  • 手机端：
    • Android 手机：安装本项目提供的 DSH Mobile Android App（推荐），或使用手机浏览器。
    • 网络：手机需与电脑在同一局域网（用于局域网访问），或能访问互联网（用于远程访问）。

2. 获取 DSH Mobile

  • 电脑端插件：通过 DSH 的命令行或插件市场安装（见下文）。
  • Android App：从项目 Releases 页面 下载最新版 dsh-mobile-*.apk 并安装到手机。

方式三：通过插件市场安装（可选）

  1. 先安装插件市场：dsh plugin --profile web add dshmarket
  2. 重启 DSH，在 设置 → 插件市场 中搜索 dsh-mobile，一键安装。

安装提示：

  • setup 命令会自动选择并记住当前局域网 IP。切换 Wi-Fi 后通常自动恢复，仅在失败时需手动指定 --address 192.168.x.x。
  • 所有设置、证书和设备信息保存在 $DSH_HOME/mobile-access/ 目录。
  • 安装后需重启 DSH 使插件生效。

📱 手机端连接配置

DSH Mobile 提供局域网和远程两套独立的连接方式，可分别管理。

1. 局域网连接（优先使用，低延迟）

适合同一 Wi-Fi 或热点网络。

  1. 在电脑端 DSH 界面：点击左下角 移动访问 → 局域网。
  2. 开启并生成密钥：点击 开启局域网访问，然后点击 生成并复制密钥（会显示配对二维码）。
  3. 在手机 App 上连接：
    • 打开 Android App，进入 局域网访问。
    • App 会自动扫描并发现同一网络下的电脑设备，点击它。
    • 扫描电脑屏幕上的二维码，或手动粘贴配对密钥。
  4. 完成配对：配对成功后，设备将被持久信任。以后打开 App 会自动连接，切换 Wi-Fi 通常无需重新配对。

不使用 App 时：可在电脑端点击 复制配对链接，在手机浏览器中打开。首次访问需按浏览器提示手动信任插件证书。

2. 远程连接（离开局域网时使用）

远程访问默认关闭，支持 Tailscale Funnel、cpolar 或自建 FRP。远程服务可能有带宽限制。

  1. 在电脑端 DSH 界面：点击左下角 移动访问 → 远程。
  2. 选择一种连接方式：
    • Tailscale Funnel：点击 启用远程访问，按提示完成 Tailscale 登录并允许 Funnel。
    • cpolar（推荐国内用户）：点击 安装官方组件，登录 cpolar 控制台取得 Authtoken，粘贴后点击 保存并连接。
    • 自建 FRP（高级）：需有 VPS。展开 自建连接，填写 VPS 信息、Token 和公开 HTTPS 地址。可使用 自动部署（需 SSH 密钥）或手动复制模板部署。
  3. 状态变为“远程访问已就绪”后，点击 生成远程配对二维码。
  4. 在手机 App 中：进入 远程访问，扫描二维码完成独立配对。之后 App 会保存信任并自动重连。

远程访问说明：

  • Tailscale Funnel 覆盖广，但在中国大陆可能不稳定。
  • cpolar 更适合国内网络，免费方案带宽限制为 1 Mbps。
  • 自建 FRP 适合有 VPS 且希望避开带宽限制的用户。
  • 不使用时，请关闭远程访问开关。

🚀 使用与自定义

基础使用

  • 配对完成后，在 Android App 中即可看到电脑端 DSH 的界面，并操作同一份会话、消息和工具。
  • App 首屏会分开显示“局域网”和“远程”入口，方便切换。

扩展与自定义（核心功能）

你可以在电脑端 DSH 的对话中，使用 /mobile 命令直接修改手机端的界面和功能。

  • 修改界面：例如输入 /mobile 把手机端做成老式终端的样子，让消息像终端输出一样逐行滚动。
  • 添加电脑能力：例如 /mobile 为手机端添加赛博朋克风格的电脑监控面板，实时显示电脑的 CPU、内存和磁盘占用。

/mobile 命令会将需求交给 DSH 的 agent，由它直接修改本机 $DSH_HOME/mobile-access/ 下的文件（mobile.css、mobile.js 或 extensions/ 下的扩展），保存后手机端会自动生效。这实现了高度可定制，且不修改 DSH 源码。

🔧 维护与故障排除

升级插件

  • 通过 npm 安装的插件会在桌面界面加载时检查新版本。有更新时，移动访问面板标题右侧会显示“更新插件”。
  • 点击更新后，需要重启 DSH 完成升级。
  • Android App 暂无主动更新通知，请关注 GitHub Releases。

连接诊断

  • App 和电脑端面板都提供 一键连接诊断 功能，可检查版本、网关、网卡、防火墙和远程通道状态，并生成脱敏报告，便于排查问题。

卸载插件

常见问题

  • App 无法发现电脑：确保手机和电脑在同一局域网，且电脑端已开启“局域网访问”。检查电脑防火墙是否允许 DSH 的端口。
  • 远程连接失败：确认远程服务（Tailscale/cpolar/FRP）已就绪。检查电脑和 VPS（如使用 FRP）的网络连通性。对于 cpolar，请确认 Authtoken 有效。
  • 配对失败：确保二维码或密钥与当前连接方式（局域网/远程）匹配。尝试重新生成密钥。
  • 浏览器访问提示证书不安全：首次通过浏览器访问时，需要手动信任插件的自签名证书。这是正常的安全机制。

通过以上步骤，你可以在手机上方便、安全地访问强大的 DeepSeek Harness，并利用其灵活的扩展能力定制专属的移动端 AI 工作台。请注意，远程访问功能涉及网络安全，请在可信网络环境中使用，并妥善保管配对密钥。
