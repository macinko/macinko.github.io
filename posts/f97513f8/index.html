GPT image 2.5: 官方作图手册解读，速通

更新于2026-09-13|aichatgpt
|总字数:1.8k|阅读时长:6分钟|浏览量:

很多人写图片 Prompt，喜欢堆这种词：

电影感、8K、史诗级、高级感、超写实、震撼、梦幻……

问题是，这些词看起来很专业，但不一定真的有用。 小小东今天细看官方报告，发现： 原来自己提示词很多写的好的， 都很符合官方要求，沾沾自喜中。

OpenAI 官方关于图片 Prompt 的建议，核心其实很简单：

不要把 Prompt 当成“咒语”，而要把它当成一份给摄影师、设计师或修图师看的需求单。

你说得越具体，模型越容易知道你到底想要什么。

下面是最值得记住的 8 个诀窍。

1. 先说你要“什么成品”

不要一上来就描述光线、镜头、风格。

先告诉模型：

  • 这是一张产品图
  • 这是一张海报
  • 这是一张人物摄影
  • 这是一个 App UI
  • 这是一张信息图

例如：

text

这句话很重要，因为同样是“一瓶香水”，电商主图、杂志广告和 Instagram 海报，画法完全不一样。

一个简单原则

先说：

我要做什么。

再说：

画面里有什么。

最后才是：

它应该长什么样。

2. 少说“高级”，多说画面到底长什么样

“高级感”“氛围感”“电影感”都很模糊。

比起说：

text

不如说：

text

为什么？

因为这些东西都是可以直接看到的。

模型更容易理解：

  • 光从哪里来
  • 人站在哪里
  • 镜头离多远
  • 背景是什么
  • 色彩是什么感觉

记住一句话

描述画面，不要只描述感觉。

3. 人物动作，一定要写具体

人物图特别容易翻车。

比如你只写：

text

可能出现：

  • 手没扶车把
  • 腿的位置奇怪
  • 人没有看前方
  • 身体和自行车关系不自然

更好的方式是：

text

也就是把动作拆开说。

你可以告诉模型：

  • 手在哪里
  • 脚在哪里
  • 人看哪里
  • 身体朝哪里
  • 人和物品怎么互动

尤其是多人、运动、拿东西、坐姿、拥抱这类画面，越具体越好。

4. 图片里要放文字，原文一定加引号

如果你要生成海报、包装、Banner，文字通常是高风险区域。

不要只说：

text

更推荐：

text

如果要求更高，还可以继续补：

text

这里有三个重点：

文字要加引号

让模型知道哪些内容必须原样出现。

告诉它出现几次

比如：

text

避免同一句话重复出现。

明确说不要额外文字

text

否则模型很可能自作主张给你加品牌名、假 Logo、小字说明。

5. 改图时，不只要说“改什么”

这是非常重要的一点。

很多人改图时会说：

text

然后发现：

衣服是换了，但脸也变了，背景也变了，连姿势都不一样了。

更好的 Prompt 是：

text

核心思路是：

告诉它改什么，同时告诉它什么绝对不能改。

你可以直接使用这个公式：

text

这对人物修图、商品换颜色、Logo 调整、UI 修改特别有用。

6. 多张参考图，一定给每张图分配任务

如果你一次上传三张图，然后说：

text

模型其实不一定知道：

到底参考谁的脸？

参考谁的衣服？

背景用哪张？

更好的方法是直接编号：

text

简单说：

不要只给参考图，要告诉模型每张参考图负责什么。

把参考图想成一个制作团队：

  • 图 1 负责人脸
  • 图 2 负责服装
  • 图 3 负责场景
  • 图 4 负责构图

模型会更容易理解你的意图。

7. 一次只改一件事

这是提高成功率最好用的方法之一。

假设第一张图出来以后，你发现：

  • 天气不对
  • 衣服不对
  • 字体不对
  • 背景也不够好

不要一次全部修改。

可以这样：

第一轮：

text

第二轮：

text

第三轮：

text

为什么？

因为一次修改十个东西，很容易出现：

改好了 A，却把原本正确的 B 和 C 搞坏了。

更稳定的方法

生成 → 看结果 → 改一个变量 → 再看结果。

把它当成修图流程，而不是买彩票。

8. Prompt 不是越长越好

很多人会写几百上千字 Prompt。

但官方建议并不是：

Prompt 越长，图片越好。

真正重要的是：

结构清楚，没有歧义。

你可以写自然语言，也可以分段。

例如：

text

这种 Prompt 的好处不是“专业”。

而是：

很好改。

如果背景不满意，你只需要改 Background。

如果构图不满意，只改 Composition。

一个可以直接复制的万能模板

如果以后不知道怎么写，可以直接套这个：

text

如果是改图，可以直接用：

text

最后，只记住这 3 条就够了

如果整篇文章你只想记住三个技巧，就记这三个：

第一，描述“看得见的画面”

少说：

高级、震撼、电影感。

多说：

光线、角度、动作、位置、材质、颜色。

第二，改图一定写“什么不能变”

不要只写：

把衣服换掉。

要写：

只换衣服，脸、姿势、背景、镜头全部保持。

第三，一次只改一个变量

不要试图一条 Prompt 把所有问题一次解决。

更稳定的方法永远是：

先出第一版，再一轮一轮修改。

说到底，写好图片 Prompt 并不需要背什么神奇关键词。

真正有效的方法只有一个：

把你脑子里的画面，说得足够具体、清楚、没有歧义。
