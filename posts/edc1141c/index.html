Ghost FTP 是注重隐私和安全性的原生桌面文件传输客户端

更新于2026-09-13|toolssoftware
|总字数:2.2k|阅读时长:7分钟|浏览量:

1. 项目简介

Ghost FTP 是一款注重隐私和安全性的原生桌面文件传输客户端，支持 Windows 和 Linux 平台。它提供专业的双窗格工作区，支持 FTP、FTPS 和 SFTP 协议，内置站点管理器、受保护的凭证处理、有界传输管理和远程文本编辑器。

核心特性：

  • 多协议支持：FTP、显式 FTPS、SFTP
  • 双窗格工作区：本地和远程窗格独立导航与排序
  • 传输队列管理：支持暂停、恢复、取消、重试，显示进度、传输字节、速度和预计剩余时间
  • 远程编辑：可直接打开远程文本文件进行编辑，支持 SHA-256 版本令牌和冲突检测
  • 站点管理器：保存连接配置文件，支持密码、SFTP 私钥和密码短语工作流
  • 24 种语言：英语为默认语言，支持多语言切换
  • 零遥测：无应用分析、广告、跟踪像素、指纹识别或强制账户

系统要求：

平台 要求
Windows Windows 10/11（x64、x86）
Linux amd64、arm64、i386 架构
构建工具 Go 1.27.1（源码编译）

重要说明：Ghost FTP 是源码可见的专有软件，源代码可见但不授予重新分发、改名、再许可或销售的权利。

6. 初始配置

6.1 首次连接

新建连接：

  1. 打开 Ghost FTP
  2. 点击 Site Manager（站点管理器）
  3. 点击 New Site（新建站点）
  4. 填写连接信息：
    • 主机地址
    • 端口（默认 FTPS 使用 21）
    • 协议类型（FTP/FTPS/SFTP）
    • 用户名和密码

协议选择建议：

协议 端口 说明
FTPS 21 新连接的默认选择，使用显式 FTPS，保持 TLS 证书和主机名验证
SFTP 22 使用 SSH 传输语义，支持主机密钥验证和固定
FTP 21 仅作为显式兼容性选项，用于必须使用未加密 FTP 的旧服务器

6.2 凭证保存

Ghost FTP 采用每次保存凭证持久化决策，而不是隐藏的自动密钥存储。保存站点时，你可以选择是否保存密码。

6.3 设置调整

在 Settings 中可调整以下参数：

设置项 范围 默认值
并行传输数 1-8 2
连接超时 5-60 秒 15
自动重试次数 0-3 0
重试延迟 1-30 秒 3
冲突策略 跳过 / 替换 / 替换+恢复备份 跳过
删除确认 启用/禁用 启用

7. 核心功能使用

7.1 文件传输

上传/下载：

  1. 在本地窗格中选择文件
  2. 拖拽到远程窗格（或反之）
  3. 传输任务加入队列，显示进度和速度

传输控制：

  • 暂停：暂停当前传输
  • 恢复：继续暂停的传输
  • 取消：取消传输任务
  • 重试：重新尝试失败的传输
  • 清除已完成：清理已完成任务列表

7.2 远程编辑

Ghost FTP 内置远程文本编辑器，无需外部工具：

  1. 在远程窗格中双击文本文件
  2. 文件在编辑器中打开
  3. 编辑后保存，系统执行事务式上传和读回验证
  4. 支持 SHA-256 版本令牌和冲突检测

限制：

  • 有界编辑大小限制
  • UTF-8/文本验证，拒绝二进制文件
  • LF/CRLF/CR 保留，拒绝混合行尾

7.3 冲突处理

传输冲突时，Ghost FTP 提供三种策略：

策略 说明
Skip 跳过冲突文件
Replace 直接替换目标文件
Replace + recovery backup 替换前创建恢复备份

采用安全分阶段激活/回滚机制，而非直接破坏性覆盖。

8. 安全与隐私

8.1 安全基线

Ghost FTP 保留以下安全机制：

  • FTPS 证书/主机名验证
  • 显式安全协议选择，无静默降级
  • SFTP 主机密钥验证/固定
  • 受保护密钥的生命周期规则
  • 本地根路径保护
  • 分阶段传输激活/回滚
  • 可信 Linux 传输/AskPass 来源
  • Windows 精确对象清理

8.2 隐私保护

Ghost FTP 不包含以下功能：

  • 应用分析
  • 广告
  • 跟踪像素
  • 指纹识别
  • 自动崩溃上传
  • 强制产品账户
  • 隐藏配置文件同步

Go 遥测在生产 CI 和发布工作流中被禁用。

9. 常见问题与解决方案

9.1 无法连接到 FTPS 服务器

问题：FTPS 连接失败。

解决方案：

  • 确认服务器支持显式 FTPS
  • 检查 TLS 证书是否有效
  • 确认防火墙允许端口 21
  • 注意：TLS 协商失败不会静默转换为普通 FTP

9.2 SFTP 主机密钥验证失败

问题：首次连接 SFTP 服务器时提示主机密钥验证失败。

解决方案：

  • 确认服务器主机密钥指纹是否正确
  • 如果是首次连接，接受并固定主机密钥
  • 检查服务器的 SSH 配置

9.3 传输速度慢

问题：文件传输速度不理想。

解决方案：

  • 在设置中增加并行传输数（最大 8）
  • 检查网络连接质量
  • 确认服务器没有带宽限制

9.4 远程编辑无法保存

问题：编辑远程文件后无法保存。

解决方案：

  • 确认文件是 UTF-8 文本格式
  • 检查文件大小是否超过远程编辑限制
  • 确认服务器文件权限允许写入
  • 注意混合行尾会被拒绝

10. 部署架构总结

部署方式 适用场景 安装命令 特点
Windows 安装包 Windows 用户 双击 Setup.exe 开箱即用，含安装向导
Windows 便携版 免安装使用 双击 Portable.exe 无需安装，可放任意目录
Linux deb 包 Debian/Ubuntu sudo dpkg -i *.deb 系统集成，自动更新
Linux 便携版 通用 Linux tar -xzf *.tar.gz 无需安装，直接运行
源码编译 开发者 go build 完全可控，便于定制

Ghost FTP 是一款注重隐私和安全性的现代 FTP 客户端，通过预编译安装包可以在 Windows 和 Linux 上快速完成部署。Windows 用户建议使用安装版获得系统集成，Linux 用户可使用 deb 包或便携版。部署完成后，通过站点管理器创建连接配置，即可开始使用双窗格工作区进行文件传输和远程编辑。需要注意的是，该项目采用专有许可证，源代码可见但不授予重新分发的权利。
