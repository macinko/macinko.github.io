iPhone Location Move：macOS 原生 iPhone 定位模拟工具

更新于2026-09-05|osmacos
|总字数:679|阅读时长:2分钟|浏览量:

官方仓库：https://github.com/cashwu/iphoneLocationMove

iPhone Location Move 是一款用 原生 SwiftUI + MapKit 制作的 macOS 应用，通过 USB 连接并控制一台 iOS 17+ 的 iPhone，实现定位模拟。

它基于 Apple 官方提供给开发者的 DVT simulate-location 机制（与 Xcode 的 Location Simulation 同一层级），使用 pymobiledevice3 实现，不需要越狱，也不修改 iPhone 系统。

主要功能

  • 单点定位：搜索地点或在地图上点选，直接设置模拟位置
  • A → B 步行路线：
    • 使用 MapKit 生成真实步行路线
    • 支持速度 1–7 km/h
    • 可暂停、继续、调整速度
    • 支持往返循环
  • 安全清除机制：停止模拟、App 退出、USB 拔除时都会自动向 iPhone 发送 clear，避免残留模拟位置
  • 最小权限设计：使用经过验证的离线 wheelhouse，不通过网络安装套件

环境需求

运行需求：

  • macOS 13+
  • Apple Silicon Mac（目前内嵌的 privileged tunnel 仅支持 arm64）
  • iOS 17+ iPhone
  • 可传输数据的 USB 线
  • iPhone 已解锁、信任这台 Mac，并已开启 开发者模式（Developer Mode）
  • Python 3.9+（或已有兼容的 pymobiledevice3）

开启开发者模式步骤：

  1. iPhone「设置 → 隐私与安全性 → 开发者模式」
  2. 开启后重启 iPhone
  3. 重新解锁并确认启用

下载与安装

  1. 从 Releases 下载最新 .dmg
  2. 将 App 拖到「应用程序」
  3. 因为未经过 Apple 公证，首次运行前需移除 quarantine 属性：
  4. 打开 App，按照提示完成「设备支持安装」与 Helper 授权

使用方式

单点定位：

  1. 搜索地点或在地图点选
  2. 确认坐标
  3. 点「设置位置」

A／B 步行路线：

  1. 在地图指定 A、B 两点
  2. 等待 MapKit 生成路线
  3. 选择速度（1–7 km/h）
  4. 可勾选「往返循环」
  5. 点「开始」
