LiveContainer 部署教程：在 iOS 上无需安装即可运行应用

更新于2026-09-05|osios
|总字数:1.9k|阅读时长:5分钟|浏览量:

LiveContainer 是一款特殊的应用启动器，它允许你在 iOS/iPadOS 设备上运行其他 iOS 应用，而无需通过 App Store 或 AltStore/SideStore 进行传统意义上的“安装”。它利用动态链接和代码签名绕过技术，在一个容器内启动应用，从而规避了免费开发者账户的 3 个应用 ID 限制。

本教程将指导你完成 LiveContainer 的安装、配置和使用。

📦 第一步：前提条件与准备

在开始之前，请确保你满足以下要求：

  • 设备与系统：一台运行 iOS/iPadOS 15.0 或更高版本 的设备（多任务功能需要 iOS/iPadOS 16.0+）。
  • 侧载工具：已安装 AltStore 2.0+ 或 SideStore 0.6.0+。这些工具用于将 LiveContainer 安装到你的设备上。
  • IPA 文件：你想要在 LiveContainer 内运行的应用的 .ipa 文件。
  • 电脑与网络：一台电脑（用于侧载）和稳定的网络连接。

⚠️ 重要安全警告：
LiveContainer 是一个开源项目。请务必只从官方 GitHub 仓库或可信来源获取。警惕第三方闭源构建版本，因为它们可能包含恶意代码，并且能够完全访问你存储在其中的所有应用数据，包括密码和敏感信息。项目团队不为任何第三方构建版本提供支持。

🚀 第二步：安装 LiveContainer

LiveContainer 的安装方式与侧载普通应用相同。

  1. 下载 IPA 文件：
    • 稳定版：从 LiveContainer 的 GitHub Releases 页面 下载最新稳定版的 .ipa 文件。
    • 夜间版 (Nightly)：如需体验最新功能，可下载带有 nightly 标识的版本。
    • 集成 SideStore 版本：如果你希望使用内置的 SideStore 刷新功能，可以选择 LiveContainer+SideStore 的版本。
  2. 使用 AltStore/SideStore 安装：
    • 将下载的 .ipa 文件通过 AirDrop 或文件管理器发送到你的 iOS 设备，并使用 AltStore 或 SideStore 打开。
    • 或者，在 AltStore/SideStore 的 “My Apps” 界面，点击左上角的 “+” 号，选择下载好的 IPA 文件进行安装。
  3. 信任证书：首次运行时，如果提示“未受信任的开发者”，请前往 iOS 的 设置 → 通用 → VPN 与设备管理，找到对应的开发者证书并点击“信任”。

⚙️ 第三步：在 LiveContainer 中安装并运行应用

  1. 打开 LiveContainer：首次启动时，它是一个空的应用列表。
  2. 添加应用：
    • 点击右上角的 “+” (加号) 按钮。
    • 在弹出的文件选择器中，浏览并选择你想要安装的 IPA 文件。你可以从“文件”App 或其他位置导入。
  3. 安装与启动：
    • LiveContainer 会解析并“安装”该 IPA 到其内部存储空间。这通常很快。
    • 安装完成后，该应用图标会出现在 LiveContainer 的主列表中。
    • 轻点图标即可启动该应用，就像在系统桌面上打开一样。

✨ 第四步：核心功能与技巧

4.1 管理应用与多容器

  • 长按应用图标：可以呼出管理菜单，你可以：
    • 创建多个数据容器：为同一个应用创建多个独立的“数据沙盒”，实现多账号同时在线。
    • 删除或重命名应用及其数据。
    • 修改特定设置：如为某些应用开启“修复文件选择器”或“修复本地通知”以解决兼容性问题。
  • 拖拽排序：长按并拖拽图标可以调整应用在列表中的顺序。

4.2 多任务与分屏 (iOS/iPadOS 16+)

  • 启用多任务：在 LiveContainer 的设置中，你可以将默认启动模式改为“多任务”。
  • 启动多任务：长按应用图标，在弹出的菜单中选择 “多任务 (Multitask)”。应用会在一个可自由调整大小、缩放的虚拟窗口中打开。
  • 画中画 (PiP)：支持将多任务窗口最小化为画中画模式。
  • iPad 原生窗口：在 iPad 上，应用可以以独立的系统窗口形式运行，体验更接近原生。

4.3 添加到主屏幕 (快捷方式)

虽然应用本身在 LiveContainer 内，但你可以为常用应用创建系统主屏幕快捷方式，实现“假装”安装的效果。

  1. 在 LiveContainer 中，长按应用图标。
  2. 选择 “添加到主屏幕” 或类似选项。系统会自动生成一个指向该应用的网页快捷方式，点击它即可直接跳转到 LiveContainer 并启动对应的应用。

4.4 “打开方式”集成 (Open In App)

  • 分享扩展：在 Safari 或其他 App 中分享一个链接或文件时，可以在分享菜单中选择 LiveContainer。它会弹出一个列表，让你选择用哪个已安装的内部应用来打开该内容。
  • URL 链接：在 LiveContainer 的“Apps”标签页，点击右上角的链接图标，手动输入 URL，它会自动检测并询问用哪个应用打开。

🛠️ 第五步：高级功能与故障排查

5.1 启用 JIT (即时编译)

  • 作用：启用 JIT 可以完全绕过代码签名验证，使你不必对应用进行签名即可运行，同时也能提升某些应用的性能。
  • 要求：需要启用 JIT 的工具（如 Jitterbug、AltJIT 或 SideStore 的 JIT 功能），并且设备需要与电脑连接（或使用云端 JIT 服务，如 StikDebug，并通过 PID 附加）。
  • 方法：通常需要在 LiveContainer 设置中启用 JIT 支持，然后在运行应用前通过外部工具启用 JIT。

5.2 安装外部插件 (Tweaks)

LiveContainer 支持加载 TweakLoader.dylib 插件文件，你可以将适用于特定应用的插件放入指定目录，实现功能扩展。

5.3 常见问题

  • 文件选择器无法使用：在应用专属设置中，开启 “修复文件选择器 (Fix File Picker)”。
  • 无法接收本地通知：在应用专属设置中，开启 “修复本地通知 (Fix Local Notifications)”。
  • 应用闪退或无法启动：并非所有应用都兼容。可以查阅 LiveContainer 的 兼容性列表 或提交 Issue。尝试关闭 JIT 或调整应用的运行模式 (如单应用模式)。
  • 物理键盘输入在 iPad 上失效：这是已知问题 (#793)，通常与 iPad 的镜像功能有关，多任务模式下可能存在此限制。

🏗️ 第六步：从源码构建 (面向开发者)

如果你想为 LiveContainer 贡献代码或自行构建最新版本：

  1. 克隆仓库：

  2. 配置开发团队：

    • 用 Xcode 打开 LiveContainer.xcodeproj。
    • 找到 xcconfigs/Global.xcconfig 文件，将 DEVELOPMENT_TEAM[config=Debug] 的值修改为你的 Apple 开发者团队 ID。

  3. 编译运行：在 Xcode 中连接你的 iOS 设备，选择目标，然后点击运行 (⌘R)。这会将调试版本的 LiveContainer 安装到你的设备上。
