go-music-dl 是一个基于 Go 语言的全网音乐搜索与下载工具

更新于2026-09-13|toolssoftware
|总字数:1.5k|阅读时长:5分钟|浏览量:

📌 项目简介

go-music-dl 是一个基于 Go 语言的全网音乐搜索与下载工具。它聚合了网易云、QQ音乐、酷狗、Bilibili、汽水音乐等 10+ 个主流平台，支持无损音质下载，并提供 Web 界面、TUI 终端、桌面应用和移动端 (Android) 四种使用模式。

🚀 方式一：桌面应用 (最简单推荐)

这是最开箱即用的方式，适合普通用户，无需安装任何环境。

第 1 步：下载应用

  1. 访问项目的 Releases 页面。
  2. 下载 music-dl-desktop-rust.exe (推荐) 或 music-dl-desktop-go.exe (备选)。

第 2 步：运行
解压下载的文件，双击 music-dl-desktop-rust.exe 即可运行。它会自动启动一个内置的 Web 服务器并打开原生应用窗口。

  • 特点：原生窗口体验，无需浏览器，自动处理端口，单文件绿色免安装。
  • 注意：若窗口空白，请检查并安装 WebView2 运行时 (微软官方下载)。

1. 生产环境部署 (直接拉取镜像)

Web 模式关键说明：

  • 管理员登录：修改系统设置、管理 Cookie 等需要登录。首次触发设置时，终端会打印一个一次性初始化令牌，打开初始化页面填入令牌并设置用户名/密码 (≥6位) 即可创建管理员账号。
  • 反向代理：若挂载到二级目录 (如 /dl/)，启动时需加 --base-path /dl，并参考项目文档配置 Nginx。

📱 移动端 (Android APK)

项目为 Android 提供了 APK 安装包，可在 Releases 页面下载：

  • 推荐：music-dl_arm64-v8a.apk (适用于绝大多数现代 Android 设备)。
  • 备选：music-dl.apk (无分片兼容包，仅当上述版本无法安装时使用)。

安装后，建议在 Web 界面右上角 设置 中，将“本地下载目录”改为 /sdcard/Music，方便系统音乐应用识别。

⚙️ 重要配置与功能说明

  • FFmpeg 依赖：Web 设置中的“下载时内嵌元数据 (封面/歌词)”功能依赖 FFmpeg。未安装时此功能无效，但不影响核心下载。安装方法：Windows (winget install Gyan.FFmpeg)，macOS (brew install ffmpeg)，Ubuntu (sudo apt install ffmpeg)。Docker 和 Android APK 已内置。
  • Cookie 与扫码登录：在 Web 设置中可为各平台配置 Cookie，以获取更高音质或读取“我的歌单”。网易云、QQ、酷狗、Bilibili 支持点击“扫码”按钮，用官方 App 扫码自动登录。汽水音乐的扫码登录暂未调通，需手动配置 Cookie。
  • 本地音乐管理：Web 端提供“本地音乐”入口，可扫描、上传、管理下载目录中的音频，支持分页、缓存、添加到自制歌单。
  • 数据持久化：所有配置、Cookie、下载的音乐、自制歌单均保存在项目目录下的 data/ 文件夹中 (Docker 部署已挂载此目录)，方便备份和迁移。

💎 总结

go-music-dl 部署方式非常灵活：

  • 个人桌面使用，首选桌面应用，下载即用。
  • 服务器远程访问或团队共享，推荐 Docker 部署 (docker compose up -d)。
  • 开发者或终端爱好者，可使用 Web 服务 或 CLI/TUI 模式。

无论哪种方式，核心数据都保存在 data/ 目录，便于管理。配置好 Cookie 后，即可享受聚合搜索、无损下载和歌单管理的完整体验。
