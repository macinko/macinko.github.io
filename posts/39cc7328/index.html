Microsoft Agent Framework for Go 详细部署与实践教程

Microsoft Agent Framework (MAF) for Go 是微软推出的、用于构建生产级 AI 代理（Agent）和多代理工作流的 Go 语言框架。它支持 Microsoft Foundry、Azure OpenAI、OpenAI 等模型提供商，并集成了 Model Context Protocol (MCP)、Agent2Agent (A2A) 等关键协议。

本教程将带你从环境配置到创建第一个工作流，完成在 Go 语言下的完整部署与开发实践。

1. 系统要求

  • Go 版本：需要 Go 1.21 或更高版本。建议使用最新稳定版。
  • 操作系统：Windows、macOS 或 Linux 均可。

第四步：深入学习与生产化路径

成功运行基础代理后，你可以按照以下路径逐步构建更复杂的应用。

1. 学习路径

官方提供了清晰的循序渐进教程，建议按顺序学习：

步骤 核心概念 说明
1. 第一个代理 基础创建与调用 你已完成这一步。
2. 添加工具 函数调用 (Function Calling) 让代理能调用你定义的函数，例如查询天气、数据库。
3. 多轮对话 会话与状态管理 使用 Session 对象维护对话历史，实现上下文感知。
4. 记忆与持久化 上下文提供者 通过注入持久化上下文，让代理“记住”用户信息。
5. 工作流 多代理编排 构建顺序、并发、条件路由等复杂的工作流。
6. 代理“缰绳” 规划与任务追踪 创建更高级的代理来规划和分解复杂任务。
7. 托管代理 服务化部署 将代理暴露为 HTTP 或 gRPC 服务。

2. 关键诊断工具

  • deeptutor doctor：如果你遇到环境配置问题，这个命令可以检查你的工作空间是否就绪。
  • 故障排除：遇到身份验证错误时，首选方案是运行 az login。对于 API 密钥错误，请检查密钥是否正确且具有相应权限。

总结

通过本教程，你完成了 Microsoft Agent Framework for Go 的环境搭建，并成功运行了第一个基于 Foundry 的代理。核心要点如下：

  • 安装：使用 go get github.com/microsoft/agent-framework-go 安装框架。
  • 核心代码：使用 azidentity.NewDefaultAzureCredential() 进行认证，通过 foundryprovider.NewAgent() 创建代理，并使用 RunText().Collect() 获取响应。
  • 关键现状：该框架处于公共预览阶段，部分高级功能（如 RAG、声明式代理）尚不可用，但核心的代理和工作流编排能力已经具备。
  • 后续步骤：建议按官方教程逐步添加工具、会话、工作流等功能，向生产级应用迈进。
