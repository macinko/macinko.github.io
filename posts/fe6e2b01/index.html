玩转 ChatGPT Image 2.5 教程 这一篇教程就够了

更新于2026-09-13|aichatgpt
|总字数:1.4k|阅读时长:4分钟|浏览量:

记得 AI 生图 Midjourney 刚出来的时候，想要生成好看的图片，还得去背诵各种各样的 Prompt 咒语

什么8 K电影感、震撼、高清

尤其中文还不好使，还非得用那刚过四级的英语水平去记一些复杂的高级词汇来硬凑画面

ChatGPT Image 2.5的更新，就是冲着这一个痛点来的

这次不仅出图速度直接砍半，还更新了手绘草图生图、评论精准局部修图。设计智能体模板和分镜功能

当你想要生成好看的图片，脑子里有画面，但是不知道怎么表述，Image 2.5 就来解决你的问题

无论你是自媒体博主、独立游戏开发者，还是日常做海报做封面的设计师，这篇教程都会把视频里提到的全部核心玩法与实测细节一一拆解透彻

首先，最有意思的亮点更新：Sketch 草图涂鸦

很多时候，我对对画面的构图、主体位置、文字排版有非常清晰的预想。但是每次生图又有偏差，我总是让他往左挪一点点，站在画面上方1/3处。但是他怎么改都达不到你想要的效果。这个时候这个功能就能帮你去解决这个问题

如何进入？目前只有 ChatGPT 网页版更新了这些全部内容

打开 ChatGPT 网页版，展开左侧栏，点击图片，进入创作页

点击第一个小花花图标（Sketch）就可以进入啦

在这里，其实你的画工是火柴人水平也没有关系。你随手画一下整个画布的一些大致的轮廓和位置。还可以用文字工具去输入你想要生成的字。最后再搭配一个简单的描述，在输入框里面说一些简单的提示词

这里睿奇就给大家献丑一下，让 Image 2.5 生成一个抽象的牛来海报 画完之后给你一段默认的提示词，你可以保留或者删掉。保留的话它会问你一些画风相关的选项，你根据喜好去填写就行。 我这边我就直接跟他说，我想要生成一个，牛来票房庆祝的一个海报

来看看最后的生成效果

哈哈哈，怎么样，感觉我画的草图生成的图片比电影要好多了

构图基本上和我画的一致。然后人物的比例以及颜色都比较符合我原来绘画的画面

第二个玩法：评论批注修图 —— 指哪打哪

众所周知，评论批注修图并不是一个新的功能。其他的生图工具像 Grok 或者用一些插件，都能实现相应的效果，但是效果嘛，真的很难评。拿我自己的案例来说

我在Grok里生成了两辆赛车，后面的赛车前盖上多了字母，这本来是一个简单的事情，我通过勾选图层，框选了字母，让他去掉

最后的结果却是：一次连同把前车的所有字母都去掉了，然后还删掉了路上的花纹 一次字没有去掉，人物给我去掉了

以前所有的生图模型都会遇到这样的问题，局部修改经常出问题，牵一发而动全身，修改一处其他地方多多少少会收到影响

Image 2.5 新加入的评论编辑功能，让改图变得像在 Figma 或协作文档里提批注一样简单 哪里不爽点哪里，我一共也是添加了5处的联合批注

  1. 这里6000w改成6亿
  2. 这里不要草图
  3. 这里改成 不是所有牛都叫牛来
  4. 这里改成奶牛
  5. 这里改成拿着牛奶 点击发送后，AI会同时理解这5条建议，相比于以前的模型，还需要一次次修改，有了极大的进步

最后的效果也是堪称完美，把所有要求改的地方都改动了，没有要求改的地方也保留了。

为了验证 Image 2.5 到底有多严谨，是否有“没圈到的地方坚决不乱动”的控制力，视频展示了海外创作者的经典换装实测

第三个玩法：精灵像素战斗GIF

今天 X 上超火的用 Image 2.5 生成像素战斗

步骤很简单：

1️⃣ 把你的角色参考图丢给模型（如 Image 2.5 / Codex），输入提示词： 为这个角色制作一个128px的简化像素艺术战斗动作的精灵图集。请做到透明。以4x4的格式排列 (战斗动作可按需替换，比如：待机呼吸、蓄力聚气、拔剑突刺、大招释放、胜利比耶)

2️⃣ 让它直接自动将 4x4 序列帧切片，并打包合成一个循环连贯的 GIF，一键搞定！

当然，如果你不喜欢这种像素战斗风格，也可以直接让他生成对应的分镜，丢给 视频模型去生成视频

官方模版

官方这一次提供了模板页的标签，相当于就是其他深图 Agent 预设的一些 Skill，或者说模板场景，然后官方帮你做了出来。

我也是看很多的模板，就是他有使用我们用户自己开发的那些非常有意思的一些 Skill和提示词的影子，这也是前人栽树的一个过程吧，帮助每一个产品更加完善
