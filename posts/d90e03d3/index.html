Qiaomu Anything-to-NotebookLM 详细部署教程

Qiaomu Anything-to-NotebookLM 是一个强大的 Claude Code Skill，能将任何内容（微信文章、网页、YouTube、PDF等）通过 Google NotebookLM 自动转换为播客、PPT、思维导图、Quiz等多种格式。本教程将引导你完成从安装到使用的完整流程。

一、准备工作

在开始安装前，请确保你的系统满足以下基本要求：

  • 操作系统：macOS、Linux 或 Windows（建议使用 macOS/Linux，体验更顺畅）。
  • Python 环境：Python 3.9 或更高版本。在终端/命令行中运行 python3 --version 来检查。
  • Git：用于克隆仓库。
  • Claude Code：这是运行此 Skill 的 AI 助手环境。你需要安装并配置好 Claude Code。
  • Google 账号：用于登录和使用 NotebookLM。

注意：此 Skill 的核心功能依赖 Google NotebookLM 的 AI 能力，并且部分功能（如播客转写）可能需要额外的 API 密钥（如 Get笔记）。

第三步：配置 MCP (Model Context Protocol)

  3. 保存配置文件后，重启 Claude Code 以使配置生效。
