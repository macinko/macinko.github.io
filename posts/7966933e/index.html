Pluely 极轻量、注重隐私的 AI 助手桌面应用

更新于2026-09-05|aitool
|总字数:1.3k|阅读时长:4分钟|浏览量:

🧭 Pluely 是什么？

Pluely 不是一个传统的聊天机器人，而是一个浮于所有应用之上的隐形 AI 覆盖层。它有两种核心模式：

  • Ask 模式：你可以打字、语音提问，或让它“看到”你的屏幕内容（截图、文件）来回答问题。
  • Listen 模式：实时转录你的麦克风和系统音频，能在对话中自动生成建议回答。

重要提醒：根据官方说明，Pluely v1 及后续版本已转为闭源，以应对源代码被克隆和滥用的问题。目前提供的是已编译的二进制安装包，核心功能免费，并附带付费的专业版计划。

📦 下载与安装

1. 获取安装包

  • 官方下载：从项目网站 pluely.com/releases 或 GitHub Releases 页面下载。
  • 支持平台与格式：
    • macOS：.dmg 文件
    • Windows：.msi 或 .exe 安装器
    • Linux：.deb、.rpm 或 .AppImage 包

2. 安装过程

  • macOS/Windows：像安装普通桌面软件一样，双击安装包并拖拽或运行即可。
  • Linux：根据你的发行版安装对应的包（如 sudo dpkg -i pluely.deb）。注意，Linux 需要系统已安装 WebKitGTK 运行时（这是 Tauri 框架的依赖，可参考 Tauri 官方指南）。

3. 首次启动与权限

  • Pluely 启动后，会请求必要的系统权限：
    • 屏幕录制权限：用于“Use image”功能（截取屏幕内容）。
    • 麦克风权限：用于语音输入和“Listen”模式的音频转录。
  • 请务必在系统设置中为 Pluely 授予这些权限，否则相关功能无法使用。

🚀 核心功能使用

Ask 模式（提问）

  1. 呼出覆盖层：使用全局快捷键（默认可设置）在任何应用中呼出 Pluely 的透明覆盖层。
  2. 提问方式：
    • 文本输入：直接输入问题。
    • 语音输入：使用“按下说话”功能。
    • 屏幕上下文：点击“Use image”，可截取整个屏幕、选择区域或上传文件，让 AI 基于屏幕内容回答。
  3. 获取答案：答案会以 Markdown 格式流式显示在覆盖层上，并可复制或保存。

Listen 模式（倾听）

  1. 启动监听：在 Pluely 中切换到“Listen”模式，点击“Start”。
  2. 实时转录：它会实时转录你麦克风（你说话）和系统音频（对方说话）的内容，并尝试区分说话人。
  3. 自动建议：根据对话内容，Pluely 可以：
    • 自动响应：当检测到有人提问时，自动生成回答建议。
    • 按需建议：你也可以随时点击“Suggest”按钮获取基于当前对话的回复建议。
    • 后续问题：每个回答下会生成智能的后续提问建议。
  4. 会议记录：所有“Listen”模式的对话都会被保存为完整的会议记录和转录文本。

⚙️ 高级配置与隐私

  • AI 模型选择：
    • 免费方案：使用你自己的 API 密钥（如 OpenAI、Google Gemini 等），在设置中配置即可。
    • Pro 计划：直接使用 Pluely 内置的 200+ 托管模型（包括 GPT、Claude、Gemini 等），无需管理密钥。
  • 隐身上班：
    • Pluely 的设计目标就是在屏幕共享和录屏中完全不可见。
    • 进一步可在设置中隐藏其 Dock 栏或任务栏图标，实现“无痕迹”运行。
  • 数据隐私：
    • 所有聊天记录、会议转录和文件都存储在本地 SQLite 数据库中。
    • 你的 API 密钥也仅保存在本地。
    • 你的数据不会被用于训练任何 AI 模型。

📋 常用快捷键

（具体快捷键可在应用内设置或查阅 docs.pluely.com）

  • 全局呼出/隐藏覆盖层：默认组合键。
  • 截屏并提问：一键截取屏幕区域并发送给 AI。
  • 开始/停止录音：控制“Listen”模式。
  • 在覆盖层内滚动答案：使用键盘方向键等。

❓ 常见问题

  • Pluely 是免费的吗？
    • 是的，其核心功能提供免费套餐。Pro 计划提供更多托管模型和高级功能。
  • 为什么现在是闭源的？
    • 开发者说明，早期开源代码曾被大量克隆和商业化售卖，申诉无效。因此 v1 重写后转为闭源二进制分发，以保护项目可持续性。旧版 GPL-3 代码仍保留在仓库历史中。
  • 需要注册账号吗？
    • 免费使用无需账号。
  • 在会议中使用会被发现吗？
    • 不会。Pluely 被设计为从屏幕录制、截图和录屏中排除，且不加入会议，因此不会被其他参与者看到或检测到。
  • Linux 上无法启动？
    • 请确保已安装 WebKitGTK 运行时。具体命令请参考 Tauri 文档。

总结

Pluely 是一个专为在敏感场合（如面试、会议）中低调、快速、私密地获取 AI 帮助而设计的工具。部署极其简单，只需下载对应系统的安装包，授予必要的屏幕和麦克风权限即可。日常使用中，核心交互依赖于全局快捷键呼出覆盖层，利用“Ask”和“Listen”两种模式获取实时帮助。请务必熟悉其快捷键和隐私设置，以充分体验其“隐形”AI 助手的强大功能。
