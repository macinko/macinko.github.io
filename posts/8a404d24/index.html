翻墙后别再只会用 X 和 Telegram！信息差入口在这里 Discord

更新于2026-09-05|toolssoftware
|总字数:2k|阅读时长:6分钟|浏览量:

我发现很多人翻墙以后，都只学会了用 Google 搜东西、去 X 看消息、在 Telegram 找资源

但真正开始接触海外社区之后，会发现还有一个平台基本绕不开：

Discord

它看起来像个聊天软件，实际上很多 AI、Web3、开源项目、游戏社区，都会把最核心的公告、测试资格、开发进度、活动安排和社区讨论放在这里

有些信息等传到 X、Telegram，甚至被中文账号整理出来的时候，已经是第二手了

但 Discord对于第一次打开的新手并不友好

服务器、频道、Role、权限、Bot、Thread，一堆东西挤在一起，新手很容易看懵

这一篇我就把 Discord 最值得新手先学会的东西整理出来，分享给大家。希望能够对大家有所帮助

一、先认识 Discord

如果一定要找一个国内软件来类比，我感觉 Discord 最像国外版 QQ

但它比普通 QQ 群更强，你可以把它理解成：

QQ群 + QQ频道 + 语音房 + 论坛 + 社群后台

全放在一个软件里

一个 Discord Server，也就是“服务器”，里面可以继续分：

  • 公告区
  • 普通聊天区
  • 问答区
  • 资料区
  • 语音房
  • 活动区
  • 管理员专区

不同身份的人，还能看到不同频道、拥有不同权限

所以 Discord 最大的特点不是“能聊天”

而是：它可以把一个社群管理得很清楚

二、注册账号

官网：

discord.com

支持 Windows、Mac、iOS、Android 和网页版

如果只是偶尔看消息，网页版就够

如果以后准备自己建服务器、改权限，建议直接用电脑客户端

注册完成以后，先认识两个名字：

  • Username：唯一用户名，用来搜索和加好友
  • Display Name：显示名称，别人平时看到的昵称

别人要加你，直接搜 Username 就行

三、注册后先把安全设置改了

进入：User Settings
进入：用户设置

建议先做三件事

1. 开启 2FA

也就是两步验证

尤其是以后准备当 Admin 或 Moderator 的人，最好直接开

2. 限制陌生人私信

Discord 大型服务器里，经常有人冒充：

  • 管理员
  • 官方客服
  • 项目方
  • Giveaway 机器人

然后发验证链接、空投链接或者下载文件

陌生 DM 里的链接，不确定来源就别点

3. 控制好友请求

如果你经常进公开服务器，可以把好友申请范围收紧一点，能少很多垃圾账号

四、第一次进服务器，先看这三个地方

加入一个 Discord 后，不要看到几十个频道就乱翻

先找：

  • #welcome
  • #rules
  • #announcements

Welcome 欢迎来到这里！

看这个服务器是干什么的

Rules 规则

看规则

有些服务器需要先验证、点按钮或者领取身份，才能看到完整频道

Announcements 公告/通知

官方公告一般都在这里

如果你加入的是项目社区，真正重要的信息优先看这里，而不是一直刷 General

五、聊天最常用的两个功能

Reply 回复

直接回复某条消息

频道里人多以后，这样别人一眼就知道你在回谁0

Thread 线程

Thread 就是讨论串

某个话题聊得比较多，可以单独开一个 Thread

这样不会把整个主频道刷满，技术讨论、项目答疑、活动讨论都很适合用

六、Discord 最核心的 4 个概念

新手先记住：

Server → Category → Channel → Role
服务器 → 类别 → 频道 → 角色

Server 服务器

服务器，相当于一个完整社区

Category 类别

分类，用来整理频道

Channel 频道

具体聊天、发公告、语音的地方

Role 角色

身份组，用来区分成员和权限

把这四个搞懂，Discord 基本就通了一半

七、自己创建一个服务器

左侧点击：

+ → Create Server
+ → 创建服务器

设置：

  • 服务器名字
  • 服务器头像

就可以创建

但新手最容易犯的错误就是：

服务器刚建好，先开几十个频道

完全没必要，前期直接用这套就够：

服务器不是频道越多越专业

真正好用的服务器，是新人进来马上知道该去哪

八、Role 是管理服务器最重要的东西

Role 可以简单理解成：

身份 + 权限

新手前期建议只建：

  • Admin
    管理员
  • Moderator
    主持人
  • Member
    成员
  • @everyone

就够了

@everyone

所有加入服务器的人默认都有

Member 成员

普通成员

Moderator 主持人

负责删违规消息、禁言、处理举报，可以理解为管理员

Admin 管理员

负责服务器设置和高权限操作

这里记住一句：

能给 Moderator 的权限，就别直接给 Administrator，Admin 越少越好

九、两个最实用的权限设置

公告频道：普通成员只能看

找到：

#announcements

，进入频道权限

给

@everyone

：
给 @所有人：

  • View Channel：允许
    查看频道：允许
  • Send Messages：关闭
    发送消息：已关闭

给 Admin / Moderator：
给管理员/版主：

  • View Channel：允许
    查看频道：允许
  • Send Messages：允许
    发送消息：允许

这样普通成员可以看公告，但不能乱发消息

管理员私人区

建立：STAFF，分类

设置：

  • @everyone

    → View Channel 关闭
    @everyone → 查看频道已关闭

  • Admin / Moderator → View Channel 开启
    管理员/版主 → 查看频道 已开启

下面的：

  • staff-chat
    员工聊天
  • reports
    报告
  • mod-log

普通成员就完全看不到

十、权限尽量放在 Category 上

这个很实用

如果一个分类下面几个频道权限都一样，不要一个频道一个频道改

直接改整个 Category，下面频道统一继承

服务器以后频道一多，这个习惯能省很多事

十一、Bot 真有需求再装

Discord Bot 很强，但不要一上来装十几个

常见用途无非几类：

  • 防 Spam
    防止垃圾邮件
  • Welcome
    欢迎来到这里！
  • 自动 Role
  • Ticket 工单
  • Poll
    投票
  • Reminder
    提醒

需要什么装什么

还有一点：

不要无脑给 Bot Administrator

一个欢迎机器人或者投票机器人，根本没必要拿整个服务器最高权限

十二、准备认真运营，再开 Community

如果只是朋友聊天，不用弄这么多

如果准备长期做公开社区，可以进入：

Server Settings → Enable Community
服务器设置 → 启用社区功能

开启以后可以用：

  • Onboarding
    入职流程
  • Announcement Channel
    公告频道
  • 社区活动
  • 更多管理功能

其中最实用的是：

Onboarding
入职流程

它可以让新人加入时先选择兴趣，再自动推荐对应频道或者分配 Role

比如：

你对什么感兴趣？

  • AI
    人工智能
  • Crypto
    加密货币
  • Coding
    编程
  • Design
    设计

选 AI，就给他显示 AI 频道

选 Crypto，就显示 Crypto 频道

这样新人就不会一进来就面对几十个频道发懵

最后

我认为Discord 真正值得学的，从来不是“会不会发消息”

而是你开始知道：

什么信息该去哪里找，什么频道值得看，什么权限不能乱给，一个社区为什么有人愿意一直留下来

前面的这些基础弄明白以后，你再去看大型项目的 Discord，会明显发现它们不是随便建了一堆频道

公告、讨论、身份、活动、管理，背后其实都有一套很清楚的结构

这才是 Discord 真正有价值的地方：

它不只是一个聊天工具，而是一套完整的海外社区基础设施
