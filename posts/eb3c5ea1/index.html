Immich 搭建属于你自己的 Google Photos：本地部署，拿来即用

更新于2026-09-05|toolssoftware
|总字数:1.6k|阅读时长:5分钟|浏览量:

Immich 是一个高性能、开源的自托管照片和视频管理解决方案，常被视为 Google Photos 的开源替代品。本教程将指导你使用官方推荐的 Docker Compose 方式，在自己的服务器上完成 Immich 的部署。

1. 准备工作

在开始之前，请确保你的服务器满足以下最低要求：

  • 操作系统：Linux（Ubuntu/Debian/CentOS 等）或 macOS。
  • 硬件：至少 6GB RAM 和 2个 CPU 核心。
  • 软件：已安装 Docker 和 Docker Compose（注意：是 docker compose 命令，而非旧版的 docker-compose）。

⚠️ 重要提醒：Immich 官方文档开头就着重强调，永远不要将 Immich 作为你珍贵照片和视频的唯一存储。请务必遵循 3-2-1 备份策略（3份数据、2种不同介质、1份异地备份）。

2. 部署 Immich 服务器

官方推荐使用 Docker Compose 进行部署，这是最简单和可维护的方式。

2.1 下载配置文件

2.2 配置环境变量（.env 文件）

使用文本编辑器（如 nano 或 vim）打开 .env 文件，并根据你的需求修改以下关键参数：

  • UPLOAD_LOCATION：这是最重要的路径，所有你通过 Immich 上传的照片和视频都会存放在这里。请确保它指向一个存储空间充足的位置。
  • DB_PASSWORD：出于安全考虑，务必修改此默认密码。你可以使用 pwgen 这样的工具生成一个强密码。

3. 首次配置与使用

Immich 启动后，你就可以开始进行初始设置了。

3.1 注册管理员账户

  1. 在浏览器中访问 http://<你的服务器IP地址>:2283（例如 http://192.168.1.100:2283）。
  2. 页面加载后，点击 “Getting Started”（开始使用）按钮。
  3. 第一个注册的用户将自动成为管理员。按照提示填写你的邮箱、密码等信息完成注册。

3.2 体验 Web 端功能

注册并登录后，你就可以在 Web 界面中开始使用了：

  • 上传照片：通过界面右上角的“上传”按钮，可以直接从浏览器上传照片和视频，体验基础功能。
  • 探索功能：Immich 提供了丰富的功能，包括相册管理、人脸识别与聚类、按元数据/对象/人脸搜索、回忆（多年前今日）、全球地图视图等。

4. 移动端配置（推荐）

Immich 的强项之一是移动端自动备份。

4.1 下载 App

你可以从以下官方渠道下载 Immich 移动端 App：

  • iOS：Apple App Store
  • Android：Google Play Store 或 GitHub Releases（APK 文件）
  • F-Droid：开源应用商店

4.2 登录并设置备份

  1. 打开 App，在 “Server Endpoint URL”（服务器端点 URL）字段中输入你的服务器地址：http://<你的服务器IP地址>:2283。
  2. 使用你在第 3.1 步注册的管理员账号（或新创建的用户）登录。
  3. 登录后，点击右上角的云朵图标进入备份设置页面。
  4. 你可以选择要备份的手机相册，然后向下滚动并点击 “Enable Backup”（启用备份）按钮。App 将开始自动上传你选中的照片和视频。

总结

恭喜！通过以上步骤，你已经成功部署了一个功能强大、完全属于你自己的私有照片管理平台。

Immich 的核心价值在于它让你重获数据主权，将个人隐私照片和视频从公有云服务中解放出来，同时提供了近乎 Google Photos 的现代使用体验。其 Docker Compose 部署方式使得安装和维护都相对简单。

如果你在部署过程中遇到问题，可以随时参考 Immich 官方文档 或访问其 GitHub 仓库 寻求帮助。
