你的WorkBuddy积分又没了？3分钟接个免费牛来 Ox Alpha

更新于2026-09-05|aiagent
|总字数:966|阅读时长:2分钟|浏览量:

用 workbuddy 写文章的时候，最怕的就是，写着写着，突然来一个“积分不足”的提示。

这个时候，我会习惯性的点到左下角，然后去看你的积分，刷了又刷，发现果然是 0。

这时候你还有几个选择。

第一，每日签到。得100积分。但奈何不够用啊。

第二，它的成长计划。完成每一项任务会赠送一些积分，但是有的积分是需要你完成之后才有，不是点一下就立即送的，它需要有个过程。

**第三，邀请别人来。**这样可以最高得 650。但，也可能是 100。

**第四，去充值。**那个标准版的按月购买的话是 99，连续包月的话是 70，这么算下来的话也不便宜。

每天盯着积分，就是怕它很快就用完了。

我算了笔账，越算越不得劲。

第一笔账，workbuddy 内置的模型，Hy3 是限时免费的。

但是你要处理比较复杂的任务，或是要去生图，你就发现，很快就不够用了。

第二笔账， workbuddy 一直留了一个口子，就是可以接入自定义模型。自定义模型可以接入你想要的 API。

我就接入了一个 deepseek，日常主力用的是它，也会用Hy3。

第三笔账，就在今天，Openrouter 上了一个神秘模型叫 Ox Alpha。限时免费。

这个模型什么来头？Openrouter 上架的这个，这个模型不管你是编程，还是长时间任务等等，它全可以。

而且有开发者把它接入编码 agent， 初步测试显示，能力已逼近当前顶级的代码模型。

这谁受得了啊。

有人还特意看了它的名字，发现这个“Ox”，翻译过来就是，牛来。

这不禁让人想起，最近特别火的牛来电影了。

咱就说，这个牛来大模型看来也是要来场“牛市”的节奏啊。

至于这款牛来大模型到底是是是哪家的？目前有几个猜测，有的说是智谱的，也有的说是小米的，不过目前还在猜测中。

不管是谁家的，我们就先用着，接入流程不复杂，配下来也就3分钟左右，我这就来给你说下。

第一步，去这个

OpenRouter.ai

去拿 key。我用的是github登录，进去之后有一个 create key。搞了一个串以 sk 打头的，记得立即把它保存一下，要不然的话，一会就找不到了。

第二步，workbuddy接入自定义模型。在这个设置里面有一个自定义模型，配置如下

接口地址：

https://openrouter.ai/api/v1/chat/completions

API Key：
API 密钥：

直接复制刚才那一大长串。

模型名称：

stealth/ox-alpha。
潜行/奥克斯-阿尔法。

其他的配置，能全选就全选，强度直接上最高，极致。输入和输出，按照它说的，1M走起。

第三步，回到你的聊天框测试。选择这个自定义模型，就可以开始了。

在测试过程中，我发现它的响应和反应能力有一点慢。

就算这样，因为免费嘛。

我们可以拿它做一些，比如说 plan 呀，或者是一些长文的任务，或者那些不着急的，都可以丢给它。

主力的话你可以用 deepseek 或者是 workbuddy 的这个 Hy3。

这样的话你不仅可以省一下成本，还可以省下 积分，两全其美，多好。

哈哈。

AI 时代的底气，是你手里始终有得选，想换就换，主动权在咱们自己手里。

模型会下架，也会改套餐，用了好的话，后面涨价是迟早的。

但，

现在它是免费的，我们就可以用，而且要使劲的用。
