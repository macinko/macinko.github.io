Polymarket BTC 15m Assistant 实时交易助手详细部署教程

Polymarket BTC 15m Assistant 是一个为 Polymarket “比特币15分钟涨跌”预测市场设计的实时终端交易助手。它能聚合链上和交易所价格、技术指标，并提供简易的交易信号，帮助您做出更明智的决策。本教程将指导您完成从安装到运行的每一步。

项目是什么

这是一个用 Node.js 编写的命令行工具，专为交易 Polymarket 上 “比特币15分钟涨跌” 合约的用户设计。它通过一个实时刷新的控制台界面，为您提供关键的市场信息和简易的交易信号。

数据来源与计算：

  • Polymarket 市场数据：当前市场的实时价格和流动性。
  • 实时价格源：通过 Polymarket WebSocket 获取 Chainlink 提供的 BTC/USD 实时价格（与 Polymarket UI 显示一致），并备有 Polygon 链上数据作为备用。
  • 参考价格：从币安 (Binance) 获取的 BTC 现货价格，用于对比。
  • 技术指标：在实时价格基础上计算短期技术分析快照，包括：
    • Heiken Ashi 平滑K线
    • RSI (相对强弱指标)
    • MACD (指数平滑异同移动平均线)
    • VWAP (成交量加权平均价格)
    • 1分钟和3分钟价格变化率 (Delta)
  • 交易信号：基于上述技术指标的综合评分，给出一个简单的做多 (LONG) 或做空 (SHORT) 百分比建议。

核心功能

  • 实时数据聚合：在一个终端界面同时查看市场赔率、真实价格源、参考价格和技术指标。
  • 自动化市场选择：默认自动选择最新的15分钟市场，也可手动指定特定市场。
  • 多数据源容灾：主数据源（Polymarket WS）失效时，自动切换至链上 RPC 备用数据源。
  • 代理支持：支持通过 HTTP/HTTPS/SOCKS5 代理运行，适应不同网络环境。

系统要求与准备

软件要求

  • Node.js：版本 18 或更高。您可以在终端运行 node -v 检查版本。
  • npm：随 Node.js 一起安装。
  • Git (可选)：用于克隆仓库，也可以直接下载 ZIP 文件。

网络要求

  • 能够访问 polymarket.com 和相关 RPC 节点（如 polygon-rpc.com）。
  • 如果网络受限，需要准备一个可用的代理。

界面解读

启动后，终端会显示一个实时刷新的静态信息面板，通常包含以下区域：

  1. 市场信息：当前监控的市场名称、结束时间、UP/DOWN 价格和流动性。
  2. 实时价格：来自 Polymarket Chainlink 喂价和备用源的 BTC/USD 价格。
  3. 参考价格：来自币安的 BTC 现货价格。
  4. 技术指标快照：最新计算的 Heiken Ashi, RSI, MACD, VWAP 和 Delta 值。
  5. 交易信号：基于上述指标给出的 LONG/SHORT 百分比建议。

常见问题排查

问题：启动后长时间没有显示 Chainlink 价格更新。

  • 解决：
    1. Polymarket WebSocket 可能暂时不可用，脚本会自动切换到 RPC 备用源。请确保配置了有效的 POLYGON_RPC_URLS。
    2. 检查网络连接，确保可以访问配置的 RPC 节点。

问题：终端显示乱码或界面刷新异常。

  • 解决：确保终端使用的字体和字符编码支持标准输出。部分终端对 readline.cursorTo 等刷新命令的支持可能不完美，可尝试在 Windows Terminal 或 VS Code 的集成终端中运行。

问题：运行 npm start 报错，提示缺少依赖。

  • 解决：确保已正确运行 npm install。如果依然报错，可以尝试删除 node_modules 文件夹和 package-lock.json 文件，然后重新运行 npm install。
