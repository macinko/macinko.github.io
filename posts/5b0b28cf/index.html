Grok Bot VPS 当网络出口：解锁 Gemini，免 Cloudflare 验证

更新于2026-09-13|aiagent
|总字数:1.5k|阅读时长:4分钟|浏览量:

最近折腾半天 Gemini 3.8 Flash 解锁，自己的美国 VPS 被屏蔽了，连 WARP 也被屏蔽了，最后用 Grok Bot 的 VPS 出口解决了。。。

Grok Bot 这条 VPS 线路，我愿称它为 AI 神机出口！！！

Grok Bot 不只是能跑自动化，它的 VPS 出口 IP 才是隐藏王炸，虽然它没有提供公网 IP，但它的 VPS 的出口 IP 质量，比我买的很多节点都干净。

比如，有的网站经常弹出 Cloudflare 的人机验证，用了它当出口之后，验证都没有了，真的太神了。。

很多人不知道我是怎么玩的，让我出教程，这篇我就来整理下。

核心思路就是：利用 Tailscale 实现组网，然后使用 3X-UI 面板实现出口和路由。

Tailscale 组网

因为 Grok Bot 的 VPS 没有公网 IP，所以我们需要让我们的 VPS 和 Grok Bot 的 VPS 通过 Tailscale 实现组网，这样它们就在同一个内网中了，就能够实现网络出口。

Tailscale 是什么？

Tailscale 是一组网工具，它可以把分散在不同网络里的设备，组成一个虚拟局域网。

比如，如果你有 MacBook、iPhone、家里的 Mac mini、美国 VPS、香港 VPS 这些设备……

这些设备可能分别位于家庭宽带、手机流量、美国机房等不同网络中。安装 Tailscale 后，它们可以获得各自的 Tailscale IP，然后像在同一个局域网里一样互相访问。

它最大的特点是不需要公网 IP，也不用自己配置复杂的端口转发和 NAT 穿透，设备之间能够直连。

官网：

https://tailscale.com/

Grok Bot 安装 Tailscale

Grok Bot 快速安装 Tailscale，可以直接在 Grok Bot 中发送以下指令：

在当前 Grok Bot 云电脑安装并配置 Tailscale，然后配置一个仅监听 Tailscale IP 的 SOCKS5 代理服务器，支持 TCP 和 UDP，不允许公网直接访问，并保证服务可以持续运行。

中间它会弹出来要你输入 Tailscale 的 Auth Key，去这里获取并生成一个：

https://console.tailscale.com/admin/settings/keys

为了安全起见，可以给 SOCKS5 加上用户名和密码：

完后，你就拿到了 Tailscale 给你的：

  • 地址
  • 端口
  • 用户名
  • 密码

保存这些信息，后面我们会用到。

VPS 安装 Tailscale

根据你的系统类型选择安装：

https://tailscale.com/download

如果你的 VPS 是 Linux 的可以一条命令安装：

curl -fsSL

https://tailscale.com/install.sh

安装完成后，启动 Tailscale 客户端：

sudo tailscale up

它会输出并显示一个 URL，你需要打开它进行 Tailscale 认证。

完成认证后，可以在管理控制台的 Machines 页面查看设备列表：

如上，显示成功连接的设备说明连接并组网成功了。

配置 VPS 网络出口

我们的 VPS 和 Grok Bot 的 VPS 通过 Tailscale 实现组网后，就可以让 VPS 的网络通过 Grok Bot 的 VPS 网络进行出口了，对方网站看到的就是 Grok Bot 的出口 IP。

这里以 3X-UI 面板为例进行演示，其他请自行 AI，原理应该都差不多。

添加出站

打开「出站」菜单，点击「+ 出站」按钮添加一个出站：

主要配置以下信息：

  • 协议：选择「socks」协议。
  • 目标解析策略：选择网络协议，我选的仅 IPv4。
  • SOCKS 信息：输入之前 Grok Bot 生成的 SOCKS5 信息。

保存成功后，可以点击右边的测速按钮进行测试：

测试下延迟，没问题就继续。

添加路由

打开「路由」菜单，点击「+ 路由规则」按钮添加一个路由规则：

主要配置以下信息：

  • 网络：一般选择 Any，可按需选。

  • 域名：就是哪些域名需要通过这个路由规则出站，不填就所有域名都走这个出站。解锁 Gemini 只需要配置 domain:

    googleapis.com

    域名就行了。

  • 入站标签：就是你用的入站的协议。

  • 出站标签：就是上面配置好的出站。

配置好后，需要重启 3X-UI 面板才能生效。

到这里，全部工作就做完了，你的 VPS 上的 3X-UI 节点都能走对应的 Grok Bot 路由规则出口了。

验证出口

可通过下面的网站检测当前 IP：

https://ping0.cc/

显示 Grok Bot 的出口 IP，就说明我们的出口配置成功了。

Grok Bot 的出口 IP 是原生 IP，虽然还是 Cloudflare 的 IDC 机房 IP，但可能是企业特供，没有被 Google 屏蔽，质量还是杠杠的。
