DeepSeek V4 Flash 0731 开源发布：Agent 能力与前端代码生成大幅升级

更新于2026-08-22|aideepseek
|总字数:562|阅读时长:1分钟|浏览量:

DeepSeek 正式发布全新的 DeepSeek-V4-Flash-0731 开源模型。相比此前的 Preview 版本，新版本在 Agent 调用、推理性能以及前端代码生成能力上实现了显著跃升，同时原生支持 Responses API 并全面兼容 Codex。

核心更新亮点

  • Agent 能力增强：全面适配 Responses API 与 Codex，在复杂 Agent 工作流中的稳定性和多轮执行表现明显提高。
  • 基准测试升级：综合推理能力超越前代 V4-Pro-Preview 模型。
  • 前端代码生成暴涨：在 AI Arena Frontend Coding 分类中获得 1586 分，全球总排名第 7（开源模型排名第 3，消费级产品第 4）。
  • 极低使用成本：具备高达 99.5% 的 Cache 命中率，API 调用成本大幅降低。

社区实测表现

在前端开发与 3D 场景构建方面，DeepSeek V4 Flash 0731 展示了一次性生成高质量代码的能力：

  1. 单文件 HTML 跑酷游戏：可单次 Prompt 完整生成包含 UI、动画、音效及分数系统的商业级单文件游戏。
  2. Three.js 3D 场景开发：支持快速搭建 3D 场景（如超级马里奥、工业流水线、钢铁厂等）以及可交互的 3D 生物细胞探索器。
  3. 同价位横向对比：在魔方动画与手写渲染测试中，稳定性优于同价格段竞品；生成汽车发动机 3D 建模完成度可达高阶模型的 70%–80%。
