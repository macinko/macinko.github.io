Y2A-Auto 详细部署教程

Y2A-Auto 是一个全自动化的视频搬运工具，它能将 YouTube 视频下载、提取字幕、AI 翻译、内容审核后，自动上传到 AcFun 和 Bilibili。项目内置了完整的 Web 管理后台，支持 Docker 或本地部署。

  4. 部署方式二：本地运行

💻 系统要求

部署方式 环境要求 内存 磁盘
Docker (推荐) Docker Engine + Docker Compose，任何支持 Docker 的系统（Windows/macOS/Linux） 最低 2GB，建议 4GB+（Whisper large 模型需 4GB+） 20GB+（用于视频缓存和数据库）
本地运行 Python 3.11+, FFmpeg, yt-dlp 同上 同上
Windows 便携包 Windows 10+，无需 Python/FFmpeg 同上 同上

注意：所有部署方式必须准备目标平台的登录 Cookie，否则无法上传视频。

🔄 核心工作流程

Y2A-Auto 将搬运流程串联为一条自动流水线：

  1. 下载：使用 yt-dlp 下载视频与封面。
  2. 语音识别 (ASR)：调用 Whisper 或 Voxtral 生成原始字幕。
  3. 字幕翻译：通过 AI（OpenAI/DeepSeek 等）将字幕翻译为目标语言。
  4. 字幕质检 (QC)：自动检查时间轴、错别字和断句。
  5. AI 元数据生成：AI 生成标题、简介、标签和分区推荐。
  6. 内容审核：可对接阿里云 Green 进行合规检测。
  7. 自动上传：将视频、字幕和元数据发布到 AcFun / Bilibili（支持双平台）。

🐳 部署方式一：Docker 部署（推荐）

Docker 部署无需手动安装 Python、FFmpeg 和 yt-dlp，是最推荐的方案。

步骤 1：克隆项目并准备 Cookie（必须）

Cookie 准备：在 cookies/ 目录下放入以下文件：

  • cookies/yt_cookies.txt：YouTube 登录 Cookie（Netscape 格式）
  • cookies/ac_cookies.json：AcFun 登录 Cookie（JSON 格式）
  • cookies/bili_cookies.json：Bilibili 登录 Cookie（JSON 格式）

如何获取 Cookie？

  • YouTube：使用浏览器扩展（如 “Get cookies.txt LOCALLY”）导出为 cookies.txt。
  • AcFun / Bilibili：可通过项目 Web 管理后台的「扫码登录」功能生成，无需手动导出。

步骤 2：启动服务

常用管理命令：

  • docker compose down - 停止并移除容器
  • docker compose restart - 重启服务
  • docker compose logs -f - 实时查看日志

步骤 3：访问 Web 管理后台

启动成功后，在浏览器中访问 http://localhost:5000。

🖥️ 部署方式二：本地运行

适合开发者进行调试或二次开发。

前置条件：

  • Python 3.11+
  • FFmpeg（已加入 PATH 环境变量）
  • yt-dlp（已加入 PATH 环境变量）

安装与启动：

访问 http://127.0.0.1:5000 即可。

📦 部署方式三：Windows 便携包

官方为 Windows 用户提供了免安装的便携包，开箱即用。

  1. 从 GitHub Releases 页面 下载 Y2A-Auto-win64.zip。
  2. 解压到任意目录。
  3. 运行 app.exe 或启动脚本。
  4. 注意：便携包已内置 FFmpeg，但请确保 cookies/ 目录中的 Cookie 文件已正确配置。

⚙️ 首次配置与使用

启动 Web 后台后，建议按以下顺序完成首次设置：

  1. 安全设置（重要）：进入「设置中心」→「安全」，启用 password_protection_enabled（Web 密码保护），并设置强密码。
  2. 平台账号认证：在「账号与网络」中，为 AcFun 和 Bilibili 配置 Cookie 或使用「扫码登录」完成认证。
  3. AI 模型配置：在「AI 模型」分组中，填入你的 OpenAI API Key 和 Base URL（或 DeepSeek 等其他兼容服务）。
  4. 视频转码与字幕：根据需要配置默认的 VIDEO_ENCODER 和 SUBTITLE_TRANSLATION_ENABLED 等选项。

完成配置后，即可在「首页」提交 YouTube 链接创建搬运任务，或在「YouTube 监控」中配置频道/关键词自动抓取。

🔧 常见问题与故障排除

问题 解决方案
403 / 需要登录 / not a bot YouTube 反爬或 Cookie 过期。请更新 cookies/yt_cookies.txt。建议配置 CookieCloud 自动同步。
找不到 FFmpeg / yt-dlp Docker 环境无需处理。本地运行请检查 PATH 或 FFMPEG_LOCATION 配置。Windows 便携包若出现此问题，请重新下载完整压缩包。
上传 AcFun / Bilibili 失败 更新对应的 Cookie 文件。检查「人工审核」页面的元信息是否合规。也可在 Web 后台重新扫码登录。
Docker 未启用 GPU 硬编 检查 docker-compose.yml 中 NVIDIA GPU 相关注释是否已取消，并确认宿主机已安装 nvidia-container-toolkit。
字幕翻译速度慢 在设置中调整 SUBTITLE_BATCH_SIZE 和 SUBTITLE_MAX_WORKERS，并注意 API 限速。
忘记 Web 管理后台密码 Docker 环境下，可通过 docker compose logs -f 查找启动时生成的临时密码或重置指引。

⚠️ 重要提醒

  • Cookie 安全：Cookie 等同于账号密码，请勿提交到 Git 仓库，并建议将 cookies/ 目录权限设为 600。
  • 版权合规：搬运视频前请确认获得原作者授权或素材属于 CC-BY/公有领域，并遵守各平台转载规则。
  • 内容复核：AI 生成的翻译和元数据可能存在错误，建议在「人工审核」阶段手动复核后再发布
