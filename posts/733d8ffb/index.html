Codex++ 安装与使用指南：Codex 桌面应用增强工具

更新于2026-09-05|aichatgpt
|总字数:1.7k|阅读时长:5分钟|浏览量:

Codex++ 是 OpenAI Codex / ChatGPT 桌面应用的外部启动器与管理工具。它通过注入增强脚本和管理界面，提供供应商切换、协议转换、会话管理与界面增强等功能。它不修改官方应用的 app.asar，也不向安装目录写入补丁文件，所有增强都是非侵入式的。

1. 系统要求与准备

1.1 软件要求

  • 操作系统：Windows、macOS (Intel 或 Apple Silicon)。
  • 官方应用：已安装 OpenAI Codex 或 ChatGPT 桌面应用。
  • 网络：需要互联网连接以使用 API 功能和下载更新。

1.2 前提条件

  • 您拥有一个有效的 OpenAI Codex / ChatGPT 账号，或已准备好 API 密钥。
  • （可选）了解供应商（Provider）和模型（Model）配置的基本概念。

2. 安装步骤

2.1 下载安装包

从项目的 GitHub Releases 页面 下载适用于您操作系统的最新版本安装包：

  • Windows：下载 CodexPlusPlus-*-windows-x64-setup.exe。
  • macOS Intel：下载 CodexPlusPlus-*-macos-x64.dmg。
  • macOS Apple Silicon：下载 CodexPlusPlus-*-macos-arm64.dmg。

2.2 安装应用

  • Windows：双击运行下载的 .exe 文件，按照安装向导完成安装。安装包会创建桌面和开始菜单快捷方式。
  • macOS：打开下载的 .dmg 文件，将 Codex++.app 和 Codex++ 管理工具.app 拖入 Applications 文件夹。

2.3 macOS 安全提示处理

由于当前安装包未签名/未公证，macOS Gatekeeper 可能会拦截并提示“已损坏，无法打开”。如果遇到此情况，请在终端执行以下命令解除隔离属性：

执行后重新打开 Codex++ 或 Codex++ 管理工具 即可。

3. 快速开始

安装完成后，您会看到两个应用入口：

  1. Codex++ 管理工具：用于配置所有增强功能、供应商、模型、会话管理、更新和诊断。
  2. Codex++：静默启动官方 Codex/ChatGPT 应用，并加载已保存的配置与增强功能。

首次使用建议流程：

  1. 打开 Codex++ 管理工具。
  2. 确认官方应用的路径和运行状态（在“安装维护”和“关于”页面检查）。
  3. 配置您想使用的供应商和模型（见下一节）。
  4. 根据需要开启界面增强功能（如会话管理、模型白名单等）。
  5. 关闭管理工具，从 Codex++ 入口启动官方应用，享受增强体验。

4. 核心功能详解

4.1 供应商与模型管理

这是 Codex++ 的核心功能，允许您切换不同的 API 后端。

供应商模式：

  • 官方登录：仅使用 ChatGPT / Codex 官方账号登录。
  • 纯 API：不依赖官方账号，完全使用自定义 Base URL 和 API Key。
  • 官方登录 + API：保留官方账号，但模型请求走您配置的 API 后端。
  • 聚合供应商：在多个 API 供应商之间实现故障转移或负载均衡（按会话/请求/权重轮转）。

操作：

  1. 在管理工具中，进入供应商配置界面。
  2. 选择或创建一个供应商，配置：
    • 协议：Responses 或 Chat Completions。
    • Base URL 和 API Key。
    • 模型列表：可手动添加或通过“模型列表”功能自动获取。
    • 上下文窗口：为每个模型设置窗口大小（如 1M、200K）。
  3. 使用“模型测试”或“Provider Doctor”功能验证配置是否正确。
  4. 保存配置。切换供应商时，Codex++ 会自动保存当前状态并写入新配置。

4.2 界面增强（Codex 增强）

这些功能通过注入脚本实现，优化了官方应用的界面和操作体验。

  • 会话管理：支持会话的删除、批量删除、Markdown 格式导出。
  • 插件市场：解锁插件自动展开和模型白名单处理。
  • 粘贴修复：富文本粘贴时自动转为纯文本。
  • 界面定制：强制中文界面、启动加速、会话宽度调整、滚动位置恢复。
  • 开发工作流：支持 Upstream worktree、Zed Remote 项目识别与打开。
  • 其他：Stepwise 下一步建议、服务层级控制、Goals、自定义图片覆盖层等。

所有界面增强功能都可以在管理工具中单独开关。即使关闭“Codex 增强”总开关，Codex++ 仍可作为供应商和启动管理工具使用。

4.3 会话与数据管理

  • 会话扫描：扫描本地会话，查看 Token 用量历史。
  • 数据导出：将会话导出为 Markdown 格式。
  • Provider 同步与备份：备份供应商配置到 ~/.codex/backups_state/provider-sync，便于恢复。

5. 常见问题与故障排查

问题 可能原因 解决方案
Codex++ 启动后，增强菜单未出现 未从 Codex++ 入口启动，或注入脚本未加载 确保使用 Codex++ 快捷方式启动，而不是直接打开官方应用。在管理工具“安装维护”和“关于”页检查应用路径和诊断日志。
切换供应商后 API 请求失败 配置的协议、Base URL、Key 或测试模型不匹配 在供应商详情中运行“模型测试”或“Provider Doctor”。确认纯 API 与官方混入模式使用不同的认证位置，不要混用配置文件。
macOS 提示“无法打开”或“已损坏” 应用未签名/未公证，被 Gatekeeper 拦截 执行终端命令：sudo xattr -rd com.apple.quarantine /Applications/Codex++.app 和对应管理工具的命令。
增强功能（如会话删除）不起作用 依赖注入脚本未生效，或需要重启应用 保存配置后，完全退出 Codex++ 和官方应用，重新从 Codex++ 入口启动。
Windows 安装失败或文件被拦截 安装包未签名，可能被 Windows Defender 或杀毒软件误报 确认从官方 GitHub Releases 下载。若被拦截，可选择“仍要运行”或临时关闭实时保护。

6. 总结

Codex++ 是一个强大的工具，它让 OpenAI Codex/ChatGPT 桌面应用变得更加灵活和易用。

核心使用路径：

  1. 下载并安装适合您系统的安装包，处理 macOS 的安全提示。
  2. 打开Codex++ 管理工具，这是所有配置的中心。
  3. 配置供应商：这是最关键的一步。根据您的需求（官方账号、纯 API 或混合），配置协议、Base URL、API Key 和模型列表。
  4. 开启增强功能：在管理工具中按需开启会话管理、界面优化等开关。
  5. 从Codex++入口启动官方应用，享受无缝增强的体验。

提示：

  • 所有真实 API Key 仅保存在本地，请注意不要放入日志或截图。
  • 官方 Codex 应用更新后，部分注入功能可能需要时间适配，请关注项目更新。
  • 如果您仅需供应商切换功能，可以关闭所有“Codex 增强”开关，将 Codex++ 作为一个纯粹的启动和管理工具使用。
