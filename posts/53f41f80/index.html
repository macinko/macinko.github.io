Page Agent：阿里巴巴开源的页面内 GUI 代理，一行代码接入

更新于2026-09-05|aitool
|总字数:866|阅读时长:2分钟|浏览量:

Page Agent 是一个阿里巴巴开源的页面内GUI代理，其核心功能是让开发者通过一行JavaScript代码，就能为任何网页添加一个可由自然语言控制的AI代理。

🎯 核心定位与特点

Page Agent 的设计理念是“轻量”和“易集成”，它直接在浏览器页面中运行，无需依赖外部浏览器扩展、Python环境或无头浏览器。

  • 易于集成：只需在网页中引入一个脚本标签，即可为页面配备AI代理，所有操作都在当前页面内完成。
  • 基于文本的DOM操作：与许多依赖截图和多模态模型的方案不同，Page Agent通过分析和操作页面的文本化DOM（文档对象模型）来工作，因此对普通LLM（大语言模型）友好，无需特殊权限。
  • 自带LLM：你可以自由选择使用主流云端模型（包括阿里云的通义千问）或本地部署的模型。

💡 主要应用场景

这个工具非常适合以下场景：

  • 为SaaS产品添加AI副驾驶：无需重写后端，用几行代码就能为产品界面增加一个AI助手，帮助用户完成复杂操作。
  • 智能表单填写：将需要多步点击的繁琐工作流（如ERP、CRM系统操作）简化为一句自然语言指令。
  • 提升可访问性：让用户通过语音或自然语言指令来操作网页，降低使用门槛。
  • 构建多页面代理：配合其可选的Chrome扩展，可以扩展代理能力，让它跨浏览器标签页执行任务。

  • 演示用途：官方提供的Demo CDN仅用于技术评估，使用的是免费的测试API，有使用条款限制。
  • 贡献指南：项目欢迎贡献，但明确指出，完全由机器人或AI生成、没有实质性人工参与的贡献将不会被接受。
  • 项目基础：Page Agent 的DOM处理组件和提示词受到了 browser-use 项目的启发，但它的设计目标是客户端网页增强，而非服务器端自动化。

💎 总结

Page Agent 是一个为开发者设计的、在网页内嵌入AI能力的高效工具。它的主要价值在于大幅降低了为Web应用构建自然语言操作界面的门槛，使得复杂的界面交互可以通过简单的API调用来实现自动化。

如果你正在开发一个Web应用，并希望为用户提供一种更智能、更自然的交互方式（例如，用一句话代替一系列点击操作），Page Agent 是一个非常值得尝试的解决方案。其MIT许可证也对商业使用非常友好。
