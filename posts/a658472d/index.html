Drawnix：开源一体化白板工具

更新于2026-08-22|toolssoftware
|总字数:476|阅读时长:1分钟|浏览量:

官方仓库：https://github.com/plait-board/drawnix
在线体验：https://drawnix.com

Drawnix 是一款免费开源的一体化白板工具，集成了思维导图、流程图、自由画笔等多种功能，定位为「All in one」开源白板。它基于 Plait 画图框架构建，采用插件化架构，支持本地优先使用。

名称来源：Draw（绘画）+ Phoenix（凤凰），寓意创意如凤凰涅槃，生生不息。

核心特性

  • 💯 完全免费 + 开源
  • ⚒️ 思维导图 + 流程图
  • 🖌 自由画笔（Freehand）
  • 😀 插入图片
  • 🚀 插件化架构（可扩展）
  • 🖼️ 导出 PNG / SVG / JSON（.drawnix）
  • 💾 自动保存（浏览器本地缓存）
  • ⚡ 完整编辑能力：撤销、重做、复制、粘贴等
  • 🌌 无限画布：缩放、滚动
  • 🎨 主题模式（明暗主题）
  • 📱 移动端适配
  • 📈 支持 Mermaid 语法 转流程图
  • ✨ 支持 Markdown 文本转思维导图（新功能）

快速使用

1. 在线直接使用（推荐）

访问官方网站即可立即体验：
https://drawnix.com

无需安装，打开即用，数据默认保存在浏览器本地。

底层技术

  • Plait：开源画图框架（由团队开源，源于 PingCode Wiki 的技术沉淀）
  • Slate：富文本编辑
  • Floating UI：弹出层处理
  • 插件架构，支持多种 UI 框架扩展

适用场景

  • 个人/团队头脑风暴
  • 产品原型与流程图绘制
  • 知识整理与思维导图
  • 教学课件与可视化笔记
  • 需要本地优先、隐私友好的白板工具

总结：Drawnix 是目前国内开源社区中体验较好的一体化白板之一，功能完整、界面现代，支持思维导图、流程图和自由画笔，且完全免费开源。官网即可直接使用，非常适合快速上手。
