英国 iFAST 银行开户完整教程：大陆居民亲测，附真实踩坑记录

更新于2026-09-05|globalbank
|总字数:1.5k|阅读时长:4分钟|浏览量:

🧵 为什么要开这个账户？

一句话说清楚它的定位：

如果你需要加密货币出金，那么整个链路是：USDT / USDC → Neverless → iFAST → Wise/银行卡

加密货币出金链路里，iFAST 是个「清洗池」

你把稳定币（USDT/USDC）在境外平台换成欧元， 直接打到 Wise 或香港银行？大概率触发风控。

但如果你先把欧元落进 iFAST → 再从 iFAST 转出， 触发风控的概率会极大地降低。

原因很简单：iFAST 本质上就是一个英国银行账户， 而且目前对加密资金的来源非常友好。

📌 简单说：它是你出金链路里那个缓冲层， 不是用来储蓄的，是用来「洗白通道」的。

✅ 开始之前你需要确认

  • 中国大陆居民身份证（或护照）
  • Gmail 或其他海外邮箱（不建议用 QQ/163）
  • 中国大陆手机号（+86 可以用）
  • 近 3 个月内的地址证明（银行账单 / 水电费 / 信用卡账单）
  • 苹果手机用户：台湾 Apple ID（大陆 ID 搜不到 App）

📋 完整开户流程

STEP 1 · 注册账号：

https://www.ifastgb.com/tellafriend/zhihuiz7928?campaignId=1

  1. 打开 iFAST 官网，右上角切换简体中文

  2. 点击「开户」→「个人申请人」→「开始」

  3. 选择「我是新用户」

  4. 是否受奕丰集团雇佣状态选”我不是”（就是随便选，后面职业信息再填）

  5. 填写邮箱，优先用 Gmail，系统会发验证码

  6. 点提交 → 下一步 → 同意

STEP 2 · 填写个人信息（这步最容易出错）

⚠️ 必看，每一条都是坑：

① 美国关联 → 选「与美国没有任何关系」，也不是美国公民

② 税务居民 → 选「是」，居住地区选中国

③ 税务识别号 → 就是你的身份证号码

④ 手机号 → 选中国区 +86，填大陆手机号没问题

⑤ 出生日期格式 → 注意！是日-月-年的顺序，跟中国习惯反的 → 比如 1990年3月15日，要填 15-03-1990

⑥ 国籍 + 出生地 → 都选中国

STEP 3 · 地址信息（这里有两个填写框）

第一个框填英文地址，第二个框填中文地址

英文地址怎么来？

我自己用的是中信银行的月结账单—— 账单第一行就有我的居住地址， 直接丢给 AI 翻译成英文，粘进去。

中文地址怎么填？

把地址证明上的汉字原封不动复制过来， 不要自己重新敲，一个字都不能差。

居住起始时间 → 要填 3 年前以上的日期 → 不这么填的话，系统会让你再补一个「以前的住址」 → 这个逻辑有点蠢，但就是这么设计的

STEP 4 · 职业与财务信息

职业部分建议这样填：

字段建议填写雇佣状态受雇佣职位分析师（Analyst）行业信息技术公司名称只能填英文收入来源薪水（Salary）收入金额如实填，单位是英镑净资产随便选一个档位

⚠️ 关键问题：您是否持有加密货币？ → 选「没有」 → 不管你实际情况怎样，这里不要选有

STEP 5 · 开户用途

  • 开户原因选「储蓄和投资」
  • 资金来源 + 资金转出地：尽可能选「英国」 → 这一条对开户成功率影响很大，亲测有效

STEP 6 · 条款确认

每一项条款都要点开看一下（系统会检测）， 最后确认重要信息，点「同意并继续」。

STEP 7 · KYC 身份验证（重点！）

强烈建议切换到手机 App 操作，不要用手机浏览器

手机网页版真的很卡，拍照上传各种失败， 用 App 顺畅太多了。

苹果用户注意： 大陆 Apple ID 在 App Store 搜不到 iFAST → 去淘宝或闲鱼买一个台湾 Apple ID， → 几十块钱，登进去搜索下载就行

KYC 需要准备：

  1. 身份证 或 护照（两者都可以，没太大区别）
  2. 地址证明（近 3 个月）
  3. 自拍照

地址证明上传格式： → 上传 PDF，不要上传截图 → 这个坑我踩了，下面细说

⚠️ 我踩的坑：地址证明机审 BUG

这个平台的机审有点迷， 我第一次上传的是7 月份的中信银行对账单， 明明是 PDF，系统提示我说「文件是图片，不是 PDF」。

我换了6 月份的同一家银行账单，直接过了。

所以如果你遇到同样的情况： → 换一个月份试试 → 换一种地址证明类型（水电费/信用卡账单） → 多试几次，不要慌

⏱️ 审核时间

提交完资料后，系统会先做机审， 通过机审之后进入人工审核。

我的经历：当天下午提交，次日上午收到开户成功邮件

打开 App 后会让你：

  1. 设置密码
  2. 再做一次自拍认证（大概是激活验证）

完成这两步，账户正式开好。

💰 开户之后：首笔入金怎么做

账户开好了，要往里面转钱——

首笔入金必须用传统银行转账，不要用加密换来的法币

推荐选择：

  • ✅ 香港银行卡
  • ✅ Stash Blue（新加坡华侨银行账户）

这样能最大程度降低触发风控的概率， 账户刚开好最脆弱，第一笔要走「干净钱」。

📌 最后总结一下关键点

✅ 邮箱用 Gmail ✅ 出生日期格式：日-月-年（反的！） ✅ 地址要填 3 年以上居住时长 ✅ 中英文地址各填一次，中文从证明原文复制 ✅ 有无加密资产：选「没有」 ✅ 资金来源/流向：选「英国」 ✅ KYC 用手机 App，不用手机浏览器 ✅ 地址证明上传 PDF 格式 ✅ 遇到机审报错，换月份或换类型再试 ✅ 首笔入金走传统银行，不走加密出金的钱
