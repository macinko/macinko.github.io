SideScreen 能将安卓平板变为 macOS 第二屏幕的开源工具

更新于2026-09-05|osmacos
|总字数:1.4k|阅读时长:4分钟|浏览量:

🧭 SideScreen 是什么？

SideScreen 解决了 macOS 无法原生支持安卓平板作为扩展屏的问题。它通过硬件加速的 H.265 编解码技术，实现了低延迟（USB 模式下 < 30ms）的屏幕扩展，并支持触摸交互和 HiDPI 视网膜显示。

核心优势：

  • 两种连接模式：USB-C 模式延迟最低，适合绘图或游戏；无线模式（Wi-Fi 5GHz）则更便捷，扫码配对后自动重连。
  • 真正的扩展屏：macOS 会将其识别为虚拟显示器，你可以像使用真实显示器一样将窗口拖拽过去。
  • 触摸与手势支持：平板的触摸屏可用于操作 macOS，触摸预测算法让点击和拖拽感觉自然。
  • 高性能与定制：支持最高 8K 分辨率、120 FPS 刷新率，并提供“游戏增强模式”以优化性能。
  • 无头模式：macOS 端可设置为开机自启并自动开始串流，适合 Mac mini 等无自带显示器的设备。

📦 安装与配置

1. 环境与下载

  • macOS 端：需要 macOS 13 (Ventura) 或更高版本，配备 Apple Silicon 或 Intel 处理器。
  • 安卓端：需要 Android 8.0 (API 26) 或更高版本，且设备必须支持 H.265 硬件解码。
  • 安装文件：从项目的 GitHub Releases 页面下载对应安装包。
    • macOS：下载 .dmg 文件，打开后将 SideScreen.app 拖入 Applications 文件夹。
    • Android：下载 .apk 文件并安装到平板上（可能需要开启“允许未知来源应用”）。

🚀 快速连接指南

方式一：USB-C 连接（推荐，延迟最低）

  1. 使用 USB-C 数据线 将安卓平板连接到 Mac。
  2. 在 Mac 上启动 SideScreen 应用（它会出现在菜单栏，并自动设置端口转发）。
  3. 在平板上打开 SideScreen，保持在 USB 标签页，点击 Connect。
  4. 连接成功后，你就可以将 Mac 上的窗口拖拽到平板屏幕上了。

方式二：无线 Wi-Fi 连接（便捷，无需线缆）

  • 要求：Mac 和平板需连接同一个 Wi-Fi 网络，强烈建议使用 5 GHz 频段以获得更好的稳定性。
  1. 在 Mac 上启动 SideScreen，切换到 Wireless 标签页，点击 Start 生成一个二维码。
  2. 在平板上打开 SideScreen，切换到 Wireless 标签页，点击 Scan QR Code，扫描 Mac 上显示的二维码。
  3. 配对成功后，平板会自动记住 Mac，后续启动时自动重连。

⚙️ 高级配置与优化

1. 无头模式（Headless Mode）

适用于 Mac mini 或合盖使用的 MacBook。在 Mac 端设置中：

  1. 开启 Launch at Login（登录时启动）。
  2. 开启 Auto-start streaming on launch（启动时自动开始串流）。
  3. 选择 Startup mode（启动模式，USB 或 Wireless）。
    设置完成后，Mac 启动后会自动进入待连接状态，无需任何操作。

2. 性能调优

你可以在 Mac 菜单栏的 SideScreen 设置中调整以下参数以获得最佳体验：

设置项 选项（默认） 说明
分辨率 720p 至 8K (1920x1200) 根据平板屏幕和性能需求选择
帧率 30/60/90/120 FPS (120) 高帧率更流畅，但会增加功耗和带宽
码率 20-5000 Mbps (1000) 影响画质。无线模式下，过高可能因网络不稳导致卡顿
HiDPI (Retina) 开/关 (关) 开启后画面更锐利，适合高分辨率平板，但会增加性能开销
游戏增强模式 开/关 (关) 自动优化为 1 Gbps 码率和 120 Hz，适合游戏

❓ 常见问题排查

问题 解决方案
macOS 提示“应用已损坏” 执行 sudo xattr -cr /Applications/SideScreen.app
安卓端提示“连接被拒绝” 1. 确保已安装 adb；2. 确保平板已开启 USB 调试；3. 重新插拔 USB 线缆
无线模式连接超时 1. 确认 Mac 和平板在同一 Wi-Fi 网络且同一子网；2. 在 Mac 上点击 Start 后再扫描二维码；3. 检查 macOS 是否授予了 本地网络 权限
高延迟或画面卡顿 1. 降低分辨率或帧率；2. 无线模式下，确保使用 5 GHz Wi-Fi；3. 尝试更换高质量 USB-C 数据线
虚拟显示器未出现 检查是否已在“系统设置 → 隐私与安全性 → 屏幕录制”中为 SideScreen 开启了权限

总结

SideScreen 提供了一种经济高效的方式，将闲置的安卓平板利用起来作为 Mac 的扩展屏幕。对于追求最佳体验的用户，推荐使用 USB-C 有线连接，它提供了最低的延迟和最高的稳定性。无线模式则适合日常办公等对延迟不敏感的场景。部署的核心是正确安装 ADB 工具、开启安卓 USB 调试、并授予 macOS 屏幕录制权限。请务必留意 macOS 的安全提示，并执行必要的 xattr 命令以正常启动应用。
