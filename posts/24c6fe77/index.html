czkawka 与 Krokiet：极速重复文件查找清理工具

czkawka / Krokiet 部署与使用教程

czkawka (发音: tch•kav•ka) 和它的下一代界面 Krokiet (发音: kroh-cyet) 是一款用 Rust 编写的、速度极快且功能丰富的重复文件查找与清理工具。它能在 Linux、Windows、macOS 等多个平台上运行，帮助用户高效地清理磁盘空间。

重要提示：带有 GTK 界面的旧版 czkawka_gui 已停止开发（v12.0 是最后一个版本）。新用户和现有用户都应使用基于 Slint 框架的新界面 Krokiet，它拥有更现代化的界面和持续更新的功能。

一、核心功能一览

Krokiet / Czkawka 集成了多种实用工具，所有操作均在本地完成，不联网、不收集任何用户信息：

工具类别 具体功能
查找重复 基于文件名、大小或哈希值查找重复文件。
清理空目录/文件 查找并列出所有空文件夹或大小为 0 的文件。
管理大文件 查找指定位置下体积最大的 N 个文件。
临时文件 识别并列出系统中的临时文件。
相似文件 相似图片：查找分辨率不同、带有水印的视觉相似图片。 相似视频：查找内容视觉上相似的视频。 相同音乐：通过标签或内容比对查找相似音乐。
文件完整性 无效符号链接：指向不存在目标文件的链接。 损坏文件：查找无效或损坏的文件。 坏扩展名：列出内容与扩展名不符的文件。
元数据处理 Exif 清除器：移除图片等文件中的 Exif 元数据。 视频优化器：裁剪静态部分并转换为更高效的格式。
命名检查 查找包含特殊字符等不规范命名的文件。

二、部署与安装

方式一：直接下载安装包 (推荐)

这是最简单的安装方式，适合所有用户。

1. 访问发布页面
前往项目的 GitHub Releases 页面 或 Nightly 构建页面（包含每日最新构建）。

2. 下载对应文件

操作系统 推荐下载文件 说明
Windows krokiet_*.exe 或 .msi 标准的 Windows 安装程序。也有便携版 (.zip) 可供选择。
macOS Krokiet_*.dmg 标准 macOS 磁盘映像，拖拽安装即可。
Linux .deb (Debian/Ubuntu) 或 .AppImage (通用) .deb 使用包管理器安装；.AppImage 下载后添加执行权限即可运行，无需安装。

3. 安装与运行

  • Windows: 双击 .exe 或 .msi 文件，跟随向导完成安装，然后从开始菜单启动 Krokiet。
  • macOS: 双击 .dmg，将 Krokiet.app 拖入 Applications 文件夹，然后从启动台启动。
  • Linux (AppImage): 在终端中运行 chmod +x Krokiet_*.AppImage 赋予执行权限，然后直接 ./Krokiet_*.AppImage 运行。

方式二：通过包管理器安装 (部分平台)

熟悉命令行工具的用户可以通过包管理器安装。

  • Flathub (Linux): 如果已配置 Flatpak，可搜索 org.qarmin.czkawka 并安装。
  • Homebrew (macOS): brew install czkawka (注意：可能仍为旧版 GTK 界面，请选择带有 krokiet 的选项)。

方式三：从源码编译 (面向开发者)

如果你希望使用最新代码或进行二次开发，可以编译源码。编译需要安装 Rust、Cargo 以及相应的系统依赖（可参考 Tauri 或 Slint 开发文档）。

2. 编译运行 Krokiet (推荐)

三、快速使用指南

3.1 首次使用步骤

  1. 选择扫描目录：启动 Krokiet 后，在界面中添加你想要扫描的文件夹路径。
  2. 选择工具：点击左侧边栏的相应图标，选择你要执行的任务（如“查找重复文件”）。
  3. 配置选项：根据需要调整工具的特定参数（例如，重复文件可设置按名称或哈希比较）。
  4. 开始扫描：点击“开始”或“扫描”按钮。得益于多线程和高效算法，扫描速度非常快。
  5. 查看与操作：扫描完成后，列表会显示结果。你可以勾选要处理的文件，然后执行“删除”、“移动”等操作。

3.2 高级特性与技巧

  • 缓存支持：第一次扫描后会自动建立缓存，第二次及后续扫描相同目录时会显著加快。
  • 便携使用：Windows 和 Linux 的 .zip / .AppImage 版本是便携的，可以放在 U 盘等移动设备中，无需安装即可运行。
  • 命令行操作：如果你熟悉终端，可以使用 czkawka_cli 进行自动化扫描和清理，便于编写脚本。使用 czkawka_cli --help 查看所有命令。

四、部署清单

步骤 操作 关键点
1. 选择版本 决定使用 Krokiet (新，推荐) 不再使用旧的 Czkawka GTK GUI
2. 获取应用 从 Releases 下载对应平台安装包 选择 .exe、.dmg、.deb 或 .AppImage
3. 安装 运行安装程序或解压便携版 注意系统安全提示，允许运行
4. (可选) 编译源码 安装 Rust 环境，使用 cargo run --bin krokiet 适合需要自定义功能的用户
5. 运行与配置 添加扫描路径，选择功能工具 理解各工具用途，谨慎处理扫描结果
6. 执行清理 预览结果，勾选文件，执行操作 清理前二次确认，避免误删重要文件

总结

通过本教程，你应该已经成功安装并可以开始使用 Krokiet (或 Czkawka) 这款强大的磁盘清理工具了。它的核心优势在于完全免费、速度极快、功能全面、隐私安全（无联网），是维护磁盘健康的得力助手。

后续使用建议：

  • 定期使用“重复文件”和“大文件”工具，保持磁盘清洁。
  • 在处理文件前，建议先在“设置”中开启“将文件移至回收站”而非直接删除，以提供安全保障。
  • 如果你有兴趣，可以为项目贡献翻译、报告问题或编写使用教程，帮助更多人使用它。
