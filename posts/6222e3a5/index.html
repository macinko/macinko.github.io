开源电子衣柜 Wardrobe：拍照自动识别衣服，还能预览上身效果

更新于2026-09-05|toolssoftware
|总字数:354|阅读时长:1分钟|浏览量:

wardrobe

一个开源工具，专门用来整理衣服。它用上了 OpenAI 的图像能力，拍张照就能自动识别衣服、抠出单品图，还能生成你穿上身的模拟效果图。

基于 GPT-Image 技术，把衣服照片自动提取、分类、生成穿搭预览，数据全存在本地。

Github地址

https://github.com/tandpfun/wardrobe

能干什么

  • 自动识别照片里的每件衣服，用 OpenAI Responses API 做检测
  • 抠出干净的单品图，背景去掉，只剩衣服本身
  • 可选生成”上身效果”——把你的脸和身材合成进去，看搭配效果
  • 支持拖拽上传、粘贴图片、手动编辑、重新生成、审核确认
  • 所有原始图、生成图、任务记录、JSON 数据库都存本地 data/ 目录，不上传云端

怎么用

然后浏览器开 localhost:5173 就行。没填 API key 和参考图的话，导入功能锁着，用不了。

两个自动化技能（给 AI 工具用的）

项目自带 Codex 技能脚本，适合让 AI 代理批量操作：

  • $import-clothes：指定文件夹，自动提取、生成模特图、入库
  • $generate-outfits：从已有衣服里挑搭配，生成成套上身效果图
