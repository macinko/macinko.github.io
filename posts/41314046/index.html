seedance-2.0 skill 模块化的AI代理技能包，专为指导 Seedance

更新于2026-09-05|aivideo
|总字数:1.4k|阅读时长:4分钟|浏览量:

这份详细的部署教程将指引您安装和运行 seedance-2.0 skill——一个模块化的AI代理技能包，专为指导 Seedance 2.0 视频生成而设计。它的核心工作哲学是 “指导模型，而非微观管理画面” ，通过将电影级导演思维编码为提示词，生成更具意图和连贯性的视频内容。

该技能包提供了一个可审计、可复用的操作系统，用于处理 Seedance 2.0 的视频生成工作。它会引导AI助理进行创意访谈、撰写结构化的导演提示、处理参考资产、进行安全改写，并诊断生成失败的问题。整个流程旨在将模糊的想法转化为专业、可重复的生产流程。

整个部署流程相对直接：克隆仓库，将其安装到您的AI客户端，然后根据需求加载相应的技能模块。

📥 安装步骤

第一步：获取技能文件

首先，将仓库克隆到您的本地机器。

如果没有 git，也可以使用 GitHub 页面上的 Code → Download ZIP 按钮下载并解压。

第二步：安装到您的AI客户端

项目提供了一个安装脚本 install_codex_skill.py，可以将技能复制到任何支持技能目录的客户端中。

  • 通用安装：使用 --dest 参数指定您客户端扫描技能的目录。

  • 常用技能目录：该技能支持多种AI客户端。下表列出了一些常见的安装目标，具体请参考您客户端的文档。

客户端 常见安装目录
Claude Code ~/.claude/skills/ (个人) 或 .claude/skills/ (项目)
Codex .agents/skills/ 或 ~/.codex/skills/
Google Antigravity .agents/skills/ (工作区) 或 ~/.gemini/config/skills/
OpenClaw skills/ (工作区) 或 ~/.openclaw/skills/ (可通过 clawhub 安装)
Cursor / Windsurf / Trae .cursor/skills/、.windsurf/skills/ 或 .trae/skills/
Hermes Agent ~/.hermes/skills/
Gemini CLI .gemini/skills/
GitHub Copilot .github/skills/
Qwen Code .qwen/skills/ 或 ~/.qwen/skills/

提示：许多客户端共享 .agents/skills/ 目录（如 Codex、Antigravity、OpenCode、Amp、Goose），您可以将其安装在共享位置，一次安装，多处使用。

🎬 如何使用 (核心工作流)

安装完成后，您可以通过自然语言或特定命令来触发技能。其核心是 “先读后写” 的原则。

1. 从模糊想法开始 (创意访谈)

当您只有一个模糊的概念时，AI 会引导您进行简短的创意访谈，明确核心意图。

  • 用户：”我想做一个关于未来城市中孤独机器人的视频。”
  • AI 加载：seedance-interview
  • 输出：一份聚焦的创意简报和后续的提示词路径。

2. 构建一个连贯的故事 (序列生成)

对于需要多个连续镜头的长故事，使用序列工作流。

  • 用户：”这是一个三幕的短篇故事，关于一个宇航员发现外星生命。”
  • AI 加载：seedance-sequence
  • 输出：完整的故事架构、连续性手册、镜头序列图，并生成第一个镜头的“合同”和提示词。

3. 生成单个场景的提示词 (直接提示)

当您清楚想要的场景时，直接生成一个生产就绪的提示词。

  • 用户：”我需要一个镜头：一个穿着红色外套的女人，在雨中的东京街头，看着一个发光的广告牌。”
  • AI 加载：seedance-prompt
  • 输出：一个结构化的、面向 Seedance 2.0 的提示词。

4. 延续已有镜头 (连续性生成)

在生成了一个镜头后，想要拍摄它的续集。

  • 用户：”这是上一镜的最终画面 [描述或提供画面]。现在，她转身走进了一条小巷。”
  • AI 加载：seedance-continuation
  • 输出：一个基于上一镜头真实结尾的、衔接自然的续集提示词。

5. 应用导演思维 (导演阅读)

这是该技能的核心差异点。在编写叙事提示词前，进行强制性的“导演阅读”，确保每个镜头服务于一个统一意图。

  • AI 加载：directors-read
  • 作用：分析场景的功能、转折、视角、权力转移等，然后将这些分析转化为具体的镜头、灯光、表演和声音指令，而非堆砌“史诗级”、“电影感”等空洞形容词。

🛠️ 验证与质量保证

项目包含完整的验证工具链，确保技能包本身的质量。

  • 运行离线检查：在发布前，确保技能包结构正确、引用最新。

  • 运行模型评估：使用模型运行评估工具，测试技能的实际效果。

💡 关键提示

  • 平台状态：Seedance 平台变化很快。在做出关于 API、定价、模型名称等事实性声明前，务必加载并检查 references/api-status.md 文件中的 last_verified 日期。
  • 语言支持：该技能为中文、日文、韩文、西班牙文和俄文提供了完整的阅读路径和词汇表。例如，中文用户可从 中文指南、seedance-vocab-zh 和 seedance-examples-zh 开始。
  • 专业制作：该技能包支持专业电影和商业制作团队的工作流程，能生成导演、摄影师、制片人、剪辑师等角色所需的专业文档。
