OpenDisplay 是一款免费、开源的 Mac 屏幕扩展工具

更新于2026-09-05|osmacos
|总字数:1.6k|阅读时长:5分钟|浏览量:

OpenDisplay 详细部署教程

OpenDisplay 是一款免费、开源的 Mac 屏幕扩展工具，能让你将闲置的 iPhone、iPad 甚至另一台 Mac 变成真正的第二显示器。它支持 USB 或 WiFi 连接，无需同 Apple ID，也无需订阅或硬件转接器。

本教程将指导你完成从下载到连接的全过程。

1. 了解 OpenDisplay

在使用前，先了解它的核心优势：

  • 真正扩展桌面：macOS 会将设备识别为一块独立显示器，你可以自由拖拽窗口、调整排列，而不是简单的镜像。
  • 连接方式灵活：支持低延迟的 USB 连接，也支持方便的 WiFi 连接（通过 Bonjour 自动发现）。
  • 触控与交互：在 iPad/iPhone 上支持点按、拖拽和双指滚动，就像使用触控板一样控制 Mac。
  • 高分辨率与旋转：支持 Retina 清晰度，并且设备旋转时，显示器方向会自动适配。
  • 隐私安全：所有数据仅在本地设备间直接传输，不经过任何第三方服务器。

2. 准备工作

2.1 确认系统要求

  • Mac (发送端)：需要 macOS 14 或更新版本。如果你的 Mac 是 Apple M 系列芯片，效果更佳。
  • iPhone 或 iPad (接收端)：需要 iOS/iPadOS 16.4 或更新版本。这意味着 iPhone 8 及更新机型、iPad Pro (第一代) 及更新机型均可支持。
  • 另一台 Mac (作为接收端)：需要 macOS 12 Monterey 或更新版本，并可选择安装专用的 OpenDisplayReceiver 应用。

2.2 准备数据线（如使用 USB 模式）

请使用一根支持数据传输的 USB-C 或 Lightning 线缆。仅支持充电的线缆无法工作。USB 2.0 标准的线缆带宽已足够。

3. 安装步骤

你需要在 Mac 端 和 iOS 设备端 分别安装对应的应用。

3.1 在 Mac 上安装发送端应用

  1. 访问 OpenDisplay 的 GitHub Releases 页面，下载 OpenDisplay.dmg 文件。
  2. 打开下载的 .dmg 文件，将 OpenDisplay.app 拖拽到 Applications (应用程序) 文件夹中。
  3. 该应用经过 Apple 公证和签名，可以正常打开，不会有 Gatekeeper 警告。

3.2 在 iPhone 或 iPad 上安装接收端应用

提供两种安装方式，推荐使用 TestFlight：

  • 方式一：使用 TestFlight (推荐)：在 iOS 设备上安装 TestFlight 应用，然后通过 此 TestFlight 公开链接 加入 Beta 测试并安装 OpenDisplay。
  • 方式二：从 App Store 下载：OpenDisplay 的 iOS 客户端现已在部分地区的 App Store 上架。你可以直接搜索 “OpenDisplay” 下载。如果未找到，请使用 TestFlight 方式。

3.3 在另一台 Mac 上安装接收端应用（可选）

如果你想将一台旧 Mac 用作显示器，请在它上面下载 OpenDisplayReceiver.dmg（在同一个 Releases 页面），同样拖拽到 Applications 文件夹安装。

4. 连接与使用

4.1 授权必要权限

首次运行并连接时，macOS 和 iOS 会要求你授予关键权限。这些权限是功能正常的前提。

平台 权限 用途 若未授权导致的问题
Mac 屏幕录制 捕捉屏幕内容进行编码传输 iOS 设备上显示黑屏
Mac 辅助功能 将你的触摸操作模拟为鼠标事件 触摸点击和滚动无效
Mac 本地网络 (仅WiFi) 通过 Bonjour 发现网络上的 iOS 设备 Mac 的连接菜单中无法显示设备
iOS 本地网络 (仅WiFi) 在网络上广播自身，让 Mac 可以发现它 Mac 无法通过 WiFi 发现此设备

如何授权：

  • Mac 端权限在 系统设置 > 隐私与安全性 中授予。
  • iOS 端权限在 设置 > 隐私与安全性 > 本地网络 中授予。

权限授权通常在第一次使用时会自动弹出提示，如果错过了，可以按上述路径手动开启。

4.2 通过 USB 连接（推荐，延迟更低）

  1. 使用支持数据的线缆将你的 iPhone/iPad 连接到 Mac。
  2. 在 iOS 设备上，保持 OpenDisplay 应用在前台打开。它会开始监听端口 9000。
  3. 在 Mac 上，打开 OpenDisplay.app。它会自动通过 macOS 内置的 usbmuxd 服务检测到连接的设备。
  4. 在 Mac 应用的连接菜单中，选择你的设备（连接方式会显示为 “USB” 或 “Cable”）。
  5. 连接成功后，你的 iOS 设备屏幕会显示 Mac 桌面的一部分，成为扩展显示器。

4.3 通过 WiFi 连接（方便，无需线缆）

  1. 确保 Mac 和 iOS 设备连接在同一个 WiFi 网络下，并且都已授予 “本地网络” 权限。
  2. 在 iOS 设备上，保持 OpenDisplay 应用在前台打开。
  3. 在 Mac 应用 OpenDisplay.app 的 Connection (连接) 菜单中，应该会自动出现你的设备名称（例如 “iPhone (WiFi)”），点击即可连接。
  4. 提示：如果连接菜单中没有显示设备，请检查两台设备的 “本地网络” 权限是否都已开启。

5. 使用技巧与故障排查

  • 如何调整显示器排列：连接后，前往 macOS 的 系统设置 > 显示器，你可以像排列真实显示器一样，拖拽 OpenDisplay 虚拟显示器的位置。
  • 旋转屏幕：直接旋转你的 iPhone/iPad，OpenDisplay 会自动感知并将显示器调整为竖屏或横屏模式。
  • 关于紫色屏幕录制图标：连接后 macOS 菜单栏出现紫色图标是正常的隐私提示，表明有应用正在录制屏幕。所有同类工具（如 OBS、Zoom）都会有此图标，这是系统机制，无法隐藏。
  • 连接不畅或未发现设备：
    • 优先尝试 USB 模式，它更稳定且不受网络权限影响。
    • 若使用 WiFi，务必检查 Mac 和 iOS 设备均已开启 “本地网络” 权限。
    • 确保 iOS 设备的 OpenDisplay 应用处于前台。
  • 触摸功能无效：请检查 Mac 的 “辅助功能” 权限是否已授予 OpenDisplay。

总结

通过以上步骤，你已完成 OpenDisplay 的部署。它是一款强大的开源工具，让你能充分利用闲置的 iOS 设备或旧 Mac 作为扩展屏幕，提升工作效率。它最大的价值在于提供了一个免费、灵活且注重隐私的 Sidecar 替代方案，适合想要扩展工作区但预算有限的开发者和普通用户。

如需查看更详尽的故障排除指南或技术文档，可以访问项目的 GitHub 仓库。
