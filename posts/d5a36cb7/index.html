KOReader 功能强大、高度可定制的开源电子书阅读器

更新于2026-09-05|toolssoftware
|总字数:1.2k|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您在不同设备上安装和使用 KOReader——一个功能强大、高度可定制的开源电子书阅读器。它针对电子墨水屏优化，支持PDF、EPUB、MOBI、DJVU等众多格式，并提供丰富的排版和插件功能。

KOReader 的核心优势在于其跨平台兼容性和高度可定制性。无论您使用 Kindle、Kobo、Android 设备，还是 Linux 电脑，都能获得一致的、优化的阅读体验。它通常与设备原生系统“共存”运行，不会干扰原生固件，您可以放心安装。

📥 各平台安装指南

KOReader 的安装方式因设备而异，主要分为通过包管理器安装和手动复制文件两类。

Kindle 设备

Kindle 的安装需要先完成设备越狱（Jailbreak）。

  • 新方法 (Kindle Package Manager - 推荐): 如果你的 Kindle 使用较新的越狱方法（如 2026 年 6 月后的 WinterBreak 等），则内置了 KPM。开启 Wi-Fi，在 Kindle 搜索栏依次输入以下命令即可自动安装：

    安装后，在 Kindle 的“图书馆”中会出现一个新的“书籍”（启动器），点击它即可打开 KOReader。

  • 传统方法 (手动复制): 对于较旧的越狱版本，您需要手动操作。

    1. 下载: 从 KOReader 发布页 下载对应 Kindle 的安装包（例如 koreader-kindlehf-*.zip）。对于固件版本 5.16.3 及以上的 Kindle，应选用 kindlehf 版本。
    2. 解压与复制: 解压 ZIP 文件，将其中的 koreader 和 extensions 两个文件夹复制到 Kindle 的 USB 根目录（即存储盘的根目录，与 documents 文件夹同级）。
    3. 启动: 安全弹出 Kindle。在 Kindle 首页，您会看到一个新出现的“书籍”图标，点击即可启动 KOReader。

Kobo 设备

Kobo 的安装相对简单，无需越狱。

  • 自动脚本 (推荐): 对于大多数新手用户，推荐使用社区提供的自动化安装脚本（可从官方论坛获取），它能自动处理安装和后续配置，包括为固件 4.17+ 的设备添加必要的配置项。

  • 手动安装: 下载 koreader-kobo-*.zip 文件，将其中的 koreader 文件夹解压到 Kobo 的 .adds 目录（这是一个隐藏文件夹）。如果设备固件版本为 4.17 或更高，您需要在 /.kobo/Kobo/Kobo eReader.conf 配置文件中添加以下内容，以防止系统扫描 KOReader 目录：

  • 启动器: 安装后，您可以通过 KFMon、NickelMenu 或 KSM 等启动器打开 KOReader。对于绝大多数用户，NickelMenu + KFMon 的组合是更现代、侵入性更低的选择。

Android 设备 (手机/平板)

Android 平台的安装最为直接，与安装普通应用无异。

  • 直接从 F-Droid 或 Google Play 商店 搜索“KOReader”并安装。
  • 或从 GitHub Releases 页面 下载最新的 .apk 文件，并在设备上手动安装。

Linux 桌面系统

Linux 用户有多种选择。

  • Flatpak (推荐): 可以从 Flathub 安装，命令为 flatpak install rocks.koreader.KOReader。

  • AppImage: 从 Releases 页面下载 .AppImage 文件，赋予执行权限后直接运行。

其他设备

  • PocketBook: 可直接安装 .app 文件。
  • reMarkable: 提供专门的安装脚本。
  • 开发环境 (模拟器): 开发者可通过 Git 克隆源码，使用 make 命令构建，并在 Linux/macOS 上运行模拟器进行测试。

🎯 初次启动与核心配置

  • 快速上手: 强烈建议首次启动后，阅读应用自带的“快速上手”图文说明（通常位于 resources/quickstart/），它清晰地展示了默认的触控分区和操作逻辑。
  • 基础设置: 您可以在设置中调整字体、行距、边距、屏幕方向等。KOReader 允许您为每个文档独立保存设置。
  • 在线更新: 在设置中开启“在线更新”功能，以后即可在应用内直接升级，无需手动下载安装包。

💡 实用提示

  • 与Calibre集成: KOReader 支持通过 OPDS 协议无线浏览和下载 Calibre 书库中的书籍，也可以通过 USB 传输文件。
  • 阅读进度同步: 可以配置 KOSync 服务器，在多个 KOReader 设备间同步阅读进度。
  • 故障排查: 如果遇到问题，通常可以尝试删除配置文件目录（~/.config/koreader/）来重置应用。
