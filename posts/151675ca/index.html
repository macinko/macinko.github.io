免费开源远程桌面，支持跨平台/私有化部署：BilldDesk

更新于2026-08-22|toolssoftware
|总字数:440|阅读时长:1分钟|浏览量:

之前给大家分享过：白嫖 2 年授权码！速领！「AnyViewer」远程桌面软件，不少小伙伴表示速度慢，不过毕竟免费白嫖，当做备用也好。

今天推荐这个「BilldDesk」免费开源远程桌面，支持跨平台，包括有：Win、macOS、Linux、安卓、网页，以及支持私有化部署。

根据介绍基于 Vue3 + WebRTC + Nodejs + Electron，功能方面实现了类似 ToDesk、向日葵等远程桌面的功能。

使用也很简单，就是输入设备码和密码即可远程控制设备，支持选择码率、帧率、分辨率、视频内容、音频内容。

*功能介绍*

  • web网页 控制 电脑端
  • web网页 控制 安卓端
  • web网页 控制 web网页（仅观看）
  • 电脑端 控制 电脑端
  • 电脑端 控制 安卓端
  • 电脑端 控制 web网页（仅观看）
  • 多台设备同时远程一台设备
  • 一台设备同时远程多台设备
  • 多屏操作
  • 连接鉴权
  • 按键组合键
  • 支持 macOS 系统
  • 支持 Windows 系统
  • 支持 Linux 系统（未实际测试）
  • 文件传输
  • 开机自启
  • 锁屏保活
  • 屏幕墙
  • 安卓端（Flutter）
  • 支持私有化部署
  • 更多功能还在开发中..

总结

体验上比商业的远程软件要差点，优点就是完全免费并且开源支持私有化部署，另外这个远程桌面项目功能还在继续开发中，感兴趣的可以关注下作者的项目，以及更多介绍可以看作者的 B 站视频介绍。
