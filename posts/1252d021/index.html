DeepSeek‑V4‑Flash 接入 Codex 保姆级教程

更新于2026-09-05|aiagentdeepseek
|总字数:653|阅读时长:2分钟|浏览量:

创建 API Key → 一键接入 → 验证成功 → 换回 GPT

本教程手把手教你把 DeepSeek‑V4‑Flash 接入 Codex，整个过程简单，新手也能轻松搞定。

同时还会说明使用 DeepSeek 后，如何切换回 GPT，满足不同场景需求。

开始前，先确认3件事

在接入 DeepSeek‑V4‑Flash 到 Codex 前，请确保满足以下3个条件：

\1. 先安装好 Codex，并至少打开过一次

\2. 准备好 DeepSeek 平台账号

\3. 本文以 Windows PowerShell 为例

💡小提示：为什么要先打开一次 Codex？

因为脚本会读取本地 .codex 配置目录。

准备好后，就可以开始正式接入。

一、创建 API Key📷

这一步很重要，后面配置会用到。

\1. 进入 DeepSeek 平台的 API keys 页面

\2. 点击右上角「创建 API key」

\3. 名称可以直接写 Codex

\4. 创建后立即复制保存

⚠️ API key 只在创建时可见，记得马上复制妥善保存。

二、运行一键配置脚本📷

打开普通 PowerShell，粘贴下面这条命令并回车。

💡脚本会自动帮你写入配置，不需要手改文件。

三、选择1，并输入 API Key

脚本运行后，先在菜单里输入 1，代表接入 deepseek‑v4‑flash。

首次配置时，再粘贴你的 API key（以 sk‑ 开头）。

四、这样就算接入成功

配置完成后，重点看2个地方：

\1. 左下角出现 deepseek

\2. 模型位置显示「自定义」

注意：这里通常不会直接显示具体模型名，显示“自定义”属于正常。

五、为什么显示“自定义”？

这是因为 Codex 读取本地自定义配置，界面显示“自定义”，底层实际调用的是 DeepSeek‑V4‑Flash。

• 界面层看到：自定义

• 底层实际调用：DeepSeek‑V4‑Flash

只要可以正常对话返回结果，就代表接入成功。

六、如何换回 GPT 模型

想移除DeepSeek、换回GPT，执行同一套脚本命令：

\1. 在菜单里输入 3

\2. 再次输入 y 确认

就会移除deepseek设置，恢复默认Codex配置。

需要重新接回DeepSeek时，再执行同一条命令即可。

踩坑总结

\1. 必须先打开一次Codex，否则脚本找不到配置文件夹报错

\2. API Key 以 sk‑ 开头，不要复制错误

\3. 脚本跑完重启Codex配置才生效

\4. 使用普通PowerShell，不要管理员模式

\5. 显示「自定义」不是故障，是正常现象
