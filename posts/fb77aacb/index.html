OpenAI Codex CLI 是终端 AI 编程助手：效率利器，用了就回不去

更新于2026-09-13|aiagent
|总字数:689|阅读时长:2分钟|浏览量:

OpenAI Codex CLI 是一款终端 AI 编程助手，它和你之前部署的项目性质不同，不是需要搭建后端服务的自托管软件，而是安装在本地电脑上的命令行工具。

因此，部署教程其实是一份安装与配置指南。目前https://github.com/openai/codex这个仓库无法直接访问，但根据社区和官方渠道的信息，可以整理出标准流程。

📋 准备工作

项目 要求 说明
操作系统 macOS 12+, Linux (Ubuntu 20.04+, Debian 10+), 或 Windows 11 (推荐 WSL2) 这是目前官方支持的主流环境。
运行时 Node.js 18 或更高版本 通过 npm 安装的必备环境。可用 node --version 检查。
账号 ChatGPT Plus/Pro/Team/Enterprise 订阅 或 OpenAI API Key 免费的 ChatGPT 账号可能没有 Codex 访问权限。

🔐 认证与登录

首次运行 codex 命令会引导你登录，推荐使用 ChatGPT 账号登录，这会直接使用你订阅中的额度。

备用方案：你也可以配置 API Key 使用，但通常需要额外配置 ~/.codex/config.toml 文件并设置环境变量 OPENAI_API_KEY。

💡 基础使用与配置

  1. 启动会话：在你的项目文件夹中运行 codex，就可以用自然语言和它交流了，比如“帮我解释一下 src/auth/login.ts 的逻辑”。
  2. 权限模式：Codex 默认是 workspace-write 模式，只允许在工作目录内读写。你可以根据需要调整为 read-only 或 danger-full-access，建议保持默认。
  3. 切换模型：在会话中输入 /model gpt-5-codex 即可切换模型。

⚠️ 重要提醒

  • 本文介绍的是 Codex CLI，一个本地终端工具，和 Codex 的网页版或 IDE 插件是不同产品。
  • 由于原 GitHub 仓库无法访问，建议以 OpenAI 官方文档（chatgpt.com/codex）为最终参考。
