iPolloWork 企业级智能体工作台部署教程

iPolloWork 是一个企业级、本地优先的智能体（Agent）工作台，为人类和AI智能体团队提供统一的工作空间。它集成了 Codex Harness、DeepSeek Harness 和 OpenCode 等多个智能体引擎，并统一了插件、技能、项目、任务和可编辑产出物（代码、文档、演示文稿、设计稿、视频）的管理。

本教程将指导您完成 iPolloWork 的安装、配置与运行。

1. 项目概览与核心定位

iPolloWork 并非要取代某个单一的编程智能体，而是作为 统一的协作层，连接不同的智能体运行时，解决在多工具间切换的碎片化问题。

核心理念

  • 统一工作台 (One Workbench)：在同一界面中使用 Codex、DeepSeek Harness、OpenCode 等不同引擎，无需为每个引擎重建项目体验。
  • 统一扩展系统 (One Extension System)：插件、技能、命令、服务等只需安装一次，并可选择性地绑定到特定引擎。
  • 项目级人机协作 (Project-Native Collaboration)：在共享的项目视图中管理任务、日程、执行状态和结果，而非分散在孤立对话中。
  • 可编辑的产出循环 (Editable Production Loop)：从代码到文档、网站、演示文稿、设计稿和视频，所有产出物在生成后仍保持可编辑状态。

组件兼容性

  • 默认引擎：OpenCode 是默认的本地执行运行时。
  • 可选引擎：DeepSeek Harness (DSH) 作为可选的同级运行时和子智能体委派目标。
  • Codex 集成：通过 ipollowork-ui-mcp 控制面连接，而非原生引擎适配器。

2. 环境准备

2.1 下载官方安装包 (推荐)

官方安装包发布在 GitHub Releases 页面。请根据您的操作系统和CPU架构选择对应的文件：

操作系统 CPU架构 安装包文件
macOS Apple Silicon (M系列) ipollowork-mac-arm64-<版本>.dmg
macOS Intel ipollowork-mac-x64-<版本>.dmg
Windows Intel/AMD 64-bit ipollowork-win-x64-<版本>.exe
Windows ARM64 ipollowork-win-arm64-<版本>.exe
Linux Intel/AMD 64-bit ipollowork-linux-x64-<版本>.AppImage
Linux ARM64 ipollowork-linux-arm64-<版本>.AppImage

注意：macOS 的 .zip 和 Linux 的 .tar.gz 是便携式/更新工件，大多数用户应选择 .dmg、.exe 或 .AppImage。

3. 从源码构建与开发 (可选)

如果您是开发者，希望从源码运行或打包 iPolloWork，请按以下步骤操作。

3.1 基础依赖

  • Git
  • Node.js：版本 22 或更新
  • pnpm：版本 11，通过 Corepack 启用 (corepack enable)
  • Bun：版本 1.3.10 或更新，用于构建本地 Orchestrator 边车
  • 系统编译环境：
    • macOS：Xcode Command Line Tools (xcode-select --install)
    • Windows：Visual Studio 2022 Build Tools，包含“Desktop development with C++”和 Windows SDK
    • Linux：标准的 Electron 构建环境（C/C++ 工具链、Python 3、pkg-config 等）

6. 重要注意事项

6.1 许可证限制

iPolloWork 使用 iPolloWork Source Available License 1.0，不是 OSI 批准的开源许可证。

  • 免费使用：仅限于个人自用，或少于3名用户的小规模内部使用。
  • 需要书面授权：3名及以上用户使用、任何形式的销售、转售、SaaS、托管、白标分发或面向客户的使用，均需事先获得书面授权。

6.2 架构边界

  • Codex 兼容性当前通过 MCP 控制面实现，而非原生引擎适配。
  • OpenCode 和 DeepSeek Harness 保持独立，iPolloWork 不会复刻或改写它们。
  • 所有智能体执行、任务状态和流式传输在共享引擎边界处被标准化，引擎原生行为保留在其适配器内部。

7. 常见问题与排查

问题 可能原因与解决方案
安装包无法打开 (macOS) 系统提示“无法验证开发者”。请前往 系统设置 → 隐私与安全性，在“安全性”部分点击“仍要打开”。
Windows SmartScreen 阻止安装 点击“更多信息”，然后选择“仍要运行”。这是未签名应用的正常提示。
./ipollowork 命令未找到 确保您在克隆的仓库根目录下。首次运行前需执行 chmod +x ipollowork 赋予执行权限。
pnpm install 失败 网络问题或 Node.js 版本不兼容。请检查 Node 版本 (>=22)，并尝试配置国内镜像源。
开发模式下无法启动 OpenCode OpenCode 边车在首次构建时下载。请检查网络连接，并确保 Bun 已正确安装。
如何更新版本？ 下载最新 Releases，或从源码 git pull 最新代码后重新运行 ./ipollowork package。

通过以上步骤，您已经成功部署了 iPolloWork。作为一款面向未来的智能体协作平台，它能帮助您和您的团队统一管理多智能体工作流，显著提升复杂项目的协作效率。
