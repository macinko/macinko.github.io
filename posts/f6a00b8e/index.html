Yazi：超快终端文件管理器

更新于2026-09-05|toolssoftware
|总字数:708|阅读时长:2分钟|浏览量:

官方仓库：https://github.com/sxyazi/yazi
官方文档：https://yazi-rs.github.io

Yazi（中文意思是“鸭子”）是一款用 Rust 编写的终端文件管理器，基于非阻塞异步 I/O 构建。它以极高的速度、流畅的体验和高度可定制性著称，目前处于公开 Beta 阶段，已经可以作为日常文件管理工具使用。

核心亮点

  • 🚀 全异步架构：所有 I/O 操作都是异步的，CPU 任务多线程处理，充分利用硬件资源
  • 💪 强大的异步任务调度：实时进度显示、任务取消、优先级管理
  • 🖼️ 内置多协议图片预览：支持 Kitty、iTerm2、WezTerm、Sixel、Windows Terminal 等，几乎覆盖所有主流终端
  • 🌟 内置代码高亮 + 图片解码：结合预加载机制，大幅提升预览速度
  • 🔌 并发插件系统：支持 UI 插件、功能插件、自定义预览器等（Lua 编写）
  • ☁️ 虚拟文件系统：支持远程文件管理、自定义 VFS
  • 📦 内置包管理器：一键安装插件和主题
  • 🧰 深度集成 ripgrep、fd、fzf、zoxide
  • 多标签页、跨目录选择、可滚动预览（视频、PDF、压缩包、代码等）
  • 批量重命名、解压、可视模式、回收站、Git 集成、挂载管理等

主要功能一览

功能 说明
异步 I/O 界面永不卡顿，即使处理大量文件
图片/视频预览 几乎所有终端原生支持
代码高亮 预览代码文件时直接高亮
多标签页 类似浏览器的多标签管理
插件系统 用 Lua 扩展几乎所有功能
主题系统 高度可定制界面
批量操作 批量重命名、创建、解压
工具集成 fzf、zoxide、ripgrep、fd 无缝配合
Git 状态显示 通过插件显示文件 Git 状态
鼠标支持 支持鼠标操作和拖放

项目状态

  • 目前是公开 Beta，已经可以稳定日常使用
  • 仍在快速开发中，可能会有破坏性更新
  • 社区活跃（Discord + Telegram）

官方文档：

  • 安装与使用：https://yazi-rs.github.io/docs/installation
  • 功能介绍：https://yazi-rs.github.io/features

总结：Yazi 是目前终端文件管理器中性能最强、体验最流畅的选择之一。如果你喜欢在终端工作，或者想要一个比传统 ranger、lf、nnn 更快、更现代的工具，Yazi 非常值得尝试。
