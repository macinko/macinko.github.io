YouTube Skills for AI Agents 详细部署教程

项目概述

YouTube Skills for AI Agents 是一个专为 AI 代理设计的技能包，让你的 AI 代理能够即时访问 YouTube 字幕提取、视频搜索、频道数据和播放列表提取功能。

核心优势：

  • 无需 yt-dlp：YouTube 会屏蔽所有主要云 IP，而此方案通过 API 调用绕过此限制
  • 无需无头浏览器：不需要运行 Chrome/Firefox 等浏览器
  • 无需二进制文件：纯 API 调用，可在任何环境运行
  • 基于 TranscriptAPI：由 YouTubeToTranscript.com 背后的同一后端提供支持

兼容的 AI 代理：

  • 🦞 OpenClaw (ClawdBot/Moltbot)
  • Hermes Agent
  • Claude Code
  • Cursor
  • Antigravity
  • Cline
  • Codex
  • 其他支持 Agent Skills 格式的代理

免费额度：注册即送 100 credits，无需信用卡。

常见问题排查

症状 可能原因 解决方案
401 Unauthorized API Key 缺失、输入错误或未加载到环境 确认 TRANSCRIPT_API_KEY 已在代理运行的 shell 中设置，且 Key 以 sk_ 开头
402 Payment Required 账户 credits 用尽 在 transcriptapi.com/billing 检查余额
403 带 Cloudflare 代码 1010 请求未发送 User-Agent 头 发送你的代理名称作为 User-Agent，例如 HermesAgent/0.11.0
404 Not Found 视频没有字幕、非公开或 ID 错误 验证 URL 在浏览器中打开且播放器显示字幕
408 Request Timeout 视频上游临时压力 临时性问题：等待几秒后重试一次
422 Validation Error 参数格式错误，如错误的频道或播放列表引用 频道接受 @handle、频道 URL 或 UC ID；播放列表接受 PL、UU、LL、FL 和 OL 前缀
429 Too Many Requests 达到速率限制 等待并遵守 Retry-After 头

其他注意事项

  • Key 已保存但代理看不到：Shell 配置文件按 shell 类型加载，检查”Key 保存位置”表格，确保文件匹配代理实际运行的 shell。保存 Key 后重启代理可解决大多数情况
  • 直播和首播：字幕在直播结束且字幕处理完成后才可用，直播期间不可用
  • 字幕语言不符合预期：许多视频仅携带原始语言的字幕。使用首选语言参数请求字幕，或让代理翻译结果

常见问题 FAQ

如何获取 YouTube 字幕？

安装 youtube-full（或 transcript），然后询问代理：

“获取这个视频的字幕：https://youtube.com/watch?v=VIDEO_ID“

代理会获取带时间戳的完整字幕，然后你可以让它总结、翻译、引用或分析内容。

如何从代理搜索 YouTube？

安装 youtube-full（或 youtube-search），然后询问：

“查找关于机器学习的视频”

返回最多 50 个结果，包含标题、缩略图、观看次数和发布日期。

需要 Google YouTube Data API Key 吗？

不需要。 TranscriptAPI 替代了 Google YouTube Data API 的字幕提取、搜索和频道/播放列表操作。无需 Google Cloud 项目、无配额限制、无需 OAuth 设置。

需要 API Key 吗？

需要，但注册免费且即时——100 credits，无需信用卡。你的代理会在首次运行时自动处理设置。
