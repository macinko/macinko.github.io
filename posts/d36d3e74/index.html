ServerKit 轻量级的现代服务器控制面板，用于在 VPS

更新于2026-09-05|globalvps
|总字数:989|阅读时长:3分钟|浏览量:

基于 GitHub 上 ServerKit 的官方文档，我为你整理了一份详细的部署教程。ServerKit 是一个轻量级的现代服务器控制面板，用于在 VPS 或专属服务器上管理 Web 应用、数据库和服务。

核心提示：ServerKit 的生产部署方式是直接安装在宿主机上，通过 Systemd 管理后端，并由宿主机 Nginx 直接提供前端静态文件。不推荐将整个面板放在 Docker 容器中运行，因为这会导致面板无法管理其所在的宿主机（如无法操作 Nginx、Systemd 等），仅可用于测试环境。

一、系统要求

  • 支持的操作系统：Ubuntu 22.04+ / Debian 12+ / Fedora / RHEL / Rocky / AlmaLinux 9+ (64-bit)。
  • CPU：最低 1 vCPU，推荐 2 vCPU 以上。
  • 内存：最低 1 GB，推荐 2 GB 以上（面板运行内存约 180MB）。
  • 磁盘：至少 10 GB 可用空间。
  • 网络：需要公网 IP，并开放端口 80、443 和 5000。

二、安装步骤

1. 获取并运行安装脚本

这是官方推荐的一键安装方式。脚本会自动安装依赖、拉取代码并配置服务。

./serverkit install 命令会自动安装 Docker（用于运行托管的应用）并设置 Systemd 服务 serverkit.service。

1. 访问面板

在浏览器中访问你的服务器 IP 或域名 http://your-server-ip。首次访问时，系统会引导你创建管理员账户。如果你已通过命令行创建，则直接登录即可。

2. 常用管理命令

安装完成后，可以通过 serverkit 命令进行日常管理和维护。

四、配置 SSL 证书（可选但强烈推荐）

为了安全地通过 HTTPS 访问面板，你可能需要配置 SSL 证书。

  1. 前提：你已有一个指向服务器 IP 的域名。
  2. 操作：登录面板后，在 Settings 或 Domain 相关部分，添加你的域名并开启 “Auto SSL” 功能。ServerKit 可以自动通过 Let’s Encrypt 申请并续签证书。

五、故障排查

常见问题 解决方案
安装后无法访问面板 检查服务器的安全组/防火墙是否放行了 80、443 和 5000 端口。
创建应用失败 确保你已通过 serverkit create-admin 登录或创建了管理员账户。同时检查是否有足够的磁盘空间。
面板运行异常 使用 sudo serverkit logs 命令查看详细的错误日志，这通常是定位问题的第一步。
./serverkit install 失败 确认系统满足最低要求，并且已连接到网络。可以尝试 sudo apt update && sudo apt upgrade -y 更新系统包后再试。
