图片转生图提示词插件 - PromptLens 正式发布

更新于2026-09-05|aipic
|总字数:1.5k|阅读时长:4分钟|浏览量:

image-2.0图片生成模型已经非常牛逼了，听说最近GPT 悄悄的更新了image-2.5 ，这好日子我们一定要赶上啊。

平时遇到了好看的图片风格，或者是非常哇塞的平面设计，只会说牛逼，自己却死活憋不出来生图提示词。

以后这场面就算结束了！

我为大家打造了这个插件– PromptLens

这是一款 Chrome / Edge 图片反向提示词扩展。

它可以分析网页图片、本地图片或剪贴板截图，生成可编辑的中文、英文和 JSON 生图提示词。

其实以前就发布过它的前身 – ImageToPrompt：

图片反推专业生图提示词浏览器插件– ImageToPrompt 发布！

而且我这个插件已经对提示词生成进行了规则设计，你可以试一试，基本可以生成图片与原图90% 一样的细节效果。

我已经做过非常多的测试了。

有图有真相

简单说一下插件的功能介绍：

  • 在没有限制左键的网页里，图片上右键– PromptLens，模型识别图片，给出提示词+负面提示词+关键提示词内容。
  • 输出中文、英文和结构化 JSON 提示词
  • 在限制右键的网页，你也可以直接用微信截图，把图片保存在剪切板里，然后点击扩展图标上传、粘贴本地图片，提取提示词。
  • 场景自适应分析人物、产品、建筑、风景、插画、3D、海报、UI 等图片
  • 本地历史记录、单条删除、清空和收藏保护
  • 支持多数采用 /chat/completions 与 image_url 的 OpenAI 兼容视觉模型

Chrome 安装

Edge 安装

首次使用

点击浏览器工具栏中的 PromptLens 图标，再点击“设置”。

填写你的 API Base URL、API Key 和支持图片理解的模型名称。

点击“测试连接”，成功后保存配置。

在网页图片上右键选择 PromptLens，或点击扩展图标上传/粘贴图片。

注意：PromptLens 不提供 API 额度。图片分析费用由你选择的 API 平台按照其规则收取。

说一些经常遇到的问题：

  1. 提取提示词失败，那你就去设置里，看看你的 API 是否连接正常。记得保存！
  2. 有时候会有点错版 ，和插件没关系，刷新一下就行了。
  3. 加载时间久，要怪就怪你的模型脑子不行。
  4. 收藏的提示词和历史都是有上限的，不用的就删，保存在本地的缩略图也会一起删掉节省空间。
  5. 有更新版记得去下载最新版 ，我会定时更新。或者加我微信：psercn 来单独反馈！
