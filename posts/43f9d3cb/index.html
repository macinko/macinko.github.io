自建节点第一步：一年 $21.99 起的 RackNerd VPS 购买保姆级教程

更新于2026-09-19|globalvps
|总字数:1.9k|阅读时长:6分钟|浏览量:

想拥有一个完全属于自己的节点，不限速、不跑路、不和几百人挤同一个 IP，第一步永远是先有一台自己的 VPS。

选来选去，我自己的节点最后落在了 RackNerd 上：2GB 内存的 KVM VPS 一年只要 $35.99，折合人民币两百出头，带独立 IPv4，洛杉矶机房走电信、联通优化线路，国内直连延迟和速度在这个价位里相当能打。跑了挺长时间，稳定性没得说。

这篇把购买流程从头到尾走一遍，每一步都配了截图，照着点就行。搭节点的部分（VLESS + Reality 一键脚本）我会单独出一篇，这篇先把服务器搞到手。

购买入口：

https://my.racknerd.com/aff.php?aff=20509

一、RackNerd 是什么服务商

先简单交代下背景，免得你担心买到跑路小厂。

RackNerd 是 2019 年成立的美国主机商，主打一个字：便宜。

但便宜不等于不靠谱，它连续上了 Inc. 5000 美国增长最快私营企业榜单，在 LowEndTalk（一个专门给低价主机挑刺的社区）常年口碑靠前。

它最大的两个卖点：

1. 价格锁定，续费不涨。 很多主机商玩首年特价，次年翻倍的套路，RackNerd 的特价套餐续费和首年一个价，买的时候多少钱，以后年年都是这个钱。

2. 洛杉矶机房对国内友好。 走电信、联通优化线路，国内直连延迟和速度在这个价位里算能打的。

对搭节点来说，这两点正好是最核心的需求：线路决定体验，续费不涨决定这个节点能安心用很多年。而且服务器是自己的，节点自然也不存在机场跑路。

当然它不只是台节点机，比如建站、开发测试、跑自动化脚本都行，一台有 root 权限的海外服务器，能折腾的空间很大。

二、当前在售的特价套餐

进入官网后，导航栏长这样，特价套餐在 VPS 菜单里，也可以直接从首页的促销横幅进：

目前官网 Specials 页面在售的年付套餐是这几档：

套餐 vCPU 内存 硬盘 月流量 年付
1GB 1核 1GB 20 GB SSD 20GB 固态硬盘 3 TB $21.99
2GB 2核 2GB 35 GB SSD 35GB 固态硬盘 5TB $35.99

所有套餐都带：1Gbps 端口、1 个独立 IPv4、完整 root 权限、RAID-10 纯 SSD、SolusVM 控制面板、付款后即时开通。

怎么选，说点实话：

  • 纯搭节点：1GB 绰绰有余。节点本身对配置要求极低，一年 $21.99，每月 3TB 流量个人用根本跑不完，试错成本约等于两杯咖啡。
  • 节点、顺便建个站或跑点服务：2GB 是甜点位（官方也标的 Most Popular），我这次演示买的就是它。
  • 跑数据库、多个项目：4GB 起步。

不用纠结太久，RackNerd 支持后期无损升级套餐，只需重启一次，先买小的完全没问题。

三、购买流程实操（图文）

第 1 步：进入官网选套餐

从这里进入 🔗

https://my.racknerd.com/aff.php?aff=20509

找到想要的套餐，点 Order Now。

第 2 步：配置你的服务器

进入配置页，需要选的就三样，其他保持默认：

  • 计费周期：默认年付（特价就是年付价，别动）
  • Operating System（操作系统）：新手无脑选 Ubuntu 24.04 64 Bit，教程资料最多。喜欢 Debian 的选 Debian 12 也行
  • Location（机房位置）：国内用户选 Los Angeles（洛杉矶），对国内线路最友好

页面上的 Server Label 是服务器备注名，随便填或者不动都行，以后能改。右侧订单概览确认一下配置和价格（截图里是 2GB 套餐，$35.99/年），没问题点 继续。

第 3 步：购物车确认 + 促销代码

进入购物车页面：

这里有个”应用促销代码”输入框。说明一下：特价套餐本身已经是促销价，一般不能再叠加优惠码，官网给出的那些 30% off 码主要针对原价套餐。有码（15OFFDEDI）可以试着验证一下，验证不过就直接结账，$35.99 已经是很好的价格了。

确认金额无误，点绿色的 结账 按钮。

第 4 步：注册账户 + 选择付款方式

没有账号的话这一步顺便注册：邮箱、姓名如实填写即可，地址随便填写都可以。

然后是付款，这也是 RackNerd 对国内用户特别友好的地方，支付方式给得非常全：

  • 支付宝（Stripe），可以直接用支付宝付，对没有外币卡的朋友是最省事的
  • 银联卡
  • PayPal
  • 国际信用卡（Visa / Mastercard）
  • 加密货币（BTC、USDT 等）

按你手头有什么选就行。勾选同意服务条款，点 完成订购，付款成功后 VPS 立即开通，不用等审核。

四、开通之后：3 分钟连上你的服务器

\1. 查收开通邮件

付款后几分钟内，注册邮箱会收到一封 “VPS Login Information” 邮件，里面有三样关键信息：服务器 IP、root 密码、SolusVM 面板的登录地址。这封邮件建议存好。

\2. SSH 登录

打开终端（Windows 用 PowerShell 就行）：

ssh root@你的服务器IP

第一次连接输 yes，然后粘贴邮件里的 root 密码，回车，你已经站在自己的服务器里了。

进来后先做两件事：

# 更新系统

apt update && apt upgrade -y

# 把初始密码改掉（安全起见）

passwd

\3. 两个面板别搞混

这是 RackNerd 新手最容易懵的一点，提前说清楚：

  • my.racknerd.com

    （账单面板）：管续费、升级套餐、提工单

  • SolusVM（服务器面板）：管开关机、重装系统、看流量、网页 VNC 救援

登录入口和密码是两套，各干各的活。SSH 连不上的时候，去 SolusVM 的 VNC 控制台总能救回来。

回答几个常见问题：

  1. 一年 200 块出头，续费不会偷偷涨价？特价套餐续费价锁定，我续费过，和首年一个价。
  2. 流量用超了会暂停到下个计费周期，不会产生额外扣费。2GB 套餐每月 5TB，个人用基本用不完。
  3. 不会 Linux 也可以玩。重装系统、重启这些在 SolusVM 面板上点几下就行，剩下的跟着教程一步步敲命令，很快就上手了。折腾服务器本身就是最好的 Linux 入门方式。
  4. 特价套餐买错了大概率无法退，特价套餐基本没有退款保证，所以机房和配置下单前确认好。拿不准先买 1GB 最低配试水。
  5. 需要 IPv6的话，洛杉矶机房支持免费申请，最多 100 个，开通后提交工单即可。

到这里，服务器已经在手、SSH 也连上了，自建节点最难的一步其实已经完成。后面有机会我会写在这台 VPS 上一键部署 VLESS + Reality 节点的完整流程，关注不迷路。
