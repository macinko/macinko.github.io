Android-Dex：安卓手机投屏电脑当桌面用

更新于2026-08-22|toolssoftware
|总字数:349|阅读时长:1分钟|浏览量:

一款能把你的安卓手机变成桌面电脑体验的工具，通过 Wi-Fi 连接，不用 root 就能在 Windows、macOS 或 Linux 上操控手机。

Github地址

https://github.com/Shrey113/Android-Dex

功能特性

不用 root，Wi-Fi 一连，手机秒变电脑桌面，投屏、操控、音频传输全搞定。

  • 屏幕镜像 + 远程控制，基于 scrcpy 引擎，延迟低
  • 无线 ADB 连接，插线或 Wi-Fi 都行
  • 单个应用音频独立传输，不跟系统声音混一起
  • 分身应用窗口，同时跑好几个安卓程序
  • 媒体控制中心，播放暂停切歌调音量
  • 快速操作面板，截图、返回主页、调亮度一键完成
  • 自带 ADB 环境，不用自己折腾驱动

怎么用

  1. 手机设置 → 关于手机 → 连点 7 次版本号，打开开发者模式
  2. 开发者选项里开启 USB 调试
  3. 插 USB 线首次配对，或者直接用无线调试
  4. 电脑端下载对应系统的安装包（Windows / macOS / Linux 三选一）
  5. 打开 Android DEX，等进度条跑完，桌面界面解锁，开始用

如果连接出问题，启动界面会弹出”选择设备”按钮，点进去挑对设备就行，不用重开软件。项目本身用 Flutter 写的桌面端，安卓侧是个 Kotlin 写的配套 App，两边通过 WebSocket 握手通信。
