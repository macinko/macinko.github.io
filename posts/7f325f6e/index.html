大疆 4G 模块开源玩法大全：eSIM、短信、电话、VoWiFi

更新于2026-09-05|toolssoftware
|总字数:2.6k|阅读时长:8分钟|浏览量:

🚁 大疆一代 4G 模块别吃灰：这几个开源项目，已经把它玩坏了

如果你手里有 大疆第一代 4G 模块 / QDC507，先别急着把它当成无人机配件扔抽屉里。

这东西被开源社区折腾了几年之后，现在已经可以玩出：

📱 收发短信 ☎️ 电脑直接打电话 📩 接收验证码 🪪 管理 eSIM Profile 📶 4G 蜂窝上网 📡 VoWiFi / IMS 🌐 SOCKS5 代理 🔀 多 4G 模块多出口 🖥️ 给其他设备提供蜂窝网络

甚至有人已经把它做成了一个完整的 桌面蜂窝通信终端。

而这一切，基本都来自 GitHub 上这些项目。

🧩 先说说：这玩意到底有什么用？

很多人第一次看到 DJI 4G 模块，都会觉得：

“不就是一个给无人机提供 4G 网络的小配件吗？”

其实它的本体就是一个完整的蜂窝通信模块。

只不过 DJI 把它封装成了自己的硬件。

通过 USB 接到电脑之后，配合开源项目，就可以直接和里面的 Modem、SIM、eUICC、短信、网络接口甚至 IMS 能力交互。

于是事情就开始变得有意思了 😏

📩 短信 & 验证码

SIM 卡插进去。

电脑直接收短信。

验证码来了，不需要：

拔 SIM → 插手机 → 收验证码 → 再拔出来。

直接在 Mac / Linux 上看。

一些项目甚至可以自动识别常见验证码。

对于经常需要短信验证的人来说，这个体验是真的舒服。

☎️ 电脑直接打电话

更离谱的是——

它真的可以拿来打电话。

模块负责蜂窝网络，电脑负责：

🎙️ 麦克风 🔊 扬声器 🖥️ UI

于是就可以变成：

SIM → DJI 4G Module → Mac → 拨号 / 接听

部分项目已经支持拨号、接听、拒接、静音、挂断、来电提醒以及通话记录。

甚至还有项目进一步做了通话录音。

这时候它已经完全不像一个“无人机配件”了 😂

📡 VoWiFi / IMS

这个可能才是很多人真正感兴趣的地方。

一些 SIM / eSIM 卡的激活、注册或者相关业务，会依赖特定的运营商网络条件。

而支持 VoWiFi / IMS 的方案，可以利用 IP 网络建立运营商的 IMS 通信能力。

例如：

一些需要境外蜂窝网络条件才能完成特定激活/注册的卡

在满足运营商、SIM、套餐、IMS、网络环境等条件的情况下，可以尝试通过 VoWiFi 解决部分“必须接入境外蜂窝网络”的问题。

⚠️ 当然，这里千万别理解成：

“有了这个就能 100% 激活任何卡。”

实际能不能用，取决于：

  • SIM / eSIM
  • 运营商
  • 套餐
  • 漫游状态
  • IMS
  • VoWiFi
  • ePDG
  • Modem 固件
  • 当前网络环境

它更像一个把底层能力开放出来的工具，而不是万能激活器。

🌐 直接变成 4G 网卡

这个反而是最基础的玩法。

USB 插 Mac：

DJI 4G Module → SIM → 4G → Mac 上网

一些工具可以处理模块识别、ECM、网络服务、DHCP、网络优先级以及异常恢复。

尤其是 Mac 用户应该遇到过这种情况：

模块明明已经是 4G 上网模式， 插进去却没有网卡。

这就是 4G-Connect 这类项目存在的意义。

🖥️ 给 iPad 等设备提供蜂窝网络

还有一个非常实用的玩法：

让没有蜂窝功能的设备，通过外部 4G 模块获得网络。

比如 iPad。

严格来说，它不是把 Wi-Fi 版 iPad “刷成蜂窝版”，而是让外置 4G 模块承担蜂窝网络连接。

简单理解：

iPad ← 网络共享 ← DJI 4G Module ← SIM ← 4G

所以一些原本只能 Wi-Fi 上网的设备，也可以通过这种方式获得移动网络。

🔀 多模块 = 多个蜂窝出口

这个就开始进入“玩家模式”了。

如果你同时接几个 DJI 4G 模块：

QDC507 #1 → SIM A → 4G 出口 A QDC507 #2 → SIM B → 4G 出口 B QDC507 #3 → SIM C → 4G 出口 C

然后分别提供：

SOCKS5 :1080 → Module #1 SOCKS5 :1081 → Module #2 SOCKS5 :1082 → Module #3

不同应用走不同的蜂窝出口。

这时候它已经开始像一个桌面蜂窝网络网关了。 🤯

而 CellDock 目前就在这条路线上做得比较完整。

🛠️ 这些 GitHub 项目，到底有什么区别？

这一圈项目其实挺有意思。

它们不是简单的“换皮”。

有的偏 macOS。

有的偏 Linux。

有的专门搞 VoWiFi。

有的专门解决网络。

有的直接往多模块蜂窝网关方向发展。

🛑 vohive

这是很多老玩家应该都用过的项目。

可以说是这一圈生态里比较经典的一代方案。

但后来：

vohive 宣布无限期停止维护。

于是社区开始出现各种接力、重构和衍生项目。

所以现在如果你刚开始玩 DJI 4G 模块，我反而建议直接看看后面的这些新项目。

🍎 DJOneHub

ZenGeekLabs/DJOneHub

这是一个面向大疆第一代 4G 模块的 macOS 管理工具。

功能已经相当完整：

📶 模块自动识别 📡 运营商 / 信号 / 网络状态 📩 SMS 收发 🔢 验证码提取 🪪 eSIM Profile 管理 ⬇️ 下载 Profile 🔄 启用 Profile 🗑️ 删除 Profile 🔧 AT 指令调试 🌐 USB 4G 上网 📊 实时速度 / 流量

而且它不是简单搞个远程 Web 服务。

核心逻辑直接在本机运行。

对于 Mac 用户来说，上手门槛比较低。

🍎 DJOneHubNative

cr-zhichen/DJOneHubNative

这个可以理解成：

DJOneHub → 原生 macOS 化。

它保留了 Go 后端，把前端换成了 SwiftUI。

整体架构非常有意思：

SwiftUI ↓ Unix Domain Socket ↓ Go Backend ↓ USB / QMI / eUICC / SMS

现在已经涉及：

📩 短信 ☎️ 电话 🪪 eSIM 📶 蜂窝网络 🔧 AT 调试 🔀 应用分流 🌐 SOCKS5 🛡️ sing-box 📊 网络诊断 📌 菜单栏

甚至做了模块网卡优先级以及应用级网络分流。

如果你是开发者，我反而建议把这个仓库源码翻一遍。

架构挺值得研究。

🐧 SimAdmin

3899/SimAdmin

这个路线就完全不一样了。

它更偏：

Linux 蜂窝设备管理平台

适合：

🖥️ Linux 小主机 📡 CPE 🛜 软路由 🏠 NAS 📶 蜂窝网关

底层主要围绕：

ModemManager + NetworkManager + QMI + AT + lpac

展开。

同时提供：

📩 SMS 🪪 eSIM 📡 蜂窝网络 📶 APN 🔍 运营商扫描 📊 网络状态 🌐 DDNS 🤖 自动化 🔔 通知 📦 OTA

甚至已经开始往多设备集中管理方向发展。

如果你准备把 DJI 4G 模块长期扔在 Linux 设备上跑，这个项目值得收藏。

🐱 VoCat

MengMengCode/VoCat

这个我个人觉得特别值得关注。

因为它不是单纯搞“4G 网卡”。

它明显把重点放到了：

VoWiFi + IMS + eSIM + Modem

上。

涉及：

📡 WiFi Calling 📡 IMS 🔐 EAP-AKA 🌐 ePDG / IKEv2 📩 IMS SMS 🪪 eSIM / eUICC 💬 SMS 📞 通信能力 🌐 SOCKS5 🐳 Docker 🤖 自动化

如果你折腾 DJI 4G 模块的核心目的就是：

VoWiFi / IMS / eSIM

这个项目建议重点研究。

🔧 4G-Connect

WongLoki/4G-Connect

这个项目特别纯粹。

它不想做一个“大而全”的管理平台。

它就干一件事：

解决 DJI 4G 模块插 Mac 后没有网卡的问题。

检测模块。

检查网络服务。

检查 ECM。

必要时通过 AT 指令恢复。

重启模块。

重新枚举。

重新获取 DHCP。

然后：

能上网了。

😂

这种工具看起来简单，但实际非常实用。

尤其是 Mac 用户。

💜 MaVo

moluncn/mavo

MaVo 是一个原生 macOS 菜单栏应用。

它的定位也非常明确：

让 QDC507 在 Mac 上尽可能像一台手机。

支持：

📶 蜂窝网络 📩 SMS 🔢 验证码 ☎️ 拨号 📞 接听 🔕 静音 ❌ 拒接 🎙️ Mac 麦克风 🔊 Mac 扬声器 📌 菜单栏 🔄 热插拔 🛠️ 网络自动恢复

如果你的需求就是：

“我就想在 Mac 上把这个东西当一台外置手机。”

MaVo 很舒服。

🟢 最后说 CellDock

celldock-for-mac

我目前个人最推荐这个。

不是单纯因为“功能最多”。

而是它开始把前面这些零散能力，真正整合成了一个完整的 macOS 蜂窝通信工具。

📡 多模块

可以同时管理多个 QDC507。

一个 Mac：

QDC507 #1 QDC507 #2 QDC507 #3 QDC507 #4 …

全部统一管理。

📩 SMS

后台接收短信。

系统通知。

验证码识别。

会话管理。

长短信。

基本已经不像传统 Modem 管理工具了。

☎️ 电话

拨号。

接听。

拒接。

静音。

挂断。

来电通知。

通话记录。

甚至还有：

🎙️ 通话录音

保存 M4A。

录音库。

波形。

播放。

导出。

🪪 eSIM

直接管理实体卡槽里的兼容 eUICC：

EID → Profile → ICCID → 下载 / 启用 / 停用 / 重命名 / 删除

所以一张实体 eUICC 卡插进去之后，可以直接通过电脑管理 Profile。

🌐 SOCKS5

这个是我比较喜欢的功能。

例如：

QDC507 #1 → SOCKS5 :1080 QDC507 #2 → SOCKS5 :1081 QDC507 #3 → SOCKS5 :1082

每个模块就是一个独立的蜂窝网络出口。

多个 SIM。

多个运营商。

多个 IP。

直接变成一个桌面多蜂窝网络节点。

🗺️ 所以到底应该选哪个？

如果你懒得一个个研究，可以直接这么选：

🍎 Mac 日常使用

首选：CellDock

功能最完整，尤其适合现在的新玩家。

🍎 想研究 DJOneHub 体系

DJOneHub / DJOneHubNative

尤其推荐开发者看看 DJOneHubNative 的源码。

☎️ 主要想收短信 + 打电话

MaVo

简单直接。

🔧 只想解决“4G 模块没网”

4G-Connect

专治这个问题。

🐧 Linux / 软路由 / CPE

SimAdmin

更适合长期跑在 Linux 设备上。

📡 专门研究 VoWiFi / IMS

VoCat

这个方向值得重点研究。

🧪 想研究 DJI 4G 模块底层

DJOneHub

从 USB、AT、eUICC、SMS 到网络模式，都可以往下挖。

🤯 最有意思的地方其实在这里

最开始：

它只是一个大疆无人机的 4G 模块。

一个本来给无人机用的配件，硬是被开源社区玩成了一个：

开源蜂窝通信实验平台。

这才是我觉得这套东西最有意思的地方。🔥
