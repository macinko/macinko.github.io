ATBClone 详细部署教程：macOS 应用分身与隔离引擎

更新于2026-09-13|osmacos
|总字数:1.3k|阅读时长:4分钟|浏览量:

ATBClone 是一款专为 macOS 设计的应用程序多实例与隔离工具，它允许你在同一台 Mac 上创建任意应用（如微信、Chrome、Telegram）的多个完全独立的副本，每个副本拥有独立的数据目录、网络代理，并可选解除沙盒限制。本教程将详细介绍其两种部署方式（GUI 和 CLI）以及核心功能的使用。

1. 系统要求与准备

  • 操作系统：macOS 13.0 及以上版本（支持 Apple Silicon 和 Intel 芯片）。
  • 系统工具（如使用 CLI 或从源码运行）：需要安装 Xcode Command Line Tools，在终端中执行 xcode-select --install 进行安装。

2. 部署方式一：使用图形界面（GUI）—— 适合普通用户

这是官方推荐给绝大多数用户的方式，无需使用终端，操作直观。

  1. 下载应用：访问项目 GitHub Releases 页面，下载最新版本的 ATBClone-arm-x.x.x.dmg（Apple Silicon 芯片）或对应的 Intel 版本。
  2. 安装：双击打开下载的 .dmg 文件，将 ATBClone.app 拖拽到 Applications 文件夹中。
  3. 首次启动：从启动台或 Applications 文件夹中打开 ATBClone.app。如果系统提示“无法验证开发者”，请前往“系统偏好设置 -> 安全性与隐私”中允许该应用运行。

3. 部署方式二：使用命令行界面（CLI）—— 适合高级用户与自动化

CLI 工具提供完整的克隆引擎控制能力，适合需要脚本化、批量操作或深入探索的高级用户。

3.1 安装 CLI 工具

  1. 下载二进制文件：从 GitHub Releases 页面 下载 ATBCloneCli.tar.gz 并解压。

  2. 添加到 PATH（可选）：将解压得到的 ATBCloneCli 二进制文件移动到一个在 PATH 中的目录，例如 /usr/local/bin，或直接通过其完整路径运行。

3.2 从源码安装（开发者模式）

如果你希望从源码运行或贡献代码，可以克隆仓库并使用 Python 环境。

使用 GUI 创建分身

  1. 打开 ATBClone.app，点击主界面的 “新建分身” 按钮。
  2. 在弹出的向导中，点击 “浏览” 选择你想要克隆的应用（例如，在 Applications 文件夹中选择 WeChat.app）。
  3. 自定义分身名称、显示图标、独立数据存储目录（可放在外置硬盘）和网络代理。
  4. 保持默认设置并点击 “下一步” 即可完成创建。

4.2 查看与管理分身

  • 列出所有克隆（CLI）：使用 list 命令查看所有已创建分身的详细信息，包括名称、策略、代理状态等。

  • 启动、更新与删除（GUI）：在 GUI 主界面的卡片上，可以一键 启动、更新（当原应用升级后，可同步更新克隆并保留数据）或 移除 分身。

4.3 高级功能：使用 App Prober

对于未收录在内置“食谱”中的应用，ATBClone 的智能探测器（Prober）可以自动分析其架构和沙盒权限，并推荐最佳的克隆策略。

该命令会生成一个 YAML 格式的规则文件并存放在 ~/ATBClone/recipes/，之后即可像普通应用一样克隆它。

5. 故障排查与注意事项

  • 系统完整性保护（SIP）：ATBClone 的硬克隆机制依赖动态库注入，可能会被 macOS 的安全策略拦截。如果遇到问题，请检查 系统偏好设置 -> 安全性与隐私 中是否有相关提示。
  • 权限请求：写入 /Applications 目录需要管理员权限，系统会弹出授权窗口，输入密码即可。
  • 应用兼容性：并非所有应用都能完美克隆。例如，企业微信（WeCom）因其复杂的进程架构目前尚不支持。
  • 环境自检（Doctor）：如果遇到问题，可以运行 ATBCloneCli doctor 命令进行全面的系统环境检查，排查 Xcode 工具链、签名环境等问题。

重要提醒：ATBClone 是一个强大的底层工具，请仅用于合法合规的目的（如测试、多账号管理），并注意遵守各应用的用户协议。
