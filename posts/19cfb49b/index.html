Mimik 详细部署教程

Mimik 是一款浏览器扩展，它能在您操作时自动捕捉您的每一步点击和键盘输入，并将其转化为一份带有标注截图的、分步指导教程。整个过程完全在本地浏览器中运行，无需账户、无需云服务、无数据追踪。

本教程将指导您完成 Mimik 的安装、配置与核心功能使用。

1. 安装浏览器扩展

Mimik 是一款标准的浏览器扩展，您可以直接从各大浏览器的官方商店安装。

1.1 支持的浏览器与安装链接

根据您使用的浏览器，点击下方对应的安装链接即可：

浏览器 安装渠道
Google Chrome Chrome 网上应用店 (搜索 “Mimik”)
Mozilla Firefox Firefox 附加组件 (搜索 “Mimik”)
Microsoft Edge Microsoft Edge 加载项 (搜索 “Mimik”)

1.2 安装后设置

  1. 点击浏览器工具栏中的 Mimik 图标，将其固定到工具栏以便快速访问。
  2. 扩展安装后即可直接使用，无需注册或登录。

2. 快速开始：创建您的第一个指南

  1. 开始录制：点击浏览器工具栏中的 Mimik 图标，然后点击 “Record” (录制) 按钮。扩展将开始监控您的操作。
  2. 执行操作：在浏览器中正常执行您想记录的工作流程，例如：填写表单、点击按钮、导航到新页面等。Mimik 会自动捕捉每个有意义的操作（点击、输入、键盘快捷键等）作为步骤。
  3. 结束录制：完成操作后，再次点击 Mimik 图标，然后点击 “Stop” (停止) 按钮。
  4. 查看与编辑：Mimik 会自动生成一份指南，并打开编辑器页面。您可以看到：
    • 每个步骤都附带一张标注了点击位置的截图。
    • 每个步骤都有一条基于操作的规则描述（例如“点击了‘提交’按钮”）。
  5. 保存与导出：编辑满意后，您可以将指南导出为 PDF、DOCX、HTML、Markdown 或 MP4 视频 格式，用于分享或存档。

3. 核心功能配置与使用

Mimik 的强大之处在于其丰富的可配置功能，您可以按需启用。

3.1 配置自动隐私保护（智能模糊）

Mimik 能自动检测并模糊截图中的敏感信息，如邮箱、电话、信用卡号等。

  1. 点击 Mimik 图标，进入 设置 (Settings)。
  2. 找到 “Smart Blur” (智能模糊) 部分。
  3. 您可以单独开启或关闭对特定类型数据的模糊处理（例如：仅模糊邮箱和电话，但保留 IP 地址）。
  4. 自定义模糊：如果您需要模糊特定元素（如某个 LOGO），可以使用 “Manual Blur Picker” (手动模糊选取器) 点击页面上的元素，它将出现在所有相关截图中被遮盖。

3.2 启用 AI 智能描述（可选，需 API 密钥）

Mimik 可以使用 AI 为您的步骤生成更自然、人性化的描述，而非机械的“点击 X”。

  1. 在 Mimik 设置中，找到 “AI Descriptions” (AI 描述) 部分。

  2. 选择您想使用的 AI 提供商：OpenAI 或 Anthropic。

  3. 输入您在该平台的 API 密钥。

    重要提醒：您的 API 密钥仅存储在本地浏览器中，仅用于直接调用您选择的 AI 服务，不会上传到 Mimik 服务器。

  4. 选择您希望 AI 生成描述的语言（如英语、西班牙语、中文等）。

  5. 之后录制时，AI 会自动为每个步骤生成更清晰的描述。

3.3 使用语音旁白（可选）

您可以在录制时直接说话，Mimik 会将语音转录为步骤描述。

  1. 在开始录制前，在 Mimik 设置中配置 “Voice Narration” (语音旁白)。
  2. 选择转录服务：OpenAI 或 Groq，并输入对应的 API 密钥。
  3. 开始录制后，像平时一样操作并同时用麦克风说话。Mimik 会将您的语音匹配到对应的步骤并转录为文本描述。

3.4 使用“Guide Me”回放模式

“Guide Me”模式可以在真实页面上回放指南，引导您或他人逐步操作。

  1. 打开您已保存的指南。
  2. 点击 “Guide Me” (引导我) 按钮。
  3. 扩展会高亮显示当前步骤需要操作的元素，并在您完成后自动前进到下一步。这非常适合用于培训或自我检查。

4. 指南编辑与导出

录制完成后，您可以在编辑器中进一步打磨指南。

4.1 编辑指南

在 Mimik 编辑器中，您可以：

  • 裁剪、标注或遮盖 任何截图。
  • 重写 步骤描述（也可以选中后使用 AI 辅助重写）。
  • 在步骤之间 插入 新的标题或说明性文字。
  • 拖拽 步骤以重新排序，或批量删除 不需要的步骤。
  • 编辑器内置了版本历史，您可以随时回退到之前的版本。

4.2 导出指南

点击编辑器中的 “Export” (导出) 按钮，选择您需要的格式：

  • Video (视频)：生成带光标移动和旁白的 MP4 视频。
  • PDF：适合打印的 A4 纵向布局文档。
  • DOCX：可在 Microsoft Word 中继续编辑。
  • HTML：自包含的网页，图片以 Base64 编码嵌入，便于在任何地方分享。
  • Markdown：可粘贴到 Notion、GitHub 等支持 Markdown 的平台。

所有导出均在本地生成，内容不会上传到任何服务器。

5. 隐私与安全要点

  • 本地优先：您的所有指南、截图、设置和 API 密钥都只存储在您的本地浏览器中。Mimik 没有后端服务器，也不会收集任何使用数据。
  • 数据离开浏览器的两种情况（详见隐私政策）：
    1. 为了显示网站图标，会向 Google 的 favicon 服务发送该网站的域名。
    2. 如果您启用了 AI 描述或语音旁白，您输入的文字或音频会直接发送给您自己配置的 AI 提供商（OpenAI、Anthropic 或 Groq）。

6. 故障排查

  • 扩展无法录制或反应迟钝：尝试刷新当前页面，或重新启动浏览器后重试。
  • AI 描述不生效：请检查您在设置中输入的 API 密钥是否正确，并确保账户有可用额度。同时确认已选择正确的 AI 提供商和语言。
  • 导出的视频或文档不完整：确保在结束录制前，页面已完全加载完毕。如果指南步骤较多，导出大型文件可能需要一些时间。
  • 找不到“智能模糊”的某些选项：请确保已更新到 Mimik 的最新版本。

总结

通过以上步骤，您已经成功部署并掌握了 Mimik 的基本用法。Mimik 的核心价值在于将重复的手动操作记录工作自动化，极大地提升了制作教程、文档和培训材料的效率。它尤其适合需要频繁更新产品文档的团队、分享操作技巧的个人，或是需要为同事提供清晰操作指引的开发者。您可以将其视为一个强大的“流程记录仪”，让您专注于操作本身，而把记录和整理的工作交给它。
