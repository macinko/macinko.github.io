4. 编写你的第一个识别程序

安装完成后，你可以按照以下步骤，在你的Python代码中调用SDK。

第一步：导入SDK并初始化
在你的Python文件开头，导入 FaceRecognition 类并创建其实例。

第二步：提取人脸特征
使用 GetImageInfo 方法处理一张包含人脸的图片，它将返回检测到的人脸信息，其中最重要的就是用于比较的 embedding（特征向量）。

第三步：比较两张人脸
要判断两张照片是否为同一个人，可以分别提取它们的特征向量，然后使用 get_similarity 方法计算相似度。

5. 其他部署场景与注意事项

除了这个Python版本，Faceplugin还提供了面向其他平台的SDK，部署方式略有不同，你可以根据需求参考：

  • Web前端 (JavaScript/React)：通过npm安装，例如 npm install faceplugin，并需要在项目中复制预训练的权重文件。
  • 移动端 (Android)：需要将 libfacesdk 文件夹复制到项目根目录，并在 settings.gradle 和 build.gradle 文件中添加相应的依赖配置。
  • 核心文件路径：在Linux环境下部署时，你或许需要手动修改 face_util/faceutil.py 文件，确保它正确加载了 libFaceUtil.so 文件。
