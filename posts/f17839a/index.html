Quill 专为 macOS 设计的快速、系统级的语音输入工具

更新于2026-09-05|aiosmacosaudio
|总字数:994|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 Quill——一个专为 macOS 设计的快速、系统级的语音输入工具。它由 Gemini 3.5 Transcribe 模型驱动，让您可以在任何应用（浏览器、编辑器、聊天软件等）的文本框中，通过语音自然地输入文字。

Quill 的核心优势在于其系统级集成和注重隐私的设计。您无需在应用间切换，只需使用全局快捷键即可在任何地方进行语音输入，且您的 API 密钥和语音数据仅用于与 Google 服务的通信，不会在应用内存储或上传您的历史录音。

整个部署流程非常简单，只需下载应用、授予必要权限并配置一个 Gemini API Key 即可开始使用。

📥 安装与初始设置

1. 安装应用

  1. 从项目的 Releases 页面 下载最新版本的 Quill.app。
  2. 将 Quill.app 拖拽到您的 Applications 文件夹中。
  3. 在 Applications 文件夹中双击 Quill.app 启动它。

2. 获取 Gemini API 密钥

Quill 需要 Google Gemini API 密钥才能工作。

  1. 访问 Google AI Studio API Keys 页面，并使用您的 Google 账户登录。
  2. 点击 Create API key，按提示选择或创建一个 Google Cloud 项目。
  3. 复制生成的 API 密钥。您将在 Quill 的首次设置中粘贴它。

3. 授予系统权限

首次启动 Quill 时，它会引导您完成必要的系统权限设置。

  • 麦克风权限：Quill 需要访问您的麦克风以捕获语音。请在系统弹窗中允许。
  • 辅助功能权限：此权限允许 Quill 将转录的文本粘贴到您当前光标所在的任何输入框中。这也是必需的。

4. 粘贴 API 密钥并完成设置

在 Quill 的欢迎界面中，粘贴您之前复制的 Gemini API 密钥，并完成剩余设置。

🎙️ 基本使用

设置完成后，您就可以在任何地方使用语音输入了。

  • 开始录音：将光标放在任何可编辑的文本字段中，按住 ⌥ Option + Space 键。
  • 停止并插入文本：说完后，松开快捷键。Quill 会将转录的文字自动插入到您光标所在的位置。
  • 取消录音：在录音过程中，按下 Esc 键即可取消。
  • 重新粘贴上一次转录：按下 ⌃ Control + ⌥ Option + V，可将您上一次使用 Quill 转录的文本再次粘贴出来。
  • 打开 Quill 菜单：点击菜单栏中的 Quill 图标。

⚙️ 自定义设置

您可以通过菜单栏中的 Quill 图标进入 Settings，对应用进行个性化配置。

  • 快捷键：在 Settings → Dictation 中，您可以自定义“开始/停止语音输入”和“粘贴上一条转录”的全局快捷键。
  • 麦克风：您可以选择使用 macOS 的默认麦克风，或在此指定一个特定的麦克风设备。
  • 转录模式：
    • Smart (智能模式)：自动优化标点和可读性，推荐日常使用。
    • Verbatim (逐字模式)：更贴近您的原始用词。
  • 语言：您可以让 Quill 自动检测语言，或手动指定一种偏好语言。
  • 自定义词汇：您可以添加专有名词、术语或缩写，以提高对这些词汇的识别准确率。
  • 开机启动：您可以在设置中启用“登录时启动”选项。

🔒 隐私与数据

  • Quill 使用辅助功能权限仅为了将文本插入到正确的输入框中。
  • 麦克风权限仅在您主动按下快捷键开始录音时才会被使用。
  • 您的语音数据会被发送到 Google Gemini API 进行处理。Quill 应用本身不会保存您的录音或转录历史。

🛠️ 开发者信息

  • 从源码构建：如果您是开发者，想自行编译或贡献代码，请参考项目中的 Building Quill from Source 文档。
  • 许可证：Quill 使用 Apache License 2.0 开源许可。
