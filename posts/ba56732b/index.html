Docspell 开源的个人文档管理系统（Document Management System / DMS），专门帮助整理来自扫描仪、邮件和其他来源的大量文件

更新于2026-08-22|toolssoftware
|总字数:536|阅读时长:1分钟|浏览量:

Docspell 是一个开源的个人文档管理系统（Document Management System / DMS），专门帮助整理来自扫描仪、邮件和其他来源的大量文件。

GitHub：https://github.com/eikek/docspell
官网：https://docspell.org
许可证：AGPLv3 or later
Star：约 2.3k

核心定位

Docspell 面向家庭、个人或小型团队，帮助你把扫描仪扫描的文件、邮件附件等“乱七八糟”的文档变得有序、可搜索。它通过机器学习自动建议元数据，大幅减少手动整理的工作量。

主要功能

  • 智能元数据建议
    利用 Stanford CoreNLP 进行自然语言处理（NLP），自动建议对应人（correspondent）、标签、日期等，并能从已有文档中学习。

  • OCR 文字识别
    自动对扫描件或图片 PDF 进行 OCR（依赖 Tesseract、ocrmypdf 等工具）。

  • 全文搜索
    支持对文档内容进行全文检索。

  • 邮件集成
    优秀的邮件导入支持，方便把邮件附件直接纳入文档库。

  • 标签、对应人、自定义元数据
    灵活的分类与标记系统。

  • Web 界面
    移动友好的 SPA（单页应用），使用 Elm + Tailwind 构建。

  • 多端支持

    • Android App（方便从手机直接上传）
    • 命令行工具（dsc）
    • 完整 REST/HTTP API

  • 多用户 / Collective
    支持家庭或小组共享使用。

其他安装方式包括：

  • Debian/Ubuntu deb 包
  • 直接下载 zip 运行
  • Nix / NixOS
  • Helm Chart（Kubernetes）

技术栈

  • 后端：Scala（函数式风格，Typelevel 生态：Cats、FS2、Http4s、Doobie 等）
  • 前端：Elm + Tailwind CSS
  • 机器学习：Stanford CoreNLP
  • 文件处理：Tesseract、ocrmypdf、unoconv 等

适合谁用？

  • 家里有大量扫描件、发票、合同、信件需要整理的人
  • 想把邮件附件和纸质文档统一管理的人
  • 喜欢自托管、开源、注重隐私的用户
  • 小型团队或家庭需要共享文档库的场景

Docspell 的目标是用最小的努力把文档整理好，智能建议功能是它的一大亮点。
