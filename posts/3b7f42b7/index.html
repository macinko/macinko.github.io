免费 Any Router 公益中转站：从申请注册到 CC + Codex

更新于2026-09-19|aiagent
|总字数:2.9k|阅读时长:9分钟|浏览量:

Any Router（或简称”Any公益站“） 是个面向国内开发者的”Claude Code 免费公益中转站“，靠可观的免费额度和 linuxdo 一键登录走红。

Any 站适合零成本尝鲜 Claude Code 最新模型，但它定位是”快速体验”而非”稳定生产”，正式开发后在意数据安全的同学，建议另找更可靠的官方或付费方案。

Any 解决了什么痛点

Claude Code 是 Anthropic 出的命令行 AI 编程工具，代码生成和理解能力很强，但国内用户直接用官方服务有三大障碍：

  • 网络限制：官方 API 在国内访问不稳定，通常要干净、高质量、稳定的全局代理节点才能访问；
  • 支付门槛：官方订阅需要海外支付方式，还经常封禁账号；
  • 注册门槛：海外手机号验证、KYC海外身份验证。
  • 中转站贵：国内很多API中转站看起来 token单价低，但是缓存要么没做要么命中率低，API地址稳定期不佳，还带系统prompt拼接等各种原因，导致最终 Token 综合成本还是很高，按量计费方式的 Token 服务，远远不如官方订阅套餐成本划算。

AnyRouter 解决掉了以上 4 大痛点，让初学 vibe coding 的新同学能 0成本0门槛的立即体验到 claude code 最新模型的能力和效果，也是非常不错的体验了。

Any 为什么在 linux.do 上很火

最大的吸引点是免费额度：通过邀请链接注册大致是「注册送 $50 + 邀请送 $50 = $100」，并且有”每天登录签到送额度”的活动（ $25/天）。

再加上它支持用

linux.do

账号一键登录（GitHub 注册通道时开时关），所以在

linux.do

这种开发者社区里讨论度特别高，大家都在分享”白嫖教程”和邀请码。

Any 使用中遇到大部分问题，也都可以在这个论坛找到佬友的分享，基本都可以找到答案解决掉问题。

如何注册账号？

Any最开始邮箱都可以直接注册，后来开放了有半年以上的 GitHub 账户验证登录即可注册，因为薅羊毛的人越来越多，现在提高了门槛（关闭邮箱注册）：

现在支持 2 种方式注册，通过邀请链接

https://goshr.link/anyrouter

进入，然后：

1、用

linux.do

论坛账号验证登录注册；

此方法，需要 论坛账号等级3级及以上老用户发送邀请链接才可以注册论坛，同时还需要写申请”小作文“，通过管理员人工审核才算注册成功。

我开始也是自己闲鱼花几块钱找人买了一个邀请链接，自己去写了申请小作文，最后没通过，可能写的理由没打动管理员。

秉承时间就是金钱，就再找闲鱼花了60元子找了个邀请链接+代写小作文 包过的服务，最终等待了大半天成功审核通过获得了一个 linuxdo 账号。

后来在推上看到 码良

@cxjwin

分享了申请账号写小作文的经验文章，我和赞同他的观点：

那一刻我意识到一件事：我之前对 LinuxDo 的理解完全错了。它不是一个薅羊毛的工具站，它是中文圈里少有的一手信源集散地。”

LinuxDo 有一个在当下非常难能可贵的特质：严格防 AI。发帖明确不允许 AI 生成，很多高热度帖子都是佬友们一个字一个字手敲出来的。在这个 AI 内容泛滥到几乎所有平台都被淹没的时间点，能保持”人味儿”的中文技术社区已经不多了。”

LinuxDo 既然严控 AI，那申请文案就更不能用 AI 写。我自己手敲了 200 多字，没追求字数，只追求一件事——活人感。

我写的大致内容：

- 我目前在团队里做什么——iOS Tech Lead，正在一个两百万行量级的遗留 Objective-C 工程上做 harness 建设。这块工作有一定的独特性，因为大体量遗留代码的 AI 协作建设，本身就是个有挑战、值得分享的题目。

- 我为什么想加入——不想再被动接收二手的、被嚼过的信息，希望接触到真正的一手信源。

- 我能贡献什么——把自己在 harness 建设上的探索和实践分享出来。就这么三段，第二天顺利过了。 > >回头看这两次申请的差别，关键根本不在文笔，而在你有没有把自己当成一个具体的人去写。 > >第一次没过，因为我写的是一个想注册账号的人的模板。第二次过了，因为我写的是”我，一个在两百万行 OC 工程上做 harness 的 iOS Tech Lead，想加入这个社区的具体理由“。 > >LinuxDo 的小作文门槛说白了就是在筛这一件事：你是不是一个具体的、有温度的人。“

没有 linuxdo 账号的同学，可以参考上面的思路去写小作文提交申请，大概率是能通过的。

稍微花点点时间和用心，也能省去大几十元子，比很多人时薪都要高的，还是很值也对论坛会有更深的认识，未来可能还从上面获取到更多有价值的信息，哈哈。

2、用注册满3年的 GitHub 账户

这个就没啥好讲的了，有就有没有就发挥自己的超能力去（buy）搞即可。

Any 后台简单介绍

注册登录后简单熟悉可以看到，这就是一个 newapi程序搭建的中转站，用过中转的同学应该都会了。

默认后台首页可以看到总览信息：余额、消耗量、还有右侧的 API 端点链接。

左侧导航【API令牌】进去创建 API密钥，这里需要注意下，过期时间 直接选永不过期 即可；

下面的 模型限制 要么不选，要选的话就记得把自己想用的模型都勾选☑️上。

都支持哪些模型，可以点击顶部导航【定价】进去查看或搜索，点击模型 id 即可复制出来去自己常用的客户端中配置了。

这里并不是说收费的，Any 是免费公益站，这里的定价只是系统记录 Token使用的一个统计方式，价格客户忽略。

Any 如何持续免费使用？

要像持续免费用API，就是要获得足够多的赠送余额，有2个方式：

1、每天早上10点后 登录签到；

签到发放记录在左侧菜单【使用日志】内可以查看到。

也有一些邪修方法，通过脚本自动签到的，这个 在linuxdo论坛有一些分享教程，大家自己去发掘吧，不过感觉这种稳定和安全性有一定风险，自己斟酌着玩就行。

2、分享邀请链接 ，给需要的同学注册，成功邀请一个同学注册，双方都会各赠送 $50 刀额度。

我的邀请链接

使用 Any 需要注意的坑（重要）

  • 稳定性一般：它属于”免费公益 / 共享性质”的中转站，高峰期或被攻击时经常 429 拥堵崩溃、注册困难，有人形容”周末持续崩溃—恢复来回循环”。用来免费体验没问题，真要拿它干正经商业项目，可靠稳定性无法百分百保证。
  • 安全风险：中转站理论上能看到你发送的全部请求内容，小道消息说是国内某大厂高的，为了收集大家数据做训练模型和蒸馏使用（无可验证），因此建议别在上面跑敏感代码或泄露有商业价值的密钥/隐私信息。
  • 额度≠真金白银：所谓 $100、$25/天赠送额度是平台自定的体验额度，规则有可能会变，且账号/接口非正常按官方规定使用，可能有封禁和随时失效可能。

最后想说的话

Any 虽然免费、额度也给的比较大方，每天签到加上注册送，在顺手分享推荐下，随便一个月就是上千刀余额了。但是也因为他免费，薅羊毛的人就比较多，时不时会线路拥堵，可以错峰挑人少（比如晚上大家都休息后）挂机跑代码。

还有就是上面提现的潜在坑，如果在意数据安全🔐和稳定性，就只拿来学习和体验新模型即可。

如果你是新手，囊中羞涩或者不方便订阅官方账号，Any 公益站值得薅一下。
