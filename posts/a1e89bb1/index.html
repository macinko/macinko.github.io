cloudbak 云朵备份：数据备份恢复利器

更新于2026-08-22|osubuntukalidebianwindowsarmbianopenwrtpveomvtruenas
|总字数:896|阅读时长:3分钟|浏览量:

云朵备份：

一个微信云备份程序，使用云朵备份可以将微信数据备份到服务器，通过浏览器访问数据，你可以像正常使用微信一样浏览数据和搜索数据（参考微信网页版），除了不能发消息，以及一些特殊功能，大部分功能都可以在云朵备份上实现。

效果

TIP：

由于微信数据都比较私密，对于这个应用是否安全，需要自行辨别。

安装

可以根据不同系统，选择下面的模板进行安装

Docker Compose

UNRAID 模板

用到的参数

参数 简单说明
9527 访问的端口
/app/data 存放应用数据

使用

浏览器中输入 NAS的IP:9527 就能看到编辑器界面

初次使用需要先注册账号

输入账号密码进行登录

这里还需要配套同步客户端，才能进行正常使用

点击下载 Windows 客户端

解压，启动应用

提示缺少运行环境，点击进行下载（默认安装即可）

正常启动应用后，需要填写为 NAS 的地址，用户名和密码

TIP：

此时 PC 端的微信需要启动，已经登录的状态

点击“添加 Session”

可以看到微信 PC 端运行的进程，填写 Session 名称，点击“添加”

点击“同步”

等待同步完成（数据比较多的话要等挺久的）

出现数据同步完成，就可以看 NAS 网页端了

网页刷新一下就出现 UI 界面了，看起来还是很像微信的样子

电脑端存在的图片也都可以加载浏览

分享的视频也是可以正常播放

总结

这种微信备份的项目还是挺少见的，不过因为数据很多都比较私密，使用其他应用去备份总是感觉不安全。体验下来个人觉得还是有挺多提升空间的，比如 UI 界面的兼容性问题，功能还是太少了，查找聊天记录也不能搜索或者根据日期进行搜索，很多图片如果不是本机存在的也都只有缩略图等等。

存在的一些小问题：

一些特殊名称会出现乱码（不能全怪适配，主要我的名称是透明）

有部分群聊和人的头像无法显示，看起来比较奇怪

不是本电脑的数据，虽然有缩略图，但是原图是没有的（直接电脑看可以加载出来）
