Burrow 安装与使用指南：开源的 macOS 系统伴侣

更新于2026-09-05|toolssoftware
|总字数:1.7k|阅读时长:5分钟|浏览量:

Burrow 是一款原生 macOS 系统工具，将垃圾清理、开发文件清理、应用卸载（含残留清理）、重复文件查找、磁盘分析和实时系统状态监控整合在一个免费、开源的应用中。它最大的特色是内置了MCP (Model Context Protocol) 服务器，允许 AI 代理（如 Claude Code）查询系统状态和执行清理任务。

1. 系统要求

  • 操作系统：macOS 14+ 是目前成熟、稳定的旗舰版本。Windows 10/11 有预览版，但功能尚在完善中。
  • 权限：为获得最佳体验，建议授予 “完全磁盘访问权限” (Full Disk Access)，以避免系统反复提示权限。您也可以在需要时使用“以管理员身份扫描”选项，通过输入密码单次授权。

2. 安装步骤

Burrow 的安装方式非常灵活，推荐使用 Homebrew。

2.1 使用 Homebrew 安装（推荐）

这是最简单、推荐的方式，可以确保自动更新。

2.2 直接下载安装

  1. 访问项目的 GitHub Releases 页面。
  2. 下载最新的 Burrow-x.y.z.zip 文件（请确保下载 0.11.0 或更高版本，这些版本经过 Apple 公证）。
  3. 解压并将 Burrow.app 拖入 Applications 文件夹。
  4. 首次打开时，如果提示“无法验证开发者”，请右键点击应用并选择“打开”，然后确认即可。

3. 核心功能概览

Burrow 将系统管理任务分为几个清晰的功能模块：

工具 功能说明 对应的命令行工具
Status (状态) 实时仪表盘，显示 CPU、内存、GPU、磁盘、网络、电池的实时曲线图，以及可排序的进程列表。 mo status --json
Clean (清理) 预览并可清理系统缓存、日志和其他可回收的垃圾文件。 mo clean
Purge (深度清理) 清理开发项目中的依赖目录，如 node_modules、target/、__pycache__ 等，释放磁盘空间。 mo purge
Installers (安装包) 查找并批量删除残留的 .dmg 和 .pkg 安装文件。 mo installer
Optimize (优化) 一键执行安全维护任务，如重建缓存、修复元数据、刷新 DNS、重启 Dock/Finder 等。 mo optimize
Software (软件) 列出所有已安装的应用，支持搜索、排序和批量卸载（含残留文件清理）。同时提供 Homebrew 更新检查。 mo uninstall, brew outdated
Analyze (分析) 以矩形树图 (Treemap) 形式可视化磁盘空间使用情况，可点击进入任意文件夹查看详情。 mo analyze --json
History (历史记录) 本地存储的长期系统指标历史（可保存 5 分钟至 90 天数据），可查看趋势图表。 独有功能，CLI 工具不保留。
Activity (活动日志) 记录 Burrow 执行的所有清理、优化、扫描操作及其状态。 独有功能。

4. AI 代理集成 (MCP 服务器)

Burrow 最独特的功能是内置了 MCP 服务器，允许 AI 代理（如 Claude Code、Cursor、Codex）直接与您的系统交互。所有操作都需要您的明确同意（Consent-Gated），确保安全。

4.1 手动配置

在您的 AI 代理的 MCP 配置文件中添加以下内容：

  • Claude Code：编辑 ~/.claude/settings.json。
  • Cursor：编辑 ~/.cursor/mcp.json (全局) 或项目中的 .cursor/mcp.json。

4.2 可用工具

配置完成后，AI 代理可以使用以下工具（部分需授权）：

  • 只读查询：burrow_snapshot (当前快照)、burrow_history (历史指标)、burrow_top_processes (进程排行)、burrow_disk_forecast (磁盘预测) 等。
  • 诊断分析：burrow_doctor (系统健康检查，包括 SIP、Gatekeeper、电池状态等)、burrow_ports (端口监听)。
  • 磁盘与应用：burrow_analyze (磁盘分析)、burrow_list_apps (列出应用)、burrow_deleted_files (查看已删除文件记录)。
  • 操作工具（需授权）：burrow_clean、burrow_optimize、burrow_uninstall、burrow_purge。这些工具默认执行 --dry-run (预览)，只有当您在设置中开启授权，并在请求中明确 confirm:true 时才会实际执行。

4.3 HTTP API

除了 MCP 协议，Burrow 还提供一个本地 HTTP API (127.0.0.1:9277)，可用于仪表盘或 curl 命令。每个请求都需要携带一个随机生成的令牌进行认证。

5. 常见问题排查

问题 可能原因 解决方案
应用无法启动或提示损坏 下载的版本未经过公证或隔离属性未解除 1. 确保下载 0.11.0 及以上版本。 2. 在终端执行：sudo xattr -rd com.apple.quarantine /Applications/Burrow.app。
清理/扫描时频繁弹出权限请求 未授予“完全磁盘访问权限” 在 系统设置 > 隐私与安全性 > 完全磁盘访问权限 中，添加 Burrow 应用。
MCP 服务器无法连接 AI 代理配置中的路径不正确 确认 command 路径指向正确的 Burrow.app 位置。Homebrew 安装后也可使用 command: "burrow", args: ["mcp"]。
AI 代理执行操作无响应 操作需要用户授权 在 Burrow 的设置中，为相应的操作（如 Clean）启用 “Allow AI agent to perform this action” 选项。
菜单栏图标不显示 应用运行在 Dock 模式 打开 Burrow 主窗口，进入 设置 (Settings)，将 “Menu-bar icon” 选项切换为开启状态。
Windows 版本无法运行 当前为预览版，未签名 需要安装 .NET 8 运行时，或从源码构建。如果遇到 SmartScreen 警告，需手动点击“仍要运行”。

6. 总结

Burrow 是一个功能全面且对开发者友好的系统工具。其核心流程是：通过 Homebrew 安装 → 授予必要的磁盘权限 → 在菜单栏运行 → 使用各工具模块管理您的 Mac。

对于希望深度利用 AI 的用户，可以按照以下路径快速上手 MCP 集成：

  1. 在 Burrow 设置中开启所需操作的 AI 授权。
  2. 在您的 AI 代理配置中添加 Burrow MCP 服务器。
  3. 直接在对话中让代理查询系统状态或执行清理任务（例如：“清理超过 100MB 的缓存”或“分析我的磁盘空间并告诉我如何释放空间”）。
