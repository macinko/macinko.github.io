一、这张卡是什么，值不值得入

Ultra Mobile PayGo 前身是 T-Mobile 的 $3/月套餐，2019 年转给 Ultra Mobile 运营，是目前月租最低的美国原生实体电话卡。走的是 T-Mobile 网络，覆盖美国全境。

套餐内容

$3/月固定月租，套餐内包含：

  • 100 分钟美国通话
  • 100 条短信
  • 100MB 美国流量（仅在美国本土可用）

重要：上述套餐额度必须开启 Wi-Fi Calling 才能在国内使用，否则全部按国际漫游资费计算（接打电话 $3.59/分钟，收短信 $0.1/条）。

能注册哪些服务

可以完美接收银行、券商及社交网站的验证短信，包括：美国银行账户（Chase、Wells Fargo 等）、美区 PayPal、美区 Apple ID、美国 Stripe、Zelle、ChatGPT、Claude、Telegram、WhatsApp、X、Instagram。这是 Google Voice 虚拟号无法替代的核心优势。

插入手机后可被 TikTok 识别为美区号码，用于注册美区 TikTok 账号。

与 Google Voice 的本质区别

Google Voice 是虚拟号码，很多金融服务（如 Zelle、Wells Fargo 短信验证）直接拒绝。PayGo 是美国原生实体号，等同于在美国本地使用一张真实手机卡，接码成功率远高于 GV。

⚠️ 2026 年重要提示

从 2025 年 2 月起，大量 PayGo 套餐在中国激活后 1-2 天内被封，表现为无信号、无法登录官网。入手前务必了解封号风险（详见第十节）。

二、去哪买，怎么不被坑

PayGo 不在国内运营商渠道销售，但买到手其实不难。

主要购买渠道

淘宝、京东、拼多多搜索「Ultra Mobile PayGo」或「美国紫卡」，可以找到含未激活空卡的商品。部分卖家提供代激活服务，收到即插即用。官网或 eBay 也可以下单，但需要美国地址转运，国内新手不推荐。

空卡自激活 vs 代激活卡，怎么选

  • 代激活卡：省事，直接用，适合不想折腾的人
  • 空卡自激活：便宜一点，激活过程自己操作（见第三节）

两个买之前必须问清楚的坑

坑一：激活用的什么 IP？

2025 年封号潮之后，部分代激活卡是用国内 IP 激活的，触发风控概率极高。买之前必须问清楚卖家用什么 IP 激活——正规做法是使用美国住宅 IP，而非机场共享 IP。

坑二：充值不要走卖家代充

自己绑双币信用卡在官网充值更安全，卖家代充存在账号关联风险，出问题责任也不好界定。

号码归属地可以指定吗

不能直接指定号码，但可以通过激活时填写的邮编影响归属地区号。常用邮编参考：

纽约：10008 洛杉矶：90016 西雅图：98104

携号转网激活的可以完全指定号码，风控风险也更低（详见第三节）。

三、激活全流程 SOP

标准激活步骤

① 访问

paygo.ultra.me/activate

，激活过程中请勿使用代理工具，推荐 Chrome 无痕模式（使用美国 IP 激活更安全）

② 输入卡背面 11 位 ACT CODE，点击开始激活

③ IMEI 检测步骤可直接点右上角 Skip 跳过

④ 输入美国邮编分配号码（参考上表），邮编决定号码归属城市区号

⑤ 填写真实长期邮箱（后续找回账号、转 eSIM、接客服邮件都要用，不要用临时邮箱）

⑥ 创建账号密码（务必设置，跳过密码设置是最常见的致命失误，欠费后无法登录后台充值）

⑦ 激活完成，卡内自带 1 个月 $3 月租，到期前记得充值

携号转网激活（推荐）

默认随机分配的号码有可能是其他人用过、注册过很多服务的老号，骚扰电话多。更好的方式是：

  • 在 Google Voice 库里自选一个靓号，转移到 PayGo（GV 转出费用 $3，转入后号码完全归你，可正常接收银行短信）
  • 或在 NumberBarn 平台花 $5–$15 买一个干净号码，携号转入 PayGo（选号时 Plan 记得选 Port Away）

激活后第一时间

✅ 确认账号密码已设置 ✅ 确认邮箱已绑定 ✅ 立即开始 Wi-Fi Calling 设置（见第七节） ✅ 记录下激活邮编、911 地址、绑定邮箱——这些是日后找回账号的关键信息

四、充值全攻略——三种方式怎么选

方式一：官网绑卡自充（推荐）

登录

my.ultramobile.com

，在账单信息里绑定 VISA 或 Mastercard 双币信用卡，国内双币卡可以用。充值面额 $5、$10、$20。

充值报错怎么办： 大概率是 IP 问题，切换节点或下载 Ultra Mobile App 在 App 内充值，成功率更高。

方式二：购买充值卡

在淘宝搜「Ultra Mobile 充值卡」，买虚拟充值码，面额 $5/$10/$20/$30/$50，到账时间 5 分钟至 24 小时。没有美国信用卡、或者充值报错解决不了的用这个方式。汇率约 1:7，比官网直充略贵一点。

方式三：开启自动续费

在官网账户里选择 Auto Renew，绑卡后每月自动扣款 $3。设置好之后最省心，忘记充值断号的风险直接清零。建议自动续费面额设 $5，每月扣完月租还剩 $2 余量慢慢积累，账户始终保持 $5 以上缓冲。

五、激活后必做清单 + 保号 SOP

激活后必做清单

  • ✅ 设置账号密码（最重要，跳过就是埋雷）
  • ✅ 绑定长期真实邮箱
  • ✅ 设定自动续费或提醒充值计划
  • ✅ 充值面额建议 $10 起，账户余额保持 $5 以上缓冲
  • ✅ 记录：激活邮编、Wi-Fi Calling 的 911 地址、绑定信用卡后四位、账户登记美国地址

保号核心

月租 $3/月固定，每月自动扣款。余额归零即断号——这是和 giffgaff 最大的区别，giffgaff 是 0 月租 180 天保号，PayGo 是强制每月扣款。

务必开启自动续费，或在日历里设置每月提醒。预付卡在零余额时仍能维持基础信号，但累计欠费达 60 天将永久停机。

骚扰电话太多怎么换号

发短信 GOGO + 你的邮编 到 6700 申请更换号码，SIM 卡不变，账户余额和密码保留，每年最多更换 2 次。

六、Wi-Fi Calling 是什么，为什么必须开

先搞清楚两套资费逻辑

开了 Wi-Fi Calling：相当于美国本地使用，套餐内 100 条短信 + 100 分钟通话全部可用，收发短信免费。

没开 Wi-Fi Calling：国内漫游资费，套餐额度完全用不上；接打电话 $3.59/分钟，收短信 $0.1/条，发短信 $0.5/条，流量 $0.03/MB。

两套资费差距不是一点点。没开 Wi-Fi Calling 的 PayGo，约等于一张随时在爆炸的定时炸弹。

Wi-Fi Calling 的原理

本质是通过互联网把手机接入 T-Mobile 的美国基站，让系统认为你在美国本地通话。所以只要有 Wi-Fi 或能上网，就能以本地资费收发短信、接打电话。这也是为什么国内 GFW 会干扰它——T-Mobile 的 ePDG 服务器域名被墙，需要额外处理（见第八节）。

哪些设备支持

  • iPhone：5c 及以上机型全部支持，设置路径在「设置 → 蜂窝网络 → Wi-Fi 通话」。双卡 iPhone 记得选插了 PayGo 的卡槽。

  • 安卓：国产机绝大部分不支持，三星、LG 等国际版机型支持，部分华为、小米新机型支持 VoWiFi 可以用。具体机型在

    ultramobile.com

    官网查询。

一句话总结

Wi-Fi Calling 不是可选项，是 PayGo 能不能正常用的开关。卡到手第一件事就是开它。

七、Wi-Fi Calling 设置手把手教程

iPhone 设置步骤

① 插入 PayGo SIM 卡，等待出现信号

② 进入「设置 → 蜂窝网络 → Wi-Fi 通话」，打开「在 iPhone 上用 Wi-Fi 通话」

③ 弹出填写地址的窗口，填入一个真实的美国地址（这是 911 紧急呼叫的默认定位地址，建议填和激活邮编同州的地址，并记录下来备用——客服验证身份时会问这个地址）

④ 提交后等待收到 6700 发来的短信：「您的 Ultra Mobile 帐户启用了 WiFi 呼叫！」

⑤ 收到短信后，再进一次 Wi-Fi 通话菜单重新提交保存一次

⑥ 等待生效，快则几分钟，慢则 24 小时，不要反复开关

安卓设置步骤

先登录 Ultra Mobile 官网或 App，在账户设置里找到 Wi-Fi Calling 选项，在线填写 911 地址提交，等待后台开通。后台开通后再插卡进手机，在手机设置里找到「WLAN 通话」或「Wi-Fi 通话」开启。

建议新激活的卡先在 iPhone 上把 Wi-Fi Calling 状态生效，再换到安卓手机使用，成功率更高。

设置成功的标志

手机顶部信号栏出现「Wi-Fi」字样，或运营商名称旁边显示 Wi-Fi 通话图标。没出现不代表失败，等够 24 小时再判断。

苹果用户注意：iOS 版本要求

需将 iOS 更新到 12.5 或以上版本，否则 Wi-Fi Calling 功能可能无法正常启用。

八、Wi-Fi Calling 进阶排障——图标消失了怎么办

根本原因

国内 Wi-Fi Calling 由于 GFW 封锁无法直接稳定使用。T-Mobile 的 ePDG 服务器域名被墙，手机连上普通家庭宽带后经常连不上，导致图标消失或无法开启。

解决方案一：Clash / Quantumult X 用户（最简单）

在代理软件里添加 IP-CIDR, 208.54.0.0/16 规则，走代理。这样在任何 Wi-Fi 下都能秒开 Wi-Fi Calling，也是外出时最灵活的方案。

解决方案二：路由器方案（最稳定）

在家里 OpenWrt 或梅林固件路由器上加两条 Ultra Mobile 对应的 DNS 规则，让手机连上家庭 Wi-Fi 后自动走正确的 DNS 解析，是最稳定的长期方案。不需要每次手动操作，手机连上家里 Wi-Fi 自动生效。

解决方案三：香港/泰国流量卡热点（最省事）

买一张香港或泰国免翻墙直连外网的流量卡开热点，手机连上这个热点可以秒开 Wi-Fi Calling。对 Wi-Fi Calling 有重度依赖的用户，这是最稳定的方案，实测美国流量卡热点也可以秒开。

换 Wi-Fi 后图标消失的临时处理

换了 Wi-Fi 后顶部 Wi-Fi Calling 标识消失，开启飞行模式等几秒再关闭，通常可以立即恢复。

接码时记得关 VPN

收发短信和通话时最好先关掉 VPN，否则会扣话费余额而不是套餐额度，万一扣一下就是 $3.59 起步。

九、接码能力篇——能收哪些验证码，哪些收不到

可以完美接收的服务

  • 美国银行账户（Chase、Wells Fargo、Bank of America 等）
  • 美区 PayPal、美区 Apple ID
  • 美国 Stripe、Zelle
  • ChatGPT、Claude、Telegram、WhatsApp
  • X（Twitter）、Instagram、TikTok 国际版

Google Voice 做不到但 PayGo 能做到的三个场景

  • Wells Fargo 的短信验证码（GV 收不到）
  • 新设备登录美国 PayPal 时要求添加手机号（GV 被拒）
  • 注册 Zelle（明确不接受 Google Voice 号码）

这三个场景是很多人从 GV 换到 PayGo 的核心原因。

语音验证码也能接

语音前十秒可能没有录制上，但大部分网站会重复播放 2 次以上，不影响使用。

接码时注意事项

收发短信和通话时先关掉 VPN，否则扣话费余额而非套餐额度。确认 Wi-Fi Calling 图标在信号栏显示后再进行接码操作，图标不在就是漫游资费。

十、2025 封号潮——现在还值得入吗

2025 年 2 月起大规模封号

从 2025 年 2 月起，大量 Ultra Mobile PayGo 套餐在中国激活后 1-2 天内被封，表现为无信号、无法登录官网。这不是个例，是系统性问题，且封号后账号基本无法恢复。

根本原因

Ultra Mobile 开始主动识别并限制中国大陆 IP 激活的账号。激活时使用中国 IP，或者激活后长期在国内漫游且没有正常的美国使用记录，都可能触发风控。部分代激活卖家用国内 IP 批量激活，风险更高。

现在入手的建议

若仍然想入手 PayGo：

  • 激活时推荐使用美国 IP（不要用机场共享 IP，用家庭住宅代理更安全）
  • 激活后立即完成 Wi-Fi Calling 设置，建立正常的使用记录
  • 优先考虑携号转网激活，比随机分配号码风险更低
  • 购买代激活卡时建议确认卖家使用美国 IP 激活

备选方案

需要美国电话卡但不想承担封号风险的，可以考虑：

  • Tello：$5/月，无需配置 Wi-Fi Calling 即可在国内使用，稳定性更好
  • Google Voice：免费，但金融类接码能力弱

一句话总结

2025 年的 PayGo 不再是「无脑入」的神卡，入手前务必评估封号风险，做好被封后的备用方案。

十一、eSIM 转换篇——什么时候该转，怎么操作

什么情况下应该转 eSIM

  • 国内丢卡或卡损坏：转 eSIM 比补办实体卡快得多，补卡只能寄美国地址再转运，eSIM 当天就能搞定
  • 手机卡槽不够用：双卡手机同时插国内卡 + PayGo，转 eSIM 直接解放一个卡槽
  • 换手机：eSIM 换设备比实体卡迁移方便，在新手机 App 里重新下载即可

转换前必须确认的事

手机必须支持 eSIM，国内发行的部分机型不支持。转换前在 Ultra Mobile 官网确认设备兼容性。转了之后原实体卡直接作废，不可逆，操作前想清楚。

操作步骤

① 下载 Ultra Mobile 官方 App，登录账户（建议插卡登录，否则可能提示密码错误）

② 进入 Account → Change Device → Get an eSIM

③ 系统生成订单，每年免费转换 2 次，超出收费 $3/次，点击立刻订购

④ 账户绑定的邮箱会收到 eSIM 信息，点击「install my eSIM」

⑤ 跳转至包含 eSIM 信息的二维码，iOS 和 Android 版本分开，扫码添加到手机

⑥ 激活成功后原实体卡自动失效，Wi-Fi Calling 需要在新设备上重新设置一次

也可以联系客服申请：拨打 (888) 777-0446，客服会发送 eSIM 二维码到邮箱，扫码激活。

eSIM 换设备怎么迁移

在新手机下载 Ultra Mobile App，登录账户，进入 Account → Change Device → Switch to an eSIM，重新下载即可，号码和余额全部保留。

注意：eSIM 不给二维码

eSIM 激活必须使用原生支持 eSIM 的手机，通过刷入或第三方工具写入小白卡的方式无法完成 PayGo eSIM 下载。

十二、欠费断号急救篇——号没了不一定真的废了

欠费断号的机制

预付卡在零余额状态下仍能维持基础信号，但当累计欠费达 60 天时将永久停机。也就是说，欠费后你有 60 天的救援窗口期，超过才是真的没了。

救号步骤

充值 $10 后，欠费账户会在半小时内自动补扣月租费 $3 并恢复信号。建议账户余额始终保持 $5 以上作为缓冲。

没有设置过账号密码怎么充值

可以通过虚拟号平台代充值，只需提供 PayGo 号码，无需密码直接充值，到账时间 5 分钟至 24 小时。充值成功后再登录官网设置密码。

欠费超过 60 天怎么办

超过 60 天永久停机后，号码无法恢复。唯一能做的是重新购买一张新卡，把绑定在旧号上的服务逐一换绑到新号。这也是为什么务必开启自动续费的原因。

十三、卡丢失/损坏急救 + 激活时必须做的 5 件事

补卡流程（2025 年 3 月起）

从 2025 年 3 月起可以通过客服补办实体卡：

  • 补卡要求：账户不处于欠费状态，且记得官网密码
  • 补卡费用：在官网充值 $13 后，客服 3 个工作日内处理
  • 收货时间：完成验证后 2 天内寄出新卡，收到后插卡即恢复原号码和余额
  • 重要限制：新 SIM 卡仅支持寄送至美国境内地址，需要额外支付转运费用（约 $40，耗时约 1 个月）

在国内丢失的，最省事的方案是直接转 eSIM——联系客服把号码迁移到 eSIM，比等实体卡邮寄快得多。

联系客服时需要准备的验证信息

客服可能需要你提供以下信息来确认号码归属：

  • 最近拨打过的 5 个号码
  • 官网账户登记的姓名和美国地址
  • 账户绑定邮箱
  • 绑定信用卡后四位
  • Wi-Fi Calling 设置的 911 地址
  • 最近三次充值时间与金额

激活时必须做的 5 件事（出问题时能不能救回来，全靠这 5 步）

① 设置账号密码：跳过密码设置是最常见的致命失误，欠费后无法登录，什么都做不了 ② 绑定真实长期邮箱：找回账号、转 eSIM、接客服邮件都要用 ③ 记录 Wi-Fi Calling 的 911 地址：客服验证身份时会问，不记得就是失去这条验证路径 ④ 记录账户登记的美国地址：补卡或联系客服时需要提供 ⑤ 开启自动续费，保持 $5 以上余额：最省心的长期保号方式

十四、PayGo vs Tello——两大美卡一次说清楚

月租： PayGo 是 $3/月，Tello 是 $5/月。

国内使用门槛： PayGo 必须配置 Wi-Fi Calling，Tello 无需配置，直接可用。

短信额度： PayGo 套餐内 100 条，需要开 Wi-Fi Calling；Tello 是无限量收发。

通话： PayGo 是 100 分钟美国通话；Tello 是 100 分钟，含全球 60+ 国家，包括中国。

号码质量： PayGo 随机分配，可能是老号；Tello 是 T-Mobile 实体线路，骚扰电话较少。

上手难度： PayGo 偏高，必须配置 Wi-Fi Calling；Tello 偏低，插卡即用。

Tello 的核心优势

无限量短信收发全部免费，100 分钟通话包含全球 60 多个国家含中国，均免费，适合有一定通话需求的用户。最关键的是——不需要开 Wi-Fi Calling 就能在国内直接收发短信和打电话，省去了最麻烦的那一步设置。

PayGo 的核心优势

月租只要 $3，比 Tello 便宜 $2，一年省 $24。如果只是需要一个美国号码接收银行验证码、偶尔注册服务，根本用不上 Tello 多出来的功能，多花的钱纯属浪费。

怎么选

  • 主要用途是保号 + 接验证码，对通话没需求 → PayGo
  • 需要频繁打电话（尤其是打回国内）、不想折腾 Wi-Fi Calling → Tello
  • 两张都想要 → 先入 PayGo，用到需要打电话再考虑 Tello

十五、终极进阶——用这张 +1 号享受完整美国服务体系

很多人入手 PayGo 只是为了接码，但这张 +1 号能做的远不止于此。

六步搭建路径

Step 1：用 PayGo 的 +1 号码注册美区 PayPal

Step 2：用美区 PayPal 绑定美国银行账户或美国虚拟信用卡

Step 3：用美国号码 + 美区 PayPal 注册美区 Apple ID

Step 4：把海外服务号码都换成美国的，不能换的用美国号另注册一个备着

Step 5：订阅 Claude、ChatGPT 等，直接用美区 Apple ID + 美区 PayPal 支付，不挑卡、不拒付，封号退款快

Step 6：有条件的逐步扩展到美国银行卡（如 Wise、Mercury 等）

与 giffgaff 英国号的配合

PayGo（+1 美国号）和 giffgaff（+44 英国号）定位不同，覆盖的平台基本不重叠：

  • PayGo 主攻：美国银行、美区 PayPal、美区 Apple ID、美国 Stripe、Zelle
  • giffgaff 主攻：英区 PayPal、WhatsApp、Telegram、各类跨境注册服务

两张合计年成本约 ¥400 左右，搭建出完整的英美双号体系，基本覆盖所有主流海外服务场景。
