项目是什么

这是一个信息聚合导航项目，它收集并整理了多个提供免费 API 额度的 AI 中转站和公益站。您可以把它看作一个“福利情报站”，通过它快速找到当前可用的免费资源并完成注册配置，从而免费使用 Claude Code、Codex 等 AI 编码工具。

核心功能：

  • 聚合信息：统一展示各站点的免费额度、模型、状态和注册链接。
  • 自动化数据：通过脚本自动抓取站点公开数据，更新额度与模型信息。
  • 一键配置：提供交互式脚本，快速为 Claude Code 配置环境变量。

1. 选择并注册一个福利站
从上方表格或项目 README 中点击一个站点的注册链接（务必通过邀请链接注册，才能拿到额外赠送的额度）。按站点要求完成注册（通常支持 GitHub 或邮箱）。

项目数据流向：

  • data/sites.json：人工维护的站点主数据（名称、链接、配置模板）。
  • data/live.json：脚本自动抓取的实时快照（额度、模型、在线状态）。

常见问题

注册后看不到额度？

  • 退出账号，重新登录一次，额度通常在登录时结算。
  • 部分站点余额显示有延迟，稍等片刻或刷新页面。

Claude Code 报 401 Unauthorized？

  • 检查 Base URL 是否正确（Anthropic 协议不要加 /v1）。
  • 确认 API Key 完整且已激活。
  • 检查模型名称是否在站点的可用列表中。

请求返回 400 内容拦截？

  • 部分站点只允许中/英/法/德/俄语，请检查输入内容。

我之前登录了 Claude Pro，会冲突吗？

  • 环境变量优先级高于本地登录。要切回官方订阅，执行 unset ANTHROPIC_BASE_URL ANTHROPIC_AUTH_TOKEN ANTHROPIC_MODEL 并重开终端。

免责声明与安全提示

  • 邀请链接：本页所有注册链接均为邀请链接，通过它注册双方均可获得站点奖励，不影响您的注册流程和应得额度。
  • 信息聚合：本项目仅为信息导航，与各站点无隶属关系，不承诺任何站点的可用性、稳定性或额度真实性。公益站随时可能调整规则或关停。
  • 数据安全：请勿将生产密钥、敏感隐私数据、企业专有代码上传至来源不明的第三方中转服务。重要项目请使用官方 API。
  • 遵守条款：请遵守各站点及上游模型服务商的使用条款，禁止批量注册、刷量、转售额度等行为，违规账号将被封禁。
