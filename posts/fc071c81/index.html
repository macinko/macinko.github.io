🧭 核心功能与特点

PyTube Downloader 旨在提供一个简单、快速且功能全面的 YouTube 媒体下载体验。其核心特点包括：

  • 格式与质量选择：支持从 144p 到 8K 的视频质量，以及 MP4、MP3 等多种格式。
  • 播放列表下载：支持直接粘贴播放列表链接进行批量下载。
  • 多任务并行：支持同时下载多个视频，提高效率。
  • 自动下载模式：可预先设置好质量、格式和保存位置，之后一键快速下载。
  • 动态文件夹组织：可自动按播放列表、质量或类型分类保存文件。
  • 跨平台支持：可在 Windows、Linux 和 macOS 上运行。
  • 多语言界面：支持英语、中文、僧伽罗语、泰米尔语和俄语。

1. 前提要求

🚀 使用指南

  1. 启动应用：运行上述命令后，会打开 PyTube Downloader 的图形界面。
  2. 输入链接：在主界面的输入框中，粘贴一个 YouTube 视频或播放列表的 URL。
  3. 选择模式：根据输入内容，选择“单视频”或“播放列表”模式。
  4. 选择格式与质量：从下拉菜单中选择你需要的输出格式（如 MP4）和视频质量（如 1080p）。
  5. 开始下载：点击“下载”按钮。应用会解析链接并开始下载，进度条会显示实时进度。
  6. 查看文件：下载完成后，文件会保存在你设定的输出文件夹中（默认为项目目录下的 Downloads 文件夹）。

⚙️ 高级功能与配置

  • 自动下载设置：你可以在设置中预设默认的视频质量、音频格式和下载位置。之后，只需粘贴链接并点击“自动下载”，应用就会使用这些预设快速开始下载。
  • 动态文件夹整理：在设置中开启此功能后，下载的文件会自动按播放列表名称、视频质量或文件类型（视频/音频）分类到不同子文件夹中。
  • 键盘快捷键：应用支持一些快捷键，方便快速操作（具体可在应用内的“帮助”或设置中查看）。
  • 日志与调试：应用会生成结构化的日志文件（位于 logs/ 目录），便于排查问题。

❓ 常见问题与注意事项

  • 下载失败或解析错误：YouTube 可能会频繁更新其内部 API，导致 pytubefix 库需要更新。请确保已安装最新版本：pip install --upgrade pytubefix。
  • FFmpeg 未找到：如果下载视频时提示缺少 FFmpeg，请确保它已正确安装并放置在系统 PATH 或项目指定的 ffmpeg/ 目录中。
  • Windows 依赖问题：win11toast 和 hPyT 是 Windows 专用的可选依赖，用于通知等功能。在 Linux/macOS 上运行时，这些不会影响核心下载功能。
  • 法律与使用政策：项目声明仅限个人使用，请尊重 YouTube 服务条款 和内容创作者的版权。

总结

PyTube Downloader 为喜欢图形界面操作的 YouTube 视频下载用户提供了一个便捷工具。部署的核心是确保 Python 环境和 FFmpeg 正确安装，然后通过 pip install -e . 快速设置。其丰富的质量选项和并行下载能力使其成为日常使用的实用工具。如果遇到解析问题，优先检查并更新 pytubefix 库。项目采用 MIT 许可证，欢迎社区贡献。
