Narrator AI CLI Skill 详细部署教程

Narrator AI CLI Skill 是一个为 AI 编程助手（如 Claude Code、OpenClaw、Windsurf 等）设计的技能包，它能教会您的 AI 助手如何使用 narrator-ai-cli 工具，从而全自动地完成电影解说视频的创作。您只需用自然语言提出要求，AI 就会处理从搜索素材、选择模板到合成视频的全部流程。

Narrator AI CLI Skill 是什么

这是一个技能文件（SKILL.md 及其配套的 references/ 参考文档），它本身不包含任何可执行代码，而是为 AI 智能体提供了一套清晰的“操作说明书”。

核心关系：

  • narrator-ai-cli (CLI 工具)：这是真正干活儿的“手”。它是一个 Python 命令行工具，负责调用后端 API 来搜索电影、选择模板、合成视频等。
  • narrator-ai-cli-skill (技能包)：这是 AI 的“大脑”。它教会 AI 何时、以及如何使用 CLI 工具的各种命令来完成视频创作任务。

简单来说，您需要同时部署 CLI 工具和 Skill 技能，您的 AI 助手才能完整地执行视频制作任务。

工作流程概览

当您对 AI 说“帮我制作一个《肖申克的救赎》的解说视频”时，AI 会按照 Skill 的指引执行以下步骤：

  1. 搜索电影：使用 CLI 工具搜索可用的电影素材。
  2. 选择模板：根据您的风格要求（如“喜剧风格”），从 90+ 种解说模板中选择。
  3. 选择背景音乐 (BGM)：从 146 首内置 BGM 中挑选合适的音乐。
  4. 选择配音：从 63 种不同的配音声音中选择。
  5. 生成脚本：AI 根据电影信息和模板生成解说脚本。
  6. 合成视频：调用 CLI 工具合成最终视频。
  7. 返回结果：将生成的视频下载链接返回给您。

部署前准备

1. 安装 Python 环境

  • 需要 Python 3.10 或更新版本。您可以在终端运行 python --version 检查。

2. 获取 API 密钥

  • 该项目需要有效的 API 密钥才能工作。
  • 获取方式：发送邮件至 merlinyang@gridltd.com 联系获取。邮件中请说明您的使用场景。

在 AI 助手中安装 Skill

Skill 由 SKILL.md 文件 和 references/ 参考目录组成，两者都需要安装到您的 AI 助手的技能目录中。

推荐方法：使用 git clone
直接克隆整个仓库到您 AI 助手的技能目录中，这样能确保文件结构完整。

根据不同 AI 助手，选择对应的安装路径：

AI 助手 安装命令 (在终端中执行)
OpenClaw mkdir -p ~/.openclaw/skills git clone https://github.com/NarratorAI-Studio/narrator-ai-cli-skill.git ~/.openclaw/skills/narrator-ai-cli
Windsurf / Claude Code (项目级) mkdir -p /path/to/your/project/.skills git clone https://github.com/NarratorAI-Studio/narrator-ai-cli-skill.git /path/to/your/project/.skills/narrator-ai-cli
Cursor mkdir -p /path/to/your/project/.cursor/rules git clone https://github.com/NarratorAI-Studio/narrator-ai-cli-skill.git /path/to/your/project/.cursor/rules/narrator-ai-cli
WorkBuddy / QClaw (腾讯) 通过技能管理界面上传 SKILL.md 和整个 references/ 文件夹，保持目录结构不变。
任何支持 Markdown 技能的 Agent 将仓库克隆到您的智能体可读取的技能目录中，或直接指向 SKILL.md 文件。

💡 提示：如需更新 Skill，只需进入克隆的目录 (narrator-ai-cli)，执行 git pull 即可。

使用示例

安装完成并重启 AI 助手后，您就可以用自然语言下达指令了。

基础用法：

“帮我给《肖申克的救赎》制作一个解说视频。”

指定风格：

“用喜剧风格的模板，给《泰坦尼克号》做一个解说视频。”

批量生成：

“为《阿甘正传》、《盗梦空间》和《星际穿越》这三部电影各生成一个解说视频。”

查询资源：

“显示一下目前有哪些可用的电影素材？”

AI 助手会根据您的指令，自动调用 CLI 工具完成所有步骤，并最终返回视频的下载链接。

更新与卸载

更新

  • 更新 Skill：进入 Skill 克隆目录（如 ~/.openclaw/skills/narrator-ai-cli），运行 git pull。
  • 更新 CLI：重新运行安装命令 pip install "narrator-ai-cli @ git+https://github.com/NarratorAI-Studio/narrator-ai-cli.git" --upgrade。

卸载

  1. 移除 Skill：直接删除克隆的 Skill 目录即可。
  2. 移除 CLI (可选)：运行 pip uninstall narrator-ai-cli。
  3. 清除配置 (可选)：手动删除 CLI 创建的配置文件（通常位于用户目录下的 .config/narrator-ai-cli/）。

常见问题排查

问题：AI 助手找不到 Skill。

  • 解决：确认 Skill 已安装在正确的目录下，并且目录结构包含 SKILL.md 和 references/ 文件夹。重启 AI 助手会话。

问题：CLI 命令执行失败，提示未找到命令。

  • 解决：确认 narrator-ai-cli 已成功安装，并且其安装路径（通常为 Python 的 bin 目录）已添加到系统 PATH 环境变量中。

问题：视频生成任务失败。

  • 解决：
    1. 检查 API 密钥是否有效且余额充足。
    2. 查看 CLI 返回的错误信息。Skill 的 references/ 文档中包含了 18 种 API 错误码的说明和应对建议。
    3. 确认您选择的电影、模板等资源确实存在且可用。

通过以上步骤，您应该能够成功部署 Narrator AI CLI Skill，让您的 AI 助手获得一键生成电影解说视频的强大能力。如需获取最新的 API 密钥或查看详细的资源列表，请参考项目 README 中的联系方式。
