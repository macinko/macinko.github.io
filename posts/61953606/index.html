career-ops 旨在帮助你高效筛选职位、定制简历并跟踪申请进度

更新于2026-09-13|aitool
|总字数:1.5k|阅读时长:4分钟|浏览量:

📋 准备工作

在开始前，请确保你的系统满足以下要求：

  • Node.js：需要安装 Node.js（npx 命令会随 Node.js 一起安装）。
  • AI 编程 CLI：你需要安装并配置好一个支持的 AI 编程命令行工具，例如 Claude Code、Codex、OpenCode、Antigravity (Gemini) 或 Grok Build CLI 等。career-ops 将运行在这些 CLI 环境中。
  • （可选）Playwright：用于 PDF 生成和某些自动化任务，安装过程中会提示。

career-ops 的部署和配置过程主要通过命令行和 AI 对话完成。

第二阶段：初始配置

career-ops 的设计理念是通过与 AI 对话来完成配置，而不是手动编辑大量文件。

  1. 启动你的 AI 编程 CLI：在 career-ops 目录下，输入命令启动你常用的 AI 编程工具，例如：

  2. 首次启动引导：在 AI CLI 中，career-ops 会通过对话引导你完成初始设置。你只需要根据提示，在聊天框中提供以下信息：

    • 你的简历：可以直接粘贴 cv.md 文件的内容，或让 AI 帮你创建。
    • 个人资料：包括你的姓名、联系方式、目标职位等。
    • 目标角色：你希望申请的职位类型（如 “后端工程师”、”AI 产品经理”）。

    核心原则：你不需要手动编辑配置文件。直接告诉 AI 你的需求，例如：“请根据这份简历更新我的个人资料” 或 “将目标岗位类型改为前端开发”。

🎯 基本使用方法

career-ops 的核心功能通过 AI 对话中的斜杠命令（/career-ops）触发。注意：部分 CLI（如 Codex）可能不支持斜杠命令，此时直接用自然语言描述要执行的任务即可。

以下是几个最常用的命令：

功能 斜杠命令 / 自然语言示例 说明
评估一个职位 /career-ops https://company.com/jobs/123 或 评估这个职位：https://company.com/jobs/123 对单个职位进行深度评估，生成 A-H 结构化报告和评分，并自动添加到追踪列表。
扫描职位看板 /career-ops scan 或 运行 career-ops 扫描模式 扫描 portals.yml 中配置的公司和职位看板，发现新的职位机会。
生成定制简历 /career-ops pdf 或 为最新的评估职位生成 PDF 简历 根据之前评估的某个职位，生成一份定制化的、ATS 优化的 PDF 简历。
查看申请追踪 /career-ops tracker 或 显示当前申请状态汇总 在终端或对话中展示一个包含所有申请状态、评分和备注的追踪看板。
生成求职信 /career-ops cover 或 为 [职位名称] 生成求职信 为特定职位生成一份定制化的求职信。
深度研究公司 /career-ops deep 或 研究 [公司名] 的 AI 战略和文化 生成一份结构化的研究提示，帮助你对目标公司进行深入调研。

⚙️ 进阶配置与自定义

  • 定制化你的系统：你可以直接用自然语言告诉 AI 来修改 career-ops 的行为。例如：“请将评估标准中的‘薪资’权重调高”或“把扫描的默认公司列表换成欧洲的科技公司”。AI 会帮你修改对应的配置文件（如 modes/_shared.md）。
  • 使用外部数据目录：默认情况下，你的个人数据（如简历、追踪记录）存放在项目目录下。你可以通过设置环境变量 CAREER_OPS_ROOT 来指定一个独立的个人数据目录，方便与代码库分开管理和备份。
  • 运行在预算内：career-ops 支持通过 OpenRouter 使用免费模型，或接入 Ollama 等本地模型，以降低 API 调用成本。详见 docs/RUNNING_ON_A_BUDGET.md。

🔧 故障排查与重要提示

  • API 计费问题：如果你已订阅 Claude Pro/Max，但发现 career-ops 在消耗 API 积分，很可能是环境变量 ANTHROPIC_API_KEY 覆盖了登录凭证。请检查并移除该环境变量，然后重新登录。
  • Windows 用户：请参考 docs/WINDOWS.md 获取特定于 Windows 的安装和配置指南，如 Git Bash 配置和换行符问题。
  • 核心原则：career-ops 是一个筛选和辅助工具，它永远不会自动为你提交申请。所有生成的简历、求职信和邮件都需要你亲自审核并手动提交。这个“人类最终决策”的设计是其核心理念。

通过以上步骤，你就成功部署并可以开始使用 career-ops 来优化你的求职流程了。它的强大之处在于通过 AI 将琐碎的信息收集和初步筛选工作自动化，让你能专注于最有价值的申请机会。
