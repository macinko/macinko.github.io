Lyca Mobile AT&T号码，中国可激活，$15用3个月，还能返32

更新于2026-09-05|globalsim
|总字数:2.5k|阅读时长:7分钟|浏览量:

最近有几位宝宝都在问小猫美国手机号的问题，说实话哦。美国手机号小猫当时就写过一期Google Fi的教程，但是寿命就2-3天。平台直接从0元门槛直接抬价$20/月的门槛，然后就一直没发现正规的美国手机运营商号码。今天给大家讲的是一个比较适合短期使用的美国手机号：Lyca Mobile。

这张卡目前有一个比较有意思的优惠：

15 美元可以用 3 个月，相当于每个月 5 美元，同时还能通过 返利平台 返 32.32 美元。

如果想多赚一点，也可以选择它的 **12.5 美元/月套餐。**目前返现额度接近 20 美元，意思就是买了套餐还能赚$20🤣。

不过小猫先提醒一下，这张卡我之所以把它定义成“短期可用”，主要还是因为促销结束之后，正常套餐价格会比较高，所以不太适合长期放在中国国内保号。

但它有一个比较实用的地方：Lyca Mobile 使用的是 AT&T 网络，所以如果你刚好需要一个美国手机号去参加一些特定活动，或者后面需要做携号转网，这张卡就值得留意一下。

比如之前比较火的 Metro 手机活动，如果你想通过携号转网去参加，就可以临时准备一个 Lyca Mobile 的号码。

另外，如果通过特定活动购买手机，像之前提到的 Pixel 系列优惠，使用外网手机号参与活动也是一种思路。

所以，如果你只是临时需要一个美国手机号来注册账号、接收短信，或者准备拿它去做携号转网参加活动，这张卡还是挺合适的。

下面小猫就把从购买到激活的整个流程给大家从头到尾讲一遍！

一、先去 返利平台 看返利

小猫这里建议大家第一步先看一下活动页面，确认返利活动是真实存在的，再去购买。

首先我们先打开返利平台：

www.topcashback.com/ref/member845786218142

（复制后将点换成“ . ”）

返利平台不止手机套餐可以返利，搜索“VPN”还能看到返利105%的VPN。相当于白耗1-2年的VPN使用，但是这里有个问题。VPN官方有写30-45天可退款的，那么你的返利就不会很快到账。需要退款期过了之后才会有返利哦！

然后在顶部的搜索栏 输入 “ Lyca Mobile ”

显示下图内容点击进去

二、在 打开的页面里 选择 Lyca Mobile 套餐

进入活动页面之后，就可以看到目前的返利金额。

如果你和小猫一样，准备选择 12.5 美元/月的套餐，那么直接点击对应的红色按钮就可以跳转到 Lyca Mobile。

如果你想选择的是 3 个月 15 美元这个套餐，就需要注意一下活动页面里面的套餐选项。

找到写着：

3 Months for $15
15 美元，3 个月的时间

的那个活动。

这个套餐同样可以获得 32.32 美元返现。

小猫这里当时选择的是 12.5 美元/月的套餐。

这个套餐就在下面的位置，是一个无限流量套餐，每个月 12.5 美元。

如果你人本身就在美国，其实也可以考虑一下这个套餐，具体值不值得用，还是要根据自己的需求去算。

三、跳转到 Lyca Mobile 购买手机号

这里就以 3 个月 15 美元的套餐为例。

点击之后，会直接跳转到 Lyca Mobile 的套餐页面。

这里可以看到，原本这个套餐的价格是 23 美元，现在活动价是：

3 个月 15 美元。

也就是平均下来一个月只需要 5 美元。

这个价格还是非常合适的。

接下来我们选择 eSIM。

然后选择一个新的 Lyca Mobile 手机号码。

把个人信息填写好，最后完成支付就可以了，整个过程还是比较简单的。

四、支付成功后安装 eSIM

支付完成之后，你会收到一封邮件。

邮件里面会有用于安装 eSIM 的二维码。

另外，在支付成功的页面里，也会看到对应的二维码。

所以这里一定要注意：

你的手机需要支持 eSIM。

小猫自己是把这张卡安装在 Pixel 手机上的。

如果你的手机不支持 eSIM，那就可以考虑购买一张支持 eSIM 的实体转换卡，具体怎么操作，可以根据自己的手机型号来选择。

之前小猫也写过不少关于 eSIM 转换卡的教程，大家可以自己找一下适合自己设备的方案。

五、安装完成之后是什么样？

安装成功之后，就可以在手机的 SIM 卡设置里面看到 Lyca Mobile。

大家可能会发现，刚开始手机是没有网络的。

这个不是卡有问题，你要看一下自己的移动数据有没有自动关闭了。

把移动数据重新打开之后，就可以看到 5G 信号。

这张 Lyca Mobile 的卡在小猫测试的时候，是可以在 Pixel 手机上正常显示 5G的。

六、登录 Lyca Mobile APP 查看套餐

小猫当时是把 Lyca Mobile APP 安装在 iPhone 上的，并不是安装在 Pixel 手机上，所以就不用用截图给大家展示了。小猫继续用文字口述。

使用激活之后的 Lyca Mobile 手机号，就可以登录 Lyca Mobile APP。

登录进去之后，可以看到自己的套餐详情。

这里有一个比较重要的东西：

Credit 余额。

小猫当时这个账户里面有 10 美元 Credit。

也就是说，你虽然购买这个手机号花了 12.5 美元，但账户本身还有一定的余额，可以用于一些付费操作。

七、关于中国国内使用流量的问题

这里还有一个比较奇怪、同时也比较值得测试的地方。

小猫人不在国内无法进行国内网络测试，

那么只能让国内的宝宝们去测试啦。

所以这里小猫也不敢给大家下一个绝对的结论：

这个无限流量套餐在中国国内到底有没有一定额度的免费流量，我目前并不能完全确定。

按照 Lyca Mobile 官网的信息，它的 50GB 流量主要是美国境内使用，而电话和短信则支持中国漫游。

所以中国国内的移动数据到底是什么规则，那小猫目前也不清楚啦！

八、Lyca Mobile 一个非常好用的地方：携号转网信息直接查看

这个也是小猫比较喜欢 Lyca Mobile 的一个地方。

我们刚才说到，如果你准备参加 Metro 或者其他运营商的携号转网活动，就需要准备两个非常重要的信息：

Account Number

和

PIN Number

也就是账户号码和转网 PIN。

很多美国运营商如果想拿到这些信息，需要联系客服，通过在线聊天或者电话才能获取。

但 Lyca Mobile 比较方便的一点就是：

登录它的 PC 端后台之后，可以直接在账户管理里面查看 Account Number 和 PIN Number。

这样就省去了联系客服沟通的麻烦。

尤其是如果你的英语口语不是特别好，或者本身就不想和美国客服在线聊天，这个功能还是非常方便的。

所以小猫觉得 Lyca Mobile 有两个地方比较实用：

第一，通过 TopCashback 买卡还能拿返利。

第二，Account Number 和 PIN Number 可以比较方便地获取，后面做携号转网会方便很多。

九、看看它使用的 IP

接下来再看看移动数据对应的 IP。

这次测试下来，显示的是 AT&T 的 IP。

因为这是移动网络产生的 IP，所以它本身就属于运营商移动网络的 IP。

再来看 ASN：

AS7018

这个 ASN 属于 AT&T。

从这次小猫实际测试的结果来看，这个 IP 的网络属性还是比较漂亮的。

也就是说，如果你在中国国内确实可以正常使用这张卡的移动数据，那么它除了可以用来注册账号、接收短信之外，在某些需要美国移动网络环境的场景里，也可能会比较有用。

最后叨叨一下啊

这次小猫测试的 Lyca Mobile，比较适合的是：

短期美国手机号需求。

比如：

  • 临时注册美国账号
  • 接收短信验证码
  • 准备做美国手机号携号转网
  • 参加部分需要美国手机号的活动
  • 临时需要一张美国运营商号码

目前这个活动比较吸引人的地方，就是：

3 个月 15 美元，平均一个月 5 美元。

同时通过 TopCashback 购买，还可以获得 32.32 美元返现。

如果选择 12.5 美元/月的套餐，也有对应的返现活动。

不过小猫还是那句话：

它更适合短期使用，不太适合当成中国国内长期保号卡。

因为促销结束以后，正常套餐价格会比较高。

如果你只是想临时弄一个美国手机号，又刚好需要拿这个号码去做携号转网，那么 Lyca Mobile 这张卡还是可以关注一下的。
