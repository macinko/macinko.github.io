DevSpace 详细部署教程：把 ChatGPT 网页版变成 Codex

DevSpace 是一个自托管的 MCP 服务器，能让 ChatGPT 网页版直接读写、搜索和运行你电脑上的本地项目代码，相当于把网页版 ChatGPT 变成 Codex 风格的编程助手。它的核心价值在于让 ChatGPT 网页版的模型能力（包括 GPT-5.5 Pro）和独立额度可以直接用于本地开发工作。

本教程将带你从零开始，在 macOS、Linux 或 Windows 上完成 DevSpace 的完整部署。

第一步：准备工作与环境检查

DevSpace 对运行环境有明确要求，请先确认你的系统满足条件。

1. 系统与软件要求

平台 支持状态 必备条件
macOS / Linux 完全支持 Node.js、npm、Git、Bash
Windows (Git Bash / WSL) 支持 Node.js、npm、Git、Git Bash (推荐) 或 WSL
Windows (PowerShell / cmd) 暂不支持 需先安装 Git Bash 或使用 WSL

关键版本要求：

  • Node.js：版本需 >=22.19 且 <27，推荐使用 Node 22 LTS。
  • Git：需要可用命令行。
  • Bash：兼容的 Shell 环境。

第四步：初始化 DevSpace

打开新的终端窗口（Windows 用户继续使用 Git Bash），运行初始化命令。DevSpace 会询问你几个问题。

根据提示进行配置：

  1. 使用场景：选择 ChatGPT、Coding Agents 或 Both（两者都选）。
  2. 允许访问的本地项目目录（关键！）：
    • 输入你允许 ChatGPT 操作的本地文件夹路径。
    • 务必保持范围狭小，例如只指定一个专门用于测试的项目文件夹，而不要选择整个用户目录或系统盘。
    • 路径示例：
      • macOS/Linux: /Users/你的用户名/Projects/test-project
      • Windows (Git Bash 风格): D:/Work/my_projects 或 /c/Users/你的用户名/dev
    • 如果有多个目录，用逗号分隔。
  3. 本地端口：通常保持默认 7676。
  4. 公网 HTTPS Base URL：
    • 粘贴你在第三步中从 Cloudflare Tunnel 获取的公网地址（例如 https://随机字符串.trycloudflare.com）。
    • 注意：这里不要添加 /mcp 后缀。

初始化完成后，终端会打印一个 Owner Password。请务必记录下这个密码，它稍后用于在 ChatGPT 首次连接时进行身份验证。这个密码也会保存在 ~/.devspace/auth.json 文件中。

第六步：连接 ChatGPT 网页版

现在，将 DevSpace 连接到你的 ChatGPT 网页版。

  1. 打开 ChatGPT 网页版，点击左下角的个人头像，进入 “Settings” (设置)。
  2. 找到 “Developer” (开发者) 或 “MCP” (模型上下文协议) 相关设置选项。
  3. 点击添加新的 MCP Server 或 Custom App。
  4. 填写连接信息：
    • URL (地址)：填写你完整的 MCP 端点地址，即公网 HTTPS 地址 加上 /mcp 后缀。
    • 例如：https://随机字符串.trycloudflare.com/mcp。
    • Name (名称)：可随意填写，如 DevSpace-Local。
  5. 保存连接配置。ChatGPT 会尝试建立连接。
  6. 批准连接：在连接过程中，DevSpace 会在本地终端或自动打开的浏览器页面中显示一个 Owner password 审批页面。输入你在第四步中记录下的 Owner Password 来完成批准。

第七步：验证与使用

连接成功后，你就可以在 ChatGPT 网页版的对话中操作本地代码了。

  1. 打开工作区：首先，你需要让 ChatGPT 打开一个你允许的本地项目目录。例如，发送指令：

    “打开项目：D:/Work/my_projects“ (请替换为你的路径)

  2. 开始协作：一旦工作区打开，ChatGPT 就可以执行以下操作：

    • 读取和理解：阅读项目文件、README、代码结构。
    • 搜索和编辑：查找特定代码，并直接在你的本地文件中进行修改。
    • 运行命令：执行测试、构建、Git 操作等 Shell 命令。
    • 遵循项目指引：读取并遵循项目中的 AGENTS.md 或 CLAUDE.md 文件。

  3. 安全提示：请将 ChatGPT 视为一个可以操作你机器的可信编程伙伴。始终注意你授予了哪些目录的访问权限，并留意它的操作。

总结与注意事项

通过以上步骤，你已经成功将 ChatGPT 网页版打造成了能够直接操作本地代码的强力助手。这相当于将 ChatGPT 网页版的额度与模型能力（如 GPT-5.5 Pro）复用到了编程场景中。

重要提醒：

  • 成本与合规：使用 DevSpace 本身是合规的 MCP 连接方式。但你的使用行为仍需遵守 OpenAI 的《使用政策》。
  • 安全第一：永远只允许 AI 访问你明确授权的、不包含敏感信息的项目目录。
  • 隧道稳定性：Cloudflare Tunnel 的免费临时地址会在每次重启后改变。若需长期稳定地址，可考虑使用自己的域名或付费隧道服务。
