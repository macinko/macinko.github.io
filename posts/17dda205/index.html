德国 O2 eSIM 全网最细通关手册（4.99€开卡 + Wise 自动保号）

更新于2026-09-19|globalsim
|总字数:3.1k|阅读时长:9分钟|浏览量:

先说结论，别往下划才发现自己条件不够：

• 现在不是 0 元开卡。官网 Prepaid Basistarif 一次性 4.99€，同时送 5€ 启动余额，0 月租、无合约。

• 中国护照可以过 IDnow。

• 德国沃达丰、格鲁吉亚 eSIM 这类口子，最近一批一批在关。O2 这个窗口也在收，能办就现在办。

• 这张号不是拿来天天打电话的，是给后面的海外基建、、账户、U卡、撸毛、收款、交易所、AI 账号、社媒矩阵留一条德国原生线。

我自己刚把全流程走完：下单 → 4.99 付款 → IDnow 扫证 + NFC + 视频自拍 → 出 eSIM 码 → 登录 Mein O2 → 发短信拿保号 IBAN → Wise 设自动转 0.01€。下面每一步都按屏幕上的真实页面写。

为什么还值 4.99€

以前那波教程还在写「0 元白嫖」。那是半年前的事了。官网现在写得很清楚：Basistarif 一次性 4.99€，含 5€ Startguthaben，无月租。

账算明白：

贵吗？对比一张后面能用两三年的 +49 德国大网号，不贵。Vodafone 德国对网络环境和支付越来越挑，格鲁吉亚那类 eSIM 也一批批失效。O2 现在还能过，指不定下个月就加视频客服或砍掉护照通道。

这张号我自己会拿来干什么：欧洲银行账户/欧卡/德区apple商店/部分券商短信等，最重要的是准备开的高质量U卡Bybit欧卡；ChatGPT、Claude、Telegram、部分交易所二次验证；iMessage / FaceTime；国内用 Wi‑Fi Calling 收短信，不走国际漫游。

它不是流量卡。别拿它当旅行网，那是另一件事。

开卡前准备（少一样都容易卡）

必须有

\1. 有效中国护照（信息必须和后面填的拼音、生日一字不差）

\2. 能收信的 Gmail / 常用邮箱

\3. 一张能过 3DS 的 Visa / Mastercard（PayPal 有时也行，我走的卡）

\4. 一个德国地址：谷歌地图搜柏林 / 慕尼黑住宅区，抄邮编、街道、门牌。eSIM 不邮寄，这个地址只要像真的

\5. 相对稳定的网络。德国住宅 IP 最稳，美国住宅很多人也过了。全程别来回切国家

强烈建议：电脑 + 手机都开着；网页下单，IDnow 用手机 App；沉浸式翻译；光线好、一个人；护照原件能读 NFC。国行手机不会原生装 eSIM 的，先看文末卡托科普。

不要做：姓名写成微信名；生日和护照不一致；KYC 做到一半切 App / 锁屏；激活后开数据漫游。

官方入口：

https://www.o2online.de/mobilfunk/prepaid/esim/

选 eSIM，套餐选 Basistarif / Prepaid Basistarif，不要手滑点到带月租的 S/M/L。

第一步：选套餐，进购物车

打开页面，SIM 类型选 eSIM，不要 SIM-Karte。Basistarif 现在标的是：0€ 月租、一次性 4.99€、含 5.00€ Startguthaben。点 Jetzt bestellen 进购物车，确认还是 eSIM、金额 4.99€、运费 0。

图1 选 eSIM + Basistarif + 购物车 4.99€

到这一步还没花钱。看清楚再往下。

第二步：邮箱、姓名、生日，必须跟护照同一套

先填邮箱——后面验证码、订单、IDnow 通知全往这儿扔。一个邮箱目前只能挂一个客户账户。

称呼按护照选先生/女士；名、姓用护照拼音，不要自己发明拼法；出生日期必须和护照一致。页面会提醒：填的资料要跟证件一致，否则激活会卡。

图2 邮箱、德国地址、选择付款方式

地址官网写的是「德国期间能联系到你的住址」。没有真实住址就用谷歌地图找居民楼：邮编先填，城市经常自动带出；街道+门牌号编一个合理的；楼层可空。填完点「进行付款 / Weiter」。

图3 条款同意 + 邮箱验证 + 银行卡表单

第三步：付款方式选 Visa / Mastercard

可选 Bankkonto、Visa/Mastercard、PayPal。Bankkonto 要德国账户，直接划掉。我建议 Visa / Mastercard，4.99€ 一笔，3DS 验证一下就过。页面会提示直接扣款仅限 18 岁以上。

营销同意能不勾就不勾。邮箱再要一次验证码。卡信息按卡面填，持卡人姓名用卡上的拼音/英文。

图4 3DS 付款 → 等待 → OnlineIdent 须知

提交后进 3DS / OTP 页，金额显示 €4.99，商户 o2。付完不要关页。有时会卡在「请稍等片刻」，一两分钟都正常，别刷新，别点浏览器后退。

图5 参考编号、下 App、扫码、相机权限

第四步：IDnow 身份验证（最容易翻车）

O2 用的是 Telefónica 合作的 OnlineIdent / IDnow。要求：有效证件、带摄像头的手机或电脑、稳定网络、光线足、房间里没别人。勾选同意后点「接管并继续」。

网页会给参考编号 + 二维码。手机下 Identity Online（开发者 IDnow GmbH）。用 App 扫网页二维码，或手动输入 identity code。

图6 同意、扫描护照主页

App 顺序基本是：拍证件正面（居中、四角在框、别反光）→ NFC 贴着读芯片（护照和手机都别挪）→ 拍反面 → 短视频自拍（表情中性、一个人）→ 系统核验。

图7 NFC + 视频自拍 + Verifying

血泪经验：安卓白屏闪退的人不少，优先 iPhone；NFC 失败就重贴，别退出整个流程；核验成功后不要杀 App、不要关浏览器，它要自己跳回官网，有人要等整整两分钟才出码；护照姓名生日必须和第一步完全一致；少数情况走人工视频，听不懂就开翻译。

第五步：出码，装进手机

跳回官网后会出现 eSIM 安装页：下载 Profile + 二维码。

图8 Data check 等待 + eSIM 二维码

海外版 / 支持 eSIM 的手机：设置 → 蜂窝网络 → 添加 eSIM → 扫码。

国行 iPhone / 不支持原生 eSIM 的安卓：走卡托。我长期用 Xesim，App 里直接扫这个码，或用简易下载码写入。卡托怎么选、怎么写号，单独写过一篇，先看再买：

https://x.com/i/article/2092930821560897537

购买链接（下单填优惠码 J888，九折）：

https://xesim.cc/?DIST=RE5CHlo%3D

先把二维码截图存好。万一这次没装上，登录 Mein O2 还能再生成。

装上立刻做两件事：关掉这张卡的数据漫游；有 Wi‑Fi Calling / WLAN-Telefonie 就打开。主卡流量继续走自己的号，O2 这张只负责收验证码。

第六步：立刻注册 Mein O2

去

https://login.o2online.de

，选「我是移动用户 / Mobilfunk-Kunde」，输入刚拿到的德国号码。先短信验证码，再邮箱验证码，然后设密码：12 位以上，大小写+数字+符号，不能带简单连号，也不能太像你的号码。

图9 Mein O2 入口 + 登录 + 注册类型

图10 输入号码 + 短信码 + 邮箱码

图11 设密码 + 登录成功，余额 5.00€

后台优先做一件事：关掉语音信箱转接。路径大致是：管理 SIM 卡和合约 → Mailbox / 语音信箱 → 关闭「忙线 / 未接转到语音信箱」。不关的后果：别人打进来你没接，转语音，扣费。

图12 套餐说明 + SIM 管理 + 语音信箱

以后换设备，也在这个后台重新生成 eSIM，不用再 KYC。

第七步：拿到专属保号 IBAN

最省钱的是银行转账，不是短信充值。用这张 O2 号发短信到 56656，内容写 iBAN。过几秒 o2 Info 会回收款人、IBAN、BIC、附言。

格式类似：Telef….. erm…… / IBAN DE……………… / BIC …………….. / 附言 0179-你的号码-四位校验。

图13 56656 短信 + o2 回复 + Wise 欧元账户

注意：IBAN 对很多用户是同一条 Telefónica 对公户，区分你的是附言。附言必须原样填，少一段钱到不了你的号。把整条短信丢进备忘录。

第八步：Wise 首充测试 + 自动保号

官方说法：预付费余额最迟每 6 个月要有一次充值，否则可能丢号。充值一般按 182 天续期，上限大约一年。社区长期玩法是 1 欧分银行转账。我测过能入账，但它不是印在官网上的「保号价目表」。重要号别卡着最后一天只打 1 分赌运气，提前 30 天转更稳。

8.1 在 Wise 加收款人

货币 EUR，地区选欧洲境内，企业名称 Telef…….. Germ……，IBAN 填短信里那一串。识别成功会显示 UN……… BANK / Hyp………bank 绿勾。

图14 选 EUR + 填机构信息 + IBAN 识别成功

8.2 先手动转一笔测试

金额 0.10€ 或 1€ 都行。附言 / 付款参考号必须填短信里的 0179-xxxxxxx-xxxx。漏了这步，钱进对公户，你的号上没余额。

8.3 设置自动保号

Wise 里走「付款 → 定时汇款」：从你的 EUR 余额到 Tele…….. Germ……；金额 0.01€（想稳就 0.10€）；频率每季度一次或每 5 个月一次；结束日期拉远；附言还是那串校验码，一次都别改。

图15 Wise 定时汇款 0.01€ + 附言已填

季度扣 1 欧分，一年几分钱，号一直活。钱包里常备 1–2 欧欧元余额，别让自动任务因余额不足失败。日历再备一个 5 个月提醒，进去 Mein O2 看一眼。

使用时真正会踩的坑

\1. 数据漫游：在中国开 O2 流量，按兆计费，能把 5€ 瞬间打穿。这张卡只开 Wi‑Fi Calling。

\2. 语音信箱：关掉。

\3. 短信资费：往外发 9 欧分起，短指令可以，别群发。

\4. 保号不是「卡一直插着就行」。必须在周期内完成充值或产生计费。

\5. 1 欧分不是官方保底。过期后再转，有时要走 Lastschrift。

\6. 下单到 KYC 结束，IP 尽量同一出口。

\7. 一个护照短期别贪多开。一张高质量德国号，比五张废号有用。

\8. IDnow 成功但没码：先等邮件，再登录 Mein O2 下载 profile。境外偶发延迟。

\9. 国行装不上不是 O2 的问题，是手机没有 eSIM 权限。回头看卡托那篇。

和我之前两篇怎么配合看

eSIM 是什么、国行怎么用卡托、Xesim 怎么写号：

https://x.com/i/article/2092930821560897537

没有卡托的，下单用

https://xesim.cc/?DIST=RE5CHlo%3D

，优惠码 J888（10% off）。苹果优先 X2 Pro，安卓 X2 就够。

另一张更便宜的入门海外号（大约 9 块那档，功能定位不一样）在这里。德国 O2 是重量级原生号，别混着用：

https://x.com/Jin111026Jin/status/2089573935373590762

O2 这篇解决的是：要一张德国大网、能过一堆正规平台风控的号。卡托那篇解决的是：国行手机怎么把这张号装进去。两篇叠在一起才是完整基建。

我的建议：办不办

办。前提是你真的在搭海外资金和账号体系。4.99€ 换一条 +49，后面开户、过 2FA、留底，比临时接码号稳得多。

不办的情况也很清楚：只想白嫖流量、只想当天接一条验证码、护照快过期、不愿意做 IDnow。那种去买一次性旅行 eSIM。

政策会收。窗口从「0 元 + 护照秒过」变成「4.99€ + App 核验」，下一步可能是强制人工视频或拒非欧护照。这篇的重点不是又一个羊毛，是趁还能过，把底层号码补上。

我是做海外资金和金融基建的，号对我来说是工具，不是收藏品。工具齐了，后面的卡、账户、出金路由才有地方落。

你要是按这篇跑通了，评论区丢个「过了」就行。卡在哪一步，把页面关键词发出来。

免责：流程、价格、保号规则以

o2online.de

当时页面为准。身份信息必须真实并与证件一致。海外支付、KYC、转账有失败和风控可能，损失自担。本文只记录 2026 年 9 月的实操路径，不是 O2 官方文档。
