dsh-desktop 是社区维护的 DeepSeek Harness（DSH）原生

更新于2026-09-05|aitool
|总字数:1.2k|阅读时长:4分钟|浏览量:

dsh-desktop 是社区维护的 DeepSeek Harness（DSH）原生 Windows 桌面客户端。它把官方 DSH 的 Web UI 包进一个真正的桌面程序：无边框窗口、系统托盘、原生通知、单实例、可选开机自启，不用安装 Node.js，不用敲命令，下载安装后双击即可使用。

  • 官方仓库：https://github.com/SnowCrescenter-tech/dsh-desktop
  • 协议：MIT
  • 平台：目前专注 Windows（无边框 + 托盘等原生体验）
  • 定位：社区项目，非 DeepSeek 官方产品

DeepSeek Harness 仍处于开发者预览阶段，后续可能有破坏性变更。本项目不修改官方 DSH 核心逻辑，只提供顺手的桌面外壳。

1. 项目解决了什么问题？

官方 DeepSeek Harness 需要：

  • Node.js 22.19+ 或 24
  • pnpm
  • 命令行启动 dsh web 等

对非技术用户门槛较高。dsh-desktop 将这一切打包成：

  • 内置 Node 运行时
  • 自动拉起并守护 DSH CLI
  • 在独立桌面窗口中展示官方 Web UI

2. 功能一览

功能 说明
无边框窗口 自绘 36px 标题栏 + 实时状态点（青=运行中，灰=启动中，红=出错）；Windows 11 下圆角由 DWM 原生渲染
系统托盘 常驻后台；单击唤回窗口；右键：打开主界面、开机自启、关于、退出
原生通知 标准 Windows 通知；不支持时降级为托盘气泡
单实例 同时只允许一个进程；重复启动只唤出已有窗口
开机自启 可选，通过注册表 Run 键实现
首次引导 首启粘贴 DeepSeek API Key，Key 仅存本机 /.env
端口自动分配 –port 0，系统挑选空闲端口，避免与 3080 等冲突
自动更新 安装版后台静默下载，就绪后通知并支持「重启并更新」；便携版引导到 GitHub Releases

3. 快速开始

  1. 打开仓库 Releases 下载最新安装包。
  2. 安装完成后，双击桌面上的 DeepSeek Harness 图标。
  3. 首次启动弹出引导对话框，粘贴你的 DeepSeek API Key，保存后主窗口自动打开。

程序会自动启动本地服务并加载官方 Web UI，无需手动操作。

获取 API Key

  1. 打开 https://platform.deepseek.com 注册并登录。
  2. 在 API Keys 页面创建 Key（形如 sk-…）。
  3. 粘贴到引导窗口并保存。

Key 只保存在本机，不会上传。

4. 首次运行内部流程

  1. 获取单实例锁；若已有实例，本进程退出并唤出已有窗口。
  2. 若未配置 API Key → 弹出引导对话框，写入 /.env。
  3. 写入 desktop profile，以 dsh –profile desktop –port 0 启动捆绑的 CLI。
  4. 等待就绪行：dsh web: http://127.0.0.1:。解析成功后加载 Web UI，状态点变青；超时则显示带重试的错误页。

5. 日常使用提示

  • 关闭窗口：默认最小化到托盘，程序仍在后台；需完全退出时从托盘菜单选「退出」。
  • 开机自启：在托盘右键菜单中勾选即可。
  • 更新
    • 安装版（NSIS）：后台自动检查并下载；就绪后通知，托盘选「重启并更新」。
    • 便携版：托盘「检查更新」打开 Releases，自行下载 zip 替换。
  • 数据目录：默认 %USERPROFILE%.dsh，可用环境变量 DSH_HOME 覆盖。
  • 中文路径：支持，可安装在含中文的目录下。

6. 常见问题

SmartScreen / 杀软误报 打包未做数字签名，属常见情况：

  • SmartScreen：更多信息 → 仍要运行
  • Defender / 360 / 火绒 / 电脑管家：将安装目录加入信任/排除

端口冲突 使用系统自动分配端口，一般不会冲突。

费用 软件本身免费开源；调用 DeepSeek API 按官方计量计费（价格以官方文档为准，含峰谷价等）。

7. 技术架构（简述）

  • 框架：Electron 43，内置 Node v24.19.0
  • 上游：通过 @deepseek-ai/dsh（如 0.1.0-rc.6）启动 Web UI
  • 主进程：窗口、托盘、通知、开机自启、CLI 监督器
  • 渲染：自绘标题栏 + 沙箱 WebContentsView 承载官方 Web UI
  • Profile 加载顺序：@deepseek-ai/dsh-base → @deepseek-ai/dsh-web-app → @dsh-desktop/client
  • 设计：简约风格，强调色参考 DeepSeek 品牌蓝（#4D6BFE）

8. 免责与相关链接

  • 社区项目，非 DeepSeek 官方。
  • DeepSeek Harness 为 developer preview，可能发生不兼容变更。
  • 问题优先查阅官方 DSH 文档与本仓库 Issues。

相关链接：

  • 本项目：https://github.com/SnowCrescenter-tech/dsh-desktop
  • DeepSeek Harness：https://github.com/deepseek-ai/deepseek-harness
  • API 控制台：https://platform.deepseek.com
  • 文档站（仓库内）：website/ 目录

9. 总结与上手路径

dsh-desktop 适合想在 Windows 上「像普通软件一样」使用 DeepSeek Harness、又不想折腾 Node/pnpm/命令行的用户。

推荐步骤：

  1. 从 Releases 下载安装包并安装。
  2. 首次运行粘贴 API Key。
  3. 在托盘中熟悉「唤回窗口 / 开机自启 / 退出」。
  4. 需要时在托盘检查更新。
  5. 深入使用时再查阅官方 DeepSeek Harness 的插件与 Agent 能力。
