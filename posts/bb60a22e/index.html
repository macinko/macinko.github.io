OpenMinis 详细部署教程

OpenMinis 是一款完全免费开源的跨平台 AI Agent 应用，它在你的 iPhone 或 Android 手机上内置了一个完整的 Linux 沙箱环境，让 AI 助手能够真正地操作文件、运行脚本、控制浏览器，并深度集成系统功能，如日历、健康、提醒事项等。本教程将指导你完成从环境准备到源码编译，再到最终配置与使用的全流程。

准备工作

在开始之前，需要理解 OpenMinis 本身不内置任何 AI 模型，它需要你自带大语言模型（LLM）的 API Key 才能工作。因此，你需要提前准备一个受支持的 AI 服务商的账户和 API Key。

支持的模型提供商（部分）：

  • Anthropic (Claude)：推荐，性能强大。
  • OpenAI (GPT)：支持 API Key 或 OAuth 账号登录。
  • Google (Gemini)：需使用 API Key。
  • DeepSeek：国内用户首选，注册简单，性价比高。
  • OpenRouter：聚合平台，可访问多种模型。
  • 其他兼容 OpenAI API 格式的服务（如 通义千问、Kimi、MiniMax 等）。

DeepSeek API Key 获取示例：

  1. 访问 DeepSeek 开放平台并注册登录。
  2. 完成身份验证后，在左侧菜单栏找到「API Keys」，点击「创建 API Key」。
  3. 命名后即可获得一个 sk- 开头的密钥，请妥善保存。
  4. 建议为账户充值少量金额（如10元）以进行测试。

获取与安装App

OpenMinis 为不同平台提供了便捷的安装方式。

  • iOS 用户：在 App Store 中搜索 “Open Minis” 下载安装。要求 iOS 16 以上版本。
  • Android 用户：从 GitHub Releases 页面下载最新的 APK 安装包进行安装。要求 Android 10 以上版本。
  • 测试版 (Beta)：如果你想体验最新功能，可以加入官方的 TestFlight 测试计划[iOS] 或关注 GitHub 的预览版 APK[Android]。

配置AI模型 (核心步骤)

安装完成后，首次打开 App，需要配置 AI 模型才能开始使用。

  1. 启动应用：打开 OpenMinis App。
  2. 添加服务提供商：在欢迎界面或主界面，点击 「Add a Provider」 或 「添加 AI 服务商」。
  3. 选择服务商类型：根据你准备好的服务，选择合适的选项。
    • 若使用 OpenAI/兼容 API：选择「OpenAI/Compatible API」。
    • 若使用 Claude/Gemini 等官方服务：选择对应的图标进行 OAuth 登录或 API Key 绑定。
  4. 填写连接信息（以 DeepSeek 为例）：
    • 标签 (Label)：自定义一个名称，如 “DeepSeek”。
    • API Key：粘贴你之前获取的 sk- 开头的密钥。
    • 自定义 API 地址 (Base URL)：填入 https://api.deepseek.com。重要：务必关闭「自动附加 “/v1”」选项，否则会导致连接失败。
    • 其他国内模型：通义千问、Kimi 等可使用其官方或代理的兼容地址，填写时均注意不要附带 /v1 后缀。
  5. 选择模型：添加成功后，在模型列表中勾选你想要使用的具体模型（如 deepseek-chat 或 claude-3-opus）。

完成以上步骤，你就可以开始与 OpenMinis 对话了，它会利用你配置的模型来理解和执行任务。

从源码编译 (可选)

对于开发者或希望自行定制、为项目做贡献的用户，OpenMinis 提供了完整的源码编译指南。由于项目包含 Linux 沙箱环境 (iOS 使用 iSH，Android 使用 PRoot) 和 FFmpeg 等原生依赖，首次编译会花费 30-60 分钟。

通用准备

  1. 克隆仓库：必须使用 --recurse-submodules 参数，确保拉取 iSH 和 PRoot 子模块。

  2. 编译时自定义 (可选)：复制模板配置文件，用于注入 OAuth 等敏感信息。留空也不影响 API Key 方式的使用。

进阶配置与使用技巧

  1. 授予必要权限：为了让 AI 真正”操作”手机，需要授予相应权限。例如，在 Android 上可通过 Shizuku 获得更高权限，实现自动化操作，或开启无障碍服务让 AI 模拟点击。
  2. 技能 (Skills)：OpenMinis 支持社区贡献的”技能”。你可以将包含 SKILL.md 文件的技能包加载给 AI，让它学习完成特定任务的流程。技能库见 OpenMinis/MinisSkills 仓库。
  3. 工作区 (Workspaces)：通过 minis://workspace/ 链接可以组织不同的任务上下文，实现工作隔离。
  4. 记忆与持久化：AI 可以跨会话记住关键信息。你可以将长对话的总结写入记忆文件，以便开启新会话时 AI 能继续之前的任务。

常见问题与解决

  • Q: 如何选择推理模型？ DeepSeek V4 Flash 速度快、价格低，适合日常任务；DeepSeek V4 Pro 或 Claude Sonnet 质量更高，适合复杂任务。
  • Q: Gemini OAuth 登录失败？ 官方提示 Gemini 的 OAuth 限制较严，建议优先使用 API Key 方式连接。
  • Q: 使用代理时连接不稳定？ 为 OpenMinis 配置固定的代理节点，避免在 Agent 执行任务过程中切换网络导致中断。
  • Q: 编译时提示找不到子模块？ 确保你使用了 git clone --recurse-submodules 命令。如果已克隆，运行 git submodule update --init --recursive 补全。
  • Q: 编译 iOS 项目时出现链接错误？ 请严格按照 build_lame.sh -> build_ffmpeg.sh -> build_ish.sh 的顺序执行，因为 FFmpeg 依赖于 LAME。
