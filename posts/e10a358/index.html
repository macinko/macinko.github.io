xAI Grok 4.5 正式发布：极速 80 TPS、全面提升的强化学习与全新 Grok Build 体验

更新于2026-08-22|toolssoftware
|总字数:768|阅读时长:2分钟|浏览量:

xAI 近日正式发布了旗下最强的 AI 模型 —— Grok 4.5。

作为 Grok 系列的重要升级版本，Grok 4.5 重点针对软件开发、智能 Agent、工程计算及技术推理等场景进行了深度优化。目前，该模型已对拥有 X（Twitter）账户或 SuperGrok 账户的用户限时免费开放。

核心技术突破

1. 顶尖的软件工程与编码能力

Grok 4.5 在真实工程环境中的代码生成和复杂任务处理上取得了长足进步，支持 Rust、C/C++、Python、JS/TS 等多语言全栈开发。在多个国际编程基准测试中表现亮眼：

  • SWE Marathon：以 29% 的准确率成功夺冠，超越了 Claude Opus 4.8 Max 和 Claude Fable Max。
  • SWE Bench Pro：取得 64.7% 的高分，位列行业第三。
  • DeepSWE 1.0：取得 62% 的成绩，仅次于 Claude Fable Max 和 OpenAI GPT-5.5 XHigh。
  • Terminal Bench 2.1：取得 83.3% 的高分，位列第三。

2. 数万块 GB300 GPU 算力支撑

Grok 4.5 的预训练在数万块 NVIDIA GB300 GPU 构建的算力集群上完成。官方表示，训练过程不仅扩大了数据规模，更聚焦于高覆盖率的数据混合、领域去重与质量评分，确保了更高的数据信号密度。

3. 大规模异步强化学习（RL）

在强化学习阶段，xAI 引入了涵盖数十万个任务的异步训练平台。通过长达数小时的 Agent 持续运行、自动评分和模型自我反馈，显著提升了模型在多步骤软件工程和 Agent 工作流中的执行效率。

4. 2倍速度提升

Grok 4.5 的推理速度最高可达 80 TPS（Tokens Per Second），整体 Token 效率相比上一代提升约 2 倍，能够极速响应长上下文和复杂代码生成请求。

生产力与场景应用

Grok Build：默认升级至 Grok 4.5

Grok 4.5 已成为 Grok Build 的默认底座模型，大幅强化了日常办公和原型开发能力：

  • 应用开发：支持通过一句自然语言（如：使用 Three.js 构建 3D 太阳系轨道模拟器）直接生成包含精美 UI 和完整交互的运行项目。
  • 数据分析：支持构建复杂的 Excel 数据模型、自动编写跨工作表公式。
  • 幻灯片与报告：支持使用 PowerPoint 原生形状绘制流程图，自动排版并生成结构清晰的 Word 报告。
