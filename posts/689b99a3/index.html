Dashy 把常用的网站和服务聚合到一个美观的仪表盘上

更新于2026-09-13|toolssoftware
|总字数:811|阅读时长:2分钟|浏览量:

Dashy 是一个自托管的个人导航页，可以把常用的网站和服务聚合到一个美观的仪表盘上。它最方便的地方是所有配置都通过一个 YAML 文件管理，而且自带可视化编辑器，改配置不用重装服务。

🐳 部署方式一：Docker 运行（最快上手）

这是官方推荐的方式，一条命令就能跑起来。

参数说明：

参数 作用
-p 8080:80 把容器 80 端口映射到宿主机 8080（可改成你喜欢的端口）
-v .../my-conf.yml:/app/public/conf.yml 关键。把本地的配置文件挂载进容器，改配置不用进容器
--restart=always 容器异常退出或宿主机重启后自动拉起

启动后访问 http://你的IP:8080 就能看到界面了。第一次启动会慢一些，因为容器内部要跑一次构建，日志出现 DONE Build complete 就说明好了。

如果你还没建配置文件，可以先不挂载 -v，直接跑起来，然后从界面里进入编辑模式改配置，再用 docker cp 把容器里的配置拷出来。

📦 部署方式二：Docker Compose（适合长期管理）

用 Compose 管理更清晰，方便后续更新和调整。

执行 docker compose up -d 启动。

如果 DockerHub 拉取遇到限流，可以换用 GHCR 镜像源：把 image 改成 ghcr.io/lissy93/dashy:latest。

⚙️ 配置文件怎么改

Dashy 的配置全部集中在 conf.yml 里，结构很简单，主要就三块：

改完配置后，Docker 容器会自动检测到文件变化并重新构建，稍等片刻刷新页面即可。

三种编辑方式，按需选择：

方式 适合场景 说明
直接改 YAML 想精确控制、批量修改 用编辑器改挂载出来的 conf.yml，最灵活
UI 可视化编辑器 新手快速调整 点界面上的编辑按钮，直接拖拽、填写，保存到磁盘即可生效
UI JSON 编辑器 需要 Schema 校验 在 Config 菜单里打开，有字段提示和校验，减少语法错误

🔧 可选：远程访问

如果你想让 Dashy 在局域网外也能访问，可以配合内网穿透工具。比如用 cpolar 创建一个隧道，把本地的 8080 端口暴露出去，就能通过公网地址访问了。

✅ 验证部署

访问 http://你的IP:8080，看到 Dashy 的默认界面或你配置好的导航页，就说明部署成功了。如果界面没出来，先检查日志（docker logs dashy），确认构建是否完成。
