OpenBrowser：本地指纹浏览器，管理多个隔离的 Chromium 环境

更新于2026-09-05|toolssoftware
|总字数:1.2k|阅读时长:4分钟|浏览量:

这是一个关于 OpenBrowser 的详细部署教程。OpenBrowser 是一个本地的指纹浏览器桌面应用，用于管理多个隔离的 Chromium 环境。

本教程将涵盖从环境准备、源码运行到不同平台（Windows、macOS、Ubuntu）的打包构建全过程。

📋 部署前准备

在开始前，请确保你的系统满足以下要求：

  • 操作系统：Windows (x86_64)、macOS (x86_64/arm64) 或 Ubuntu (x86_64)。
  • Node.js：需要安装 Node.js LTS 版本。
  • 包管理器：npm（通常与 Node.js 一同安装）。

⚙️ 核心功能与配置

OpenBrowser 的核心功能围绕多环境隔离展开，部署完成后，你可以通过应用界面进行配置：

功能模块 说明
环境隔离 每个浏览器环境拥有独立的 Chromium 配置（Cookie、缓存、存储等）
指纹控制 可自定义平台、语言、时区、User-Agent、Canvas、WebGL、WebRTC 等指纹参数
代理支持 可为每个环境单独配置 HTTP/HTTPS/SOCKS 代理，并支持出口检查
本地 API 默认在 127.0.0.1:50325 提供本地 API 和 MCP 集成，可设置 OPENBROWSER_API_KEY 增强安全
备份选项 支持将配置备份到本地、WebDAV、GitHub 或云盘（需显式配置）
窗口同步 基于 CDP 的窗口同步，包括点击、滚动、输入和标签页同步
本地 RPA 内置流程自动化，支持导航、等待、点击、输入和截图

❓ 常见问题

  • 问：打包后的应用无法启动？
    • Windows/macOS：检查是否有安全软件拦截，确保以管理员/普通用户身份正确运行。
    • Ubuntu：请确认已安装上文列出的所有系统依赖库，并以普通用户身份运行。
  • 问：如何更新应用？
    • 由于仓库不存储内核二进制文件，更新时请拉取最新代码，并重新执行 npm ci 和打包步骤。官方包会从更新源获取匹配的内核。
  • 问：数据存储在哪里？
    • 用户数据（如配置文件、日志）存储在系统用户目录下，不会存储在源码仓库内。启动失败时可查看 browser-startup.log。
