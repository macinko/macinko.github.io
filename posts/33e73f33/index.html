App Sandbox 专注于性能和易用性的虚拟机应用，支持 Windows 和

更新于2026-09-05|toolssoftware
|总字数:1.4k|阅读时长:4分钟|浏览量:

根据 App Sandbox 的官方仓库，这是一个专注于性能和易用性的虚拟机应用，支持 Windows 和 macOS，能轻松创建用于开发或运行 AI 模型的隔离虚拟机环境。以下是基于其文档整理的部署与使用教程。

🧭 核心功能与定位

App Sandbox 旨在让你能够一键创建和管理完整的桌面虚拟机（Windows 11、Ubuntu 或 macOS），而无需繁琐的配置。它的核心优势包括：

  • 无需 Hyper-V（Windows）：可在 Windows 11 家庭版上运行，通过底层 API 实现虚拟化。
  • 强大的 GPU 加速：支持 GPU-PV（GPU 虚拟化），允许虚拟机直接使用宿主机的 GPU 进行 DirectX 12、OpenGL、Vulkan、CUDA 和 OpenCL 加速。
  • 无网络 SSH：通过 Hyper-V 套接字或 virtio-vsock 实现主机与虚拟机之间的 SSH 连接，无需网络配置。
  • 快照与分支：支持对虚拟机状态进行快照，并能从快照创建分支，方便测试不同场景。
  • 无头模式（Headless）：提供本地 HTTP/JSON API 和轻量 Python SDK，可编程方式创建和管理 GPU 加速虚拟机，适合 CI/CD 或自动化工作流。
  • 跨平台：支持在 Windows 11（x64）和 Apple Silicon Mac 上运行，并可在 Windows 主机上运行 Windows/Ubuntu 虚拟机，在 Mac 主机上运行 macOS/Windows 11 ARM 虚拟机。

📦 部署与安装

1. 获取安装包

App Sandbox 以预编译二进制形式发布，从项目的 GitHub Releases 页面 下载对应系统的安装包：

  • Windows：.exe 安装包（EV 签名）。
  • macOS：.app 或 .dmg 文件（Apple Developer 签名）。

2. 系统要求

  • Windows 主机：Windows 11（x64 处理器），无需 Hyper-V，但需要启用 Virtual Machine Platform 功能（WSL2 也依赖此功能）。
  • macOS 主机：macOS Tahoe 或更新版本（仅限 M 系列芯片）。

3. 安装与首次启动

  • Windows：运行下载的安装程序，按提示完成安装。该软件会配置必要的 Windows 功能。
  • macOS：将 .app 文件拖入 Applications 文件夹，首次启动可能需要通过系统安全验证。

🚀 快速使用

图形界面方式

  1. 启动 App Sandbox。
  2. 选择操作系统：点击“新建”，选择要创建的虚拟机类型（Windows 11、Ubuntu 或 macOS）。
    • Windows/Ubuntu：你需要准备一个官方 ISO 镜像文件。
    • macOS：应用会自动下载所需的恢复镜像。
  3. 配置并创建：设置虚拟机名称、内存、CPU 核心数等，点击“创建”。
  4. 启动与使用：创建完成后，启动虚拟机，你将看到一个完整的桌面环境。它支持复制粘贴、音频、GPU 加速，并可通过 SSH 从主机连接（无需配置网络）。
  5. 高级操作：在虚拟机运行时，你可以通过界面进行暂停、快照、分支或关闭操作。

无头模式（Headless API / Python SDK）

App Sandbox 提供了一个强大的无头模式，适合需要自动化或集成到脚本中的场景。

  1. 启动守护进程：

    • Windows：在命令行中运行 appsandbox.exe --headless。
    • macOS：运行 sudo /Appsandbox.app/Contents/MacOS/AppSandbox --headless。
      守护进程会在 127.0.0.1 上启动一个 HTTP API 服务。

  2. 使用 Python SDK：
    SDK 是纯 Python 标准库，无需额外依赖。

    完整的 API 参考和示例可在项目的 tools/headless-api/ 目录下找到。

⚙️ 高级功能与配置

  • GPU 加速测试：在 Windows 虚拟机内运行 gpu-test.exe（可从项目文档链接获取），它会显示 6 个旋转立方体，分别测试 D3D9、D3D10、D3D11、D3D12、OpenGL 和 Vulkan。这可用于验证 GPU 虚拟化是否正常工作。
  • 驱动开发测试模式：Windows 虚拟机内置 Test Mode，支持测试签名驱动，且不影响宿主机的 Secure Boot 配置。
  • 多虚拟机并发：在硬件资源允许的情况下，可同时运行多个虚拟机。

❓ 常见问题

  • Windows 11 家庭版可以运行吗？ 可以。App Sandbox 不依赖 Hyper-V，只需要开启 Virtual Machine Platform 功能。
  • GPU 加速需要独立显卡吗？ 支持 GPU-PV，宿主机的 GPU（包括集成显卡）可被虚拟机共享使用。
  • 如何从主机访问虚拟机文件？ 推荐使用 SSH（无需网络配置，通过 Hyper-V 套接字）。也可在虚拟机内启用网络共享。
  • 虚拟机性能如何？ GPU 加速性能接近原生，CPU 和内存开销取决于你分配给虚拟机的资源。
  • 开源协议：项目采用 MIT License，但其中捆绑了部分第三方组件（如 Microsoft WSL2 驱动），遵循其各自的许可协议。

总结

App Sandbox 提供了一个低门槛、高性能的虚拟机方案，尤其适合需要在隔离环境中进行开发、测试或运行“计算机使用”AI 模型的场景。对于大多数用户，推荐从图形界面开始，体验一键创建和运行虚拟机的便利。如果你需要自动化或集成到 CI/CD 管道，可以充分利用其 无头模式 API 和 Python SDK。部署前请确保你的系统满足基本要求（Windows 11 家庭版用户需开启 Virtual Machine Platform；macOS 用户需使用 M 系列芯片）。
