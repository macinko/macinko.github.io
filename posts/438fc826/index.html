豆包工作又又又进化！Office不存在了

更新于2026-09-13|aiagent
|总字数:2.3k|阅读时长:6分钟|浏览量:

大家都懂现在大厂的work类产品竞争得多激烈，所以我一直挺关注这几个产品的动向的，毕竟需要给各位粉丝姥爷做评测。

上周我刚写过它一次，那篇我把自己写的报告 skill 打包传了上去，让它在云电脑上写了份 28 页的调研报告，写完还把那个 skill 开源了，想着这个技能生态刚起来，给它添点大家都能用的东西。结果这东西还没捂热，这周它自己又进化了一大截。

这周他们主要上的是两个功能，都已经全量，你现在把客户端更新到最新版就能用：

一个叫本地Office编辑。你电脑里的 Excel 和 PPT，以前想让 AI 改，得先上传、改完再下载回来，现在在豆包工作里直接打开、直接改，文件不出你的电脑。

表格直接在里面选中、编辑，操作过程是这样的：

PPT也一样，打开已有文件，选中文字就能调整格式：

Word的话似乎还要等一等，不过我估计接下来一两周他们也会搞定的。

另一个叫任务执行环境自由切换。以前一个对话开始的时候选了本地电脑，中途就改不了了，想换到云电脑得重开一个对话，前面聊的全作废。现在一个对话里随时切。

我花了一个下午挨个试，试的时候脑子里一直是最近常听到的一句话：AI 你只要学得够晚，你就不用学了。这话现在成不成立我还不那么肯定，但以前很恼人的 Office 三件套的用法，尤其是 Excel 那一大堆公式和技巧，你是真的不用再学了，这我还挺特么羡慕的。

下面是实测记录，一个生产力 agent 有了这两个功能，对经常要做表格，要写文档，做PPT 的人到底意味着什么。

一、先说本地Office是怎么个用法

前面演示过你可以直接拿豆包打开你本地的Excel文档了，当然，如果这个Excel本身是你要求豆包去统计生成的，那也完全没问题，在对话里点一下，右侧工作台就开出一个标签页，表格在里面直接打开了，菜单、格式刷、字体字号、查找替换、公式栏，顶上是 sheet 页签，跟你平时用的表格软件差不多。右上角有个打开按钮，下拉能一键转给本机装着的 Excel，也能弹成独立窗口。

我另外造了张四行的小表试了下边界：它把合计列填成公式 =B2+C2，我在打开的表里直接把 B2 从 1200 改成 2000，D2 当场重算成 2340，Cmd+S，桌面上那个文件的修改时间变了，用脚本读出来 B2 是 2000，公式还在。

然后我在对话里补一句：我刚在表里手动改了一格并保存了，你重新读一遍，告诉我改的是哪一格。它答：B2 从 1200 变成了 2000，其余单元格未变，D 列合计随之联动。

反过来也一样。我让它给开着的表加一列环比，特意说先别保存。几分钟后我眼前这张表的 E 列自己长出来了，整列淡蓝高亮，标签名旁边挂出一个蓝色的未保存，桌面上那个文件的修改时间没动。

保存那一下还在我手里。 我觉得这是这个功能里设计得最对的一处，它改的我看得见，看完我再决定存不存。

用法就这些。接下来再谈谈PPT。

二、PPT，排版我不用琢磨了

我手上有一份讲期货期权的 PPT，13 页，是之前为了测试我的一些设计skill，以及提升自己对相应概念的理解做的。风格倒是没什么问题。但是里面一张图都没有，全靠 emoji 当图标撑着，所以明显差点品质。

这一步我之后拿豆包工作去做，核心还不止是它能直接编辑PPT，我觉得最最关键的还是它还有很强的文生图seedream模型，所以相比别的产品来说，内容中需要配图的时候很容易直接实现了。相当于把找素材的环节也省了。

我的要求就两句：先读出这份 PPT 的配色、字体、版式；再用它自己的生图能力，给三个讲故事的页各配一张风格统一的插画，插进去别盖住原来的字。

它先把视觉系统读了出来，三个主色、字体、连只出现一次的强调色都有（我扒 XML 核过，全对），然后开始生图。最后对比效果大概如下👇

到了这一步，我觉得基本可以了。配色、腾地方、重排这些我是真不用琢磨了，但要不要插画、多大才算参与版面、像不像设计师做的，判断还是我在做。

顺带说一句，它现在不止是能改 PPT。我另外让它做了一份 20 页的印象派科普 PPT，排版、配图、审美都挺到位的，用的都是它自带的 PPT 技能，我一张图没找、一页没排。翻一遍是这样的：

三、第二个功能：人不在电脑前的时候

上面这些好处有个共同前提，你人得在这台电脑前面。文件在你硬盘上，编辑器在你客户端里，保存键在你手里，三件事都要求你坐在那儿。

上周我在外面跑了四天，武汉上海来回，人很多时候不在电脑前，这种时候活全绑在那台机器上，临时来个需求，这条对话差不多就停在那儿了。这周同时上的另一个功能就是冲这个来的。

我是这么试的：先在本地电脑模式下让它读我桌面上一张 GitHub 仓库清单（六十个仓库），报一下 star 最高的三个，它读完给了三个仓库和各自的 star 数。然后我点了一下输入框底部那个写着本地电脑的按钮，下拉里选云电脑。

会话没有重开，界面上唯一变的是那个按钮变成了云电脑，上面那轮问答原样都在。接着我在同一个对话里追问：刚才那三个仓库，去 GitHub 上查一下现在各自多少 star，跟表里对一下。它知道那三个仓库是谁，在云端抓了页面，给了我一张对比表，三个仓库分别多了 82、37、5 个 star。

有意思的是下一句。我让它把刚才那张本地 csv 再打开一次，念一下第 5 行。它说：

当前云端环境里找不到这个文件 —— 之前读它是在你的 Mac 本地环境，现在运行环境已切换成云端 Linux，这个路径在云上不存在。

然后它还是把第 5 行念出来了，但补了一句：这是上一次读取时记录的内容，不是刚才新打开文件念的。

上下文跟着走，文件不跟着走。 所以我自己的用法是看这活的产物是什么：要改表、要出 PPT、要动硬盘上的文件，就老实待在本地别切；只是查点东西、写点东西、拿已经读进去的数据算一算，切到云电脑，这活跟我这台 Mac 就没关系了。

以及，我查了下，似乎如果你有多台电脑的话，对下拉里能列出你其他已登录的电脑，出门在外可以用家里那台的算力和文件做接力。我只有一台 Mac，这条没测。

四、最后

按它十六天十七个版本这个节奏，我写在这儿的东西大概过不了几周就不准了。

那也挺好的呢。

不过呢，话也说回来。你不需要学 Excel 的操作了，但对业务数据的理解、数据分析的基础能力还是要有的，其实接下来对人的考验还是存在的。只是现在你不需要琢磨怎么做 PPT、怎么排 Word 了，但你依然要知道怎么通过这些文档去呈现、表达自己的想法。

我觉得豆包工作这类 work 产品在 Office 三件套上发力，意义也在这儿：它让你可以把苦活累活更放心地交给 AI，自己专注在做业务时真正重要的理解、洞察和规划上。

如果你想试，我的建议是别从空白开始，拿一张你每个月都要手动整理一遍的表给它，让它试试完成你之前可能需要几个小时甚至数天才能完成的任务，做完之后用你自己电脑上的 Excel 打开一次。那一下打开，比它说一百句已验证都管用。

哦对了，最近下载「豆包工作」似乎还可以免费领 30 天订阅权益，官网：
