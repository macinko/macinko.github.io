easy-stock：A 股行情分析与 AI 投研桌面应用

easy-stock 部署与使用教程

easy-stock 是一款面向个人投资者的 A 股行情分析与 AI 智能投研桌面应用。它聚合了行情、题材、涨停、资讯等多源数据，并通过 AI 能力帮助用户完成盘后复盘、个股分析、持仓巡检等研究工作。本教程将指导你完成从安装到配置使用的全过程。

一、核心功能概览

在开始部署前，了解 easy-stock 的核心能力有助于你理解其价值：

功能模块 核心能力
大V自动复盘 自动收集雪球、淘股吧等平台观点，生成共识与分歧报告
超短连板分析 分析涨停梯队、晋级率与情绪周期
趋势题材雷达 识别市场主线，分析题材阶段与资金流向
个股AI分析 判断个股路径（情绪连板/趋势容量等），生成可解释报告
持仓AI巡检 组合健康度评分，识别集中度与联动风险
行情总览 统一展示指数、资金、龙虎榜、公告等市场信号

重要提示：本项目仅供学习、研究和信息整理使用，不构成任何投资建议。AI 输出和第三方数据可能存在延迟或错误，请独立判断并自行承担决策风险。

二、系统架构概览

easy-stock 采用分层架构，各层职责清晰：

层级 核心职责
AI投研体验层 行情总览、题材趋势、个股分析、持仓巡检等用户界面
业务编排层 Go API、分析引擎、调度任务与数据源状态管理
AI Agent平台层 Hermes 负责模型调用、会话、记忆、工具路由与模型网关
数据智能层 统一市场模型、题材归因、SQLite 存储与缓存快照
外部生态层 行情数据源、内容平台、大模型服务与浏览器执行能力
桌面运行边界 Electron 生命周期、随机端口、一次性 Token 与本地资源装配

三、部署步骤

方式一：作为终端用户使用（推荐）

这是最简单的使用方式，无需安装 Node.js、Go 或 Python 等开发环境。

1. 下载安装包

前往 GitHub Releases 页面，根据你的操作系统下载对应的安装包或压缩包：

  • Windows: 下载 .exe 安装包。
  • macOS: 下载 .dmg 文件。
  • Linux: 下载对应的 AppImage 或 deb 包。

2. 安装并启动

下载后，双击运行安装程序，按照提示完成安装。首次启动时，应用会进行初始化并准备本地运行环境。

3. 配置大模型服务

首次使用前，你需要配置 AI 服务才能启用智能分析功能。进入 设置 → AI 服务，目前支持配置 OpenAI、DeepSeek、通义千问、Moonshot、Anthropic 以及兼容 OpenAI 协议的自定义服务。

以 DeepSeek 为例：

  • 访问 DeepSeek 官网，注册并购买 API 额度。
  • 创建 API Key。
  • 在 easy-stock 设置中填入 API Key 和对应的 Base URL（如有需要）。

4. 配置内容平台登录（可选）

如需使用“大V自动复盘”功能自动抓取雪球、淘股吧等平台的文章，需要在设置中配置这些平台的登录状态，以便应用能够访问相关内容。

如果你希望进行二次开发或调试，可以从源码运行。

1. 环境准备

  • Node.js: 22 或更高版本。
  • Go: 1.21 或更高版本（用于后端服务）。
  • Git: 用于克隆仓库。

2. 克隆源码

3. 安装依赖并启动
具体的启动命令和详细配置，请参考项目根目录下的 开发者文档。通常涉及以下步骤：

启动后端服务和前端开发服务器后，即可通过浏览器访问应用。

四、关键配置与使用

4.1 配置 AI 服务

AI 服务是 easy-stock 智能分析功能的核心。配置好 API Key 后，以下功能将可用：

  • 个股 AI 分析: 系统会结合行情数据、题材信息，通过 AI 生成详细的个股分析报告。
  • 持仓 AI 巡检: 选择你的交易风格（激进/均衡/稳重），添加持仓股票和仓位，AI 会生成组合健康度报告，识别风险。
  • 大V观点共识: 从收集到的多篇文章中，AI 会提炼共同观点、分歧和次日验证条件。

4.2 启用 Skills（技能）

easy-stock 支持通过 Skills 扩展能力。你可以在应用内浏览、安装和启用 Skills。具体的添加与启用方法，可参考项目文档中的 Skill 添加与启用说明。

五、部署清单

步骤 操作 关键点
1. 环境准备 确认操作系统版本 Windows / macOS / Linux 均可
2. 获取应用 从 Releases 下载对应安装包 无需安装开发环境
3. 安装启动 运行安装程序，首次启动初始化 等待本地环境准备完成
4. 配置AI服务 在设置中填入 API Key 支持 DeepSeek、Kimi 等多种服务
5. 配置数据源 （可选）登录雪球、淘股吧 用于自动复盘功能
6. 开始使用 探索行情总览、个股分析等功能 数据会随交易日动态更新

总结

通过本教程，你应该已经掌握了 easy-stock 的安装与基本配置。作为一款本地优先、证据驱动的 AI 投研工具，它旨在帮助你更高效地感知市场结构、沉淀研究记忆。
