WIN软件RetainPDF - 开源 PDF 保留排版翻译工具

开源社区做保留排版的项目不少，但是都围绕可复制，可编辑的 PDF，以及行内公式不复杂的场景。这款「RetainPDF」从一开始就是要解决各类 PDF 的保留排版翻译问题，尤其是图片型/扫描版 PDF，以及行内公式的渲染问题。提供 Windows、macOS、Linux 客户端，支持 Docker 部署。

功能介绍

在保留排版翻译这个领域，正面硬刚闭源模型,并且在一些场景下做得更好，比如翻译后的 PDF 体积、整体速度和字体大小控制。

此外本项目是前后端分离、OCR、翻译、排版与交付打通的全栈项目，整体结构尽量解耦，既能直接使用，也方便后续开发者继续扩展、替换模块和二次开发。

WIN软件TinyPic - 漫画/图片批量压缩工具

漫画/图片批量压缩工具「TinyPic」用来把漫画文件夹或压缩包整理并压缩成更适合阅读器使用的 CBZ。它提供双页处理、白边/页码裁剪、批量任务和持久化设置，适合日常整理漫画库或给电纸书、平板阅读器减体积。

功能介绍

📦 输入与输出

  • 输入类型：文件夹、ZIP、CBZ、RAR、CBR、EPUB
  • 输出类型：CBZ
  • 输出命名：自动输出为同目录下的 *_tinypic.cbz
  • 批量处理：支持一次拖入多个任务，逐个处理并显示结果

✂️ 页面处理

  • 双页处理模式：拆分双页、自动旋转、不处理
  • 封面保护：首张图片按封面处理，不做双页拆分
  • 裁剪模式：不裁剪、白边裁剪、白边 + 页码裁剪
  • 裁剪力度：0.0 - 3.0 可调，白边裁剪和页码裁剪共用同一力度参数

🗜️ 压缩与画质

  • 压缩质量：60 - 95 可调，默认 72
  • 动态质量控制：尽量避免裁剪后体积反而变大
  • 灰度检测：黑白漫画会按更合适的方式编码
  • MozJPEG 优化：额外做无损 Huffman 优化
  • 输出格式：统一写入 JPEG 页面并打包为无压缩存储的 CBZ

⚡ 性能与稳定性

  • 多线程处理：1 - 8 线程可调
  • 低峰值内存：文件夹、ZIP/CBZ、EPUB、RAR/CBR 都按需读取，避免整本预读进内存
  • EPUB 回退机制：优先读取 OPF 清单；如果元数据损坏，会回退到图片扫描而不是直接失败
  • 任务结果可见：界面会显示压缩前后大小、压缩比例和单任务错误数量
  • 单文件 EXE：打包后为单个 TinyPic.exe，便于分发

💾 设置记忆

  • 会记住选项：压缩质量、处理线程、裁剪模式、裁剪力度、双页处理模式
  • 源码运行：配置写入项目根目录的 config.json
  • 打包运行：配置写入 TinyPic.exe 同目录的 config.json

扩展插件Just One Page PDF - 网页保存为 PDF

在日常浏览网页时，我们常常需要保存长文、报告、教程等内容，传统浏览器打印转 PDF 易分页截断、排版混乱，截图又无法复制文字。

推荐一款免费 Chrome 浏览器插件「Just One Page PDF」 核心定位是一键将任意网页转为单页 / 多页高质量 PDF，兼顾便捷性与专业性，无需复杂设置，轻点图标即可完成转换，适配各类网页内容保存场景。

功能介绍

  • 单页完整 PDF 导出：自动合并超长网页为无分割单页 PDF，杜绝分页错乱、内容截断，保留原版排版，文字可复制。
  • 双模式自由切换：支持单页长版 / A4 标准多页模式，内置多类纸张尺寸，兼顾离线阅读与打印需求。
  • 精准内容精简：可框选局部区域导出，一键隐藏导航栏、广告、侧边栏等无关元素，文档干净清爽。
  • 本地离线处理：所有转换仅在浏览器本地运行，不上传数据，隐私安全有保障。
  • 操作极简高效：一键生成下载，无需多余设置，多标签页可批量转换，快速归档网页资料。
