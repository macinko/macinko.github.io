魔因漫创 (Moyin Creator) 面向 AI 影视创作者的生产级桌面工具

更新于2026-09-16|aivideo
|总字数:971|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 魔因漫创 (Moyin Creator)——一款面向 AI 影视创作者的生产级桌面工具。它支持从剧本到成片的全流程批量化创作，并集成了 Seedance 2.0 等多模态 AI 模型。

魔因漫创 的核心价值在于将影视制作流程自动化。它遵循 剧本 → 角色 → 场景 → 分镜 → 视频 的完整链路，每一步的产出会自动流入下一步，极大简化了短剧、动漫番剧等内容的批量生产流程。该应用基于 Electron 构建，是一款跨平台桌面工具。

整个部署流程对开发者非常友好，只需克隆代码、安装依赖并启动即可。

📥 安装与运行

方式一：下载打包程序 (推荐普通用户)

对于非开发者，项目提供了可直接运行的打包版本。

🎬 首次使用配置

启动应用后，您需要先进行基础配置才能开始创作。

  1. 配置 API Key：进入应用内的 设置 → API 配置 页面。
  2. 填入密钥：填入您所使用的 AI 图像/视频生成服务商的 API Key。应用支持多个供应商，并可以实现 API Key 轮询负载均衡。

🚀 核心工作流

配置好 API 后，您可以按照以下流程体验自动化创作：

  1. 📝 剧本：在“剧本”板块中，输入或导入您的剧本文本。剧本解析引擎会自动拆解出场景、分镜和角色。
  2. 🎭 角色：进入“角色”板块，系统会根据剧本自动识别角色。您可以为每个角色生成或上传参考图，并通过6层身份锚点系统确保其在不同分镜中的外观一致性。
  3. 🖼️ 场景：在“场景”板块中，系统会根据剧本描述生成场景视觉提示词，您可以选择生成场景参考图。
  4. 🎬 分镜：在“分镜”板块中，您可以看到剧本被拆解成的具体镜头。您可以调整每个镜头的电影级摄影参数（如景别、机位、运动方式），并一键生成分镜图。
  5. 🎞️ 视频 (S级板块)：这是集成了 Seedance 2.0 的核心板块。
    • 您可以将多个分镜组合，生成连贯的叙事视频。
    • 系统会自动收集角色参考图、场景图作为多模态引用 (@Image, @Video, @Audio)。
    • 智能提示词构建器会自动融合动作、镜头语言和对白唇形同步信息。
    • 系统会自动校验 Seedance 2.0 的参数限制（如图片≤9张，视频≤3个等）。

🛠️ 技术架构简介

  • 桌面框架：Electron 30
  • 前端框架：React 18 + TypeScript
  • 状态管理：Zustand
  • UI 组件：Radix UI + Tailwind CSS
  • AI 核心：@opencut/ai-core 包（负责提示词编译、角色管理和任务轮询）
