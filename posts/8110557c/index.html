Robin 由人工智能驱动的暗网开源情报（OSINT）调查工具

更新于2026-09-13|aitool
|总字数:1k|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 Robin——一个由人工智能驱动的暗网开源情报（OSINT）调查工具。它利用大语言模型（LLM）来优化查询、筛选暗网搜索引擎的结果并生成调查摘要。

⚠️ 重要法律声明

此工具仅供教育和合法调查使用。 访问或与暗网内容交互在您的司法管辖区内可能违法。使用前，请确保您遵守所有相关法律和机构政策。作者对任何滥用行为概不负责。此外，使用第三方LLM API时请注意数据敏感性和服务条款。

🐳 方式一：使用 Docker 部署（强烈推荐）

这是官方推荐的方式，能提供一个干净、隔离的运行环境，且易于管理。

  1. 前提条件：确保系统已安装并运行 Tor 服务。

  2. 准备环境变量：在项目目录下创建一个 .env 文件，用于存储API密钥。你可以参考项目中的 .env.example 文件。

  3. 拉取并运行 Docker 镜像：

    • 基础运行：

    • 持久化调查结果（推荐）：挂载一个本地目录以保存调查记录，防止容器重启后丢失。

      保存的调查会存放在你当前目录的 investigations/ 文件夹中，可以从侧边栏的“Past Investigations”面板加载。

  4. 访问应用：在浏览器中打开 http://localhost:8501 即可开始使用。

🐍 方式二：使用 Python 直接运行（开发版）

如果你需要修改代码或进行开发，可以使用这种方式。

  1. 前提条件：

    • 系统已安装 Python 3.10+ 和 Tor（安装方法同上）。

    • 安装项目依赖。

  2. 配置 API 密钥：与Docker方式相同，在项目根目录下创建 .env 文件并填入你的LLM API密钥。对于 Ollama，需将环境变量设置为 OLLAMA_BASE_URL=http://127.0.0.1:11434（可能需要将Ollama服务在 0.0.0.0 上监听）。对于任何其他OpenAI兼容的提供商（如LM Studio, Groq），可直接在Web界面的侧边栏中通过“Custom API Provider”填写配置，无需修改 .env 文件。

  3. 启动应用：

  4. 访问应用：在浏览器中打开 http://localhost:8501。

🔧 核心配置与使用

  • 选择LLM模型：在Web界面的侧边栏中，你可以选择使用 OpenAI、Claude、Gemini、Ollama 或其他任何与OpenAI API兼容的服务。对于Ollama等本地模型，需要确保其API地址能被Robin容器访问到（Docker方式使用 host.docker.internal）。
  • 进行暗网搜索：在搜索框中输入你的调查关键词（例如：一个用户名、电子邮件地址或特定事件）。Robin会：
    1. 调用LLM优化你的查询词。
    2. 通过Tor网络在暗网搜索引擎（如Ahmia）上进行搜索。
    3. 让LLM分析并筛选返回的结果。
    4. 生成一个结构化的调查摘要。
  • 后续操作：
    • 对话式追问：你可以基于当前调查结果提出后续问题，无需重新搜索。
    • 一键转向：界面会基于发现内容推荐相关的调查方向，点击即可启动新调查。
    • 导出报告：可以将调查结果保存为文件，用于报告或进一步分析。

🩺 健康检查

Robin提供了一个健康检查功能，可用于验证LLM API和搜索引擎连接是否正常。在Web UI的侧边栏中可以找到并运行此检查。

如果在部署或使用中遇到问题，可以查阅项目的 GitHub Issues 或参考 贡献指南。
