Claude Ads 部署教程：AI 驱动的广告运营技能包

Claude Ads 是一个专为 Claude Code 设计的技能包，它将 12 个主流广告平台（Google、Meta、YouTube、LinkedIn、TikTok、Microsoft、Apple、Amazon、Reddit、Pinterest、Snapchat、X）的运营工作流整合在一起。它能够基于授权导出的数据，执行来源可溯的审计、计划制定、创意生成、实验设计和报告产出。本教程将指导你在 Claude Code 中完成 Claude Ads 的安装与基本配置。

核心概念与设计哲学

  • 只读默认，安全第一：所有操作默认为只读。任何账户变更（如修改出价、预算）都需要经过多道明确的门禁（能力启用、ID 确认、差异预览、审批、幂等键、审计和回滚计划）才会生效，且不支持永久删除。
  • 来源可溯的审计：所有审计结论都基于证据，并带有明确的置信度。缺失数据或来源冲突会被明确报告，不会强行给出完整结论。
  • 版本化 JSON 结果：审计、计划、报告的核心产物是版本化的 JSON 文件。Markdown、HTML 或 PDF 格式的文档都是基于这个 JSON 渲染生成的，确保了数据的一致性和可追溯性。
  • 平台聚焦的技能：每个广告平台都对应一个独立的技能模块，包含审计逻辑、控制参考和能力声明。

准备工作：环境与前提条件

  • 核心依赖：Claude Code 是官方推荐的运行环境。你需要已安装并认证好 Claude Code。
  • Python 环境：部分核心逻辑（如评分、验证）使用 Python 编写，需要 CPython 3.11 或 3.12。安装脚本会自动处理依赖，但需确保系统有兼容的 Python 版本。
  • 外部依赖 (可选)：
    • Playwright：用于浏览器截图捕获功能，需另行安装浏览器 payload。
    • WeasyPrint & Pango：用于渲染 PDF 报告，需在系统层面安装这些库。

安装完成后，在 Claude Code 会话中（确保已启用该技能），你需要为特定的客户或账户创建配置文件。

    • 账户 (Account) 信息：具体的广告平台账户 ID。

第三步：核心工作流：审计、计划、创建

配置完成后，你可以开始使用核心功能。所有命令都遵循 /claude-ads:ads <命令> 的格式（也可以简化为 /ads，如果与其他技能无冲突）。

  2. 制定计划：
    基于审计结果或新目标，生成渠道、预算和实验计划。

  3. 生成创意资产：
    创建广告文案、图片或视频脚本的简要 (Brief)。

  4. 草拟变更 (只读)：
    在真正执行变更前，务必先以草稿形式预览。

    草稿会清晰地展示“变更前”和“变更后”的差异，供你审查。

第四步：账户安全与变更管理 (重要)

当需要实际应用变更时，Claude Ads 内置了严格的多阶段门禁机制。你无法通过一个简单的命令直接修改广告账户。

  1. 准备变更：使用 --draft 命令生成包含所有详细信息的变更计划文件。
  2. 提交审批：在 Claude Code 中指示应用该计划。系统会要求你确认：
    • 能力和操作是否被明确启用。
    • 账户和对象 ID 是否准确。
    • 差异 (diff) 和影响范围是否可接受。
    • 需要输入一个幂等键 (Idempotency Key) 以防止重复执行。
  3. 执行与验证：审批通过后，变更会执行，并记录审计日志。系统随后会验证远程账户状态是否与变更前提一致。

核心原则：永久删除不受支持。所有变更理论上都应有对应的回滚计划。

故障排查与常见问题

  • 命令无法识别 (Command not found)：
    • 确保已在 Claude Code 中正确安装了该插件。
    • 尝试使用完整命名空间 /claude-ads:ads 而不是简写 /ads。
  • Python 依赖错误：
    • 安装脚本通常会自动处理。如遇到问题，可以手动进入项目目录，激活虚拟环境 (.venv/bin/activate)，然后运行 pip install -r requirements.txt。
  • 审计运行不完整或报告缺失：
    • 检查网络连接，确保可以访问所需的广告平台 API 或导出的数据文件。
    • 查看终端输出，看是否有特定平台的错误信息。例如，缺少某个平台的 API 权限会导致该平台审计失败，但不会影响其他平台。
  • 账户变更没有生效：
    • 这是设计使然。检查你是否通过了所有必需的门禁步骤。变更请求会被系统性地审查，未达到所有安全标准（如缺少审批、缺失幂等键、无回滚计划）的操作不会被应用。请遵循“草稿 -> 审查 -> 批准 -> 应用”的完整流程。

总而言之，Claude Ads 是一个面向专业广告运营人员的 AI 辅助工具包。它最大的价值在于将专业知识、数据分析和安全操作流程集成到一个 AI 对话界面中。建议你从 /ads setup 开始，为一个测试账户运行 /ads audit，并通过 /ads launch --draft 熟悉其安全变更流程，然后再在实际生产环境中使用。始终牢记其只读默认和多门禁变更的核心安全原则。
