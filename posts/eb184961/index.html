LeePanel：免费开源的 Linux 服务器面板，下一代运维体验

更新于2026-08-22|webpanel
|总字数:1.6k|阅读时长:5分钟|浏览量:

LeePanel 是一款免费开源的下一代 Linux 服务器管理面板（桌面端软件），由 gna1280072 开发，发布于 2026 年 7 月。

官网：https://www.leepanel.com
GitHub：https://github.com/gna1280072/LeePanel

一、工具介绍

核心设计理念

传统 Web 面板（如宝塔、1Panel、aaPanel 等）需要在服务器上安装面板程序，并开放额外端口，面板本身经常成为安全漏洞的重灾区。

LeePanel 的解决思路非常彻底：

  • 服务器端零代码、零安装、零残留
  • 所有操作都通过本地电脑的 SSH 远程执行
  • 不在服务器上安装任何面板程序
  • 不开放额外端口（只使用你已有的 SSH 端口）
  • 关闭软件后服务器完全恢复原状

这从根本上消除了“面板自身被黑 = 整台服务器沦陷”的风险。

技术架构

层级 技术
桌面框架 Tauri 2.x
前端 React 19 + TypeScript
构建工具 Vite 8
终端 xterm.js 6
SSH/SFTP russh + russh-sftp（Rust）
本地存储 SQLite
国际化 中英双语

安装包体积极小（约 6MB 起），跨平台支持 Windows / macOS / Linux。

主要功能

连接与终端

  • SSH 密码 / 密钥认证（支持凭证本地存储）
  • 完整 xterm.js 终端（剪贴板、超链接、搜索）
  • 断线自动重连
  • 多服务器侧边栏快速切换 + 并发管理

文件管理

  • 远程文件浏览器（拖拽上传/下载）
  • 大文件分块上传 + 进度显示
  • 压缩/解压（zip、tar.gz）
  • 权限管理（chmod）、批量操作、收藏夹

LNMP 环境一键管理

  • 一键安装 Nginx、MySQL/MariaDB、PHP-FPM（支持版本选择）
  • 服务启停/重启/重载
  • PHP 多版本切换

站点管理

  • Nginx 虚拟主机创建与配置
  • Let’s Encrypt SSL 证书申请与管理
  • 反向代理（支持 WebSocket）
  • 防盗链、Rewrite 规则、站点级 PHP 切换

数据库管理

  • MySQL/MariaDB 数据库 CRUD
  • 用户权限管理
  • 备份/恢复（zip）、SQL 导入
  • Root 密码管理

Redis 管理

  • Key 浏览、CRUD、TTL 支持
  • 多数据库切换、清空、备份恢复

Docker 管理

  • 容器生命周期管理
  • 镜像拉取/删除/运行
  • 日志查看、镜像源配置
  • 一键安装 Docker

系统与网络

  • CPU/内存/磁盘/网络实时监控
  • 进程与端口查看（v1.0.21 新增）
  • 防火墙规则管理（ufw / firewalld / iptables）
  • BBR 一键开启
  • 系统信息仪表盘

其他

  • SSH 密钥生成与部署（RSA / Ed25519 / ECDSA）
  • 隧道内网穿透功能（v1.0.21 新增）
  • 明暗主题切换
  • 中英双语

当前服务器支持：主要针对 Ubuntu / Debian 测试通过，其他发行版持续适配中。

二、详细部署教程

LeePanel 是桌面客户端，部署非常简单，分为「下载安装」和「连接服务器」两步。服务器上不需要安装任何东西。

1. 系统要求

本地电脑（运行 LeePanel）

平台 版本要求
Windows 10 / 11（64 位）
macOS 12+（Intel 或 Apple Silicon）
Linux x64 / arm64（AppImage）

服务器端

  • 推荐：Ubuntu 20.04 / 22.04 / 24.04 或 Debian 11 / 12
  • 必须已开启 SSH 服务（默认 22 端口或自定义端口）
  • 建议使用 root 或具有 sudo 权限的用户

2. 下载与安装

  1. 前往 GitHub Releases 页面下载最新版本：
    https://github.com/gna1280072/LeePanel/releases

  2. 根据系统选择对应安装包：

    • Windows：.msi 或 .exe
    • macOS：.dmg（支持 Intel 与 Apple Silicon）
    • Linux：.AppImage、.deb 或 .rpm

  3. 安装方式：

    • Windows：双击安装包，按提示完成安装
    • macOS：打开 .dmg，将 LeePanel 拖入「应用程序」文件夹。首次打开可能需要在「系统设置 → 隐私与安全性」中允许
    • Linux（AppImage）：
    • Linux（deb）：

3. 首次使用与连接服务器

  1. 启动 LeePanel。
  2. 点击「添加服务器」或「新建连接」。
  3. 填写连接信息：
    • 主机地址（IP 或域名）
    • 端口（默认 22）
    • 用户名（推荐 root 或 sudo 用户）
    • 认证方式：
      • 密码认证：直接输入密码
      • 密钥认证：选择本地私钥文件（支持 RSA、Ed25519、ECDSA）
  4. 可选：勾选「保存凭证」（凭证加密存储在本地 SQLite）。
  5. 点击连接。连接成功后即可进入主界面。

支持同时管理多台服务器，侧边栏可快速切换，各会话互不影响。

4. 推荐使用流程（新手）

  1. 连接服务器 → 确认终端和文件管理正常。
  2. 系统监控 → 查看 CPU、内存、磁盘状态。
  3. 防火墙 → 根据需要放行端口（建议先开放 80、443、SSH 端口）。
  4. 一键安装 LNMP → 选择需要的 Nginx、MySQL、PHP 版本进行安装。
  5. 创建站点 → 添加域名、配置 PHP、申请 SSL 证书。
  6. 数据库 → 创建数据库和用户，导入数据。
  7. Docker（可选）→ 一键安装 Docker 并管理容器。

  • Node.js ≥ 18
  • Rust（稳定版）
  • Tauri 所需系统依赖（参考 Tauri 官方文档）

6. 常见问题与注意事项

  • 连接失败：检查服务器 SSH 是否正常、防火墙是否放行 SSH 端口、密钥权限是否正确（私钥建议 chmod 600）。
  • 功能不完整：目前主要适配 Ubuntu/Debian，其他系统部分功能可能异常。
  • 安全性：LeePanel 本身不在服务器留任何代码，安全风险极低。但仍需保护好本地电脑和 SSH 密钥。
  • 卸载：直接删除本地应用即可，服务器无任何残留。
  • 更新：关注 GitHub Releases，下载新版本覆盖安装即可。

总结

LeePanel 用「桌面端 + 纯 SSH」的架构，把传统面板最大的安全隐患彻底消除，同时提供了完整的 LNMP、站点、数据库、Docker、防火墙等管理能力，安装包仅约 6MB，非常适合追求安全与轻量的个人开发者或运维人员使用。

如果你已经习惯传统 Web 面板，强烈建议尝试一下这种「用完即走、零污染」的新方式。有问题可到 GitHub Discussions 反馈。
