WeChat Intelligence Hub 详细部署教程：本地优先的微信个人情报库

WeChat Intelligence Hub 是一个将本地微信聊天记录转化为可检索、可行动的个人情报的系统。它能自动生成日报、待办事项、承诺追踪、商机识别和联系人复联线索。本教程将带你完成部署，但必须首先明确其数据访问的安全边界与法律要求。

1. 项目定位、前提与法律声明

1.1 它能做什么？

  • 情报化检索：将微信聊天记录转化为可结构化查询的本地知识库。
  • 自动化报告：生成日报、周报，提炼待回复事项、承诺、商机。
  • AI 辅助行动：支持通过自然语言（如“查看今天最需要处理的10件事”）与情报库交互，获取回复建议。

1.2 核心前提与法律/道德红线（必读）

  1. 本地优先，数据归你：所有数据（包括聊天记录、联系人、Profile）均存储在你的本地设备上，不会上传到任何云端。
  2. 只读，不操作：系统设计为只读，不会发送消息、修改微信状态或操作微信界面。
  3. 数据访问与授权：系统不会自动破解或入侵你的微信数据库。要读取完整聊天历史，你需要本人授权并提供本地数据库的访问材料。项目本身不捆绑获取工具。在 macOS 上，初始安装后可能仅能读取系统通知预览（入站消息），这不代表完整聊天记录。
  4. 法律合规：你必须确保自己有权访问和分析所使用的微信数据（即，只能分析你自己的账号数据）。 严禁用于监控、窃取他人隐私等非法目的。运行任何涉及账号、支付或外部写入的动作前，需由你最终确认。
  5. 勿分享敏感数据：绝对不要将你的微信数据库、密钥、密码或生成的包含真实聊天内容的报告提交到 GitHub Issue、社群或发送给维护者。

重要提示：安装成功 ≠ 已经能读取聊天。 实际读取能力取决于你是否有权访问本地的微信数据库（通常需要密钥）。系统会在你明确授权和确认影响后，协助你准备必要工具，但不会自动进行破解。

2. 系统要求与准备

  • 操作系统：macOS（主要支持），Linux/Windows 可能有限支持（需查阅项目最新文档）。
  • 依赖：需要 git、Python 3、sqlcipher（用于加密数据库读取）。安装脚本会自动处理大部分依赖。
  • Codex（推荐）：项目设计为与 AI 编程代理 Codex 深度集成，通过自然语言驱动。纯命令行使用也支持，但体验更偏技术向。
  • 微信环境：你需要在本地已登录并同步了需要分析的聊天记录的微信客户端。

3. 安装步骤

方式一：通过 Codex 自动安装与配置（推荐）

这是项目官方推荐的方式，你只需在 Codex 中发送一条指令，代理会完成剩余工作：

  1. 在 Codex 中，发送以下指令（可复制并修改）：

    请从 https://github.com/Rion-Wu-tech/wechat-intelligence-hub 安装微信CLI和微信个人情报库，接入这台电脑上我自己的微信。
    先读取仓库说明，检查是否已经安装、当前配置是否可用；已有可用配置或key就复用，不覆盖我的个人Profile和数据。
    缺少依赖由你处理；确实缺key时，由你核验并准备固定版本工具，说明影响、经我确认后执行。我负责登录微信和完成系统授权，不会把密码或key发给你。
    完成数据库验证和配置后，告诉我能读取哪些范围、还有什么未就绪；再协助初始化个人情报库。遇到错误请定位并修复，不要把一堆命令交给我，也不要无限重试。

  2. 按照 Codex 的提示，完成必要的本地授权和确认工作。

4. 初始化和日常使用

4.1 初始化个人画像 (Profile)

让系统了解你的背景和优先级，以提高报告质量。在 projects/wechat-intelligence-hub 目录下运行：

  • 个人说明.md：可包含你的身份、业务、擅长领域等。
  • 本月计划.md：可包含近期目标、重点项目、截止时间。

4.2 日常交互（在 Codex 中）

安装并初始化后，直接用自然语言对话：

  • 生成日报：

    $wechat-intelligence-hub 生成过去 24 小时的完整微信情报日报，分析群聊、重点联系人、待回复事项和商业机会。

  • 查找联系人历史：

    $wechat-intelligence-hub 总结我和「联系人名字」最近聊到哪里，还有什么承诺没有完成。

  • 搜索特定话题：

    $wechat-intelligence-hub 搜索过去 7 天所有微信聊天里关于「AI 培训」的讨论。

  • 获取行动清单：

    $wechat-intelligence-hub 查看今天最需要我处理的 10 件事。

  • 生成回复草稿：

    $wechat-intelligence-hub 根据最新聊天上下文，帮我给「联系人名字」写一条符合我语气的回复草稿。

4.3 输出格式

完整报告默认生成两种版本：

  • wechat_daily_full.md：Markdown 总入口，适合阅读和进一步处理。
  • wechat_daily_report.html：交互式 HTML 报告，支持搜索、筛选、明暗主题切换。

5. 故障排查与注意事项

  • 权限与访问范围：如发现只能读取少量通知，说明尚未获取完整数据库访问权限。切勿使用非法手段。请按工作流提供授权材料或检查微信版本兼容性。

  • 依赖缺失：如果 sqlcipher 未安装，安装脚本会自动处理。在 Linux 上可能需要手动安装：sudo apt install sqlcipher。

  • 微信版本更新：微信升级可能导致读取器失效。届时可参考项目提供的排障提示词，或重新运行安装适配流程。

  • 配置文件位置：个性化配置文件通常位于用户目录下的 .config/wechat-intelligence-hub/ 或项目目录内，具体可查阅 docs/USAGE.md。
