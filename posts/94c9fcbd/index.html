Munder Difflin 有趣而强大的桌面应用：装机必备，省时省力

更新于2026-09-05|aitool
|总字数:1.1k|阅读时长:3分钟|浏览量:

这份详细的部署教程将指引您安装和使用 Munder Difflin——一个有趣而强大的桌面应用，它能将您已有的AI编程助手（如Claude Code、Codex、Grok等）变成一支可以自主协作的”代理办公室”。

它的核心创意是：将您电脑上安装的各类终端AI代理（claude、codex等）作为员工，在虚拟的办公室楼层上以像素头像呈现。一个名为”Michael”的GOD代理会像老板一样协调任务，而您则从旁监督和指导。所有代理共享记忆和消息系统，让它们能像一个团队一样工作。

🖥️ 系统要求与准备

在开始之前，请确保您的环境满足以下条件：

  • 操作系统：macOS (需安装 Xcode Command Line Tools)、Windows 或 Linux。

  • Node.js 18+ 和 npm。

  • C/C++ 编译工具链：用于编译 node-pty 原生模块。

  • 至少一个支持的AI代理：安装在您的 PATH 中，并已通过身份验证。支持列表包括：claude (默认)、agy (Antigravity)、codex、grok、kimi、gemini、qwen、opencode、crush、pi、copilot 或 cursor-agent。

    便捷提示：如果缺少某个代理，Munder Difflin 的界面中通常会提供”自修复”安装指引。

📦 安装与运行

步骤一：克隆与安装依赖

步骤二：启动应用

首次启动会进入欢迎向导，之后您会看到办公室主界面。点击 “Add agent” 即可创建您的第一个代理，Michael 会自动出现在办公室中。

其他常用命令

  • npm run build：生成生产环境构建文件。
  • npm run typecheck：进行 TypeScript 类型检查。

🎮 核心概念与界面

办公室楼层 (The Floor)

  • 这是主界面，使用 Pixi.js 渲染。每个代理都会以像素头像（基于《办公室》角色）的形式出现在楼层中。
  • 代理会”走”到工作站工作，完成任务后”走”回座位。它们之间传递消息时，会有”信封”飞行的动画。

Michael (GOD 代理)

  • 他是您的主要对话对象。您向 Michael 下达指令，他会负责任务路由、分配和决策。
  • “Talk” 按钮：您可以使用语音向 Michael 下达指令。

代理面板与终端

  • 点击任意代理头像，可以打开其详细面板。
  • 您可以看到该代理的实时终端输出（基于 xterm.js），也可以直接向它的终端输入命令。
  • 每个代理都有独立的工作目录、身份和生命周期。

命令中心 (Command Center)

  • 这是Michael的控制面板，包含多个标签页：
    • Terminal/Floor/Memory/Activity/Tasks/Triggers/Handbook：用于监控代理活动、管理记忆、查看任务看板、设置触发器等。
  • 内置 IDE：应用集成了 Monaco 编辑器，您可以直接在应用内浏览和编辑代理工作目录下的文件，并查看 Git 变更历史。

⚙️ 高级配置与管理

  • AI 引擎配置：在 Settings → AI Engines 中，您可以：
    • 为每个代理提供商配置自己的 API 密钥（密钥会安全存储）。
    • 配置本地 LLM 服务地址（如 Ollama、LM Studio）。
  • 记忆与知识库：
    • 语义记忆：代理可以将信息存储在一个语义索引中，实现跨会话即时回忆。
    • 企业知识图谱：您可以导入自己的文档，供所有代理查询。
  • 安全与控制：
    • 人工审批：对于高花费、破坏性操作等敏感任务，Michael 会请求您的批准。
    • 断路器：当代理陷入循环或超出预算时，系统可以自动干预。
    • 预算与遥测：可以为每个代理设置 token 预算，并查看实时成本。

📚 了解更多

  • 完整文档：项目根目录下的 HIVE.md、SPEC.md 和 DESIGN.md 详细描述了多代理设计、终端/事件平面和视觉系统。
  • 贡献指南：欢迎贡献代码或反馈。请阅读 CONTRIBUTING.md。所有 PR 必须包含修改前后对比截图或录屏。

总结：Munder Difflin 提供了一个可视化的”AI 办公室”，让您能以直观、有趣的方式管理和协调多个 AI 代理。
