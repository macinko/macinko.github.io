更新与卸载

自动更新

使用 npx、Bash 脚本、Smithery、Docker 或手动配置安装的版本支持自动更新：

  • 每次重启 Claude Desktop 时自动检查并更新到最新版本
  • 无需手动操作

卸载

自动卸载（推荐）

自动卸载会：

  • ✅ 从 Claude 配置中移除 Desktop Commander
  • ✅ 自动备份配置文件
  • ✅ 提供完整的包移除指导

手动卸载

  1. 打开 Claude Desktop 配置文件
  2. 删除 "desktop-commander" 条目
  3. 保存文件并重启 Claude Desktop

配置文件位置:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Linux: ~/.config/Claude/claude_desktop_config.json

常见问题排查

❌ Claude 无法启动

解决方案:

  1. 检查配置文件 JSON 语法是否正确
  2. 恢复备份配置文件（自动卸载会创建备份）
  3. 临时移除 desktop-commander 配置项

❌ Node.js 未找到

解决方案:

  1. 安装 Node.js 18+：访问 nodejs.org
  2. 或使用 Docker 安装方式（无需 Node.js）

❌ 命令执行失败

解决方案:

  1. 检查 blockedCommands 配置是否阻止了该命令
  2. 确认命令在终端中可正常执行
  3. 查看日志：~/.claude-server-commander/claude_tool_call.log

❌ Docker 安装后无文件访问权限

解决方案:

  1. 确认在 Docker 配置中正确挂载了文件夹（使用 -v 参数）
  2. 检查 Docker Desktop 是否正在运行
  3. 运行 --status 命令查看 Docker 状态
