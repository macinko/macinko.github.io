macUSB 是一款用于在 Mac 上创建启动 USB 的图形化工具

macUSB 详细部署教程

macUSB 是一款用于在 Mac 上创建启动 USB 的图形化工具，支持 macOS（包括较老的版本）、Windows 和 Linux。它的特点在于集成了 macOS 下载器，并针对 Apple Silicon 和 Intel Mac 做了兼容性处理，使创建启动盘的过程变得简单可靠。

本教程将指导您完成从安装到创建首个启动盘的全过程。

1. 准备工作

1.1 系统要求

  • 硬件：搭载 Apple Silicon 或 Intel 处理器的 Mac。
  • 操作系统：macOS 14.6 Sonoma 或更新版本。
  • 磁盘空间：
    • 下载 macOS 安装器：最多需要约 45 GB 可用空间。
    • 创建 macOS 启动盘：需要最多约 20 GB 可用空间。

1.2 准备 USB 驱动器

  • 容量：
    • macOS 安装器：至少 16 GB；对于 macOS Sequoia 及更新版本，建议 32 GB 或更大。
    • Windows/Linux 镜像：根据镜像大小，至少 1 GB。
  • 性能：推荐使用 USB 3.0 或更高速度 的驱动器以获得更好体验。
  • 重要警告：创建启动盘会擦除 USB 驱动器上的所有数据，请务必提前备份。

2. 安装 macUSB

您可以通过以下两种方式之一安装：

方式一：使用 Homebrew（推荐）

在终端中执行以下命令：

方式二：从 GitHub Releases 下载

  1. 访问项目的 Releases 页面。
  2. 下载最新版本的 .dmg 文件。
  3. 打开 .dmg 文件，将 macUSB.app 拖拽到 Applications 文件夹中。

3. 授予必要权限

为了确保 macUSB 能正常工作，您需要在 macOS 系统设置中授予它两项关键权限。缺少这些权限可能导致创建流程失败。

  1. 允许在后台运行：
    • 打开 系统设置 → 通用 → 登录项与扩展。
    • 在“允许在后台运行”列表中找到 macUSB 并确保其开关已开启。
  2. 完全磁盘访问权限：
    • 打开 系统设置 → 隐私与安全性 → 完全磁盘访问。
    • 点击锁图标进行更改，然后点击 + 号，从 Applications 文件夹中添加 macUSB.app 并确保其开关已开启。

4. 创建启动盘的基本步骤

4.1 选择源文件

启动 macUSB 后，您可以通过两种方式提供安装源：

  • 使用内置下载器：点击“Downloader”选项卡，浏览并下载 Apple 官方提供的 macOS 安装器（包括公开测试版）。
  • 使用本地文件：点击“Choose a local source”，选择您已下载的 macOS .app、.dmg、.cdr、.iso 文件，或 Windows/Linux 的 .iso 镜像文件。

4.2 选择目标 USB 驱动器

  1. 将您的 USB 驱动器插入 Mac。
  2. 在 macUSB 界面中，从目标磁盘列表中选择您的 USB 驱动器。
    • 注意：默认情况下，外部硬盘/SSD 是被禁用的，以防止误选。您可以在 Options → Enable external drives support 中手动启用。

4.3 检查并启动创建流程

  1. 仔细检查界面中显示的源文件、目标驱动器信息和操作步骤。
  2. 点击 Start 按钮。
  3. 监控进度条，macUSB 会分阶段显示创建过程的详细信息。
  4. 完成后，会显示结果摘要，指示您如何进行下一步（例如，将启动盘插入目标 Mac 并开机）。

5. 特殊场景与高级选项

5.1 为老旧 Mac（PowerPC）创建启动盘

macUSB 支持为 PowerPC Mac 创建启动盘，并提供了专门的 Open Firmware 引导指南。

  • 支持系统：Mac OS X Tiger (10.4) 和 Leopard (10.5)。
  • 注意事项：
    • Tiger 的 Multi-DVD 版本需要手动在 Options → Skip file analysis → Mac OS X Tiger 10.4 (Multi DVD) 中强制检测。
    • Leopard 仅需标准的单 DVD 镜像。
  • 兼容性：已在 iMac G5 上验证通过 USB 启动，但在部分机型（如 iBook G4）上可能无法引导。

5.2 创建 Windows 安装盘

  • 支持的版本：从 Windows Vista/Server 2008 R2 到 Windows 11/Server 2025。

  • 自动配置：对于 Windows 10/11，macUSB 可以选择创建 autounattend.xml 文件，用于跳过硬件检查、Microsoft 账户要求等 OOBE 设置。

  • 处理大文件：FAT32 格式有单文件 4GB 限制。如果镜像中的 install.wim 超过此限制，macUSB 会调用 wimlib 工具将其拆分为更小的 .swm 文件。您需要预先安装 wimlib：

    macUSB 会在需要时自动检测并使用它。

5.3 创建 Linux 安装盘

  • 支持广泛：已在 19 个主流发行版上测试，包括 Ubuntu、Fedora、Debian、Arch Linux 等。
  • 原始镜像写入：对于 .img 格式的 Linux 镜像，可以通过菜单栏的 Tools → Write Raw Linux Image (.img)… 进行写入。
  • 强制模式：如果镜像未被自动识别，可在 Options → Skip file analysis → Linux 中手动指定模式。

5.4 验证镜像完整性

macUSB 可以计算并显示所选镜像的 SHA-256 校验和，方便您核对下载文件的完整性。

6. 故障排查

  • 创建过程失败：
    • 首先检查是否已按照“授予必要权限”部分正确开启了“允许在后台运行”和“完全磁盘访问”权限。
    • 确保 USB 驱动器容量足够且没有硬件问题。
  • 目标磁盘显示为灰色无法选择：
    • 这是外部硬盘/SSD 默认被禁用以防误操作。请前往 Options 菜单中勾选 Enable external drives support。
  • Windows 创建提示缺少 wimlib：
    • 您的 Windows 镜像中 install.wim 文件大于 4GB，需要拆分。请按照前文指引使用 Homebrew 安装 wimlib。
  • 老旧 Mac 无法从 USB 启动：
    • 请查阅项目网站提供的 Open Firmware 引导指南。不同 Mac 型号的 Open Firmware 命令可能不同，且部分硬件（如早期 iBook G4）可能不支持 USB 启动。

总结

macUSB 显著简化了在 macOS 上创建多系统启动盘的流程，尤其是处理老旧 macOS 版本和现代 Apple Silicon 芯片的兼容性问题。其图形化界面和自动检测功能使得从下载到制作的过程直观且不易出错。

建议您首先通过 Homebrew 安装，并记得授予必要的系统权限。根据您需要创建的目标系统（macOS/Windows/Linux）和硬件（Intel/Apple Silicon/PowerPC），参考对应的章节进行操作。如果遇到问题，可以访问项目仓库的 Issues 页面 寻求帮助或报告问题。
