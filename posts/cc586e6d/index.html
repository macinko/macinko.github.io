Nanobrowser 详细部署教程：从零开始配置你的AI网页自动化助手

更新于2026-09-05|aitool
|总字数:1.7k|阅读时长:5分钟|浏览量:

Nanobrowser 是一款开源、免费的Chrome扩展，通过多智能体协作实现AI驱动的网页自动化。你可以使用自己的大语言模型API密钥，在本地浏览器中运行一个强大的AI网页代理，是OpenAI Operator的免费替代方案。

本教程将为你提供最全面、详细的部署指南，涵盖从安装到配置的每一个步骤。

📦 部署前准备

在开始之前，请确保你的环境满足以下要求：

  • 操作系统：Windows 10、macOS 10.12 或更新的Linux发行版。
  • 浏览器：Google Chrome 或 Microsoft Edge（正式支持，确保是最新版本）。其他基于Chromium的浏览器（如Opera、Arc）或Firefox、Safari不支持。
  • 网络：稳定的互联网连接，用于下载扩展和连接LLM API。
  • LLM API密钥：你需要至少一个受支持的大语言模型提供商的API密钥，例如OpenAI、Anthropic (Claude)、Google (Gemini)或Groq等。

🚀 三种安装方式：按需选择

Nanobrowser提供了三种安装途径，你可以根据自己的需求和技术背景选择最合适的一种。

安装方式 适用人群 优点 更新方式
Chrome应用商店安装 新手用户、追求稳定 一键安装，简单快捷，稳定可靠 自动更新（但可能稍有延迟）
手动加载最新版 想体验最新功能的用户 可获取最新特性，比商店版本更新 手动下载ZIP包替换并刷新扩展
从源码构建 开发者、需要深度定制 可以修改代码，使用开发模式热重载 git pull 拉取最新代码后重新构建

方案一：从Chrome应用商店安装（新手推荐）

这是最便捷的安装方式，适合大多数用户。

  1. 访问 Nanobrowser Chrome Web Store 页面（链接可在其GitHub主页找到）。
  2. 点击页面右上角的 “添加到Chrome” 按钮。
  3. 在弹出的确认对话框中，点击 “添加扩展”。
  4. 安装完成后，浏览器工具栏会出现Nanobrowser的图标（如未显示，点击工具栏右侧的“拼图”图标，找到Nanobrowser并固定）。

方案二：手动安装最新版本（尝鲜用户）

由于Chrome商店审核需要时间，手动安装可以让你更快体验到最新功能。

  1. 下载：访问 Nanobrowser的GitHub Release页面，下载最新版本的 nanobrowser.zip 文件。
  2. 解压：将下载的 nanobrowser.zip 文件解压到一个你容易找到的文件夹（例如 Documents/nanobrowser）。
  3. 加载扩展：
    • 打开Chrome/Edge浏览器，在地址栏输入 chrome://extensions/ 并回车。
    • 开启页面右上角的 “开发者模式” 开关。
    • 点击页面左上角的 “加载已解压的扩展程序” 按钮。
    • 在弹出的文件夹选择窗口中，选中你刚才解压出的 nanobrowser 文件夹，点击“选择文件夹”。
  4. 升级：未来需要升级时，只需重复步骤1下载新版ZIP，解压并覆盖旧文件夹，然后回到 chrome://extensions/ 页面，点击Nanobrowser扩展卡片上的 “刷新” 图标即可。

    • 安装 Node.js (v22.12.0 或更高版本)。
    • 安装 pnpm (v9.15.1 或更高版本)。

  3. 安装依赖：

  4. 构建扩展：

    构建完成后，扩展文件会生成在 dist 目录下。

  5. 加载扩展：按照 方案二 中的步骤3，在 chrome://extensions/ 页面加载 dist 文件夹。

  6. 开发模式：如果你需要边开发边调试，可以使用 pnpm dev 命令启动热重载模式。

⚙️ 核心配置：连接你的AI模型

安装完成后，你需要将Nanobrowser连接到你的LLM API，这是它能够工作的核心步骤。

  1. 打开侧边栏：点击浏览器工具栏中的 Nanobrowser图标。
  2. 进入设置：在打开的侧边栏中，点击右上角的 齿轮状“设置”图标。
  3. 添加API密钥：在设置页面的“LLM Providers”区域，选择你的LLM提供商（如OpenAI、Anthropic等），并填入对应的 API密钥。
    • 高级选项：你还可以为所有支持的提供商配置自定义 Base URL，这在需要使用代理或本地服务器（如LM Studio）时非常有用。

🤖 智能体模型分配策略

Nanobrowser采用多智能体架构，你可以为不同的“专家”智能体分配不同的模型，以平衡性能与成本。

  • Planner (规划器)：负责任务分解和策略制定。
    • 推荐模型：Claude Sonnet 4 (更好的推理能力) 或 GPT-4o 。
  • Navigator (导航器)：负责执行具体的网页点击、滚动、数据提取等操作。
    • 推荐模型：Claude Haiku 3.5 (在性能和成本间取得良好平衡) 或 Gemini 2.5 Flash、GPT-4o-mini (成本效益高)。

对于本地模型 (Ollama)：
如果你希望完全免费且保护隐私，可以使用Ollama等工具在本地运行模型。

  • 配置：在设置中添加Ollama作为提供者，Base URL通常是 http://localhost:11434。
  • 推荐模型：社区反馈表现较好的模型包括 Qwen3-30B-A3B-Instruct-2507, Falcon3 10B, Qwen 2.5 Coder 14B 和 Mistral Small 24B。
  • 提示词：使用本地模型时，指令需要更清晰、更具体。

🧪 验证安装：第一次任务

配置完成后，你可以通过一个简单任务来验证一切是否正常工作。

  1. 在Nanobrowser侧边栏输入框，输入一个任务指令，例如：

    “打开GitHub Trending页面，并提取前5个仓库的名称和简介。”

  2. 点击发送按钮。

  3. 观察AI智能体如何自动打开新标签页、浏览网页、提取信息并在侧边栏中向你汇报结果。

🔧 常见问题排查

问题 可能原因 解决方案
扩展无法加载 开发者模式未启用；文件路径不正确或损坏 确认 chrome://extensions/ 页面中“开发者模式”已开启；重新下载ZIP包并解压加载。
AI智能体无响应 API密钥无效或未正确配置；网络连接问题；模型地区不可用 检查API密钥，确认账户余额充足；检查网络；在设置中尝试更换其他模型。
任务执行失败或卡住 任务指令过于模糊；目标网站结构复杂或有反爬机制 尝试将复杂任务拆分为更清晰的步骤；检查设置中模型的“思考深度”参数。

至此，你已经成功完成了Nanobrowser的部署和基本配置。你可以开始探索它的强大功能，例如自动化新闻摘要、GitHub研究、购物比价等。如果遇到问题或想分享经验，可以加入他们的Discord社区。
