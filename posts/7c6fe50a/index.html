OPC Skills 是一套为独立开发者、一人公司设计的 AI Agent

更新于2026-09-05|aiagent
|总字数:1.2k|阅读时长:4分钟|浏览量:

OPC Skills 是一套为独立开发者、一人公司设计的 AI Agent 技能集，可扩展 Claude Code、Cursor、Codex 等 16+ 款 AI 编程工具，自动化完成 SEO 优化、需求调研、域名查询、Logo 生成等任务。本教程涵盖所有安装方式与配置细节。

一、安装前准备

1.1 系统要求

  • Node.js 环境（用于运行 npx 命令）
  • 已安装至少一种支持的 AI 编程工具（Claude Code、Cursor、Windsurf 等）
  • 网络能访问 GitHub 和 npm 仓库

1.2 检查工具兼容性

OPC Skills 通过 npx skills add 可安装到 16+ 款 AI 工具，包括：

工具 Agent 标识 安装路径（项目级）
Claude Code claude .claude/skills/
Cursor cursor .cursor/skills/

Codex codex .codex/skills/
Gemini CLI gemini-cli .gemini/skills/
Factory Droid droid .factory/skills/
Windsurf windsurf .windsurf/skills/

六、包含的技能清单

OPC Skills 包含以下 10 个技能：

技能名称 功能描述
seo-geo SEO 与 GEO 优化，适配 ChatGPT、Perplexity、Google 等 AI 搜索引擎
requesthunt 从 Reddit、X、GitHub 调研用户需求
domain-hunter 搜索域名、对比注册商价格、查找优惠码
logo-creator AI 生成 Logo，支持裁剪、去背景、导出 SVG

producthunt 搜索 Product Hunt 帖子、话题、用户和收藏
archive 归档会话学习和调试解决方案

七、常见问题

Q1：提示“No skills found”

确保仓库包含有效的 SKILL.md 文件，且文件中包含正确的 name 和 description 字段。

Q2：技能在 Agent 中没有加载

  • 检查技能是否安装到了 Agent 对应的正确路径
  • 确认 Agent 是否支持 Agent Skills 标准
  • 检查 SKILL.md 的 YAML 格式是否正确

Q3：权限不足无法安装

确保你对目标目录有写入权限。项目级安装需要项目目录的写入权限，全局安装可能需要管理员权限。
