OpenHuman 本地优先、注重记忆和编排的个人 AI 助理

更新于2026-09-05|aitool
|总字数:1.3k|阅读时长:4分钟|浏览量:

OpenHuman 的部署方式非常灵活，覆盖了从“一键安装”到“源码编译”的全场景。它的核心是一个本地优先、注重记忆和编排的个人 AI 助理。

下面为您梳理出三种主要的“部署”（即获取并使用）路径，您可以根据自己的技术背景和需求选择。

📋 部署方式速览

方式 适用人群 特点 操作复杂度
1. 直接安装 (推荐) 所有用户，特别是新手 UI 界面，几分钟可用，无需命令行或配置 ⭐ 极简
2. 云平台一键部署 希望快速拥有公网服务的用户 点击即用，自动配置云端环境 ⭐⭐ 简单
3. 从源码运行 开发者、贡献者 完全控制，可修改和调试代码 ⭐⭐⭐ 复杂

🚀 方式一：直接安装（最简单、最推荐）

这是官方为普通用户设计的开箱即用方式，让你在几分钟内就能拥有一个带图形界面的 OpenHuman。

  1. 下载安装包：
    • 访问官方网站 tinyhumans.ai/openhuman 或项目的 GitHub Releases 页面。
    • 根据你的操作系统（Windows, macOS, Linux）下载对应的安装包（如 .exe, .dmg, .deb, .AppImage 等）。
  2. 安装并运行：
    • 双击下载的安装包，按照系统提示完成安装（macOS 用户可能需要将应用拖入 Applications 文件夹）。
    • 首次启动时，按照界面引导完成初始设置（如创建账户、连接你的数据源等）。

☁️ 方式二：云平台一键部署（如 DigitalOcean App Platform）

如果你想快速拥有一个公网可访问的 OpenHuman 服务，可以利用官方提供的部署模板。

  1. 准备工作：确保你有一个 DigitalOcean 账号。
  2. 一键部署：在 OpenHuman 的 README.md 或 docs 目录中查找 “Deploy to DigitalOcean” 按钮（通常是一个徽章）。点击它会自动跳转到 DigitalOcean 的部署页面。
  3. 配置并部署：在 DigitalOcean 页面中，通常只需选择区域和资源规格，大部分配置已被模板预设。点击 “Deploy” 即可。部署完成后，你会获得一个公网访问链接。

注意：此方式的具体可用性和配置项，请务必参考项目官方文档中的最新说明，因为云平台集成可能会更新。

🛠️ 方式三：从源码运行（面向开发者）

如果你是开发者，希望基于最新代码进行开发或贡献，可以按照以下步骤从源码启动。

Node.js 24+ 项目使用 pnpm 管理，需确保 Node 版本符合要求。
pnpm 10.10.0 核心包管理器。可用 npm install -g pnpm 安装。
Rust 1.93.0+ (含 rustfmt, clippy) 用于构建核心后端组件。
CMake & Ninja 最新稳定版 构建一些原生依赖所需。
ripgrep 最新稳定版 用于代码搜索，开发时可能用到。

🔧 部署后的配置要点

无论用哪种方式部署，为了发挥 OpenHuman 的全部功能，建议完成以下配置：

  1. 连接数据源：在设置中授权访问你的 Gmail、Notion、GitHub、Slack 等账户，让“记忆树”构建你的个人知识库。
  2. 配置模型与工具：你可以使用 OpenHuman 的订阅服务（默认包含模型和工具），也可以在设置中 “Bring Your Own Key”，指向你自己的 OpenAI、Anthropic API 密钥，或配置一个完全本地的 Ollama 模型。
  3. 开启隐私模式：如果对数据隐私有极高要求，可以在设置中找到 “Privacy Mode” 开关。开启后，所有推理工作都将在你的本地机器上完成，数据不离开设备。
